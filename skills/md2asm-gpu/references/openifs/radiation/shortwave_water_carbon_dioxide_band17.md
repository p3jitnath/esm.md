# Shortwave Water And Carbon Dioxide Band 17 GPU Contract

The retained acceptance record qualifies this component within the numerical and interface limits below. Complete-forecast acceptance remains pending.

Revision 1 freezes the complete SRTM_TAUMOL17 numerical route before direct PTX emission. The scientific source is ../ecmwf-openifs/ifs-source/arpifs/phys_radi/srtm_taumol17.F90, with the accepted ordered contract in skills/md2asm/references/openifs/physics/srtm_taumol17.md. Optical depth has no unit, molecular columns use the original scaled 10^20 molecules/cm2, and solar flux uses W/m2.

The original vector has 26 address slots: TDIMV, first, last, H, FAC00, FAC01, FAC10, FAC11, JP, JT, JT1, mixture cap, water, carbon dioxide, total molecules, tropopause, SELFFAC, SELFFRAC, INDSELF, FORFAC, FORFRAC, INDFOR, solar, absorption, Rayleigh, and solar cosine. Set B=last-first+1 using signed 64-bit arithmetic before narrowing. Support first>=1, last<=2147483646, 0<=B<=4096, and 0<=H<=V<=512, where V is TDIMV's first 32-bit word. Layer arrays have B*V values, cap and cosine B FP64 words, tropopause B INTEGER4 words, solar 16*B FP64 words, and each optical output 16*B*V FP64 words. Integers align to four bytes and FP64 and metadata to eight. Preserve the complete 32-byte dimension record, all input owners, night outputs, points 13..16, and unused levels.

The 80-byte live table record contains ABSA 74880 bytes, ABSB 150400, SELFREFC 1280, FORREFC 512, SFLUXREFC 640, RAYL 8, LAYREFFR 4, STRRAT 8, NSPA 56, and NSPB 56, in that order. ABSA and ABSB use the actual yoesrta17.eq.1_ and yoesrta17.eq.0_ owners. The other band symbols use __yoesrta17_MOD_ and the two species owners use __yoesrtwn_MOD_. Band 17's species counts at byte four are 9 and 5. Twelve active points use the original 16-point storage. Live input tables retain their permitted variation.

RN means one FP64 rounding to nearest with ties to even, gradual underflow, and preserved signed zero. In both atmospheric branches compute C=RN(water+RN(STRRAT*carbon dioxide)), p=RN(water/C), and replace p with cap only when p>=cap. Lower mixture position uses x=RN(8*p), while upper uses x=RN(4*p). Set J=INT(x) with truncation towards zero and f=RN(x-FP64(J)). The original MOD(x,1) has these exact bits over the accepted interval, including signed zero. Preserve conversion IXC when x differs from its exact integer round trip. Lower pressure base1/species9/pitch585 and upper base13/species5/pitch1175 give i0=species*(5*(JP-base)+JT-1)+J and i1=species*(5*(JP-base+1)+JT1-1)+J. Form L by adding table[i0]*FAC00, table[i0+species]*FAC10, table[i1]*FAC01, and table[i1+species]*FAC11 from left to right. Form U at those same indices plus one. Then M=RN(C*RN(RN(RN(1-f)*L)+RN(f*U))). Preserve each table coefficient as the first product operand.

Each continuum interpolates F=RN(b0+RN(fraction*RN(b1-b0))). The lower branch forms Dself=RN(SELFFAC*Fself), Dforeign=RN(FORFAC*Fforeign), and gas=RN(M+RN(water*RN(Dself+Dforeign))). Self pitch is10 and foreign pitch4. The upper branch has the distinct order gas=RN(M+RN(RN(water*FORFAC)*Fforeign)). It does not read self payloads. Compute RN(total molecules*RAYL) once per active cell before its twelve-point loop. Each primitive rounds separately.

Complete the lower pass before the upper pass, each in increasing layer then column order. One shared upper solar-layer integer starts at H. A previous JP below LAYREFFR and current JP at or above LAYREFFR replaces it with the current one-based layer. Store absorption, conditionally interpolate solar=RN(s0+RN(f*RN(s1-s0))) from nodes J and J+1 when the current layer equals the shared selection, then store Rayleigh. Preserve the shared state and repeated stores. A forecast may consume only solar values defined by this source route.

Consumed factors and continuum fractions are finite with magnitude <=2^20, densities are nonnegative <=2^20, columns are finite nonnegative <=2^300, coefficients and solar values are finite nonnegative <=2^100, and STRRAT is positive <=2^16. C is normal, positive and finite in both branches, cap is strictly between zero and one, and resulting depths are finite and nonnegative. Solar cosine is finite in [-1,1], with positive values selecting daylight. Daylight tropopause is 1..H, lower JP 1..12, upper JP 13..58, JT/JT1 1..4, lower INDSELF 1..9 and INDFOR 1..3 in both branches. Physical conditioning is a caller precondition. Inactive values remain unread. All original allocations remain present for nonempty calls; present live table owners must avoid every mutable owner even when a branch does not consume them. Absent tables are allowed only when no selected branch consumes them.

Pure md2asm_gpu_srtm_taumol17_values(vector:u64,table_record:u64) returns u32 newly raised Arm flags, with no errno event or elementary counters. Every numerical primitive uses the qualified 16-byte full-status add/sub/mul/div ABI. Exact bounded integer conversions are explicit. FMA, reassociation, approximate operations, and reduced precision are forbidden. Complete callable md2asm_gpu_srtm_taumol17_fp64 and kernel md2asm_gpu_srtm_taumol17 use the original vector and common 64-byte context, the 80-byte table record, no scratch, one block of one thread, and zero dynamic shared memory. Prior error returns before vector reads. Complete admission checks all owners, metadata, indices, table species, and output/context disjointness before mutation. Refusal changes only context.error. Empty B or H returns after scalar geometry without numerical or output work.
