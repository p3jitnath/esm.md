# Complete Radiation Grid on the GPU

RADINTG prepares radiation for 2,048 columns and nineteen air layers, arranged in 256 blocks of eight columns. It calculates sunlight and boundary temperatures, packs atmospheric fields, prepares aerosol and gas profiles, calls the complete radiation model and stores fluxes and heating inputs. A radiative flux measures energy crossing an area each second, in watts per square metre. The original [CPU contract](../../../../md2asm/references/openifs/radiation/radiation_grid_driver.md) defines the 59 argument addresses, scientific controls and complete input owners.

Six GPU phases run in source order, with a complete wait between phases. The Arm host manages storage, public text/statistics calls and CUDA launches. Every OpenIFS numerical calculation in this component runs on the GPU. The selected physical model retains modern radiation, twelve MACC aerosol species and prescribed gas profiles. The eight columns in each block share an equal latitude sine. Unused inputs retain their original meaning and complete observed bytes.

The application binary interface (ABI) uses the original 59-address vector, one block of one thread and no dynamic shared memory. Its entry-specific 64-byte phase context uses byte 8 for new status flags, byte 16 for the last mathematical error, byte 24 for progress from zero to six, bytes 32/40 for private storage and bytes 48/56 for a 160-byte record. The record contains ten pointer/capacity pairs for FIELD metadata, RADACT metadata, greenhouse data, a correction constant, surface data, original counters and four integer controls. Private storage needs 25,471,520 bytes. Bounds, alignment, descriptor shapes and writable separation are checked before each consumed stage. Complete buffers include inactive cells.

All calculations use 64-bit floating-point (FP64) numbers, with separately rounded operations, preserved signed zeros and gradual underflow. The CPU and GPU checks use the same production logarithm. Previously accepted child functions and constants are unchanged. The host preserves the required saved registers, x18, floating-point controls, incoming status and the system error indicator. It accepts serial callers. Shared GPU functions and the two required FIELD storage aliases are linked once.

Three complete cases match 20,296,368 output bytes and 19,245,936 readonly bytes, with exact immediate status, ABI and all 141 counter relations. Independent physical checks cover 1,898,496 relations. Thirty-seven critical controls, a complete six-phase ordinary-device graph with 540 pointer relocations, native instructions and independent source reviews pass. These checks qualify one original routine. Full GPU forecast acceptance and timing remain separate unfinished work. Detailed commands, source versions, raw results and error records remain local.
