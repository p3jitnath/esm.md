# Complete Radiation Grid on the GPU

RADINTG prepares radiation for 2,048 columns and nineteen air layers, arranged in 256 blocks of eight columns. It calculates the Sun’s radiation and boundary temperatures, packs atmospheric fields, prepares aerosol and gas profiles, calls the complete radiation model and stores fluxes and heating inputs. A radiative flux measures energy crossing an area each second, in watts per square metre. The original [CPU contract](../../../../md2asm/references/openifs/radiation/radiation_grid_driver.md) defines the 59 argument addresses, scientific controls and complete input owners.
