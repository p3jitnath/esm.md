# Complete Radiation Grid on the GPU

RADINTG prepares radiation for 2,048 columns and nineteen air layers, arranged in 256 blocks of eight columns. It calculates the Sun’s radiation and boundary temperatures, packs atmospheric fields, prepares aerosol and gas profiles, calls the complete radiation model and stores fluxes and heating inputs. A radiative flux measures energy crossing an area each second, in watts per square metre. The original [CPU contract](../../../../md2asm/references/openifs/radiation/radiation_grid_driver.md) defines the 59 argument addresses, scientific controls and complete input owners.

Six GPU phases run in source order, with a complete wait between phases. Phase four now uses preparation, parallel work and an ordered join as three separate launches. The Arm host manages storage, public text/statistics calls and CUDA launches. Every OpenIFS numerical calculation in this component runs on the GPU. The selected physical model retains modern radiation, twelve MACC aerosol species and prescribed gas profiles. The eight columns in each block share an equal latitude sine. Unused inputs retain their original meaning and complete observed bytes.

The application binary interface (ABI) defines how functions pass arguments and preserve registers. It uses the original 59-address vector and no dynamic shared memory. The five unchanged phases, phase-four preparation and the final join each use one block of one thread. The phase-four workers use 128 blocks of one thread. Its entry-specific 64-byte phase context uses byte 8 for new status flags, byte 16 for the last mathematical error, byte 24 for progress from zero to six, with the temporary value 260 after phase-four preparation, bytes 32/40 for private storage and bytes 48/56 for a 160-byte record. The record contains ten pointer/capacity pairs for FIELD metadata, RADACT metadata, greenhouse data, a correction constant, surface data, original counters and four integer controls. Private storage needs 449,838,528 bytes. It contains the original 25,471,520-byte owner, 127 private 3,341,408-byte worker areas and an 8,192-byte result table. Bounds, alignment, descriptor shapes and writable separation are checked before each consumed stage. Complete buffers include inactive cells.

Each worker evaluates two original eight-column blocks in their original local order. It has separate child arguments, status and work buffers. Worker 127 uses the original child area and finishes block 255, so the final private state retains its original owner. The child functions keep every original calculation and coefficient, while their private entry checks use the worker’s logical identity. No numerical work moves to the Arm host.

Each of the 256 result-table rows has 32 bytes. A worker writes its numerical flags, ordered error event and ratio before publishing its completion marker. The join requires all markers before it changes shared status or progress. It combines flags and counters by their original rules and commits the ratio from the last original block. Separate launches provide the required order between preparation, work and the join.

All calculations use 64-bit floating-point (FP64) numbers, with separately rounded operations, preserved signed zeros and gradual underflow. The CPU and GPU checks use the same production logarithm. Previously accepted child functions and constants are unchanged. The host preserves the required saved registers, x18, floating-point controls, incoming status and the system error indicator. It accepts serial callers. Shared GPU functions and the two required FIELD storage aliases are linked once.

Three complete cases match 20,296,368 output bytes and 19,245,936 readonly bytes, with exact immediate status, ABI and all 141 counter relations. Independent physical checks cover 1,898,496 relations. Thirty-seven critical controls, a complete six-phase ordinary-device graph with 540 pointer relocations, native instructions and independent source reviews pass. These retained checks qualify one original routine. The parallel phase additionally matches all 15,286,272 packed bytes, eight ratio bytes, immediate flags, the ordered error event and 45 counter relations. All 256 markers, ten changed admission and completion controls, native instruction checks and two independent source reviews pass. The unchanged child physics checks remain applicable. These changes add no new original routine. Full GPU forecast acceptance and matched timing remain separate unfinished work. Detailed commands, source versions, raw results and error records remain local.
