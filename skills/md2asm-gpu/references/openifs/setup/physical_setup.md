# Physical setup on the GPU

These sources retain the selected assembly calculations that initialise atmospheric, cloud, surface and radiation parameters. FP64 means the 64-bit floating-point format. The 43 complete source objects include their private helpers, loading, validation, allocation, release and error paths. Their original physical constants, units, supported shapes and field order remain unchanged. The public source is grouped by physical theme under `src/openifs/setup/gpu/`, `radiation/gpu/`, `physics/gpu/`, `dynamics/gpu/` and `support/gpu/`.

The application binary interface (ABI) defines arguments, return values and preserved registers. Each source keeps its original ABI, stack frame and storage lifetime. A pointer still addresses the original complete array or record; descriptor bounds, alignment, aliases and untouched cells retain their original rules. No recorded input supplies a production result. The shared [preserved-state header](../../../../../src/openifs/support/gpu/preserved_scalar_calls.inc.S) temporarily saves all 31 general registers, all 32 complete 128-bit vector registers, the link register and condition flags in an additional 1024-byte frame aligned to 16 bytes. After one GPU calculation, it restores this state before installing only the original destination or comparison flags. W-register results keep the original 32-bit write and zero extension.

Every ordinary addition, subtraction, multiplication, division and square root keeps its separate source rounding point. The floating-point control register, FPCR, must be zero: rounding is nearest with ties to even, underflow is gradual and signed zero is preserved. Fused arithmetic, approximate instructions and reassociation are excluded. The floating-point status register, FPSR, retains incoming flags and adds the original instruction's flags; errno retains the original mathematical error event. Conversion rules are in [source-number conversions](../support/source_number_conversions.md). Mathematical services retain their existing input bounds and error limits. In particular, the positive LOG input must be finite and at least 2 raised to −52; the general original-rounding POWER interface keeps its original special-value handling and its original declared accuracy criterion. A unit in the last place is the spacing between adjacent values near a result. Private POWER children keep their source-derived bounds.

The parents reuse the qualified water, lake and startup scalar entries, the physical-setup conversion extension and the actual GPU LOG route. POWER also requires its separately qualified seven private integer services and their exact product-sum child; the retired CPU integer implementation is excluded. Each shared host, device entry, coefficient owner and diagnostic-counter owner is linked once. Read-only coefficient tables supply constants, while the GPU performs the numerical calculation. The pressure remainder retains PPFLEV, PPSTA, PPINTP and PPT; the separately qualified PPINIT route is described in [pressure-coordinate contract](../physics/pressure_coordinates.md).

Accepted component evidence includes a complete initialisation with 27,197,300 source-defined numerical bytes and 2,748,656 bytes in three canonical fields, all exact. Both final status records also match, including FPSR 16 and FPSR 24 with errno 34. Process-specific addresses are checked through their typed owners; source-unwritten storage is identified separately and raw captures are retained. Further complete-owner checks cover three loop-data cases, 14 CPU/GPU pressure-helper pairs with 498,026 bytes and 9,040 independent relations per implementation, and the live grid-norm result and status. The existing independent physical proofs remain applicable to unchanged equations and exact outputs. Whole-source inverses, actual selected providers, native instruction audits and independent source reviews pass. The compact macro forms reproduce the complete accepted binary objects. These are component checks; this document reports no complete-forecast acceptance, routine credit or timing result.
