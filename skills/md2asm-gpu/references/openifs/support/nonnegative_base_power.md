# Nonnegative-Base Power on the GPU

This pure device function preserves the [original-rounding power calculation](../../../../md2asm/references/openifs/support/power_original_rounding.md) for every finite positive FP64 base, either signed zero base and every finite signed FP64 exponent. FP64 is the 64-bit floating-point format. Negative nonzero bases and nonfinite operands are outside this caller domain. The physical caller supplies units compatible with a real power. The original logarithm, exponential, coefficient words and ordered exact product-and-sum boundaries remain unchanged.

The [PTX source](../../../../../src/openifs/support/gpu/nonnegative_base_power.ptx) defines `md2asm_gpu_power_nonnegative`. It takes two 64-bit operand words and returns one eight-byte-aligned 32-byte aggregate: the result at byte 0, new Arm-equivalent flags at 8, an actual error-write event at 12 and unsigned 64-bit FAST/WIDE increments at 16 and 24. A zero event preserves `errno`, the C library error indicator; events 33 and 34 request the original writes even when the incoming value already matches. Callers join flags and error events in original source order and retain unsigned counter wrap.

The flags model the original FPCR-zero route: nearest-even arithmetic, gradual underflow and preserved signed zeros, with the original invalid, divide-by-zero, overflow, underflow and inexact events. FPCR is the Arm floating-point control register. The `S(a,b,c)` mathematical boundary rounds one exact product plus addend; other operations retain their separate rounding points. The [shared mathematical contract](../mathematical_support.md) and [finite device functions](../finite_mathematical_functions.md) define the reused support interfaces.

The function owns no model buffers. Its parent admits complete inputs, supplies immutable coefficient owners where required, and merges the returned status and counters. Either signed zero exponent returns exact positive one. Zero-base signs, odd-integer parity, negative-exponent poles and the original range-error paths remain those of the linked power contract. The source retains its GNU LGPL-2.1-or-later copyright and licence notice.

Existing component evidence covers 4,998 retained finite cases, 592 endpoint cases, 1,776 seeded status/error/counter observations and 178,880 compared return bytes with zero differences. Independent real-power checks cover 698 new cases at 120 and 240 decimal digits; prior accepted logarithm/exponential evidence is reused. These records qualify this mathematical component. No new forecast or performance acceptance follows from publishing its source.
