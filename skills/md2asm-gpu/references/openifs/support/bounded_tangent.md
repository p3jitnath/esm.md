# Bounded original-compatible tangent on the GPU

The pure function md2asm_gpu_tan_bounded accepts a finite FP64 angle in radians with magnitude at most the rounded pi word 400921fb54442d18. It preserves the original bounded GNU libc 2.38 algorithm, all 21 constants and 744 table words, small and table branches, reduced tangent and cotangent, signs and every intermediate rounding. The algorithm and data derive from the IBM Accurate Math Library, copyright 2001–2023 Free Software Foundation, under LGPL-2.1-or-later.

One raw input word returns a 32-byte record: result at 0, new Arm-equivalent flags at 8, zero errno event at 12, and actual FAST/WIDE exact-product-sum counts at 16/24. There are no caller buffers or mutable global values. Ordinary FP64 operations use qualified status helpers. The exact product-plus-sum helper is confined to the original mathematical algorithm. Preserve nearest-even rounding, gradual underflow and signed zeros. Table-index conversion retains inexact when it discards a fractional part. Its caller admits the bounded finite domain.

All 41,106 retained original result and status words and observed selected CPU helper counts match complete GPU records with zero differing bytes. Independent 180-digit tangent, projection and oddness checks are reused for those same words. Seeded status, exact counters, nine refusal controls and fourteen ordinary-device graph cases pass. The complete source peer, original table identity and native instruction audit pass. Sampled error remains within the original one-ulp limit, where an ulp is the spacing between adjacent FP64 numbers; this is not a uniform proof for every bounded input. This support helper adds zero original weather-routine credit.
