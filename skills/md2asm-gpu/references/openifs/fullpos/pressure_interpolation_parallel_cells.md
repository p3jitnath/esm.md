# Parallel pressure interpolation cells

PPINTP interpolates a field to requested pressure levels. The [shared pressure host](../../../../../src/openifs/physics/gpu/pressure_coordinate_shared_remainder.S) keeps its original public arguments, model guards, profiling calls and source stack. The new [PTX source](../../../../../src/openifs/fullpos/gpu/pressure_interpolation_parallel_cells.ptx) distributes independent level-and-column cells across 128 GPU threads. Each cell keeps the original two subtractions, two multiplications and one addition, including every rounding point and status return. FP64 means the 64-bit floating-point format. No reduction changes the arithmetic order.

The entry md2asm_gpu_pressure_interpolation_parallel_cells takes two unsigned 64-bit addresses: the original argument vector and a mapped 64-byte context. It requires one block of 128 threads, with all other launch dimensions equal to one and no dynamic shared memory. The vector holds addresses for the 832-byte source register state, 160-byte environment and 16-byte completion. The context points to the original 64-byte capacity table. Every owner retains its original alignment, capacity, nonwrapping range and private-owner separation checks. The host reserves the unchanged 16,384-byte transport frame; its 14,336-byte private gap precedes the original 4,096-byte source frame. Original argument pointers remain at source SP plus 256 bytes. SP is the source stack pointer.

Supported public shapes retain 24 stored columns, 8 or 24 active columns, and 4 or 19 requested levels. Each thread visits complete cells in source order with a stride of 128 cells. The fast route requires the complete output owner to be disjoint from all seven consumed input owners. Readonly inputs may alias each other. A source-valid output/input alias selects the unchanged serial GPU function, preserving the original full-loop dependencies. Private-owner admission failures retain the original rejection contract.

The callable md2asm_pressure_interpolation_parallel_values takes the original state and environment addresses and returns the unchanged 16-byte status record at 8-byte alignment. All threads reach the admission and completion barriers. Their floating-point flags join with integer OR. The greatest source cell selects the final loop-address registers; the greatest evaluated cell selects X25 and the low halves of Q0 through Q3. Q registers are 128-bit vector registers. The upper halves retain the original scalar-write zeroing. If no cell is evaluated, incoming X25 and all Q0 through Q3 words remain unchanged. The final loop indices and NZCV condition bits match the source exit. All other state words, FPCR, errno and actual counters retain their original values. FPCR controls Arm floating-point behaviour; errno records a library error.

Link this new object once beside the original pressure-field entry and value objects, the shared output-norm values, IEEE operator status and scalar arithmetic support listed in the [complete provider contract](complete_pressure_output_provider.md). The old serial function remains linked once for supported aliases. No CPU numerical routine supplies a missing stage.

Qualification compares four genuine saved packets at two protected placements, then seven complete source-state pairs against the accepted serial GPU route. These pairs include no evaluated cell, skipped terminal cells, nonfinite values, readonly aliases and an output alias. Four new prewrite controls preserve complete owner images. All 912,636 compared owner bytes agree exactly, with immediate status, ABI, x18, counter and guard checks. ABI means the register and buffer rules at a function boundary. Existing independent primitive and physical checks are reused; no original CPU, Fortran or physical calculation is recaptured. Both numerical processes completed within their 14.13-second limits and were cleaned up. Full-forecast acceptance and comparative timing remain separate.
