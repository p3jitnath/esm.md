# Pressure interpolation coordinates on the GPU

This source implements complete selected PPINIT from arpifs/pp_obs/ppinit.F90. It forms half/full pressure coordinates, their natural logarithms (logarithms with base e) and reciprocal differences between levels. Pressure uses pascals; logarithmic coordinates are dimensionless. The selected branch has 24 backing columns, either 24 or eight active columns, 19 levels and four coordinate methods. The [pressure-wind formulation](../../../../../formulations/openifs/physics/pressure_level_wind_interpolation.md) and [CPU contract](../../../../md2asm/references/openifs/physics/pressure_level_wind_interpolation.md) retain the mathematical source.

The application binary interface (ABI), which defines arguments and preserved machine state, retains nine addresses. Arrays use aligned 64-bit floating-point (FP64), with column first, level zero through 19 next and method last. For every cell the source copies both pressures, calls LOG on half pressure and then full pressure, writes exact top constants, and later forms each separately rounded difference and reciprocal. Untouched last-level reciprocal words and inactive columns retain their bits.

One thread runs the complete numerical stage with zero shared bytes, an 80-byte capacity record and no scratch. All consumed logarithm inputs are positive finite; half-level-zero pressure is finite and nonnegative. Bounds and complete output/context separation precede writes. The unchanged positive-finite LOG child matches the actual non-fused production public LOG service and adds no actual mathematical counter event. The Arm shell retains storage, original profiling, ABI and status only. No fused operation, reassociation or approximate arithmetic is used.

Qualification passes 48 protected GPU and 48 selected CPU calls, compared with 24 original Fortran placements, across 1,474,560 output bytes. There are 44,896 independent coordinate, reciprocal and preserved-cell relations; 2,711 actual LOG inputs pass 120/240-digit checks. Thirty-two controls, one ordinary-device graph, exact 756-byte provider, native audit and independent reviews pass. Only the replaced PPINIT definition is removed from its shared original-temperature member; sibling instructions and calls stay literal. No full GPU forecast or timing claim is made.
