# Surface Temperature Extrapolation on the GPU

CTSTAR estimates surface temperature from the model temperature, pressure and terrain. Temperature is in kelvin, pressure in pascals, and terrain is gravitational potential in square metres per square second. Revision 1 retains the original lapse coefficient, ordered pressure ratio, temperature correction and terrain term. It supports 1 through 24 allocated rows and the original full, partial or empty interval. Consumed fields are finite, pressures are positive, and complete output owners are separate from inputs.

The application binary interface (ABI) retains nine original address arguments, the 256-byte frame, hooks, physical constants and original integer guards. Ten floating-point sites use the unchanged qualified scalar GPU route. Each 256-byte temporary call frame preserves source-live registers, including d16 through d31, and restores them before installing the result. The host performs storage, transport and control. Every numerical operation runs on the GPU with separate nearest-even FP64 rounding, signed zeros and gradual underflow. FP64 is the 64-bit real format.

Twelve protected original Fortran, selected Arm and GPU calls agree over 3360 output bytes and 6864 read-only bytes. Independent 110-digit checks cover 492 lapse-temperature and hydrostatic relations. Immediate status, actual counters, five prewrite controls, complete source/provider bindings, native instructions and both independent source reviews pass. Existing scalar boundary and device-graph evidence is reused because its code is unchanged. Complete forecast and performance acceptance remain separate.
