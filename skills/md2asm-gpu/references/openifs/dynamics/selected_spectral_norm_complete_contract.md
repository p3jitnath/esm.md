# Complete Selected Spectral Norms on the GPU

A spectral coefficient gives the weight of one spatial wave in a model field. This phase calculates the selected wave and level norms for vorticity, divergence, kinetic energy, temperature and surface pressure. A norm measures the size of a field. The [accepted CPU contract](../../../../md2asm/references/openifs/dynamics/selected_spectral_norms.md) fixes the physical meanings, field units, live descriptors and supported selected branches. This GPU phase keeps those calculations and their separate FP64 rounding points. FP64 means a 64-bit floating-point number.

## Original Interface and Arithmetic

The original entry remains `int md2asm_compute_selected_spectral_norms(Geometry,GCONF,TDYNA,SPECTRAL,controls,persistent,results)`. Its Arm application binary interface, or ABI, uses x0 through x6 and returns zero for success or two for a refused input. The outer records contain 17,096, 1,556,112, 456 and 2,992 bytes; the six 32-bit controls occupy 24 bytes. Persistent state has 24 bytes and the complete result has 20,928 bytes. The selected grid has 19 levels, 506 coefficients and 22 wave numbers. Keep the original host guards before runtime preparation or model mutation.

The four value functions keep this order:

1. Calculate 2,112 matrix cells. Each cell visits degrees from its wave number through 21 in ascending order. Square the real coefficient, then the imaginary coefficient when the wave number is positive, and add those squares. Apply the original kinetic metric when selected, double the metric first for a positive wave number, then multiply and add to the running sum. The original inverse-Laplacian array RLAPIN has 200 bytes with bounds minus one through 23; for degree n, its byte offset is `8*(n+1)`.
2. Combine 418 kinetic-energy cells. Add the vorticity contribution at result byte 6,688 to the divergence contribution at 10,032, then multiply the rounded sum by one half.
3. Calculate 77 level values. Add the 22 wave values in ascending order, then take the square root except for kinetic energy.
4. Calculate five means in field order. Add levels in ascending order and divide by the exact source count, 19 or 1. Immediately after the divergence mean, copy that same word to persistent byte zero. Persistent bytes 8 through 23 and every result gap retain their incoming contents.

Each matrix cell keeps the original positive floor word `0x0079000000000000`. Its final addition quiets any not-a-number value. The floor therefore selects the sum only when it is greater than the floor; a quiet not-a-number selects the floor without a new flag. All earlier arithmetic flags remain. The qualified add, multiply, divide and square-root children retain every source rounding point, signed zero and gradual underflow. No expression is reassociated or fused.

## Ownership and Transport

One GPU block has 256 threads and no dynamic shared memory. Threads own disjoint matrix, energy and level cells. Each cell keeps its own serial sum. Four collective barriers wait for admission and the three parallel stages. Every admitted thread reaches each barrier, including threads without a level result. The leader then joins all thread flags and calculates the ordered means. The original numerical inputs stay live and read-only until the synchronous call returns. There is no heap allocation.

The private host call takes Geometry, SPECTRAL, persistent and results. Its two-address launch vector points to a 32-byte input record and a 16-byte completion record. The common context has 64 bytes and points to 128 capacity bytes. Admission checks 16 complete owners: those five transport records, the four private arguments, two 88-byte index maps, the 200-byte RLAPIN array, three 76,912-byte coefficient arrays and one 4,048-byte surface-pressure array. Numerical spans need eight-byte alignment; the two integer maps need four-byte alignment. All spans are mapped and nonwrapping. Writable context, completion, persistent and results must not overlap any other owner. Read-only metadata may share storage. Descriptor, map, capacity and launch-shape refusal occurs before numerical writes and changes only the context error word.

The original parent keeps its 512-byte frame, and the private transport has a 2,048-byte aligned frame. It preserves x18, saved integer and vector registers, errno and FPCR, the Arm floating-point control register. FPCR must be zero for nearest-even rounding and gradual underflow. Newly raised flags join incoming FPSR, the floating-point status register, by integer OR. The phase has no FAST, WIDE or exponential counter event and preserves the complete 64-bit error-event word. Its four pure value functions have no hardware lane identifiers, barriers or counter writes; they return a 16-byte record aligned to eight bytes, with flags at zero and three zero words after them.
