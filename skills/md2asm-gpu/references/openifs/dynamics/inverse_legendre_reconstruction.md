# Complete inverse Legendre reconstruction halves

The [physical formulation](../../../../../formulations/openifs/dynamics/inverse_legendre_reconstruction.md) gives the model meaning.

An owner is a complete allocated buffer. A stride gives the distance between neighbouring stored values. FP64 is the 64-bit floating-point format. The application binary interface, or ABI, fixes argument registers and the registers that a call must preserve. The [GPU calling rules](../gpu_call_context.md) define the shared context and status fields.

This GPU implementation moves the complete private reconstruction child of the selected LEINV assembly into one GPU call for each original half. The parent keeps its ten address arguments, integer guards, GNU descriptors, original table owners, order-zero imaginary positive-zero stores and all six source stage-counter positions. It calls the antisymmetric half before the symmetric half. Each child computes the entire selected matrix, replacing its per-product and per-addition host crossings. The frozen numerical method is arithmetic revision 2, with coverage revision 3 of the original inverse Legendre contract; no method or domain changes.

A Legendre transform changes a spherical wave field into its latitude values. For each selected field and northern latitude, initialise a sum to positive zero. In ascending degree-storage order, multiply the original basis word by the original spectral word, round that product, then add it to the sum with a separate rounding. Store the completed sum in the original output cell. Fields and latitudes are independent, but degree terms in a sum remain serial. Basis values are dimensionless, so input and output fields have the same units. No time update occurs.

One GPU thread owns one complete (field, latitude) sum. A block has 128 threads, and the one-dimensional grid covers every selected field and all 16 northern latitudes. Fields use stride two when zonal order is zero and stride one otherwise. Every selected output cell has one writer. Complete output owners are disjoint from both read-only input owners; basis and spectral owners may alias one another. The original parent already proves complete output separation from all other consumed read-only owners and descriptors. Preserve padded rows, inactive field words, metadata and unused owner bytes.

The supported parent has truncation 21, order 0 through 21, 16 northern latitudes, and complete field widths 2,4,38,76,194 or232. The selected field count equals width divided by the source column stride. A half has 1 through 12 degree terms and its first input row is one or two. GNU matrices retain eight-byte elements, first stride one, second stride equal to first extent and signed lower bounds. Complete extents remain bounded by 1000 in each dimension. Empty calls stay in the original parent and never enter this child. The accepted revision 2 unfused reference, rather than the earlier vendor fused outputs, remains canonical; its explicit original-vendor difference stays recorded.

The new private Arm binding preserves all 31 general registers, all 32 complete vector registers, NZCV integer flags, FPCR, x18 and errno in a 2048-byte aligned temporary frame. The parent has its unchanged 448-byte frame. The binding restores incoming sticky FPSR together with the GPU flags and preserves errno exactly.

Each sum starts with zero newly raised numerical flags. The inexact flag means that an operation needed rounding. Once this local flag, represented by the integer 16, is set, the two pure arithmetic sites can use a direct rounded value when both operands are normal finite numbers or signed zeros and the result’s stored exponent is between 2 and 2045. This conservative guard excludes tiny and near-overflow results. A source proof shows that only inexact can arise in this branch, and that flag is already present. Every other case keeps the original qualified multiply-status or add-status call. Each fallback has one aligned 16-byte return, with value at byte zero and flags at byte eight, both consumed immediately. Incoming host flags do not seed the local guard. Integer atomic OR merges newly raised flags across independent sums. There is no new EXP, FAST, WIDE, LOG, errno or scientific event. Round to nearest with ties to even, preserve gradual underflow and signed zeros, and forbid fused operations, reassociation, approximation and reduced precision. The source multiply-before-add degree dependency is unchanged.
