# Serial Fullpos Distribution

This component owns the complete selected one-process SUMPFPOS path. It divides the model output grid into cache blocks and records which process owns each point. The selected MODEL caller supplies the live NGLOBALPROC rank list and uses KPROMA_IN=-abs(model NPROMA), which is -24 for 2,048 points. The source is arpifs/fullpos/sumpfpos.F90. This is a numerical/storage child of SUBFPOS; the full SUBFPOS parent remains incomplete.

The entry md2asm_initialize_selected_fullpos_distribution receives controls16 in x0, the live rank list in x1, TFPGEO in x2 and record capacity in x3. The controls are four signed 32-bit words: global point count N, process count NPROC, current process MYPROC and KPROMA_IN. This finite component supports 1 through 4,096 points, NPROC=MYPROC=1, and nonzero KPROMA_IN from -4,096 through 4,096. Every consumed rank must equal one, as required by the selected serial distribution. The exact case uses N=2048 and KPROMA_IN=-24. Controls, rank list and complete output record are mapped, eight-byte aligned, non-wrapping and pairwise disjoint. The rank list has N contiguous 32-bit integers. FPCR is zero. The three output descriptor data pointers must initially be null; other output bytes can have arbitrary live preimages.

The output is the genuine 848-byte TFPGEO type from arpifs/module/yomfpgeo.F90. The genuine typed query was frozen before assembly emission: NFPRGPG is at byte 0, NFPRGPL at 4, NFPRGPLX at 8, NFPROMA at 12, NFPBLOCS at 16, NFPEND at 24, NFPRGPNUM at 88 and NFPRGPIND at 152. Integer elements have four bytes; rank-one and rank-two GNU descriptors have 64 and 88 bytes. The integer type tag is one, as confirmed by the genuine complete source gate. Only NFPRGPL, NFPRGPLX, NFPROMA, NFPBLOCS and the complete NFPRGPNUM, NFPRGPIND and NFPEND descriptors are changed. The earlier SUBFPOS store to NFPRGPG remains the caller's source-defined responsibility. Other record fields and padding retain every incoming bit, including any unrelated live descriptors. The new component does not read them.

SUMPFPOS first allocates NFPRGPNUM(1), counts ranks equal to one and sets NFPRGPL=NFPRGPLX=N. It then allocates NFPRGPIND(N,1) and fills its first column with the global indices 1 through N. If KPROMA_IN is negative, NFPROMA starts at its absolute value. If it is positive, NFPROMA starts at KPROMA_IN+1-mod(KPROMA_IN,2), the next odd value or the same odd value. It then clamps NFPROMA to [1,N]. NFPBLOCS=(N-1)/NFPROMA+1 uses exact signed integer division for positive operands. The source allocates NFPEND(NFPBLOCS), fills all preceding blocks with NFPROMA and fills the last with N-NFPROMA*(NFPBLOCS-1). No floating-point arithmetic is needed.

The three allocations and their payload writes follow source order. Their GNU 12 descriptor mechanism reuses the already accepted partition_array_storage.S representation: four-byte integer elements, one-based bounds, unit first stride, and the first extent as the second stride. This checkpoint owns a small local copy of that mechanism because the accepted partition allocator is specific to a Geometry record. Private descriptors are committed after all three owners succeed. Allocation failure frees the acquired owners and leaves the public record unchanged. Successful callers own all three buffers. md2asm_release_selected_fullpos_distribution receives TFPGEO and capacity in x0/x1, frees NFPRGPNUM, NFPRGPIND and NFPEND in that source order, clears only their data words, returns zero, and permits repeated release.

A return of zero means success, one means allocation failure and two means unsupported metadata before mutation. The entries preserve x18 and the Arm callee-saved registers and keep the stack 16-byte aligned. Only malloc/free are external. The selected quiet-startup policy omits unconsumed LALLOFP/LTRACEFP integer diagnostics. Source and native floating-point flags and errno are observed naturally; no status is forced. No original module state, type descriptor, method table, MODEL object or captured constructed-state data is used.

The grouped source gate passes three genuine cases and 13,800 complete bytes, including every owner, complete output records and released records. It covers the exact 2,048-point/-24 case, a 37-point/+24 case and the one-point/-4096 clamp. The actual case has NFPROMA=24, NFPBLOCS=86 and last-block length eight. All 2,199 independent partition relations pass. Nine typed owner-base correspondences join only declared data words after every numerical buffer agrees. Source and native ABI masks are zero; FPCR, seeded FPSR flags and errno 777 match naturally. Every input byte remains unchanged.

The new boundary gate passes 22 meaningful rejected inputs, allocation failures at each of the three owners and six protected ranges. Allocation failure leaves the complete public record unchanged and no live owner. Normal and repeated release pass. Source writes 232 outer-record bytes and retains 616 incoming bytes. The exact selected case owns 8,540 numerical bytes. Every numerical payload byte is source-defined; no allocator preimage is read or repaired.

A clean assembly-only executable starts with libc only, uses ordinary malloc, and passes the 9,364-byte source stream. Its stream includes every outer-record byte except the three data addresses, then all three complete owner payloads in source allocation order. The raw record and its addresses remain unchanged in memory. Missing arguments and output failure return 66 and 67; output failure releases the owners. The complete raw-record source gate remains the authority for every descriptor byte and typed address correspondence.

The new parent uses a 448-byte frame, and its local allocator uses 64 bytes, giving a maximum local stack of 512 bytes before malloc. Release uses 64 bytes before free. The source literal-free assembly was written directly; no compiler assembly or numerical fallback was used. The earlier accepted partition allocator representation and source proof are reused, while the new enclosing component received its own whole-source gate. No full forecast, timing run or broad child suite was repeated.
