This checkpoint replaces the selected SUFA file metadata and the complete SUAFN field-descriptor setup, including SUAFN1, SUAFN2 and quiet SUAFN3. Fullpos selects the fields that the forecast writes. Its descriptors hold names, integer field codes, storage precision and rules for spectral filtering. These operations change metadata rather than forecast values.

Remaining list records are processed in place. The physical fields receive their next code and are copied in the same way. The six source group bounds are written at their named offsets.
