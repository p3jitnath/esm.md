# Tangent for Gaussian Initial Angles

SUGAW starts each northern Gaussian latitude with an angle z equal to `((4*j-1)*pi)/130`, for j from one through 16. Its correction uses `tan(z)`. A sine/cosine quotient need not preserve the original tangent bits, so this child retains the original tangent primitive's numerical route. The supported input is a finite positive FP64 angle from 1/16 through 25/16 radians. This includes all 16 selected angles and avoids a tangent pole, where cosine is zero. Other inputs or nonzero FPCR abort before numerical work.

The source is GNU libc 2.38 IBM Accurate Math Library TAN at commit 36f2487f13e3540be9ee0fb51876b1da72176d3f. Its original polynomial coefficients and 186-by-four lookup table are immutable math-primitive constants. They contain no precomputed model angle, Gaussian root, weight or forecast state. The direct assembly calculates every tangent input at runtime. The source and tables remain locally in tangent_source/ with their hashes.

For inputs through the source threshold g3, the table index is the integer part of `-15.5+256*x`. The table supplies a nearby angle, its tangent fi and its cotangent gi. The small difference z gives `pz=z+(z*z*z)*(e0+(z*z)*e1)`. The tangent result is `fi+(pz*(gi+fi))/(gi-pz)`. Every ordinary product, sum, difference and division rounds separately. The original primitive's contracted product/sum steps use the already accepted direct integer rounded-product-sum child, which rounds the exact product and sum once without a fused floating-point instruction. This internal primitive rule does not contract the caller's arithmetic.

Larger supported inputs reduce once by pi/2 with the original high, medium and low constant parts. The rounded turn count is one throughout this input interval. The reduced angle is negative and has magnitude below g3. For magnitude above g2, the table route returns `gi-(pz*(fi+gi))/(fi+pz)`, including the source's low-angle correction before the polynomial. For magnitude through g2, the degree-eleven tangent polynomial and its low correction form a double-length result, meaning a rounded value and a small rounding remainder. The original exact-addition and double-length reciprocal rules then calculate the negative cotangent. All source rounding points, remainder terms and final sign remain explicit.

`md2asm_gaussian_tangent` receives and returns FP64 in d0. It owns no buffer and allocates no storage. It preserves x18, the AAPCS64 saved registers and FPCR; its frame is sixteen-byte aligned. Incoming FPSR flags remain set and acquire the flags raised by the original primitive. Errno is unchanged in the supported domain. No Fortran or numerical library function supplies this production calculation. C abort is used only outside the supported input or FPCR domain.
