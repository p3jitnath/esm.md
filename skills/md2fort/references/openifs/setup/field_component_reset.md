# Grid Field Component Reset

FALSIFY_GFL_COMP resets a field descriptor before registration. This component follows all its source-defined assignments across one through 2,163 consecutive 368-byte TYPE_GFL_COMP records. It sets the inactive flags, blank names, zero reference and water values, and source index sentinels. It preserves IFID, LMGRID, the chemistry members without source assignments and private padding. Its 248 written bytes and 120 preserved bytes are mapped separately. The source YGFL argument is unused and is absent from this raw interface.

md2asm_reset_grid_field_components receives the mapped eight-byte-aligned record array in x0, count in w1 and the caller-owned NUNDEFLD value in w2. The selected frozen value is -99999; MPSLP uses the distinct source value -99. The input records can contain earlier field metadata. PREVIOUS is cleared without traversing the earlier chain, and no external YLASTCOMP pointer is changed. The caller owns all records and any surrounding configuration. A complete mapped count*368-byte range is required. Return w0 is zero on success or two before mutation for unsupported pointers, counts, sentinel or FPCR.

The integer-only leaf has no stack frame or child call. It preserves FPCR, FPSR, errno, x18, x19 through x29, v8 through v15 and the stack pointer; x0 through x17 are caller scratch. FPCR must be zero. Production receives no original module address, type descriptor, vtable, callable or state packet and uses no external service. This is the reset child required before selected SUGFL2 registration, with the parent counter reset, inactive dummy associations and selected configuration still separate.

The genuine reference covers counts 1, 8 and 2,163 under three incoming byte patterns. All 799,296 complete record bytes agree without address normalization. The 260,640 source-unwritten bytes and 4,077,408 bytes of unused original YGFL scratch remain unchanged. Six immediate ABI/status calls preserve every native saved register, FPCR, FPSR and errno; the first original call's x18 change remains explicit. The 49,956 independent string, water, flag, index and null-pointer relations, 192 guard bytes and four before-mutation rejects pass. The production DSO has no undefined symbols or shared-library dependencies, and GCC 12.3.0 is the assembler driver. No original body, full SUGFL parent, forecast or timing credit is claimed.
