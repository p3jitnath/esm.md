# Operational serial block-size selection

`SUOPTPROMA` selects the number of grid points in a work block. The operational input starts with block size `NPROMA=16` and 6,599,680 grid points. The actual namelist specifies `NPROMA=0`; the original scalar-platform dimension setup restores its default of 16 and enables this optimization. This component implements the complete selected global, hydrostatic, one-thread calculation. It queries the public threading service and calculates the result through the original integer search.

The raw interface is `int md2asm_initialize_operational_serial_block_size(void *geometry, const int32_t config[2])`. Registers `x0` and `x1` carry the pointers, and `w0` returns zero on success or two for an unsupported state or thread count. Geometry spans 17,096 bytes. Config spans eight bytes and contains canonical values `LELAM=0` and `LOPT_SCALAR=1`, meaning a global model on the scalar-platform branch. Both records require eight-byte alignment, mapped nonwrapping bounds and disjoint storage. Geometry byte 0 points to a separate four-byte aligned nonhydrostatic flag whose value is zero. The flag is read-only and must be mapped and disjoint from both records. FPCR must be zero.

The admitted Geometry has 2,560 latitudes at byte 4872, initial block size 16 at byte 5144, optimization flag 1 at byte 5164, truncation 1279 at byte 5172, and 137 vertical levels at byte 5224. Its local and maximum grid-point counts at bytes 7376 and 7384 are both 6,599,680. All other bytes are complete caller inputs that stay unchanged. These explicit records replace the original global configuration inputs; no original OpenIFS variable or constructor supplies production work.

The assembly calls public FIAT `__oml_mod_MOD_oml_max_threads`, which obtains the actual OpenMP maximum thread count. Only a returned count of one is admitted, and the check completes before any Geometry write. The assembly retains the original integer divisions and strict comparison for a reduction in block count. It tests the source candidate interval from `NPROMA+1` through `NPROMA+1+NPROMA*5/100`, where integer division discards the remainder. For this input the result is 17. It writes only `NPROMA` at byte 5144, `NPROMM` at byte 5148 and `NPROMNH` at byte 5156. `NPROMM` is the collocation-grid block length and receives the selected value 17. `NPROMNH` is the nonhydrostatic workspace block length and receives 1 for this hydrostatic input. The separate SUMP caller will calculate 388,217 blocks and nine unused final-block cells from that result; this child does not allocate or fill those blocks.

The 144-byte frame is aligned to 16 bytes. The entry preserves all required saved registers, `x18`, FPCR, FPSR and the incoming error number. It allocates no owned array. Its external calls are the public thread query and error-number access. Original diagnostic printing is omitted; complete state and immediate numerical status still match the separate original-source reference.

The reference retained the complete original `SUOPTPROMA` body, with only its procedure name changed. Two complete Geometry preimages passed 102,864 compared bytes across success and refusal cases, including full records, control words and guards. Only the two borrowed nonhydrostatic-flag addresses use explicit source-to-native correspondence. Four native ABI observations passed with zero masks. Actual public thread count two and an incorrect maximum grid count were both refused without a write. Source and native FPCR, FPSR and error numbers matched under incoming FPSR zero and 24. An independent exact integer minimization checked the selected block size, resulting block count and padding. No original source or native case was rerun.

This standalone child does not qualify the full SUMP partition stage, its arrays, complete horizontal Geometry, bootstrap or an operational forecast. Existing selected routes remain unchanged. Public FIAT, OpenMP and their required language runtime are permitted dependencies; no original OpenIFS numerical provider is loaded in the native check.
