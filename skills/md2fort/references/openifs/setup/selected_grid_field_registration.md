# Selected grid field registration

`md2asm_register_selected_grid_fields(gfl, profiles, constants, levels, supplementary, effects)` builds the selected eight active field records and their complete aliases. It implements the selected SUGFL2 registration and SUGFL3 attribute effects. The complete SUGFL1 default and namelist stage is a separate parent dependency. This entry does not claim that complete original SUGFL1 has been retired.

The AArch64 interface uses x0 for a fresh zero 1,359,136-byte owned GFL record, x1 for nine 256-byte input profiles, x2 for the owned 520-byte physical constant record, w3 for 1–64 vertical levels, w4 for 0–64 supplementary levels, and x5 for two four-byte output logicals. All buffers have 8-byte alignment. FPCR must equal zero on entry, which selects round-to-nearest with ties to even and gradual underflow; a nonzero FPCR is rejected before output mutation. The output record and effect buffer are disjoint from each other and from both input ranges. Both input ranges are read-only. The constant record is produced by the owned physical constant initializer; its setup logical is true. The consumed finite positive FP64 words are RV, RCPV, RCW, RCS, RLVZER and RLSZER at bytes 192, 208, 344, 352, 392 and 400. Production reads no original module data.

The nine profiles have the qualified selected defaults in Q, L, I, S, R, A, O3, NOGW1 and NOGW2 order. Only the snow and rain input-request integers may differ, each within −1, 0 or 1. The entry checks every profile byte against the declared default child before mutating output, with those two explicit request exceptions. This fixes the eight-field membership, interpolation options and the selected no-trajectory/no-chemistry route. The complete input profiles, including source-unwritten bytes, are copied into their named record slots.

The child initializes all 2,163 embedded component records from their declared defaults, then applies the qualified FALSIFY operation. It registers Q, L, I, S, R, A, NOGW1 and NOGW2 in that order. Names retain the exact SUFA leading spaces, and field codes and field identifiers come from their declared source metadata. The first five records receive the source thermodynamic and water attributes, with precipitation true for snow and rain. Cloud fraction and the two gravity-wave fields keep their separate optional-argument choices. Registration constructs the backward component chain; a qualified child then constructs all 61 named and group aliases from the resulting embedded addresses.

Attributes are applied in the original Q, A, L, I, S, R, NOGW1, NOGW2 order. Thus the semi-Lagrangian positions for Q, L, I, S, R and A are 1, 3, 4, 5, 6 and 2, and their displacement is `(position−1)*(levels+2*supplementary)`. Only Q and A have the two physics slots. The final source-order mass-fixer scan selects component indices 1–5. There are no negative-fixer or multiple-grid fields in this supported route. The returned logicals LVSPLIP and LSPLTHOIGFL are both false. The original diagnostic console output is outside this storage service. Its genuine status is retained separately: SUGFL2 preserves each incoming status, while complete SUGFL3 including PRINT_GFL changes FPSR from 0 to 16 in the clear-flag case and preserves incoming FPSR 31 and 24. Both preserve errno 777. The utility itself preserves incoming FPSR and errno; it does not force a flag to imitate omitted formatting. A complete composed parent must compare its natural status separately.

The entry returns 0 on success and 2 before output mutation for a checked input failure. Return 3 reports an unexpected rejection by an internal qualified child after construction has begun. The function uses a 2,688-byte stack frame and preserves SP alignment, x18, x19–x29, the required SIMD registers and FPCR. Its instructions perform integer metadata and bit-copy operations only. It has no allocation, external service, original callable, original type or virtual-table input. The native immediate FPCR, FPSR and errno checks pass for clear and seeded incoming status.

The production DSO is linked only from directly written assembly children under local symbol binding, with no required shared library or undefined symbol. Three genuine SUGFL2/SUGFL3 cases compare all 4,077,408 GFL bytes at the same MODEL-backed address, including complete profiles, maps and raw pointer words. Six immediate ABI/status calls pass, with native masks zero and the original reference's x18 difference retained as mask 2. The 459 independent relations check counts, species names/codes, backward links, thermodynamic copies, semi-Lagrangian positions and five mass-fixer indices. All 672 guard bytes and seven before-mutation rejection cases pass. A standalone assembly `_start` example constructs the same owned namespace and exits 0 without any dynamic dependency or undefined symbol. No forecast or original-body count is claimed by this local checkpoint.
