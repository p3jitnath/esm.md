# Inactive Convective Cellular Controls

A record groups related model settings in one area of memory. A cellular automaton is an optional model that lets neighbouring grid cells affect convective cloud activity. This component keeps the original default branch in which that model is disabled. It implements the source control assignments in YOE_CUCONVCA::INI_CUCONVCA for an ECMWF forecast and an empty or absent NAMCA group. It introduces no cloud calculation and does not replace the active automaton.

## Accepted Checks And Limits

One call to the original disabled source branch matches all 6,296 returned record bytes and the four-byte NIJH result. An independent assignment map reconstructs all 110 source-written MODEL bytes and preserves the other 6,186 record bytes, including the unassigned logical word, padding and array descriptions. The direct success call preserves every other byte of the complete 4,275,088-byte MODEL. Three further calls check a short MODEL capacity, an overlapping NIJH output and a nonempty NAMCA group. They return two with unchanged outputs. All four direct calls preserve the ABI registers, FPCR, incoming FPSR and errno. Protected buffer boundaries pass and all temporary mappings are released. The original witness and direct checks use separate processes, with the complete typed preimage checked before reusing the source result.

These checks accept the selected disabled component. Its production entry uses assembly and the accepted integer input reader. The original library and typed helper belong only to verification.
