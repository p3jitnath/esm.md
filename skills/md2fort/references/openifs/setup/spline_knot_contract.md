# Fixed-Order Vertical Spline Knots

A knot is a dimensionless coordinate at which two polynomial spline pieces join. This child implements the complete selected `LDFIX_ORDER=true` calculation in `arpifs/setup/suvfe_knot.F90`, where the source always selects its percentile branch. It places repeated zero and one knots at the material boundaries, then interpolates the supplied level coordinates to place all interior knots. The source branch for fixed knots and diagnostic profiling/printing are outside this selected interface. No original record or numerical function is needed.

`int md2asm_vertical_spline_knots(const int32_t *order, const int32_t *basis_count, const int32_t *level_count, const double *eta, double *knots)` takes five addresses in x0 through x4 under the Arm procedure call standard. It reads four bytes from each scalar, `level_count` FP64 coordinates, and writes all `basis_count+order` FP64 knots. Integer addresses are aligned to four bytes and array addresses to eight bytes. Mapped inputs and output are disjoint, with the stated complete extents. The caller owns them. Return zero means complete output; return two rejects scalar, alignment or coordinate input before mutation. The leaf has no private stack, allocation, external call, original module data, type table or callable input. It uses only caller-saved registers and preserves x18.

For the retained small shapes, order is two through four and the level count is at least the order and at most 24. The basis count is at least the order and at most 24, with `basis_count-order <= level_count`. The additional operational shape has order four, 139 level coordinates and either 139 or 140 basis functions, giving 143 or 144 knots. Other level or basis counts above 24 remain unsupported. Input coordinates are finite and strictly increasing from zero to one. These bounds keep every source percentile lookup within the supplied coordinates. Raw address extents and disjointness remain caller preconditions. Empty interior-knot sequences are supported.

For `m=basis_count-order` interior knots, the source forms `stretch=0.5*((level_count-2)-m)`. Interior index i runs from one through m. It calculates `p=(i+stretch)/((m+1)+2*stretch)`, then `index=p*(level_count-1)+1`, rounding every operation separately to FP64. It truncates `index` to integer j. If eta(j) is zero, the knot copies eta(j+1); if eta(j) is one, it copies eta(j-1). Otherwise `weight=index-j` and the knot is `(1-weight)*eta(j)+weight*eta(j+1)`, using two separate products and their sum. The first and last `order` knots are positive zero and one. No expression is contracted, reassociated or replaced by an algebraic shortcut.

FPCR must be zero: round to nearest with ties to even and gradual underflow. Source arithmetic may add flags to the incoming FPSR; no flag is cleared. There is no external call, so errno is unchanged. Exact comparison uses the complete genuine source branch with an explicitly false diagnostic control and separate typed records. It checks actual retained 19-level input, fractional percentiles, both endpoint-copy branches, no interior knots, complete output guards and immediate ABI/status. Independent high-precision piecewise interpolation checks ordered knots, endpoint multiplicities and their location in the coordinate domain. Whole caller and forecast acceptance remain pending.

The raw knot output follows the original percentile rule, so basis admissibility is a separate caller condition. For example, order two, two positions and four basis functions produces interior knots one then zero; order two, three positions and five basis functions can repeat the middle knot three times. The basis child correctly rejects these source-produced corner cases. The selected 21-position input and basis counts 21 through 24 are unaffected. No claim that every permitted raw scalar tuple composes with the basis child is made.

The added 137-level child qualification uses four genuine original knot cases across the two new basis counts and FPSR seeds zero and 24. It compares all 4592 active output bytes and complete caller owners, inputs, guards and inactive tails. All output and complete caller bytes match the original. Its five native ABI and status observations pass, including one unsupported-count 141 no-write refusal. The unchanged 100-digit interpolation method passes 1686 independent coordinate relations. The original fixed-order source selects the percentile branch without reading its boundary pairs, so the retained generic source control remains valid. This child qualification does not admit the whole vertical operator or forecast.
