# Field membership lists

This raw child follows `FIELD_GFL_WRAPPER:GFL_FID_SETUP` for the selected absent KFIDS argument. It reads a map of field IDs to old storage indices, retains pre-existing true flags, marks available fields, and returns the ascending list of fields that are on. A zero map value leaves both flags unchanged. A nonzero value marks the field on; a value other than −1 and zero also marks it active. This preserves the source treatment of its undefined-field value.

`int md2asm_initialize_field_membership(const int32_t *map, uint64_t count, int32_t *on, int32_t *active, int32_t *field_ids, int32_t *used)` uses x0 through x5. Count is between zero and 4,200. Each array covers count four-byte words; used covers one word. Each address must be nonnull and four-byte aligned. Declared ranges must be mapped, nonwrapping and disjoint, and the incoming logical flags must be zero or one. The routine validates the flag values before any store. Return 0 means success; return 2 rejects an unsupported count, basic address or logical value without changing any output. Only the first returned used field IDs are written; the remaining list bytes are retained.

The assembly leaf allocates nothing and calls nothing. It preserves x18, all callee-saved registers, the stack pointer, FPCR, FPSR and errno. It uses integer instructions only. The caller owns all arrays and their later descriptors. Original allocation is used only in the separate source control. This child closes the selected membership computation, while container allocation and the enclosing attachment remain separate.
