# Runtime Empty Trajectory Storage

This storage component creates the empty trajectory records passed through STEPO, SCAN2M, GP_MODEL and EC_PHYS_DRV. A trajectory record holds descriptions of stored model fields. This entry allocates the records and timers, while the selected forecast keeps trajectory saving false. It allocates no numerical trajectory field. The [existing small-count entry](empty_trajectory_state.md) stays available. The new entry uses the same assembled solver at each supported runtime shape; other numerical providers retain their own limits.

`int md2asm_create_runtime_empty_trajectory_state(state,state_bytes,geometry,geometry_bytes,model,model_bytes,context,context_bytes)` receives eight arguments in x0 through x7. The application binary interface, or ABI, defines these argument positions and the registers the routine preserves. Minimum sizes are 192 state bytes, 20400 Geometry bytes, 4275088 MODEL bytes and 16 context bytes. Context byte zero holds the actual 24-byte initialization-control owner address; byte eight holds the unsigned 64-bit total allocation budget. The initialization producer must already have read the live controls and set LDFI and LJCDFI false. The complete five input and output spans must be mapped, nonwrapping and pairwise separate. State, Geometry, MODEL and context use eight-byte alignment; initialization controls use four-byte alignment. Three state pointer bases, at bytes 0, 64 and 128, start null.

MODEL byte eight must name this exact Geometry. Read positive signed 32-bit column count P, local point count N and block count B at Geometry bytes 5144, 7376 and 5160, and require $`B=1+\lfloor(N-1)/P\rfloor`$. The floor brackets mean round down to the nearest integer. Read the first and final timer indices from MODEL bytes 1359328 and 1359332, with $`0\leq START\leq STOP\leq4096`$. These counts have no units. This storage entry has no level, rank, process-count or thread-count restriction. Its allocation products and sums use 64-bit integers; every complete allocation must fit both the explicit budget and available memory.

Let $`R=STOP-START+1`$. Allocate two four-byte integer timers of R elements, then TRAJEC with STOP+1 elements of 512 bytes, CST with B elements of 96 bytes, SLAG with B elements of 3536 bytes and PHYS with B elements of 5528 bytes. Their total is $`8R+512(STOP+1)+9160B`$ bytes. The timers have bounds START:STOP and values minus 99. TRAJEC has bounds 0:STOP. Each time level shares the complete CST, SLAG and PHYS descriptions from time zero, with lower bound one, stride one and upper bound B. Shared descriptions are aliases to the same three owners, not extra allocations.

The assembly writes the source-declared null pointer bases and complete associated descriptions. All other unassociated description words, uninitialized LASTCHUNK scalars and padding retain their allocation preimages. LASTCHUNK indicates the final stored block only when an active saving stage defines it. A null pointer defines its association state; its remaining shape words do not define an array. Keep those words and targets opaque in numerical calls, argument collection, packing, transport, copies and diagnostics. The selected caller must supply actual false trajectory-saving controls before any such reader. The small B≤128 route and the larger positive-B route enter the same unchanged qualified allocation and release body.

Return zero publishes the three complete state descriptions after all six allocations succeed. Return two refuses a checked invalid bound, association, control, live incoming state or budget before allocation or state mutation. Return one frees the successful allocation prefix in reverse order and preserves every state byte and incoming errno. Errno is the operating system's error number. All returns preserve errno and the floating-point control and status registers, FPCR and FPSR. FPCR must be zero. The wrapper uses a 64-byte frame and the shared body uses 208 bytes, giving 272 bytes of private nested stack. It preserves x18, saved integer registers, required saved vector-register halves and sixteen-byte stack alignment. Production calls only the public libc allocation, release and errno-address services.

`int md2asm_release_runtime_empty_trajectory_state(state,state_bytes)` takes its two arguments in x0 and x1. After the last reader, it frees PHYS, SLAG, CST, TRAJEC and the two timers in that order, then clears only the three outer bases. A repeated release of the null graph is valid. The caller must supply either this complete live empty graph or its released graph, and must not separately free shared arrays. Release uses an 80-byte frame. Active trajectory-saving stages need their own numerical-field release before this outer release. Optional OOPS trajectories remain a separate producer route.

The later physics caller selects the actual TRAJEC(NSTEP) record, then its PHYS description at byte 256 and the current one-based block. It requires NSTEP within 0:STOP, a matching live B and a mapped 5528-byte PHYS element. This owner stays alive through the final weather reader. Its storage does not replace any missing weather calculation or extend the narrower bounds of another provider.

Two typed-source profiles pass at [P,N,B,START,STOP]=[3,385,129,0,2] and [5,1281,257,2,4]. Four verification-only typed-declaration calls and fourteen native calls cover both complete owner graphs, the retained B128 dispatch, release and repeated release, a sixth-allocation prefix failure and six prewrite refusals. All eighteen archived ABI masks are zero; FPCR is zero, seeded FPSR values zero or 24 remain unchanged, and errno remains 777. Every live guard passes and all 35 successful private allocations have matching releases. The complete source and native owner records, control records and status are retained locally; the two complete MODEL preimages and final images agree. This is a small typed-storage check, with no original procedure or numerical trajectory-field call.

The comparison requires exact source-defined timer and associated-description bytes, every source-defined null base and independent owner-address relations. It archives each complete typed source image unchanged, but does not compare or normalize undefined source representation words. Separately, every native owner byte matches its frozen allocation preimage plus the declared stores. Full source/native owner-byte equality is outside this representation boundary. The source's unused shape words must remain unread by the selected consumers. The mapped-owner event record closes with no live allocation; restoration of allocator call targets, descriptor guards and file-descriptor counts are checked in process. These results establish storage and lifetime at the two stated profiles. Genuine enclosing owner production, active trajectory saving, the complete physics caller, a forecast and comparative timing remain separate.
