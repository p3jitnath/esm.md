# Live field attachment maps

This raw child follows the selected `FIELD_GFL_WRAPPER:GFL_MAPPING_SETUP` assignments. A map translates each of 4,200 field IDs into its index in an existing GMV, GFL or surface buffer. Zero means that the source has no mapping, and −1 means that the source field is inactive. Every mapped value comes from live owned records. The production routine uses no original module, constructor, method table or callable target.

`int md2asm_initialize_live_field_maps(int32_t *maps, size_t capacity, const void *gmv, const void *gfl_description, const void *surface, const int32_t *undefined_field)` uses x0 through x5 in that order. The complete output is 168,000 bytes. It contains ten consecutive 4,200-word maps ordered MT9_MAP, MT1_MAP, MT0_MAP, MPC_MAP, MPT_MAP, MT0_DL_MAP, MT0_DM_MAP, MT9_DL_MAP, MT9_DM_MAP and MT0_SIZE. The caller owns the flat output. A later container constructor owns its individual map allocations and descriptors.

The input records are the genuine typed layouts TGMV1560, TYPE_GFLD1359136 and TSURF18224. Their numerical owners are borrowed and untouched. All roots must be nonnull and eight-byte aligned, except the undefined-field input needs four-byte alignment. All declared root, target and output ranges must be mapped, disjoint and nonwrapping; these are caller obligations. Every source-consumed named pointer must refer to a valid complete target. Pointer-array descriptors must be contiguous, one-based GNU rank-one descriptors with canonical origin; GFL component elements occupy 368 bytes and surface two-dimensional metadata elements occupy 64 bytes. Every consumed first array element must exist. Logical values must be canonical zero or one.

This selected child requires NGHG, NCHEM and NAERO to be zero. It accepts NSURF zero or positive and follows the original positive test before any surface-map target read. It requires the fixed namespace from `md2asm_initialize_main_field_metadata`; its source-defined storage classes select the corresponding SET_MAP branch. Dynamic composition fields remain zero in the maps when their three source counts are zero. The basic address, alignment, output-capacity and count checks precede all output writes. Return 0 means success and return 2 means unsupported input, leaving the output unchanged on rejection.

The routine clears every map word, then performs all 621 selected source setter calls in their source order, including maps for inactive PC and PT containers. It uses the live GMV index and undefined-field value, GFL LACTIVE and time-level index, or surface LSET and time-level index. The six source surface-array counts are written into MT0_SIZE only when the source LSET condition holds. It retains the source special case when the undefined-field value equals one. The early MT0_DL surface-pressure assignment is immediately overwritten by its unconditional SET_MAP call, so only that call supplies its returned value.

The assembly leaf allocates nothing and calls nothing. It preserves x18, x19–x29, d8–d15, the stack pointer, FPCR, FPSR and errno, and uses no floating-point instruction. Human map printouts and profiling are omitted. The source control checks the complete maps, every input record and target byte, and immediate status separately. Container ownership, field-open views, the enclosing FIELDS_CONTAIN parent and forecast use remain separate stages.
