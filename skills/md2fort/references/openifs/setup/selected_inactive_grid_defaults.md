# Remaining grid field profile defaults

`md2asm_initialize_selected_inactive_grid_defaults(gfl)` fills the 53 remaining source profile families and 52 selected phase-1 scalars in the owned grid field namespace. The profiles describe field options; they do not contain forecast values. Their complete declared ranges occupy 555,488 bytes. The active nine input profiles and all component records and aliases are constructed by separate qualified children.

The AArch64 interface uses x0 for a writable, 8-byte-aligned 1,359,136-byte GFL record. The caller supplies a valid complete allocation, with no address wrap and FPCR equal to zero. The active registration header must contain NUMFLDS 8, NNOGW 2 and NFLDSFIX 5. Every byte in the 53 remaining profile ranges must still be zero. The child checks these requirements before its first store. Return 0 means success; return 2 means a checked rejection with the complete record unchanged. Other input bytes must have the selected registration values required by the enclosing constructor.

The source-only tables contain 1,668 common member operations, 79 fixed-profile overrides and 52 scalar stores. Each operation names a typed member offset and a source literal or integer formula. They are not a saved namespace image. The child writes common members for each profile, then the fixed-index source overrides and final scalar choices. All ranges and member widths are checked against the typed layout. Source-unwritten bytes keep the explicit zero incoming-storage policy. The YAERLISI family has shape 3 by 6, with its first index contiguous. The separate wavelength family has 20 records of 24 bytes.

Character literals retain their source case and occupy 16 bytes, with spaces added on the right. CHEMICAL001 through CHEMICAL220, FORC0001 through FORC1100 and EZDIAG01 through EZDIAG50 are formed by integer decimal digits at runtime. Three integer field-code formulas retain their source index. FP64 literals with a JPRB suffix use the source double-precision value. The four unsuffixed chemical metadata literals −99999.9 first round to default REAL32, then widen exactly to FP64, giving bits `0xc0f869fe60000000`. The literal kind is part of the source arithmetic contract.

The function is an integer-only leaf with no stack frame, allocation, external call, original OpenIFS data or type metadata. It uses x0–x17 and preserves x18–x29, all SIMD registers, SP, FPCR, FPSR and errno. The enclosing genuine SUGFL1/SUGFL2/SUGFL3 comparison checks the complete final namespace at the same address in three cases, including these profiles and every raw pointer. A separate source-table check verifies 3,869 range, width, count and literal relations. No forecast or original-body count is claimed by this local child.
