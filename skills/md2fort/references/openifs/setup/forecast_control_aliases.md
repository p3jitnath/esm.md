# Owned Forecast Control Names

The accepted control and clock producers already set the values that the forecast loop needs. This include connects their existing bytes to the original GNU module names read by the direct assembly callers. An alias is a second name for the same storage. It adds no record, copied state, calculation or original OpenIFS dependency.

Include `forecast_control_aliases.inc.S` in the initial entry after its `.Lforecast_controls` and `.Lclock_state` labels are defined. Those caller-owned buffers have 51512 and 360 bytes. The new names `md2asm_owned_initial_forecast_controls` and `md2asm_owned_initial_forecast_clock` identify their full ranges. The accepted producers must finish before any forecast consumer runs. Writes through an alias change the same underlying bytes, so event schedules and step counts remain shared with their producer storage.

There are 116 original object aliases. They cover 105 YOMCT0 variables, YOMIOPNH.LTRAJNH, and ten clock variables from YOMRIP0, YOMCT2, YOMCT3 and YOMTRAJ. The control offsets and complete scalar, character and array widths follow the [selected control contract](selected_forecast_controls.md). Clock offsets follow the [model-clock contract](model_clock_initialization.md). Integers and logical values have four bytes, FP64 reals have eight bytes, and all character and array objects retain their complete source widths. Alignment gaps and source-unwritten fields keep their existing producer policy.

LSMSSIG is excluded because the [selected runtime](../support/selected_forecast_runtime.md) already owns that original name. Its checked initializer consumes the disabled source setting before the time loop. The synthetic observation-configuration word is also excluded because it is not an original scalar name. Other original control members that the accepted producers do not set remain outside this include and need their own explicit producers.

The include emits only object-symbol declarations. It has no callable interface, register use, stack, numerical operation, allocation or external API. It cannot change FPCR, FPSR, errno or output bytes. Its original names and exact object sizes match all 116 genuine module exports. A focused assembly check proves every alias has the required producer-relative address, width and complete buffer bounds. The instruction, constant, initialized-data and uninitialized-storage sections are identical to the qualified R10 entry. Existing complete source, input and state checks are reused without another numerical execution. The next enclosing entry must assemble these same declarations and retain its whole-state checks. Full autonomous forecast acceptance remains separate.
