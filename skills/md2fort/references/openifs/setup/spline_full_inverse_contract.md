# Spline Matrix Inverse From LU Factors

This child constructs a square matrix inverse from its already calculated LU factors and row pivots. It owns the selected unblocked `DGETRI` calculation. The original block size is 64 for both selected dimensions, four and 21, so its blocked matrix-update branch is inactive. The direct body calls the qualified upper inverse child, solves against the lower factor, then applies the recorded column exchanges. It does not load a stored inverse or call an original numerical provider.

`int md2asm_spline_inverse_from_lu(const int32_t *dimension, double *matrix, const int32_t *pivots, int32_t *info)` takes addresses in x0 through x3 under the Arm procedure call standard. Dimension is one through 24. Matrix is a contiguous FP64 square owner in column order, whose leading dimension equals dimension. Pivots contains dimension int32 one-based indices, with `j<=pivots(j)<=dimension`. Integer addresses have four-byte alignment and matrix has eight-byte alignment. All buffers are mapped and disjoint, with the declared complete extents. The caller owns them. All matrix inputs and executed intermediates are finite; a zero diagonal is handled as a singular input.

Return zero means the selected source processing completed. Info zero gives a complete inverse. A positive info value marks the first zero diagonal and leaves the complete matrix unchanged. Return two rejects null, alignment, dimension, pivot or nonfinite initial input before either output changes. Mapping, extents, disjointness and finite intermediates are caller preconditions. The matrix and info are the only outputs; dimension and pivots are read-only. The body has a 368-byte, 16-byte-aligned frame, including 192 bytes of private lower-column scratch. It preserves x18, x19 through x29 and the low halves of d8 through d15. Its children are the direct upper inverse and the unchanged accepted integer product/add rounding helper. Maximum nested stack use is 2,272 bytes. There is no allocation, original data, descriptor, class metadata or original callable. The helper declares libc `_exit` only for a nonfinite operand outside the supported domain.

After the upper inverse, visit columns from last to first. Copy each below-diagonal entry into private scratch and replace it by positive zero. For each later column k in increasing order, form `factor=(-1)*scratch(k)` with its own rounding, then update every row by `RN(matrix(row,k)*factor+matrix(row,j))`. The selected source matrix-vector product executes these updates even for zero scratch values; it does not inherit the zero-skip rule of the rank-one LU update. The accepted integer helper supplies the source's one final rounding without an FMA instruction. The 143 consumed source matrix-vector stages match all returned bytes and fresh status, and all 30,894 new operand tuples pass independent exact-rational bit checks. Finally visit pivot columns in decreasing order, swapping complete columns by bit copies.

FPCR is zero: round to nearest with ties to even and gradual underflow. Each standalone multiplication and reciprocal keeps its source rounding point. Source events add to incoming FPSR and errno is unchanged. Critical checks compare complete inverses, info, inputs, guards and immediate ABI/status against the original provider, including native LU composition, nontrivial pivot exchanges, singular input and size boundaries. Independent exact-rational products check both inverse identities with an allowance based on absolute terms. Condition estimation and complete `MINV_8`/`MINV_CALLER`, `SETTM` and the enclosing spline setup remain required. No whole-forecast credit is claimed.
