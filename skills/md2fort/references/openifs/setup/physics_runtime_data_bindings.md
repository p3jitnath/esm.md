# Selected physics runtime data bindings

This component supplies remaining control words and inactive array descriptors read by the selected forecast. It calls no original OpenIFS procedure and constructs no replacement numerical field. The frozen serial ECMWF route has live NCONF 1, LIFSTRAJ false, LIFSMIN false and LSFORC false. These values are checked in the owned 51512-byte forecast-control record.

The ABI is `int md2asm_initialize_selected_physics_data(forecast, text, bytes)`, in x0, x1 and x2. The forecast record has eight-byte alignment; the original text contains 1–262144 mapped bytes. Spans must not wrap or overlap each other or the 608-byte static output namespace `md2asm_owned_physics_runtime_data`. Return 0 succeeds and return 2 rejects before mutation. The routine uses an 80-byte aligned frame, preserves x18 and required saved registers, and leaves FPCR, FPSR and errno unchanged. It calls only the accepted integer empty-group reader. Both first uppercase-exact NAMDYNA_STATIC and NAMTESTVAR groups must be empty; source columns 1–10 and case-insensitive member rules remain those of the accepted reader. No NAMLSFORC is read when the live LSFORC control is false.

Five source-written false words are LGRADGP and LDRY_ECMWF from `YOMDYNA_STATIC::SUDYNA_STATIC`, LMUSCLFA from `SULSFORC`, LFORCEWR from `SU0YOMB`, and LTESTINC from `TESTVAR_MIX::SETUP_TESTVAR`. The first source SUDYNA_STATIC body is checked through the genuine module procedure. Other words use their exact named source assignments under the guarded branch, without claiming complete replacement of those enclosing procedures. For NCONF 1, ICONF=NCONF/100 is zero, so SU0YOMB does not enter SULCZ and does not allocate GPFORCEU/V/T/Q.

The five scalar words LBFASECV, LUSEKF_REF, LUSE_SMOS_TB, NPOL_MAX and NANG_MAX have saved original declarations without a source assignment in the retained OpenIFS tree. Their admitted initial state is explicitly the original ELF zero-fill policy, not a claimed declared source default. The original symbols occupy its NOBITS BSS section. The same policy supplies the four unallocated rank-four GNU descriptors, 136 bytes each. Their complete bytes are initially zero, and the component requires them to remain unallocated. It does not create fake numerical payloads. Enabling variational, observation-assimilation or forcing paths needs their real producers and storage and is outside this selected boundary.

Five writable activity flags LESMOS_ACTIVE, LESMAP_ACTIVE, LESMOS_SEKF, LEGBRAD_ACTIVE and LERAINGG_ACTIVE are outputs of the accepted GP_MODEL control body. Their static initial bytes follow the same original zero-fill policy; their later source assignments remain in that existing body. Initialization requires all BSS-policy words and descriptors to be zero and does not overwrite them. Namespace bytes 60–63 are reserved and preserved. The first five source-default words may hold arbitrary incoming bytes and receive their named assignments after every guard passes. No release is required, and initialization must precede forecast reads.

The layout include gives every original-compatible OBJECT alias, byte offset and size. Verification checks genuine SUDYNA_STATIC selection, exact source-assignment fragments, complete original initial BSS objects, every alias and complete output bytes, raw ABI/status, protected bounds and atomic refusals. Informational original I/O can end errno zero while the quiet direct control retains incoming errno; no status is forced. No forecast or complete-startup claim follows from this bounded data component.
