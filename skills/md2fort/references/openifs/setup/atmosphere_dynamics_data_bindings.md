# Owned atmosphere and dynamics data bindings

This component exposes values already calculated by the owned standard-atmosphere constructor and constructs the integer field maps assigned by original `INTDYN_MOD::SUINTDYN`. It calls no OpenIFS routine and consumes no original module data or method table. External libraries remain permitted, but neither producer requires an external call.

The atmosphere interface is `int md2asm_bind_standard_atmosphere_data(references,capacity)`, with x0 pointing to the complete 576-byte reference output and x1 at least 576. The live producer is `md2asm_initialize_standard_atmosphere`; the owned Geometry continuation stores its output at byte 1280 of the 1872-byte Geometry sidecar. Each 288-byte table contains nine FP64 heights in metres, nine temperature gradients in kelvins per metre, nine temperatures in kelvins and nine pressures in pascals, in that order. The first table is the standard atmosphere and the second is the post-processing atmosphere. This binding copies every input bit into `md2asm_owned_standard_atmosphere_data`. All 68 named original R/V scalars alias their corresponding existing values; the surface height and surface pressure words remain part of the complete table but have no YOMSTA scalar names. HEXTRAP and NLEXTRAP remain separate producer outputs and are outside this binding.

The dynamics interface is `int md2asm_initialize_dynamics_field_maps(output,capacity)`, with x0 pointing to 744 writable bytes and x1 at least 744. It writes the 28 complete records assigned by SUINTDYN in original call order. The source calls SUPTR_TXYB with nine flags, SUPTR_TXYBDER with five flags, SUPTR_TRCP four times, SUPTR_TCTY four times and SUPTR_THWIND six times. Their integers select array fields; they are not procedure addresses. The named layout include defines each record offset and byte size. `int md2asm_initialize_owned_dynamics_field_maps(void)` invokes the same direct leaf for the static owned namespace. Its 28 original-compatible aliases share these exact bytes. The unrelated TTND, TGMVT and TGFLT records are not assigned by source SUINTDYN and are outside this producer.

Word-bearing inputs and outputs require eight-byte alignment, mapped nonwrapping complete spans and writable output storage. Atmosphere input must be disjoint from the owned destination. Return 0 succeeds and return 2 rejects an invalid pointer, capacity, alignment, wrapping span or atmosphere overlap before mutation. The integer leaves support all FPCR values without changing FPCR, FPSR or errno. They preserve x18 and every required saved register and use no stack frame or allocation. The static wrapper tail-calls the raw leaf. Initialization must finish before any forecast consumer reads the aliases. There is no release operation because both namespaces have static storage and contain no pointers.

The atmosphere source order is the accepted complete SUSTA reference table interface, including its independent physics and complete numerical verification. This checkpoint checks only the new exact copy and aliases and does not repeat those calculations. The map control calls genuine source SUINTDYN in a separate verification library and compares every record byte. New checks cover distinct incoming bytes, raw status and ABI, bounds refusals, exact alias addresses and a standalone assembly entry with no OpenIFS dependency. No forecast or full-program autonomy claim follows from this component alone.
