# Owned stream geometry metadata

SUMP records its partition information in the OpenIFS stream namespace. This child owns that selected first-call effect of INI_IOSTREAM. The source's complete 872-byte TYPE_INT_VARS layout is retained as an owned record, with no original OpenIFS global variable, constructor or callable in production. The other INI_IOSTREAM optional updates are outside this child.

The ABI is `int md2asm_initialize_stream_geometry_metadata(void *stream, const void *geometry, const int32_t process[2])`. Inputs use x0, x1 and x2, and status uses w0. Stream contains 872 mapped bytes and Geometry contains 17,096 mapped bytes; both are eight-byte aligned. The four-byte aligned process pair contains the live external rank and process count, both one on this serial route. All complete objects and buffers are mapped and disjoint. Geometry supplies either the earlier tuple of 19 levels, truncation 21 and 32 Gaussian latitudes, or the exact operational tuple of 137 levels, truncation 1279 and 2,560 latitudes. NBSETSP is one on both routes. NBSETLEV gives the partition set for each vertical level, and NLOENG gives the longitude-point count for each Gaussian latitude row. Both are contiguous canonical-origin int32 arrays. NBSETLEV has one entry per level, with lower bound one. NLOENG spans NDGSAG:NDGENG and contains all active rows from one through NDGLG, the latitude count. The checked halo bounds are −1:34 for the earlier route and −1:2562 for the operational route. Data addresses point at the stored lower-bound element. Translate that lower bound before copying the active NLOENG section. These descriptors and inputs are read-only caller preconditions.
