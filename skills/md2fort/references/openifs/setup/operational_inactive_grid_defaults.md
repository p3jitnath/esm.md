# Operational inactive grid field defaults

`md2asm_initialize_operational_inactive_grid_defaults(gfl)` completes the 53 inactive profile families and 52 source phase-1 scalars after [operational nine-field registration](operational_grid_field_registration.md). Profiles describe field options, rather than weather values. Their declared ranges occupy 555,488 bytes. The existing [eight-field helper](selected_inactive_grid_defaults.md) remains unchanged.

The Arm application binary interface (ABI) receives one writable, eight-byte-aligned, 1,359,136-byte record in x0. The caller supplies the complete mapped allocation with no address wrap. FPCR must be zero. The registration header must have active-field count 9, gravity-wave count 2 and fixer-field count 5. All bytes in the 53 inactive family ranges must still be zero. The child checks these requirements before its first store. Return 0 means success; return 2 leaves the complete record unchanged. Other bytes retain the operational registration values required by the enclosing constructor.

The complete helper is a separate clone of the qualified selected helper, with only its entry name and active-count admission changed. It uses the same source table include, all 1,668 common operations, 79 overrides and 52 scalar stores. The ordered validation, profile loops, indexed character names, integer field-code formulas and final scalars remain literal. The table stores typed source constants and formulas, not a saved namespace packet. In particular, the four unsuffixed chemical literals first round to source REAL32 and then widen to FP64; their bits remain `0xc0f869fe60000000`. Source-unwritten bytes retain zero.

The helper uses integer operations with no stack frame, floating-point calculation, allocation, external call or original global storage. It uses x0–x17 and preserves x18–x29, all SIMD registers, SP, FPCR, FPSR and errno. Compile it with the existing `selected_inactive_grid_default_tables.inc.S` from the same source directory.

The enclosing [configuration check](operational_grid_field_configuration.md) compares four complete source/direct records and all control effects, with zero differing bytes and all six native ABI masks zero. Whole-source inverse checks preserve every old helper instruction and table after reversing the entry rename and count 9 to 8. The qualified table checker and unchanged scientific evidence are reused; no new physical calculation is introduced. The first parent packet's old eight-field-helper rejection remains failed in local records. No complete original-body, enclosing model or forecast claim is made.
