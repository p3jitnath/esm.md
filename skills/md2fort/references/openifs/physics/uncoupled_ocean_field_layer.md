# Uncoupled Ocean Field Layer

NEMOADDFLDS_LAYER prepares sea-surface and skin-temperature views for exchange with an ocean model. A view gives an array address and its bounds without copying values. The selected operational configuration has `LNEMOCOUP` false, so the original NEMOADDFLDS child makes no ocean-field update. This component preserves that behavior. It does not enable ocean coupling or change wave coupling.

The [assembly entry](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/physics/uncoupled_ocean_field_layer.S) selects the existing numerical body from [shared source](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/physics/shared_primitive_physics_layer_views.inc.S). Its entry name is `md2asm_surface_ocean_layer_state_r2_7358525`. The original five address arguments use x0 through x4 in this order: TSURF surface record, TMCC coupling settings, KDIM dimensions, SURFL local surface record and PSURF surface views. Their complete record sizes are 18224, 7584, 192, 2096 and 13680 bytes. All records are mapped, eight-byte aligned, nonwrapping and disjoint from their complete physical-array owners. SURFL is unused but remains a live caller-owned record.

L is not consumed by this disabled ocean stage. The first and last active columns lie within P, or are one and zero for an empty interval. The caller establishes these bounds before entry.

The complete descriptors, field records and backing arrays remain mapped and live. Each complete byte extent and address must stay within 64-bit range. Temperature units are kelvin, but no physical value is read or changed while coupling is disabled.
