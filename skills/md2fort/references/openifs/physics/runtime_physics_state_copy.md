# Runtime Physics State Copy

This entry implements the original STATE_COPY assignments. It copies the active columns of each enabled atmospheric field at every layer. The velocity fields U and V and temperature T are always copied. The output mask selects ozone, water vapour, the model field A, four cloud-water components and turbulent kinetic energy. A mask is a set of true or false values that selects which fields change. Disabled fields and inactive columns keep their original bytes. The routine changes no physical value or unit.

The application binary interface is `md2asm_copy_runtime_physics_state(dimensions, input_state, output_state, policy)` in x0 through x3. Dimensions is the complete 192-byte original record and each state is the complete 1,240-byte original record. Policy is a 16-byte caller-owned record whose first word points to an int32 false LHOOK flag and whose second word is reserved zero. This replaces the original OpenIFS hook-global dependency. All records and field owners require eight-byte alignment. The hook flag requires four-byte alignment. Complete records and owners must be mapped, nonwrapping and live through the call. Field buffers must follow the original association rules, with complete disjoint owners except identical in-place views declared by the caller.

The live column count P ranges from 1 through 1024 and the layer count L ranges from 0 through 512. The first active column ranges from 1 through P+1 and the last ranges from one less than the first through P. Each consumed FP64 descriptor is contiguous, with column bounds 1 through P and layer bounds 1 through L. The cloud array has a third dimension with 4 through 64 components. Source constants select liquid cloud water, ice cloud water, rain and snow at component indices 1, 2, 3 and 4. These indices are fixed source parameters, while P and L are live grid dimensions. Ordinary field owners need 8PL bytes. A cloud owner with C components needs 8PLC bytes. Zero layers and an empty active interval leave every output byte unchanged.

A preparation pass checks every consumed input and output descriptor and the selected controls before any field store. Return zero means success. Return two rejects unsupported input without a public byte change. The descriptor-based copy body retains its original source order and copies each full 64-bit word. The 160-byte aligned frame preserves the required saved Arm registers, while x18 is unused. Production has no imports, original OpenIFS symbol, allocation or floating-point operation. Incoming FPCR, FPSR and errno therefore remain unchanged.

The new source and native cases compare 833,888 complete output bytes with zero differences. They cover 17 columns with 137 layers, 8 columns with 5 layers, mixed masks, shifted and empty intervals and zero layers. Independent copy and unchanged-cell checks cover 104,236 words, including signed zero, subnormal values and arbitrary bit patterns. All input fields and complete state records remain exact. The main cases and a separate nonempty refusal suffix pass 36 new ABI and raw-state observations and 18 atomic refusals. The same unchanged original STATE_COPY binary supplies nine separate verification calls. No original main executable is rebuilt. Complete state construction, parent forwarding and the forecast remain separate qualifications.

The direct [assembly source](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/physics/runtime_physics_state_copy.S) follows this interface.
