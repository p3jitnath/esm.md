## Final History Arrays

The setup-state stream now ends with an append-only history section. RSAVEDP stores the earlier longitude and latitude of moving air, in radians, and its dimensionless vertical coordinate. SAVTEND stores the two wind-component rates in metres per second squared and the temperature rate in kelvin per second. The existing [dynamic-storage contract](../dynamics/forecast_dynamic_storage.md) defines their live dimensions and owner lifetimes. Output copies these complete arrays without changing any numerical value.

The little-endian section starts with the eight-byte marker `R19HST01`, followed by three unsigned 64-bit words giving format revision one, owner count two and the live MODEL address. Each owner then has three unsigned 64-bit words for its MODEL descriptor offset, live data address and payload byte count, followed by every payload byte. Descriptor offsets 1565736 and 1577528 identify RSAVEDP and SAVTEND in that order. Extents come from the actual array descriptors. Their common shape is rows by levels by three components by blocks, with rows stored contiguously. The current T21 run writes 941,184 bytes for each owner. Stored addresses are metadata and require an explicit owner correspondence across processes, while numerical payloads compare directly.
