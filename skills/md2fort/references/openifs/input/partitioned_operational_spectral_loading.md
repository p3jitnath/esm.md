# Distributed Spectral Initial-State Loading

This utility loads the TCo1279 initial wave coefficients into the [owned distributed spectral record](../setup/distributed_spectral_field_storage.md). A coefficient is one stored wave value. The file has 413 records, each with 1,639,680 real FP64 words. FP64 means the 64-bit floating-point format. The order is logarithmic surface pressure, then vorticity, divergence and temperature for each of 137 global levels, then orography. The [qualified reader](initial_spectral_field_reader.md) and its public ecCodes calls remain unchanged. The [global placement contract](operational_spectral_field_placement.md) defines the shared field order and normalization.

Vorticity and divergence use inverse seconds, temperature uses kelvin, logarithmic pressure is dimensionless and orography geopotential uses square metres per square second. Placement copies every stored bit without changing units, normalization or numerical precision. It performs no floating-point calculation. The caller first completes the distributed constructor and retains its record and all owned arrays during loading.

The placement entry is `md2asm_place_partitioned_operational_spectral_fields(values, values_bytes, metadata, metadata_bytes, spectral_record, record_bytes)`. Registers x0 through x5 carry its six arguments under the Arm application binary interface (ABI). Values need 5,417,502,720 bytes, metadata needs 9,912 bytes and the record needs 2,992 bytes. These records and numerical arrays have eight-byte alignment. Integer maps have four-byte alignment. Every complete span is mapped and does not wrap the address range. The record has the constructor's complete valid descriptors, maps, storage bounds and ownership. Writable arrays are disjoint from all inputs, maps, the record and each other. Required spans and metadata are checked before output stores.

MYMS lists the local wave numbers. For a wave number m, NASM0G and NASM0 give its one-based global and local starting word. The wave has `2*(1280-m)` real words. MYLEVS already gives each local level's one-based global level. With a zero-based field number f, where 0, 1 and 2 mean vorticity, divergence and temperature, the input record is `1+3*(global_level-1)+f`. Output levels vary fastest, followed by local coefficient and field. Surface log pressure uses input record 0, and orography uses record 412. The first vertical group has no surface spectral fields, so its one-byte empty owner remains untouched. The second group receives both complete local surface fields.

Return zero completes placement, one refuses a buffer, two refuses metadata and three refuses a consumed record or map. The placement uses a 352-byte aligned stack frame and integer instructions only. It preserves FPCR, FPSR, errno, x18, saved integer registers and vector registers. FPCR controls floating-point arithmetic, and FPSR records numerical events. Thus signed zeros, subnormal values, infinities and NaN payload bits pass through unchanged, including when a nondefault incoming control register is permitted by this integer-copy entry.

The complete loader entry is `md2asm_load_partitioned_operational_spectral_initial_state(path, spectral_record, record_bytes, loaded_orography)`. Registers x0 through x3 carry these four arguments. The caller has already qualified a same-resolution configuration requesting exactly the constructor's three volume fields and two surface fields, with no extra spectral tracer or control-variable branch. This preserves the selected utility's field work, rather than claiming every optional SUSPECG branch. The path is nonempty, ends with a zero byte and has at most 4,096 bytes including that terminator. The four-byte flag has four-byte alignment. The path, flag and record are disjoint from all numerical arrays and maps.

The loader uses a 160-byte aligned frame and owns one 5,417,512,632-byte temporary for decoded values and metadata. It releases that temporary on every returning path. It sets loaded_orography to one only after complete placement. Original SUSPECG selects its present LDSPOR flag before bounding the local surface view, so both vertical groups report selected orography even when one has no local surface coefficients. On failure, the flag and numerical arrays retain their incoming bytes. Return one refuses arguments, three reports temporary allocation failure, `10+reader_status` reports a reader failure and `20+placement_status` reports a placement failure.

The complete loader requires FPCR zero and preserves its incoming control, status and error state, as the selected global utility does. Both entries preserve the Arm saved-register rules and use directly emitted AArch64 assembly. Production imports only public ecCodes and C services. The original OpenIFS harness, global objects, numerical routines and verification controls supply no production stage.

All four actual process layouts pass the complete file comparison against the accepted independent C decoder and a separate coefficient-first inverse-map traversal. All 5,417,502,720 numerical value bytes agree, with zero differences, and both empty backing bytes remain unchanged. Two raw-bit profiles also match 2,708,751,361 complete owner bytes, including signed zeros, subnormal values, infinities and NaN payloads. They preserve nondefault FPCR and sticky status bits. Three protected buffer, metadata and map refusals occur before stores.

Twenty-two interface observations pass with native ABI masks zero. Complete loading preserves status 0/24/777, read-only records and maps, allocation guards, unused SP1D values and dummy storage. Refusals of record capacity and temporary allocation preserve complete fields and the flag. A separate failed-open suffix returns 12, releases its single temporary and preserves all caller output. The full accepted file bank is retained without replay. Detailed tools, failed verifier expectations and records remain local. These results qualify distributed spectral loading. The complete model connection, autonomous operational forecast, full memory admission and runtime remain separate.
