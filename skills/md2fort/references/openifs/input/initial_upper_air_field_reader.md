# Initial Upper-Air Field Reader

Revision 1 decodes the frozen coarse forecast's upper-air grid file, ICMGGepc8INIUA. It reads fields above the surface. Specific humidity describes water-vapour mass per unit mass of moist air. Cloud liquid and cloud ice use the same mass ratio. Cloud fraction describes the part of a grid cell covered by cloud. The three mass ratios use kilograms per kilogram, while cloud fraction is dimensionless. These fields retain their decoded units and values.

The file contains 76 ordered records, with 2,048 values on a 64 by 32 Gaussian grid in every record. Gaussian latitudes are a standard set of unevenly spaced latitude rows used by this model. Each of the four parameters has model levels 1 through 19. The parameters are 133 for humidity, 246 for cloud liquid, 247 for cloud ice and 248 for cloud fraction. The record order is humidity at levels 1 through 19, followed by the liquid, ice and cloud-fraction triplet at each level from 1 through 19. A fixed read-only record table lists that exact order. Every parameter and level pair is unique. The caller selects the frozen file; the assembly checks its record labels and sizes.

The application binary interface, or ABI, is int md2asm_read_initial_upper_air_fields(path, values, values_bytes, metadata, metadata_bytes, messages_read). Registers x0 through x5 hold those arguments in that order. Values need 1,245,184 writable bytes, metadata needs 1,824 writable bytes, and the counter needs eight writable bytes. The three output pointers are eight-byte aligned and their fixed written extents are disjoint. The caller supplies a readable path ending in a zero byte and mapped storage.

The output contains 76 consecutive records of 2,048 FP64 values, in raw ecCodes order. FP64 means a 64-bit floating-point value. Each metadata row contains three signed 64-bit integers giving the parameter, level and value count. The count output reports completed records. The reader applies no field conversion, grid reorder, model-state placement or forecast update.

A thin public entry selects the fixed schema and branches to the same private decoder as the [spectral reader](initial_spectral_field_reader.md). Each trusted schema header gives the record count, uniform values per record and complete byte extents. This is a fixed two-file interface, with no caller-provided schema or general parsing framework.

Return codes and failure mutation follow the spectral interface. Code 0 means success. Code 1 rejects a null path or output, misalignment, insufficient capacity, address overflow, output overlap or nonzero floating-point control register. Code 2 reports open failure. Code 3 reports codec, read or handle-deletion failure. Code 4 reports a wrong label, value count, message count or extra record. Code 5 reports close failure. Argument rejection writes no output. Later failures retain the committed prefix and may change the current value record.

The 224-byte stack frame stays 16-byte aligned. The reader preserves registers x18 through x30, the ABI-required vector low halves, both floating-point control and status registers, and errno. It uses only ordinary C ecCodes and libc calls. The original OpenIFS and Fortran routines remain separate reference material.

Five focused upper-air cases and a seeded native ABI check passed. All 1,245,184 decoded value bytes and 1,824 metadata bytes match the independent frozen C codec reference. A standalone assembly command produced the same complete files, with no OpenIFS or Fortran dependency. The shared spectral route also passed its retained eleven-case checker and three ABI paths. Capacity, cleanup, protected bounds and unchanged numerical status are covered by those checks. Detailed schema and check records remain local. This component does not establish complete model initialisation or an autonomous forecast. Monthly surface records and grid-state placement are outside its scope.

The shared decoder now also supports the [surface reader](initial_surface_field_reader.md). The upper-air schema, output bytes and error rules remain unchanged. All five upper-air cases and the seeded ABI path pass against the revised body.
