# Live initial input data bindings

This integer-only service binds five original-compatible scalar names to values from owned initial-file and geometry producers. It supplies no initial fields and calls no OpenIFS procedure. The original SUARG body detects GRIB input and obtains NUDATE from the input message. SUARG line 183 initializes NSTEPINI to zero. For the selected NCONF one route, MOD_INI lines 109 through 135 leave the date and NSTEPINI unchanged.

The ABI is `int md2asm_bind_initial_input_data(const uint64_t pairs[8])`, with the table in x0. Its four address/capacity pairs name the complete headers5232, vertical20400, Geometry sidecar1872 and forecast controls51512 records, in that order. Every range is mapped, eight-byte aligned, nonwrapping and disjoint from the 24-byte destination namespace. The table is also mapped, aligned and disjoint from the destination. Read-only inputs may overlap only when their existing producer contracts permit it.

Headers contain NGRIBFILE 32-bit integer at 28 and NUDATE 32-bit integer at 32. The selected header format is GRIB one or GRIB two, whose owned detector returns NGRIBFILE one. The vertical context contains the actual Geometry in its first 17096 bytes, NFLEVG19 at5224 and the live FP64 TOPPRES in pascals at20328. The sidecar borrows that Geometry through its first pointer and contains the live NLEXTRAP level index at1856. The forecast producer supplies NCONF one at35104 and LECMWF true at39520. The level index is one through19, the date is positive and TOPPRES is finite with its sign bit clear, including positive zero.

The owned static namespace is 24 bytes: NGRIBFILE 32-bit integer at0, NUDATE 32-bit integer at4, NSTEPINI 32-bit integer at8, NLEXTRAP 32-bit integer at12 and TOPPRES FP64 at16. Five OBJECT symbols name these exact words. The service copies the four live values and writes the source-selected NSTEPINI zero only after all checks succeed. Return0 means complete and2 means an atomic input refusal. All inputs remain unchanged. The leaf uses no stack, preserves x18, the callee-saved registers, FPCR, FPSR and errno, and has no external dependency or allocated owner. Rebinding from the same live producer is allowed; no release is needed.

Three complete binding profiles compare all72 output bytes and every input byte, including the retained live R17 producers and distinct date, level and top-pressure edges. Three genuine MOD_INI calls confirm that the selected NCONF one route retains each input date and source-initialized NSTEPINI zero. All native ABI masks are zero. Twenty-six invalid inputs refuse atomically. A nondefault rounding mode and seeded FPSR are retained. The standalone shared leaf has no required library or undefined symbol. Previously accepted header, vertical and atmosphere numerical checks are reused; no setup trajectory or forecast is rerun.
