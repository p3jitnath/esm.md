# Physics Context Block Services

These four services prepare the physics calculation for a block, select its input addresses and release block-local storage. They replace work_views, child_table, end_block and tendency_table in the retained temporary_storage_services.F90. A context holds records and pointers used across these operations. Its complete queried layout spans 119,384 bytes. Existing assembly owns each child method. No original Fortran callable supplies a production operation in these services.

The C interfaces are `void md2asm_physics_storage_work_views(context, block, active, global_start)`, `void md2asm_physics_storage_child_table(context, block, table)` and `void md2asm_physics_storage_end_block(context)`. Context is in x0. Work_views receives three int32 values in w1 through w3. Child_table receives block in w1 and the output address in x2. Table holds 55 eight-byte addresses, spanning 440 bytes. All addresses are mapped and aligned to eight bytes. The context is disjoint from its immutable inputs and output table. Required owned arrays remain live until their declared cleanup operation.

The context retains the shared original layout. Its Geometry, MODEL and surface inputs span 17,096, 4,275,088 and 18,224 bytes. The supplementary typed query records 79 exact offsets, including every surface group, source control, trajectory owner, microwave owner and destination view.
