# Runtime Computed Radiation Grid

This SUECRAD component constructs the octahedral radiation grid from live configuration. An octahedral grid has 20 longitude points on its northernmost row and adds 4 per row toward the equator, then mirrors that pattern in the south. Two surrounding rows at each pole support interpolation. Existing fixed-grid entries remain unchanged.

Creation accepts Geometry, its capacity, MODEL and its capacity in x0 through x3. Geometry has 20,400 bytes and MODEL has 4,275,088 bytes. Both records are mapped, nonwrapping, separate and aligned to eight bytes. The live main latitude count NDGLG is even and lies in 2 through 32,768. NPROMA and vertical levels are not consumed. MODEL.TERAD.LECOMPGRID must be true. Live NRADINT is 2 or 3. NRADRES is either a positive odd value in 1 through 8,191 or zero. Zero selects the complete original NDGLG/2 default table. Unknown default pairs and the source branch NRADRES == Geometry.NSMAX require separate caller handling and return 2 before mutation here. A successful computed grid has an even latitude count N = NRADRES + 1 in 2 through 8,192.

Two fresh owner bases must be null. NRGRI at RADGRID byte 88 contains N four-byte integers with bounds 1 through N and descriptor offset -1. NLOENG at byte 152 contains N+4 integers with bounds -1 through N+2 and offset 1. Both descriptors use the original integer type, four-byte element/span and unit stride. Both allocations complete before the records change. For zero-based row j, the row length is 20 + 4 min(j, N-1-j). Polar values reflect the first and last two rows. The source radiation resolution and scalar fields are published only after both allocations succeed. NRADINT retains its live value. The physical model and interpolation method are preserved.

Return 0 means success, 1 means allocation failure and 2 means an atomic refusal, which leaves public bytes unchanged. If the second allocation fails, creation frees the first owner. Creation and release preserve x18, the required saved registers and incoming FPCR/FPSR. Creation requires FPCR zero and uses a 112-byte aligned stack frame. Release accepts MODEL and its capacity in x0 and x1, uses an 80-byte frame, validates both descriptor shapes and complete owner separation, then frees NLOENG before NRGRI and clears their base words. Repeated empty release succeeds. malloc, free and the public __errno_location accessor are the only external services. All dimensions come from runtime state without rebuilding the original main program.

One unchanged selected-source binary covers six shapes, including the actual main count 2,560 with default radiation count 800, smaller default and explicit grids, and the 2 and 8,192 bounds. Both interpolation controls are exercised, with varied NPROMA and layer metadata. Complete MODEL, owner and raw floating-point status bytes agree exactly. Independent integer checks cover every row, north/south symmetry, total point count and polar copies. Critical checks cover new admission limits, allocation rollback, release, saved registers and buffer guards. The public transform, complete SUECRAD and autonomous forecast remain separate work.
