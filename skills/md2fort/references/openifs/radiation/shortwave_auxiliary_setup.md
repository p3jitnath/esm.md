# Shortwave Auxiliary Parameters

This component owns complete SUSRTAB, SUSRTAER and SUSRTCOP, called in that order by the selected SUECRAD setup after SRTM_INIT. Shortwave radiation comes from the Sun. A transmission value is the fraction of incident radiation that passes through an absorbing path. Optical coefficients describe the extinction, scattering and direction of radiation by aerosols and clouds. These three routines read no upstream configuration or model data. Their source loop counts are fixed at 10,001 transmission entries, 14 spectral intervals and six aerosol types.

The source files are arpifs/phys_radi/susrtab.F90, susrtaer.F90 and susrtcop.F90, with declarations in arpifs/module/yoesrtab.F90, yoesrtaer.F90 and yoesrtcop.F90. The complete owned namespaces are YOESRTAB with 80,032 bytes, YOESRTAER with 2,016 bytes and YOESRTCOP with 4,704 bytes. Their aggregate contains 86,752 bytes and 49 named fields. Each field is an FP64 scalar or contiguous FP64 array; no field contains a pointer or type-dependent padding. The source declaration order defines the new namespace layout, and a genuine typed query verifies each shape and element width. No original module data supplies a production stage.

YOESRTAER contains RSRTAUA(14,6), RSRPIZA(14,6) and RSRASYA(14,6), each with 672 bytes, in declaration order. The first array subscript varies fastest. YOESRTCOP contains 42 arrays of 14 elements and 112 bytes each in declaration order. SUSRTAB stores RODLOW=0.06, RTBLINT=10000 and BPADE=1/0.278, with the final division folded once from the declared FP64 operands. It stores TRANS(0)=1 and TRANS(10000)=positive zero. For each integer i from 1 through 9999, it computes t=i/10000, then the product BPADE*t, then 1-t, then their quotient tau, and finally TRANS(i)=EXP(-tau). Each operation rounds separately to FP64. The source REAL(i) uses the default real kind, but every integer in this loop is exactly representable before promotion to FP64. It multiplies RSASWA by the FP64 value 0.01 and RSASWF by the FP64 value 0.001 inside each interval, giving 28 separate runtime multiplications. These products must not be replaced by decimal text that rounds by another route.
