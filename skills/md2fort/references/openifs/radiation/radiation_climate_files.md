# Radiation climate file selection

This service owns the selected SUECRAD climate-file defaults and NAERAD choices, then applies the DATA path rule used by the three climate readers. It produces controls and filenames, without reading a climate payload or constructing the rest of SUECRAD. Inputs come from owned LEPHYS, LARPEGEF, LRAYFM, ozone LGP and LOPT_SCALAR logical producers. Each logical word is zero or one.

`int md2asm_select_radiation_climate_files(text, bytes, output, capacity, upstream)` receives x0 through x4 in that order. Text contains 1–262144 mapped bytes. Output is an eight-byte-aligned writable 2640-byte record, with capacity at least 2640. Upstream is an eight-byte-aligned 24-byte read-only record of the five int32 logical words above plus a reserved word. Declared ranges must be mapped and nonwrapping; output must be disjoint from both inputs. FPCR must be zero. Return zero means success and two means unsupported input, with the complete output unchanged. The caller owns all buffers; this service allocates nothing and leaves its inputs unchanged.

The first matching group has literal uppercase name NAERAD, and its first nonblank ampersand marker is in columns one through ten. Lowercase group names and markers after column ten are skipped. Member names and logical values are case insensitive. The supported members are NRPROMA, LAER3D, CRTABLEDIR, NHINCSOL, NGHGRAD, LHGHG, NGHGCMIP, NRCP, NSCEN, LEPO3RA, CSOLARIRRADIANCEFILE, CGHGCLIMFILE and CGHGTIMESERIESFILE. Integer tokens have an optional sign and magnitude at most 65535. Logical values use T, F, TRUE or FALSE with optional enclosing periods. Quoted strings contain at most 256 bytes and allow doubled quote characters. Comments, repeated members with the last value retained, and slash group termination are supported. Other tokens, keys and unsupported CMIP choices are rejected. This is the declared source-compatible subset, not a general Fortran namelist reader.

The source initializes climate modes from LEPHYS and LARPEGEF, resolves a negative NGHGRAD from those controls and LRAYFM, and uses LEPO3RA to choose 20 or 21. NRPROMA zero restores its source default, after which the source absolute-value rule applies. Blank filenames select the original solar and climatology names and one of eleven CMIP3, CMIP5 or CMIP6 scenario names. The qualified source control executes both SUECRAD NAERAD reads; their selected climate values are identical. Other source members and changes between those reads remain outside this entry.

The first nine int32 output words, at offsets 0–32, are NHINCSOL, NGHGRAD, LHGHG, NGHGCMIP, NRCP, NSCEN, NRPROMA, LAER3D and LEPO3RA. Bytes 36–47 are zero. Four blank-padded 256-byte source strings start at 48, 304, 560 and 816: solar name, climatology name, time-series name and CRTABLEDIR. Three zero-terminated 512-byte paths start at 1072, 1584 and 2096. Their uint64 byte lengths are at 2608, 2616 and 2624, and the final eight bytes are zero. No pointer or original metadata word is retained.

The public getenv API supplies DATA. Trailing ASCII blanks are removed. A name beginning with a dot or slash is used directly. Another name is prefixed by DATA followed by `/ifsdata/` when DATA is nonblank; with absent or blank DATA, the name itself is used. Embedded blanks stay exact. This selected interface rejects DATA longer than 512 bytes or a resolved path longer than 511 bytes, instead of accepting the source's truncated path. It retains no environment address after return. The caller can pass each owned path and length directly to the climate-context constructor.

The parent uses 2800 bytes of private stack. Its parser uses a further 1168 bytes, for a maximum own depth of 3968 bytes, excluding libc. It preserves x18, required callee-saved registers, stack alignment and FPCR/FPSR. It performs no floating-point arithmetic. Only public libc getenv, strnlen, strlen, memset and memcpy services are used. Their normal errno effects are retained; no source diagnostic I/O is emitted. The separate parser `md2asm_apply_selected_radiation_namelist(text, bytes, record1072)` applies the same bounded group to an existing selection record atomically and has the same input-range obligations.

Thirteen comparisons with genuine POSNAM, Fortran namelist reads and the unchanged SUECRAD filename fragment match all 34320 output bytes. Cases include the live file, absent and blank DATA, inactive physics, both greenhouse choices, all supported scenario endpoints, quoted names, duplicate members and skipped lowercase or out-of-column groups. Native ABI masks are zero, and immediate FPCR/FPSR match; source I/O errno is recorded separately from the raw service. Nine unsupported cases leave output unchanged. Complete text, output and upstream ranges ending at protected pages pass. A separate assembly process reads the live text and matches the retained 2640-byte source result with only libc in its closure. No complete SUECRAD or forecast is claimed.
