# Radiation interpolation interfaces

The grid record stores coordinates and array sizes. The process view stores the association between the four parallel processes. The `RI` record stores radiation-input interpolation maps, and the `SL` record stores the unchanged transport interpolation maps. `NASLB1` is the allocated point capacity. An array descriptor records an array’s address, element size and bounds. The small sidecar record stores ownership information.

These helpers use the Arm application binary interface, which defines how calls pass values. Arguments occupy `x0` onward in the listed order, and the integer return occupies `w0`. Capacities count bytes and use unsigned 64-bit values. Input and output records remain mapped, nonwrapping and separate as required by the enclosing contract. The raw setup and communication helpers are called collectively by the same four processes after the enclosing caller admits their inputs. They do not replace the enclosing collective admission and ownership checks.

The report format `A2` prints two characters, and each `I7` field prints an integer in seven character positions. The language runtime returns its input/output status as `IOSTAT`.

The six main descriptors are NLOENG at Geometry + 7,640, NSTA at +6,088, NONL at +6,176, NPTRFRSTLAT at +6,264, NFRSTLAT at +6,456 and NLSTLAT at +6,520. NLOENG spans −1 through 2562. NSTA and NONL span −1 through 2564 by 1 through 2, with leading dimension 2,566. Region vectors span 1 through 3. The 64-byte process view retains the accepted world size 4, rank 1 through 4, region counts 3 and 2, actual region coordinates, actual region-map pointers, false hook, unit 6 and the selected reporting controls. The enclosing caller proves their live backing spans.

All helper entries preserve the registers required by the Arm ABI, including `x18`, and keep 16-byte stack alignment. Reporting and existing communication libraries retain their natural floating-point status and errno; added admission agreement is transparent. The report's largest nested private frame is 784 bytes; the communication frame is 2,048 bytes plus small local helper frames. The local setup frame is 2,560 bytes plus its children.
