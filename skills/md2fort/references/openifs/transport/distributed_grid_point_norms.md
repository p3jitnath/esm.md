# Distributed Grid-Point Norms

A grid-point norm summarises a field at physical grid points. This GPNORM1 component returns its weighted mean, minimum and maximum, in the field’s own units. It uses the original public transform calculation and copies results to the consuming processes in source order.

`md2asm_runtime_grid_point_norm(G,PGP,KFIELDS,LDLEVELS,label,PNORMS,hidden_length,dependency)` uses registers x0 through x7. The earlier name `md2asm_operational_grid_point_norm` names this same entry. G is the live 20,400-byte geometry record. KFIELDS and LDLEVELS point to 32-bit integers. KFIELDS is 1 through 16 and LDLEVELS is zero. The optional label is absent, its hidden length is zero, and PNORMS is present. The caller selects source profiling false.

Read the block width P, block count B and local physical count N from G at bytes 5144, 5160 and 7376. P is 1 through 4096. B and N are positive signed 32-bit values, with P times B at least N and P times B minus P below N. Thus B is the number of blocks needed for N points. All strides and byte counts use 64-bit integers. The public transform identifier at G byte 5168 must describe this same grid.

The dependency has 32 bytes, with borrowed partition4096 at byte 0, configuration67616 at byte 8, an unused HYD64 address at byte 16 and reserved zero at byte 24. HYD64 may be null. The partition gives a positive process count and a process number from 1 through that count, matching the public communication and transform setup. Configuration selects the spherical grid. All complete records stay mapped through return.

PGP has dimensions P, KFIELDS and B, in that storage order, and needs 8 times P times KFIELDS times B bytes. Only N positions per field are physical points. PNORMS needs 24 times KFIELDS bytes, storing mean, minimum and maximum as three FP64 values per field. These values use 64-bit floating-point arithmetic. Output and borrowed inputs are disjoint. Records and FP64 buffers align to eight bytes, and integer arguments to four bytes. Complete ranges do not wrap around the address space. Backing capacities and valid geometry descriptors are caller obligations. Participating processes agree admission before entry.

The entry constructs GNU array descriptors in a 1,280-byte stack frame and calls public ECTRANS GPNORM_TRANS with LDAVE_ONLY false. With more than one process, it retains the three public FIAT MPL_BROADCAST_REAL8 calls in mean, minimum and maximum order. Tags are 12345, 12445 and 12545, with root process 1 and the original 12-byte labels. Optional method, communicator, error and request arguments remain absent. One process skips these broadcasts, following the source condition. No original OpenIFS routine or global supplies production work.

Return 0 on success or 2 for unsupported input before a collective call or output store. The entry owns stack storage only and has no floating-point instruction. Its application binary interface, or ABI, preserves x18, x19 through x30 and stack alignment. FPCR, the floating-point control register, is zero. Natural numerical flags and system error values remain visible. Enabled outer profiling and recovery from a library’s fatal failure are outside this selected interface.

The original standalone norm checks cover field counts 2, 5 and 10 on four real process maps, with 1,632 result bytes and 288 raw-status bytes exact and 272 independent relations per implementation. The runtime [pressure parent](surface_pressure_mass_correction.md) additionally checks block widths 17 and 31 on that same 9 km grid. The serial broadcast condition has a separate source/interface review. Other physical resolutions and a complete serial-grid forecast remain unverified.
