# Complete Surface State Stream

Revision 1 extracts the qualified standalone surface stream into a reusable assembly function. The stream records the complete live surface state for verification. The caller must complete selected surface startup before writing it and keep every owner live throughout the call.

The ABI is int md2asm_write_selected_surface_state(fd, surface, trajectory, descriptions). Register w0 contains a nonnegative, open Linux file descriptor. Registers x1 through x3 contain the unchanged, eight-byte-aligned outer records of 18,224, 408 and 46,080 bytes. Their complete live ownership graph must satisfy the selected surface startup contract. This function does not validate or construct that graph. The caller retains ownership of the file descriptor and every record.

The byte order is the eight literal bytes SS104OW1, the three complete outer records in argument order, then 104 owner records. Each owner record contains its actual 64-bit address, its unsigned 64-bit logical byte extent and that many payload bytes. Empty owners have a zero extent and no payload. Metadata owners follow source group order: each group field array, followed immediately by its four nested arrays for every layered field. The thirty-four numerical owners then follow the accepted source allocation order. Every integer uses the selected little-endian AArch64 representation. The complete stream occupies 9,350,128 bytes.

Return zero after all bytes are written, or one after invalid basic arguments or a failed or zero-length Linux write result. A failure can leave a partial stream in the caller's file. The function performs no allocation, changes no input byte, uses no floating-point instruction and preserves FPCR, FPSR, errno, x18 and all saved registers. Its stack frame occupies 112 bytes and remains sixteen-byte aligned. Private helpers use the Linux write system call directly, so they do not change the C errno value.

The focused check writes the complete stream from one live owned state, then compares all 9,350,128 bytes with a direct byte observation of those same records and allocation identities. Zero bytes differ, all inputs remain unchanged, the ABI and status pass, and invalid-descriptor and write-failure checks return one. The existing complete source and independent physical gates supply the numerical evidence. No new numerical stage or forecast is introduced.
