# Fixed-width output file names

The direct leaf `md2asm_make_output_name` implements the selected `SUFPOFNAME` and `GET_CLINC` route without the optional PTSTEP input. It receives a read-only 256-byte source name in x0, a separate writable 256-byte destination in x1, the int32 step in w2, signed digit count in w3 and NTIMEFMT in w4. Each buffer must have its complete extent, and they must not overlap. The step is a label already supplied by the caller; no time conversion occurs here.

A positive digit count from 1 through 6 adds a plus sign and the requested trailing digits of the source six-digit integer format. NTIMEFMT zero ends there, one appends :00 and two appends :00:00. A negative digit count from -1 through -16 takes the requested trailing digits of the source sixteen-digit format without a plus sign. Zero digits add no suffix. The latter two branches ignore NTIMEFMT, as the source does. A negative step produces the source overflow stars, and a positive six-digit-format step above 999999 also produces stars. Prefix trimming removes only trailing ASCII spaces; all copied bytes, including embedded zero bytes, remain exact. The complete destination is space padded. Unsupported digit/format choices or a name longer than 256 bytes exit with raw status 116 outside the supported source route.

The leaf uses only caller-saved integer registers and no stack or external service. It preserves x18, saved registers, FPCR, FPSR and errno. Its serial integer counter is the second word returned by `md2asm_output_header_count_get(index)`. Seventeen source cases compare 4,352 complete name bytes and 544 outer boundary bytes, with 34 source/direct ABI/status calls. They include both exact buffer-size edges, zero and negative digits, all three time formats, overflow stars and an embedded zero byte. All bytes agree and all ABI masks are zero. The separate original Fortran formatting control remains verification only.

The [complete forecast comparison](../../../../../src/openifs/README.md#verification) passes for this selected route, with every final owner and saved file compared. Original startup and remaining runtime services still prevent an autonomous-executable claim.
