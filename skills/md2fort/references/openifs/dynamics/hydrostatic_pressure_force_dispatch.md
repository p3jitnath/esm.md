# Hydrostatic pressure force dispatch

This source extension retains the existing hydrostatic grid calculation and adds its original unfiltered branch. The actual model supplies LGRADSP through hydrostatic_grid_controls%filter_pressure_force. The original authority is OpenIFS 48.1.1 arpifs/adiab/cpg_gp_hyd.F90, lines 414 to 442. The selected generated assembly and its existing accepted contract cover the true branch; they do not establish agreement for the new false branch.

GPGRP first calculates two pressure-force arrays. When LGRADSP is false, the wind tendency child consumes these arrays directly. The source does not read, filter or store any pressure-force history. The native false route therefore leaves both current history planes unchanged and does not require the four current or previous history indices.

When LGRADSP is true, each active point retains the existing ordered correction. If S is the new pressure force, A is its previous stored value and B is its current stored value, the corrected value is RN(S - RN(A - B)). RN means one FP64 result rounded to nearest with ties to even. The current history stores S. Both directions retain their existing loop text and all multiplication, addition, subtraction and division boundaries. The surrounding numerical children, allocation order, cleanup and status paths remain unchanged.

The canonical native module, types and routine arguments remain unchanged. Array capacity is 1 to 256 points, the layer count is 1 to 512, and the active interval is first:last, including the declared empty interval. Pressure is in pascals, geopotential is in square metres per square second, wind is in metres per second and temperature is in kelvin. The existing hydrostatic contract defines every complete output owner and its inactive cells. No extra field owner, private byte layout, control default or original scientific call supplies this branch.

The new source and build artifacts are immutable siblings under grid_drivers/hydrostatic_filter_dispatch_revision2 in the local port directory. The inverse source delta reconstructs the previous source exactly. Strict compilation, complete defined-symbol linking and focused instruction and import checks pass. The decompressed canonical module interface is unchanged except for the source filename in its header. No numerical, original-reference, model or forecast call ran. Exact outputs, natural numerical status, physical checks and production-owner agreement remain pending independent verification.
