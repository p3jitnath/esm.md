# Operational Grid Work Initialisation

Before each grid-point calculation, GP_MODEL sets its complete second interpolation buffer, called `PSLBUF2`, to positive zero. This buffer holds values used to move model fields with the flow. The selected model has no interpolation padding, so the earlier conditional write to the first buffer does not run. This stage changes no physical equation.

The Arm interface is `int md2asm_initialize_operational_grid_work(work128,capacity)`, using x0 and x1. The caller supplies the live 128-byte record from [persistent grid work](../setup/operational_persistent_grid_work.md), with all four buffers owned and its original dimensions unchanged. The record must occupy valid memory, be eight-byte aligned, have a nonwrapping address range and be separate from its complete buffers. Its borrowed MODEL remains valid and live. The signed 32-bit NSLPAD field at MODEL byte offset 1574792 must be zero.

The supported shape is 17 columns, 137 layers and 97055 blocks, with 12 scalar-work fields and 3337/1097 interpolation fields. Record byte offset 64 supplies the second-buffer address and offset 72 its 14,479,829,560-byte extent. Allocation flags at offset 112 must be 15, meaning that all four buffers are owned, and the reserved word at offset 120 must be zero. Each condition, the complete range and separation from the record is checked before a write. The caller retains the constructor's other disjoint buffer guarantees.

Return 0 means that every byte of PSLBUF2 is zero. Return 2 means refusal with no output change. Integer paired stores cover the complete buffer, including stored inactive columns, with an eight-byte remainder. The other three buffers, work record and MODEL remain unchanged. The entry has no stack frame, heap, imported service or floating-point instruction. It preserves x18, saved registers, the floating-point control and status registers, and errno, the operating-system error indicator.

The actual-size check inspects every output word after nonzero and negative-zero inputs. Every byte has the required positive-zero encoding. It also checks three refusals, input preservation, protected bounds, the Arm interface, unchanged raw status and release of all five constructor allocations. An independent source review confirms the original complete assignment. Existing constructor and interpolation physics checks are reused. This establishes the required buffer write, with no complete GP_MODEL or forecast claim. Detailed records remain in the ignored local runtime folder.
