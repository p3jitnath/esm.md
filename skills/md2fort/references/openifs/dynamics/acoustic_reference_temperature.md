# Acoustic Reference Temperature

This component supplies the vertical reference temperature for the semi-implicit acoustic-wave calculation. Temperature is measured in kelvin, K. It owns the complete `SITRAM(1:NFLEVG)` allocation from original `SUALDYN` line 113 and the complete original `SUDYN` update at lines 1892 through 1900.

The earlier accepted reference-atmosphere controls preserve the selected ECMWF hydrostatic source defaults: `SITRA=SITR` and `NOPT_SITRA=0`. Every source default branch assigns zero to `NOPT_SITRA`, although the later source update also supports a value of one. The owned first empty NAMDYN admission precedes the controls, and no unhandled override is admitted. This stage consumes those live members and does not derive them from a captured run. Keep the existing controls before this stage, and keep the standard-atmosphere producer before the scaled-temperature branch.

The update follows increasing level number. If `NOPT_SITRA` equals one, divide `STTEM(j)` by `STTEM(NFLEVG)`, round that FP64 division, and then multiply by `SITRA` with a separate rounding. Every other signed 32-bit option value copies `SITRA` to each level, as in the source. The bottom reference temperature therefore equals `SITRA` on both branches. The scaled branch preserves the standard-atmosphere temperature ratios.

The C interface is `int md2asm_initialize_acoustic_reference_temperature(Geometry,geometry_capacity,MODEL,model_capacity)`, with arguments in x0 through x3. Geometry and MODEL contain at least 17,096 and 4,275,088 mapped bytes, have eight-byte alignment, have nonwrapping address ranges and do not overlap. `NFLEVG` at Geometry byte 5,224 supports one through 255 levels. `SITRA` at MODEL byte 1,567,120 is finite and positive. The option is at MODEL byte 1,567,184, and the output descriptor starts at MODEL byte 1,568,704. Its incoming owner-address word must be zero.

Only the scaled branch reads the standard-temperature owner. Its descriptor starts at Geometry byte 3,464 and must be a genuine GNU contiguous FP64 rank-one descriptor, with element length and span eight, unit stride, bounds one through `NFLEVG`, and origin minus one. Its complete owner is mapped, eight-byte aligned, nonwrapping and disjoint from both records. Every consumed temperature is finite and positive. The divided and multiplied results must also be finite and positive. The caller keeps borrowed inputs alive and read-only throughout the call.

The assembly acquires one `8*NFLEVG` byte owner with `malloc`, fills every element, and publishes its ordinary 64-byte GNU descriptor only after the complete calculation succeeds. The published descriptor has bounds one through `NFLEVG`, unit stride, origin minus one and eight-byte FP64 elements. Allocation failure or refused input preserves the complete MODEL. A late arithmetic-domain refusal frees its private owner before returning. Return zero means ready, one means allocation failure, and two means a refused interface or domain.

`int md2asm_release_acoustic_reference_temperature(MODEL,model_capacity)` uses x0 and x1 and the same MODEL bounds. It frees the owner, clears only its data-address word and accepts a repeated call. Keep the owner alive through all forecast consumers, then release it before releasing MODEL. The initialization frame has 64 bytes and the release frame has 32 bytes, both aligned to 16 bytes. Both entries preserve x18 through x29, the return address and the required vector registers. Production calls are limited to `malloc` and `free`.

Use FPCR zero, nearest rounding with ties to even, gradual underflow and signed zeros. Preserve the source division-before-multiplication order without contraction, reassociation or reduced precision. The genuine reference retains the unchanged original allocation and complete update inside a typed wrapper. Verification compares the whole MODEL and complete owner, then independently checks the constant branch, the bottom value and the ratios with bounds that include both source roundings. It also checks the actual upstream-owned temperature profile, both option branches, minimum and maximum level counts, buffer guards, native saved registers, immediate floating-point state, allocation rollback, reverse lifetime and essential refusals. The enclosing changed forecast remains a separate acceptance gate.

The accepted local gate compares both source branches at one, four, current nineteen and 255 levels, plus a non-one option with an unread canary temperature descriptor. It finds zero differing bytes in 38,475,792 complete MODEL bytes and 4,496 owner bytes. Each implementation passes 566 independent temperature relations; the largest error uses 0.180321 of the stated rounding bound. Saved registers, immediate numerical status, input bytes, record and owner guards, repeated release, the one allocation-failure position and nine preflight refusals pass. A focused overflow case confirms late private-owner rollback. The gate uses the accepted owned standard-atmosphere temperatures at their exact saved bytes and the existing live control producer. It does not run a forecast.
