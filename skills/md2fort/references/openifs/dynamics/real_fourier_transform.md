# Complete real Fourier transform contract

Revision 1 covers the non-MathKeisan FFT992 source and its contained RPASSF and QPASSF in OpenIFS 48.1.1. The original path is contrib/ectrans/src/trans/algor/fft992.F90. The normal forecast entry is fft992_, and all eight arguments are ordinary pointers: A, TRIGS, IFAX, INC, JUMP, N, LOT and ISIGN. Integers occupy four bytes; field and trigonometric values occupy eight bytes in native little-endian FP64 format. FP64 represents each numerical value with 64 bits, and little-endian storage puts the least significant byte first. A pointer gives the memory address of an argument.

A is both input and output. Position j of field l is stored at zero-based word offset j*INC+l*JUMP. Each field has N+2 positions, including its endpoint and padding words. The complete observed owner therefore has (N+1)*INC+(LOT-1)*JUMP+1 words. TRIGS has N words; IFAX has ten four-byte words, with its first word giving the factor count. The caller supplies distinct factor and trigonometric tables, which remain unchanged. The forecast callers FTDIR and FTINV use INC=LOT=KFIELDS and JUMP=1. Genuine captured shapes will narrow the normal forecast domain without replacing the complete factor branches.

ISIGN=-1 analyses grid values into alternating real and imaginary coefficients. ISIGN=+1 synthesises coefficients into real grid values. The parent preserves the source endpoint halves, the reverse factor order for analysis, the forward order for synthesis, source-selected in-place passes, alternate scratch views, necessary complete copies and explicit endpoint zero stores. Its scratch array has N*LOT+1 FP64 words. No observer, driver or high-level routine supplies a numerical stage.

Each contained pass has fifteen ordinary pointer arguments: A, B, C, D, TRIGS, INC1, INC2, INC3, INC4, LOT, N, IFAC, LA, IERR and LIPL. These overlapping input and output views retain every original offset and stride. The passes implement factors 2, 3, 4, 5 and 6, plus factor 8 when LA=N/IFAC. The source's merged-loop condition and all symmetry and endpoint branches remain complete. Unsupported factors return IERR=2, and a factor-eight nonfinal pass returns IERR=3. The source has no LOT-greater-than-64 check.

The direct emitter assigns one separate AArch64 operation, from the 64-bit Arm instruction set, to each ordered FP64 sum, difference, product and division. The source's constant square roots are folded to their correctly rounded FP64 bits, as in the canonical strict build, so loading them does not create an extra floating-point status event. A source reciprocal is a runtime separate division. No fused multiply-add, reassociation, approximate division, precision reduction or output normalisation is allowed.

Every native entry preserves x18, x19 through x29, d8 through d15, the stack's sixteen-byte alignment and the caller's return address. It uses only bounded eight-byte loads and stores for fields and four-byte scalar loads and stores for integers. It does not change the floating-point control register, called FPCR, or errno. ## Rounding allowance

A rounding allowance is an error limit for independent physical checks; it does not alter the exact-byte limit. Let $`\epsilon=2^{-52}`$ be the spacing next to one in FP64, and let $`r`$ be the number of binary digits needed to write the positive row length $`N`$. The normal value $`N=64`$ has $`r=7`$. Work with the stored numerical values in each field's stated unit.

The full analysis proof uses $`q=\sum_j\lvert x_j\rvert/N`$, while its synthesis proof uses the sum of the absolute consumed coefficient values. Each independent coefficient or reconstructed value has the fixed absolute allowance $`256\epsilon r\max(1,q)`$. The live synthesis mean uses the source-weighted coefficient sum, in which each interior pair appears twice. The normal energy relation has allowance $`8(256\epsilon r)\max(1,E)`$, where $`E`$ is the row or coefficient energy in the stated squared field unit. These fixed allowances remain separate from zero differing bytes, exact status and canonical zero endpoints.
