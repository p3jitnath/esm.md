# Scalar Output Transform Caller

TRANSDIR_FP converts a requested scalar grid field into spectral coefficients for output. Its original source is arpifs/transform/transdir_fp.F90. The accepted wave basis is described in the [spectral formulation](../../../../../formulations/openifs/dynamics/inverse_spectral_transform.md); this caller supplies the scalar field and selected output sets to its complete direct-transform child.

The Arm application binary interface passes eight ordinary addresses in x0 through x7 and no hidden character lengths. The original source order is retained. The frame uses 2048 bytes, with 16-byte stack alignment. It preserves x18, x19 through x29 and the return address, and uses no floating-point arithmetic instructions. An array descriptor stores its data address, bounds and strides. GNU descriptors retain their declared element sizes, complete bounds and strides. The source-selected grid keeps a 24-row block pitch and the current selected output-set count; source-unselected output bytes remain unchanged.

The scalar grid descriptor PGP is sent to DIR_TRANS argument 14, rather than the wind grid argument 15, PGPUV. Argument numbers start at zero. This changes only the outgoing store destination from stack byte 760 to 752; all source buffers, descriptor words, other addresses and the external transform guard remain unchanged. The current source exports md2asm_transdir_fp_scalar_grid_binding_r2_7358525 and its original md2asm_transdir_fp_7358525 binding at the same address.

The standalone entry obtains its shared output-stage counter through md2asm_selected_output_stage_counts_7358525. That getter must resolve to the current selected-output controller, so the caller updates the same counter backing as the complete graph. It also retains the qualified DIR_TRANS child, module selectors, original hooks and progress services. It is not a closed standalone output calculation.

The retained 19-address call-table probe places the exact scalar grid in PGP, leaves PGPUV absent, increments the shared counter and preserves immediate FPCR, FPSR and errno. FPCR controls floating-point rounding, FPSR records arithmetic flags, and errno is the operating-system error value. The isolated baseline and corrected objects differ by one instruction, with identical constants and ordered relocations. That baseline includes the same shared-counter adaptation, so it does not establish equivalence to every earlier complete FULLPOS library. This publication copy changes comments only and reuses that focused proof. The retained enclosing-parent checks and joint final-state, boundary-status, ABI, completion-count and ten-file gate pass for this selected binding. The binding adds no separate routine credit.
