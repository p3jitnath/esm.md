# Selected norm calls in the forecast loop

This binding connects the selected serial T21 forecast loop to the already checked spectral and grid-point norm utilities. The utilities compute numerical diagnostics, so the binding always calls their numerical bodies. Human-readable printing remains outside this utility scope. No original OpenIFS object, method table, global variable or callable supplies a production stage.

`int md2asm_attach_spectral_norm_context(controls24, results20928, capacity)` borrows six int32 controls and a result buffer of at least 20,928 bytes. The controls are `{NSPPR, LELAM, LREFGEN, LREFOUT, NPROC, LDSPOR} = {0,0,0,0,1,0}`. `int md2asm_attach_gridpoint_norm_context(controls12, results264, capacity)` borrows three int32 controls `{NSPPR,LELAM,NPROC} = {0,0,1}` and at least 264 result bytes. Inputs are addresses in x0 and x1, and capacity in x2. Neither attachment allocates storage or changes the supplied buffers. Controls need four-byte alignment; results need eight-byte alignment. The two result buffers, both control arrays and the persistent spectral state must be disjoint and must not wrap the address space. The attachment checks null addresses, alignment, capacity, scalar controls and these supplied ranges. Mapping, complete record bounds and disjointness from subsequent numerical inputs are caller obligations.

Only one context of each kind can be attached. Reattaching the same controls and result addresses succeeds. A distinct attachment returns 2 without changing either context. `int md2asm_detach_spectral_norm_context(results)` and `int md2asm_detach_gridpoint_norm_context(results)` remove the corresponding borrowed association. A wrong result address returns 2 and retains it; an empty context returns 0. The caller must keep each attached buffer mapped at a stable address and keep its controls unchanged until detach. Detach does not free or clear numerical data. Calls and attachment changes are serial, with no concurrent access.

The void aliases `spnorm_`, `md2asm_spnorm_7358525` and `md2asm_spnorm_optional_false_r2_7358525` take Geometry17096 in x0, GCONF1556112 in x1, TDYNA456 in x2, SPECTRAL2992 in x3 and an optional int32 LDSPOR pointer in x4. The void aliases `gpnorm_gfl_` and `md2asm_gpnorm_gfl_7358525` take Geometry17096 in x0, TGFL1096 in x1 and an optional int32 LDPRINT_TL pointer in x2. Spectral LDSPOR may be null or point to a mapped, four-byte-aligned false word; true is outside this scope. Grid LDPRINT_TL must be absent (null). The source tests its presence, so even present false selects a different four-field list and is rejected before any numerical record is read. The spectral call passes the existing `md2asm_owned_spectral_norm_state` 24-byte namespace to the raw utility; it does not create a second persistent state. The raw contracts retain all numerical record, owner and mapped-range preconditions.

Each alias forwards its input records directly to its qualified raw utility, using the attached result address. A missing attachment, unsupported option or nonzero raw result terminates through the operating-system `_exit(127)` interface, because the original aliases have no status return. A successful call preserves the Arm application binary interface, x18 and the natural floating-point control register, floating-point status register and errno effects of the raw utility. It does not force status flags. Its own stack frame is 16 aligned bytes. Attachment, detach and observation calls use integer instructions and preserve status. `uint64 md2asm_norm_loop_call_count_get(index)` returns successful spectral calls for index 0, grid calls for index 1, and zero for other indices. Counts start at zero.

The spectral raw utility and persistent namespace are the published `selected_spectral_norms.S`, `spectral_norm_arithmetic.S` and `owned_spectral_norm_namespace.S`. The grid raw utility is `selected_gridpoint_norms.S`; its reduction calls the allowed public ECTRANS `gpnorm_trans_` API. Production links no original OpenIFS library. These aliases close call placement and buffer lifetime only; they add no whole-source body credit. Verification reuses the accepted source, arithmetic and independent physical checks and checks only this new live call boundary, complete results, status, bounds and attachment lifetime. The initial binding fixture also checked raw identity for grid present false, which did not establish source equivalence and is outside the corrected scope. Its numerical bytes remain archived; a focused protected-record guard check qualifies the rejection without repeating the grid arithmetic.
