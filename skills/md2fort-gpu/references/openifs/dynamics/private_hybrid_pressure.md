# Parallel Hybrid Pressure on the GPU

The [physical input](../../../../../formulations/openifs/dynamics/hybrid_pressure.md) describes atmospheric layers whose pressures follow the surface and fixed coefficients. The [scientific contract](../../../../md2fort/references/openifs/dynamics/gphpre.md) fixes the full calculation, units and ordered arithmetic. This GPU implementation keeps that method, including the shared top-layer decision, layer-boundary pressures, optional pressure coefficients and optional layer pressures. FP64 means 64-bit floating-point arithmetic.

The [Arm host](../../../../../src/openifs/physics/gpu/hybrid_pressure_host.S) retains the original nine-address application binary interface, or ABI. Its arguments address the allocated column count, layer count, first and last active columns, coordinate coefficients, vertical settings, boundary pressures and two optional outputs. The first eight addresses use registers and the ninth uses the incoming stack. Integers and logical values have four-byte alignment. Pressure arrays and coefficients have eight-byte alignment and store columns first. Their complete bounds and optional-output rules remain those in the scientific contract. The host preserves x18, saved registers, stack alignment, FPCR, FPSR and errno, while allocation and CUDA services supply no numerical stage.

The private GPU call uses a 272-byte record and the [common 64-byte context](../gpu_call_context.md). The first 256 record bytes retain the accepted pressure layout. Bytes 256 and 264 hold an optional source-owned exponential-counter address and capacity. The context word at byte 24 remains read-only. Boundary pressure, optional coefficient and pressure outputs, scratch and a present counter keep their original disjoint storage rules. An owner means a complete allocated buffer. Read-only owners may share storage, and inactive words retain their declared contents.

The [parallel entry](../../../../../src/openifs/physics/gpu/hybrid_pressure_parallel_columns.ptx) uses one block of 32 threads. Each thread owns separate active columns and retains the original increasing layer order within a column. All threads first perform the same admission and top-pressure scan, so their shared top-layer choice is unchanged. Barriers separate admission, complete scratch clearing, output copying and final status publication. Inactive threads reach every barrier. Each helper call retains its original operands, separately rounded result and returned flags. No sum or vertical recurrence is split among threads.

Only the leader publishes final flags, the complete error-event word and the actual exponential-call total. Flags combine through integer bitwise OR, and counters add with unsigned 64-bit wrap. The last nonzero event in the original layer and column order wins. Keep the [accepted serial pressure module](../../../../../src/openifs/physics/gpu/ec_pressure_counted.ptx) and shared IEEE-status, exponential and logarithm providers once for existing callers.

The changed component passes 237 retained and wider-column cases, comparing 745,864 complete-owner bytes with zero differences. Thirteen complete raw-image controls and the corrected event-only control preserve bounds, status, saved registers, inactive words and actual counter wrap. The unchanged 32,455 independent physical relations remain applicable. Detailed source pins and records stay local. Complete GPU forecast acceptance and comparative runtime remain pending.
