# Complete Legendre Analysis on the GPU

The [scientific contract](../../../../md2fort/references/openifs/dynamics/legendre_wave_analysis.md) defines the unchanged wave projection. This calculation converts latitude-dependent fields into coefficients of wave patterns on a sphere. Its coordinates and weights are dimensionless. Each multiplication and addition uses the original ordered FP64 calculation, where FP64 means 64-bit floating-point arithmetic.

The Arm host keeps the original eleven-address application binary interface, or ABI. The ABI defines the argument and preserved registers. It retains the original admission, empty-call return, allocation and release. The private interface has a 160-byte input record, 80-byte capacity record, 64-byte context and 16-byte completion. Its thirteen complete buffer owners, their bounds and eight-byte alignment rules remain unchanged. An owner means an allocated buffer, including bytes that the calculation does not write. The [GPU calling rules](../gpu_call_context.md) define the context and status fields.

One GPU block has 128 threads. Each thread first weights separate latitude and field entries, with a stride of 128 jobs. Both complete scratch halves finish before projection starts. During projection, one thread owns a complete output coefficient. It begins with positive zero and performs all sixteen latitude products and additions in ascending latitude order. Threads share no sum. Block barriers keep weighting before projection and the antisymmetric projection before the symmetric projection. Antisymmetric and symmetric describe the two field halves with opposite or equal signs across the equator. The later symmetric store retains the original overwrite when both output selectors coincide.

Read-only input buffers may share storage. Output, scratch and counters retain the existing separation from input buffers and each other. Inactive threads still reach every block barrier. Only the unique full-grid origin can publish an admission error. The leader updates actual counter words zero and two after weighting, word one after the first projection and word three after the second. The host retains release followed by word four, while an empty call increments word five without launching. Each increment wraps as an unsigned 64-bit integer. Newly raised floating-point flags join through an integer bitwise OR. The event word and errno retain their original effects.

The [host](../../../../../src/openifs/dynamics/gpu/legendre_wave_analysis_host.S) selects the [parallel entry](../../../../../src/openifs/dynamics/gpu/legendre_analysis_parallel_output_entry.ptx) and its [numerical functions](../../../../../src/openifs/dynamics/gpu/legendre_analysis_parallel_output_values.ptx). Keep the [serial entry](../../../../../src/openifs/dynamics/gpu/complete_legendre_analysis_entry.ptx) and [serial function](../../../../../src/openifs/dynamics/gpu/complete_legendre_analysis_values.ptx) once for existing compatibility callers. Link the shared IEEE-status and scalar-arithmetic providers once. No verification wrapper supplies a numerical stage.

The changed component passes fifteen retained complete calls across 667,580 owner bytes and eleven raw controls across 360,448 bytes, with zero differences. Checks include read-only aliases, identical output selectors, nonfinite values, status, preserved registers and actual counter wrap. The unchanged independent transform checks remain applicable. Detailed source pins and results stay local. These component results do not establish complete GPU forecast acceptance or a comparative runtime.
