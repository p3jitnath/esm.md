# Complete spectral north to south derivative

The [scientific contract](../../../../md2fort/references/openifs/dynamics/spectral_latitude_operators.md) defines the unchanged equations, interface and accepted domain. The [physical formulation](../../../../../formulations/openifs/dynamics/spectral_latitude_operators.md) gives the model meaning.

An owner is a complete allocated buffer. A stride gives the distance between neighbouring stored values. FP64 is the 64-bit floating-point format. The application binary interface, or ABI, fixes argument registers and the registers that a call must preserve. The [GPU calling rules](../gpu_call_context.md) define the shared context and status fields.


This GPU implementation moves the complete SPNSDE calculation into one GPU call. SPNSDE forms the latitude derivative of a scalar field stored as spherical wave coefficients. The wave numbers and coefficients have no units. The original five address arguments, empty field return and two selected public and private names remain unchanged. The UVTVD and VDTUV siblings stay literal in their complete shared source object.

The inherited contract accepts integers $`0\le M\le N\le T\le4096`$ and $`0\le K\le4096`$. Each scalar field has a real and an imaginary column. A zero wave order updates only real columns. All original signed GNU row and column strides, gaps and unused shared storage remain supported. Complete address arithmetic fits signed 64 bits. Consumed cells in different arguments must not overlap when either cell is written. Read-only views and unused parts of owners may share storage. No new whole-owner separation is required between model arrays.

The source visits degree $`n`$ from $`N+1`$ down to $`M`$. It first changes the sign bit of the stored $`RN(n-1)`$ word and multiplies it by $`EPS(n)`$. It separately multiplies $`RN(n+2)`$ by $`EPS(n+1)`$. These two rounded coefficients multiply the two neighbouring field rows before their separately rounded sum is stored. Keep every source multiplication and addition. FP64 means the 64-bit floating-point format. Use nearest rounding with ties to even, gradual underflow and preserved zero signs. There is no fused operation, reassociation, approximation or new mathematical method.

One block has 128 threads. Thread zero forms the two coefficients once per degree. A barrier makes the coefficient words visible before columns run. Each thread then owns separate output columns in that degree. A second barrier completes every column before the next degree. Thus overlapping output rows retain the original descending degree order. Nonzero output column stride gives distinct cells within one degree. If that stride is zero, thread zero executes the complete original ascending column loop while the other threads wait. This GPU path preserves general legal alias patterns without rejecting them. There is no CPU numerical fallback.

The private header has 256 bytes and eight-byte alignment. Eight-byte words at 0,8,16 and24 contain EPS, the original RN minus-one base, the input descriptor base and output descriptor base. Words32,40,48 and56 contain the lowest bounded input address, its byte extent, the lowest bounded output address and its byte extent. Words64 and72 contain the complete EPS and RN byte capacities. Signed byte strides for input row, input column, output row and output column occupy80,88,96 and104. Four-byte words 112, 116, 120, 124 and 128 contain M,N,T,2K and column step. Bytes132 through255 are zero. The step is two for M zero and one otherwise.

The bounded input field span covers source row offsets zero through $`N+3-M`$ and columns zero through $`2K-1`$. The output span covers row offsets one through $`N+2-M`$ and those columns. Signed extrema define each lowest address and extent. These ranges can include inactive cells; the kernel changes only original selected cells. EPS has $`T+3`$ words and RN has $`T+5`$ words, starting at original index minus one. The private seven-owner transport retains its qualified 16-byte vector,64-byte context,64-byte record,32-byte completion and two unchanged eight-byte counter owners. These private owners are disjoint from all nested model spans. Model spans may overlap only under the inherited consumed-cell rule.

Admission checks the complete private and nested bounds, exact controls, signed span equations, launch shape and zero reserved words before numerical writes. The original caller supplies valid descriptors and coefficient provenance. The integer-only Arm host packs their original bases and strides and preserves all general registers, all full vector registers, x18, FPCR, NZCV and errno. Sticky floating-point flags are the bitwise union of source operations and incoming flags. No EXP, FAST, WIDE or routine event counter changes. Empty K still reads only the original field-count argument and writes no array bytes.

Component checks compare complete owners, including padding and status, with retained original records. Existing independent physical checks remain applicable to the unchanged equations. The exact component records stay local. Complete forecast acceptance and its wall-time comparison remain separate.
