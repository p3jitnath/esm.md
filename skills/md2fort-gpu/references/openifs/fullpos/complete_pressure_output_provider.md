# Complete pressure-output GPU provider

This bundle supplies the complete pressure-output stages selected by [the shared host](../../../../../src/openifs/physics/gpu/pressure_coordinate_shared_remainder.S). It preserves the original PPFLEV, PPINTP, PPSTA and PPT public arguments, guards, profiling boundaries, storage and ordered arithmetic. FP64 means the 64-bit floating-point format. The [original CPU interfaces](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/fullpos/pressure_interpolation_helpers.S) remain a separate implementation, with no CPU numerical fallback in these GPU stages.

PPFLEV keeps its complete numerical loop serial. PPINTP uses its [guarded parallel-cell contract](pressure_interpolation_parallel_cells.md), while supported model-array aliases retain the original serial GPU route. PPSTA uses its [guarded parallel-cell contract](standard_pressure_output_parallel_cells.md) and otherwise the unchanged serial GPU body. PPT keeps its source stage boundaries and genuine public mathematics calls. Link each of the following modules exactly once. A value module supplies callable calculations; an entry module admits a launch and transfers status.

Each pressure entry takes two unsigned 64-bit addresses: an argument vector and the mapped 64-byte context. The vector contains three addresses for registers, environment and completion. The 832-byte register record is 16-byte aligned. General registers occupy bytes 0–247, original SP occupies byte 248, full vector registers occupy bytes 256–767, FPCR/FPSR/condition codes occupy bytes 768–791, and errno pointer/value occupy bytes 792–807. FPCR is the Arm floating-point control register; FPSR stores sticky arithmetic flags. Remaining bytes are private control storage. Each owner retains its entry-specific alignment, capacity and nonwrapping range checks. The context must already be mapped and readable before its initial error word is inspected.

PPFLEV and PPINTP use a 160-byte environment, 16-byte completion and 64-byte capacity table. Their transport reserves 16384 bytes, including a private source-stack gap; the original 4096-byte source frame follows it. Original argument pointers remain at source SP+256. Public paths retain 24 stored columns, 8 or 24 active columns and the original output-level guards. Four-byte integer views keep their four-byte alignment. Source/model extents are checked from live shape words before model access. Originally permitted model aliases remain valid, while added private owners must be disjoint from model views.

The remaining stage and complete PPSTA transports retain their 4096-byte envelope, 192-byte environment, 16-byte completion, 96-byte capacity table and 2048-byte private gap. The host invokes generic stage modes 0, 5, 6 and 7. Earlier mode definitions remain literal private compatibility entries with no second provider. Every checked range must fit without address wrap and remain representable. Original CPU guards, allocation and public error boundaries remain outside the numerical cuts.

The shared md2asm_gpu_batch_numeric_minmax_status function takes two raw 64-bit operands and an unsigned 32-bit mode: 17 selects maximum-number and 18 selects minimum-number. Its 16-byte return is 16-byte aligned: result at byte 0, new floating-point flags at byte 8 and a zero word at byte 12. It retains signalling-NaN flags, quiet-NaN preference, signed-zero selection and equality rules. It replaces no broad input domain with a finite-only comparison shortcut. Its module also retains the accepted callable norm children and is linked once by all callers.

Unchanged mathematical dependencies are [IEEE operator status](../../../../../src/openifs/support/gpu/ieee_operator_status.ptx), [scalar arithmetic support](../../../../../src/openifs/support/gpu/scalar_exponential.ptx), [exact product and sum](../../../../../src/openifs/support/gpu/exact_product_sum.ptx) and [general power values](../../../../../src/openifs/support/gpu/general_power_values.ptx). Link each existing object once, including when other model stages use it. The [general-power contract](../support/general_power_complete_contract.md) defines its 32-byte result. A pressure caller consumes value, new flags and actual errno writes, while discarding private FAST/WIDE work totals for genuine public POW. FAST and WIDE count two original exact-product rounding paths. Genuine LOG calls retain the Arm 26.01 public library boundary.

The source rounding points, sticky flags, source-ordered errno writes and register obligations remain unchanged. The host restores x18 after each service. Qualification reuses the accepted R23 component batch, complete serial PPSTA packet, parallel PPSTA packet and independent hydrostatic relations. The changed PPINTP route adds four saved packets at two placements, seven full-state serial-GPU comparisons and four prewrite controls, with zero differing owner bytes. Publication adds no numerical replay. Complete-forecast acceptance remains pending.
