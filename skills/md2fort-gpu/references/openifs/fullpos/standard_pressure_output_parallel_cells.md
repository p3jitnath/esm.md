# Parallel standard-pressure output cells

This GPU phase keeps the standard-atmosphere calculation in `md2asm_ppsta_7358525`. Its [original assembly interface](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/fullpos/pressure_interpolation_helpers.S) takes 24 stored cells, 8 or 24 active cells, and 1 through 20 target pressure levels. Pressure is in pascals, temperature is in kelvins, and geopotential is in square metres per square second. FP64 is the 64-bit floating-point format. Each separate FP64 operation retains its rounding point, including signed zeros and gradual underflow.

The [host source](../../../../../src/openifs/physics/gpu/pressure_coordinate_shared_remainder.S) keeps the public arguments, shape guards, profiling calls and four-kilobyte source frame. It also keeps nine CPU LOG calls and their nine coefficient GPU requests in the original order. The shared host source contains the previously accepted PPFLEV, PPINTP and PPT stages as well as PPSTA. Their device providers must be linked once with the serial and parallel PPSTA providers.

The [entry](../../../../../src/openifs/fullpos/gpu/standard_pressure_output_parallel_entry.ptx) takes two unsigned 64-bit addresses: a 24-byte argument vector and the existing mapped 64-byte context. The vector points to an 832-byte register record, a 192-byte environment and a 16-byte completion record. The host also supplies a 96-byte capacity record, a 2048-byte private gap and the original 4096-byte source frame. These addresses are eight-byte aligned; each checked range must fit without address wrap. The context must already be mapped and readable before its initial error word is inspected. The entry uses one block of 256 threads and three collective barriers, which every thread reaches.

One leader classifies the source pressures and forms the original RD/RG ratio. Each active thread then runs one or more independent cells through the [ordered value functions](../../../../../src/openifs/fullpos/gpu/standard_pressure_output_parallel_values.ptx). A thread copies the leader register record and source frame into its own 4928-byte workspace slot. The complete module workspace has 1261568 usable bytes and a 16-byte guard at each end. Its lifetime is the module context; the ordinary runtime serialises these synchronous parent requests.

Parallel execution requires both output ranges to be disjoint from each other, all inputs, the original source frame, constants, transport owners and workspace. Read-only inputs may overlap. Every other originally supported layout uses the unchanged serial GPU body, including a shared temperature/geopotential output owner. It adds no public rejection and no CPU numerical fallback.

Each cell keeps its original branch and arithmetic order. The genuine public POW seam uses the accepted GLIBC 2.38 value, new-flags and errno-event behaviour. Its internal work counts are discarded because the public call changes no FAST or WIDE counter. The genuine LOG calls retain their Arm 26.01 provider. Threads combine new floating-point flags with bitwise OR, then select the last nonzero errno write by original cell position. A write is retained even when its code equals incoming errno. The last source-ordered assignment to D4 and the complete returned register state are also restored. The host restores x18 after each service and preserves its full general/vector register, FPCR, FPSR, condition-code and errno obligations.

Five bounded component calls passed: two saved complete parents, one shared-output serial fallback, and one serial/parallel pair with an errno 34 write followed by zero-error POW calls. All 76925 owner bytes agree, together with ABI, x18, FPCR, FPSR, errno, real counters, private stack addresses and workspace guards. The event control changes a finite RG value only inside verification and restores it after each call. Production constants and physics are unchanged. The 2560 accepted hydrostatic relations are reused; no CPU or Fortran numerical reference was repeated. A separate matched timing used nine alternating repetitions for each route and shape, with every post-call check outside the timer. These component results do not establish complete-forecast acceptance.

[The complete pressure-provider contract](complete_pressure_output_provider.md) lists all required source modules and shared mathematical providers. RD is the dry-air gas constant, measured in joules per kilogram per kelvin. RG is gravitational acceleration, measured in metres per second squared. Their live source values remain unchanged.
