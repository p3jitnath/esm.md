The original vector has 26 address slots: TDIMV, first, last, H, FAC00, FAC01, FAC10, FAC11, JP, JT, JT1, mixture cap, water, carbon dioxide, total molecules, tropopause, SELFFAC, SELFFRAC, INDSELF, FORFAC, FORFRAC, INDFOR, solar, absorption, Rayleigh, and solar cosine. Set B=last-first+1 using signed 64-bit arithmetic before narrowing. Support first>=1, last<=2147483646, 0<=B<=4096, and 0<=H<=V<=512, where V is TDIMV's first 32-bit word. Layer arrays have B*V values, cap and cosine B FP64 words, tropopause B INTEGER4 words, solar 16*B FP64 words, and each optical output 16*B*V FP64 words. Integers align to four bytes and FP64 and metadata to eight. Preserve the complete 32-byte dimension record, all input owners, night outputs, points 11..16, and unused levels.

The 80-byte live table record contains ABSA 74880 bytes, ABSB 150400, SELFREFC 1280, FORREFC 512, SFLUXREFC 1152, RAYL 8, LAYREFFR 4, STRRAT 8, NSPA 56, and NSPB 56, in that order. ABSA and ABSB use the actual yoesrta21.eq.1_ and yoesrta21.eq.0_ owners. The other band symbols use __yoesrta21_MOD_ and the two species owners use __yoesrtwn_MOD_. Band 21's species counts at byte twenty are 9 and 5. Ten active points use the original 16-point storage. Live input tables retain their permitted variation.

RN means one FP64 rounding to nearest with ties to even, gradual underflow, and preserved signed zero. In both atmospheric branches compute C=RN(water+RN(STRRAT*carbon dioxide)), p=RN(water/C), and replace p with cap only when p>=cap. Lower mixture position uses x=RN(8*p), while upper uses x=RN(4*p). Set J=INT(x) with truncation towards zero and f=RN(x-FP64(J)). The original MOD(x,1) has these exact bits over the accepted interval, including signed zero. Preserve conversion IXC when x differs from its exact integer round trip. Lower pressure base1/species9/pitch585 and upper base13/species5/pitch1175 give i0=species*(5*(JP-base)+JT-1)+J and i1=species*(5*(JP-base+1)+JT1-1)+J. Form L by adding table[i0]*FAC00, table[i0+species]*FAC10, table[i1]*FAC01, and table[i1+species]*FAC11 from left to right. Form U at those same indices plus one. Then M=RN(C*RN(RN(RN(1-f)*L)+RN(f*U))). Preserve each table coefficient as the first product operand.

Each continuum interpolates F=RN(b0+RN(fraction*RN(b1-b0))). The lower branch forms Dself=RN(SELFFAC*Fself), Dforeign=RN(FORFAC*Fforeign), and gas=RN(M+RN(water*RN(Dself+Dforeign))). Self pitch is10 and foreign pitch4. The upper branch has the distinct order gas=RN(M+RN(RN(water*FORFAC)*Fforeign)). It does not read self payloads. Compute RN(total molecules*RAYL) once per active cell before its ten-point loop. Each primitive rounds separately.

Complete the lower pass before the upper pass, each in increasing layer then column order. Each column has its own private solar-selection integer, initially equal to its tropopause. In each lower cell read both current JP and the next stored level JP. If current JP<LAYREFFR and next JP>=LAYREFFR, replace that column's selection by min(current one-based layer+1,tropopause). At the selected lower layer interpolate solar=RN(s0+RN(f*RN(s1-s0))) from adjacent nine-node solar columns J and J+1. Store gas, conditionally solar, then Rayleigh at every one of ten points. Retain repeated writes and the last actual write. Upper cells change no solar state. A forecast may consume only solar words defined by this source route. Private per-column integers use 16384 bytes of bounded thread-local storage for at most4096 columns; they are never an original model owner.
