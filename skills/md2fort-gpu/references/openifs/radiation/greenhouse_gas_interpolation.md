# Gas Profile Interpolation on the GPU

Revision 1 implements RADGHG::INTERP_GAS from [gas-profile physics](../../../../../formulations/openifs/physics/greenhouse_gas_profiles.md), preserving the [ordered CPU calculation](../../../../md2fort/references/openifs/physics/greenhouse_gas_interpolation.md). Pressure uses Pa. The output is gas mass per air mass in kg/kg.

The eleven original addresses name the first column, last column, allocated column count, latitude-pair indices, latitude weights, climatology layer count, model layer count, pressure descriptor, mass descriptor, model face pressures and output ratios. Support 1–4,096 allocated columns, 0–4,096 model layers and 1–4,096 climatology layers. Columns change fastest. An empty selected range or zero model layers returns before reading unused tables or output arrays.

Blend adjacent latitude profiles as `low + weight*(high-low)` with separate FP64 rounding. Accumulate the rounded climatology amounts from positive zero. Visit model pressure faces in order, retaining the selected monotone interval search and original final-interval extrapolation. Interpolate cumulative amounts, subtract consecutive rounded amounts, then divide by each separately rounded pressure thickness. Keep signed zeros, gradual underflow and full arithmetic status. Consumed pressures are finite and strictly increasing from zero. Weights lie from zero to one and amounts are nonnegative. Returned nonfinite arithmetic retains its natural status without clipping.

[The device entry](../../../../../src/openifs/radiation/gpu/gas_profile_interpolation_entry.ptx) receives the original vector and common 64-byte context. The 32-byte record gives complete pressure and mass owner bases and capacities. Descriptor labels, signed strides and gaps define complete available table spans, including unused logical tails. Scalar integer controls use four-byte alignment and all real cells, descriptors, vectors and records use eight. Check every calculated address and complete span before model or scratch stores. Scratch holds one FP64 prefix per climatology face and needs `8*(NC+1)` bytes for nonempty work, where NC is the climatology layer count. Use one block, one thread and no dynamic shared memory. Mutable output, scratch and metadata are separate from consumed inputs. Readonly owners may overlap.

[Host assembly](../../../../../src/openifs/radiation/gpu/gas_profile_interpolation_calls.S) retains `md2asm_grid_gas_layer`, the original eleven-address ABI, x18, saved registers, aligned stack and actual serial-state query. It supplies no numerical stage. The 32-byte pure return contains flags at 0, error at 4, event zero at 8, one completed-call observation at 16 and reserved zero at 24. This observation is separate from production global counters.

The retained corpus passes 102 original, selected-CPU and GPU calls over 20,432 output bytes, with 3,217 independent relations. Fifty-three refusal cases, a complete ordinary-device graph, native inspection and source peers pass. Seven original zero-layer status differences remain explicit because the selected CPU returns before the original intermediate blends. GPU status matches that selected boundary. Complete RADGHG and forecast acceptance remain pending.
