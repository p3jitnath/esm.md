# Mean Sea Level Pressure on the GPU

PPPMER estimates sea-level pressure from model pressure, temperature and terrain. Pressure is in pascals, temperature in kelvin, and terrain is gravitational potential in square metres per square second. Revision 1 retains all original temperature choices, strict terrain thresholds, the pressure-copy branch and the hydrostatic exponent polynomial followed by EXP. EXP returns the exponential function. The ordinary route supports 1 through 24 allocated rows and the original full, partial or empty interval. The optional QNH mode is absent or false. Consumed pressures are positive and all used values and intermediate results are finite.

The application binary interface (ABI) retains nine address arguments, the 768-byte frame, two preparation rows, constants, hooks, complete owner bounds and original integer guards. Thirty arithmetic, sign and comparison sites use qualified scalar GPU modes. The original conditional selection transports the selected word, and EXP uses its accepted GPU provider and actual counter owners. Each 256-byte temporary call frame retains integer conditions and all source-live upper floating-point registers. The host contains no weather arithmetic, and each FP64 operation keeps its original rounding point, signed zero and gradual underflow.

Sixteen protected original Fortran, selected Arm and GPU calls agree over 2192 output bytes and 8968 read-only bytes. Independent 110-digit checks cover 488 hydrostatic relations with the original Taylor-remainder bound. Immediate status, actual counters, six prewrite controls, complete provider bindings, native instructions and both source reviews pass. Forty-four actual EXP pairs pass independent 120- and 240-digit checks within the unchanged one-ULP limit. An ULP is the spacing between adjacent FP64 values. This is a separate archive member, so accepted post-physics water calculations remain intact. Complete forecast and performance acceptance remain separate.
