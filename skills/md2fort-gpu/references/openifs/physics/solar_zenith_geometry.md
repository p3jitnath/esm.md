# Solar Zenith Geometry on the GPU

COS_SZA calculates the cosine of the Sun's angle from the local vertical. This dimensionless value describes direct sunlight on a horizontal surface. The complete GPU calculation retains the original midpoint and time-average methods, the model and radiation states, polar day/night and sunrise/sunset limits. The [CPU contract](../../../../md2fort/references/openifs/physics/cos_sza.md) records the full physical domain and ordered equations.

The application binary interface (ABI) keeps ten original addresses for three solar-state records, first/last columns, allocated column count, latitude sine, longitude, a logical control and output. The three records need 2,040, 48 and 175,976 bytes. Integer/logical words need four-byte alignment. Real arrays need eight-byte alignment and contain one 64-bit floating-point (FP64) value per allocated column. Support one through 4,096 columns, contained partial/empty ranges, latitude sine between negative and positive one, and longitude from zero to two pi radians. Time averaging retains the source's centred-time and single-illuminated-period conditions. Preserve inactive output cells and complete readonly owners.

One serial GPU thread uses a 64-byte common context, a 128-byte record and eight bytes of private work per allocated column. The record holds ten owner capacities, then the source pi and day-length pointer/capacity pairs, with two zero reserved words. The trace identifier stays unchanged. The device prepares active results privately and commits after all selected columns succeed. Bounds, alignment, original controls and writable separation are checked before output. The original ten-address Arm boundary has a 768-byte frame and preserves x18, saved registers, floating-point state and the system error indicator. It accepts serial callers and performs no model arithmetic.

Forty-eight original Fortran, selected-CPU and GPU calls match 2,960 complete output bytes and 8,553,760 readonly bytes, with exact status and ABI. An independent 110-digit sunlight calculation checks 954 relations. Forty-one critical controls, an ordinary-device graph and replay, native instructions and independent source reviews pass. Newly consumed trigonometric arguments pass independent higher-precision checks. The private EC_PHYS alias names this same complete calculation and adds no second routine. This component adds one original routine, with full GPU forecast and timing results still unfinished.
