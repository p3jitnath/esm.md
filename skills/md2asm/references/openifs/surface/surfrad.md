# SURFRAD Wrapper Contract

The [surface-radiation note](../../../../../formulations/openifs/surface/surface_radiation.md) explains the physical fields. The direct [assembly](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/surface/surfrad.S) implements the complete 36-address surf/external/surfrad.F90 wrapper and calls the accepted complete [SURFRAD_CTL calculation](surfrad_ctl.md). A wrapper maps a model's stored fields to a calculation's arguments without supplying an omitted physical stage.

## Inputs and complete calculation

The original argument order is YDSURF, KDD, KMM, KMON, KSECO, KIDIA, KFDIA, KLON, KTILES, KSW, KLW, LDNH, PALBF, PALBICEF, PTVH, PALCOEFF, PCURC, PCVH, PASN, PMU0, PTS, PWND, PWS1, KSOTY, PFRTI, PHLICE, PTLICE, PALBD, PALBP, PALB, PSPECTRALEMISS, PEMIT, PALBTI, PCCNL, PCCNO and LNEMOLIMALB. The scalar integers are signed 32-bit values. Field arrays use the original GNU Fortran descriptors. Their precision, bounds, shapes and physical limits are the same as the complete controller's accepted contract.

YDSURF is an address containing a registered surface-object handle. A handle is an address retained by the model so that later calls can find a stored object. ALLO_SURF originally registers C_LOC of the complete surface object, so the token is the object's own address. The qualified token remains registered, aligned and immutable for the complete call. Storage has 11,584 bytes. The measured member offsets are TCST 3,816, TLW 4,960, TSW 10,096, TRAD 6,376, TRDI 6,424, TSOIL 7,680, TFLAKE 4,104 and TURB 11,112. The native wrapper uses these measured addresses directly. Allocation, registration and release happen outside numerical execution and are not supplied as a missing calculation by the verifier.

Preserve every original array-size check. The first dimension of each field contains at least KLON cells. PFRTI and PALBTI contain at least KTILES columns, PALBD and PALBP contain at least KSW columns, and PSPECTRALEMISS contains at least KLW columns. The complete controller additionally enforces its accepted coefficient columns, shapes, data kinds, array bounds and distinct-owner rules. Resolve the eight scheme members, then pass all 43 original controller addresses in order, including the final coupling switch. The complete child supplies all reflection, emission and cloud-particle calculations, with its complete canyon child and accepted bounded math routes.

## Arm interface and output

The first eight addresses use x0 through x7 and the other 28 addresses start at the caller's stack pointer. A 768-byte aligned frame stores the original addresses and the complete outgoing 43-address call. Preserve saved registers, the return address, stack alignment and control register. The child preserves the exact original status and value bits. Null or misaligned ordinary addresses, a null handle, unsupported field sizes and overlap with the immutable scheme object are rejected before a public write. The domain requires the original registered-handle lifetime, and does not admit arbitrary addresses as handles.

The canonical output is the same eight complete owners as SURFRAD_CTL, in original order PALBD, PALBP, PALB, PSPECTRALEMISS, PEMIT, PALBTI, PCCNL and PCCNO. Preserve every unselected and padding cell. The private controller and canyon bodies have unique names to distinguish their genuine calls in the paired verifier. These bodies are unchanged direct assembly, and local counting wrappers supply no arithmetic or physical stage.

## Original-first evidence

Four protected original wrapper calls pass 13,016 complete owner bytes and 5,575 independent 120-digit relations, before native emission. The inputs include two albedo schemes and spectral shapes, a single column and cropped fields with nonunit strides. The registered 11,584-byte scheme remains unchanged in every call. The original status is 16 and errno remains 47. Existing controller, canyon and private math proofs are reused. Eight protected native placements pass 26,032 complete owner bytes with zero differences and 11,150 independent relations. Six full 36-address ABI calls compare 17,944 bytes and preserve saved registers, stack alignment, control, inherited status and errno. Ten shared-owner entry rejections leave all 3,808 public bytes unchanged per case. Four paired calls compare 13,016 bytes, 50,592 complete controller input and output trace bytes, and 672 selected canyon trace bytes. They count four genuine source and native calls to each complete child. Two profiled pairs add 4,032 complete bytes with exact status and errno. A source-first physical rejection leaves every public byte unchanged. Startup and a complete pair from /tmp pass, with absolute helper-library paths. Actual forecast acceptance remains pending.
