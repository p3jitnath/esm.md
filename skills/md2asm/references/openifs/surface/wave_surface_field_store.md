# Wave Fields Returned To The Surface

This component implements the original WVRG2XF assignment from arpifs/phys_ec/wvrg2xf.F90. The wave model returns one value for each local point and field. The component copies each value to the matching blocked surface field. A block is a short group of horizontal points. This copy performs no numerical arithmetic and must preserve all 64 bits, including signed zeros and NaN payloads.

The direct interface is `int md2asm_store_operational_wave_surface_fields(surface, surface_bytes, fields, fields_bytes, field_count, point_count, block_width)`. The seven arguments use x0 through x6. Surface is an 18224-byte TSURF record, with its accepted final-address SD_WS and YSD_WS descriptors. The input is a contiguous column-major array with point_count rows and field_count columns. The caller keeps the complete record, pointed-to descriptors and owners alive through the call. All buffers are mapped, align to eight bytes, are disjoint and do not wrap.

The accepted SD_WS descriptor is dense, with lower bounds one and dimensions block_width, surface field count and block count. YSD_WS holds a dense 64-byte field-record array whose MP word selects a destination surface column. Every consumed MP lies from one through the surface field count. The constructor accepts 1 through 9 returned fields, 1 through 1024 points per block and zero through 6599680 local points, bounded by the declared destination owner. It derives the final active rows from point_count and preserves all unused columns, final-block padding and descriptor bytes. No input value is used to choose an implementation path.

Original field units remain unchanged. The selected run can include the dimensionless Charnock roughness parameter and surface Stokes velocities in metres per second. This stage only moves their stored values and does not change their physical definitions. Source metadata determines which fields are active.

Return zero after a complete copy. Return two before destination mutation on invalid capacities, dimensions, canonical metadata, field maps or overlap. FPCR must be zero. The leaf has a 96-byte frame and has no allocation, imported symbol or numerical dependency. It uses caller-saved integer registers and preserves x18, x19 through x30, the low halves of v8 through v15, FPCR, FPSR and errno.

Qualification compares the complete target owner with original WVRG2XF for the actual 1649920-point,17-wide, three-field shape and a small remapped final block. It independently checks each copied field and unchanged padding, full guard bytes, metadata, raw status and the application binary interface. Include an empty case and only refusals needed to protect the declared buffer contract. Full coupled forecast acceptance remains separate.

This is the [field-assignment leaf](../../../../../src/openifs/surface/wave_surface_field_store.S). Its enclosing coupling caller still supplies the original profiling boundaries and live wave-model results. The accepted four source/native cases compare 39,599,568 complete destination bytes with zero differences and check 4,949,777 independent bit assignments, 15 raw-status observations and seven atomic refusals. The actual local grid has 1,649,920 points, block width 17 and three returned fields. Empty and remapped final blocks are included. The publication changes only source comments and prose, reproducing the complete accepted object without replaying its numerical bank. This result does not decide which wave-model library boundary the complete forecast permits.
