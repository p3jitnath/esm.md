# Bounded original-compatible tangent

The physical input is [the bounded angle formulation](../../../../../formulations/openifs/support/angle_tangent.md). The unique direct entry is `md2asm_tan_original_rounding(double)`. It accepts finite binary64 radians with magnitude at most the binary64 word `400921fb54442d18`. The caller must use a zero Arm floating-point control register (FPCR), which selects round-to-nearest, gradual underflow, and the declared floating-point settings.

The frozen graph is GNU libc 2.38 `sysdeps/ieee754/dbl-64/s_tan.c` from commit `36f2487f13e3540be9ee0fb51876b1da72176d3f`. It uses 21 source constants and the complete 186-row table of four binary64 words per row. The small argument, direct table, reduced tangent, and reduced cotangent branches are complete within this bound. Larger argument reductions are outside this helper's contract.

Each ordinary multiplication, addition, subtraction, and division rounds separately to binary64. Where the original math route rounds a product plus a sum once, the accepted integer helper `md2asm_round_product_sum_candidate` produces that same bit pattern. The direct assembly uses no hardware fused floating-point instruction, approximate division, reassociation, or lower precision. These explicit math boundary operations do not change the separate arithmetic required in the caller.

For tiny inputs the original returns the input. A nonzero subnormal also evaluates its square to preserve the original underflow and inexact status. The helper preserves signed zero, existing floating-point status bits, FPCR, and `errno`. Unsupported inputs abort before arithmetic. It exports no global `tan` symbol.

The scalar Arm application binary interface uses D0 for the input and result. The 336-byte stack frame is aligned to 16 bytes. The helper preserves X19 through X29 and the low 64 bits of D8 through D15. It has no caller-owned buffers. Its only numerical child is the unchanged private integer rounding helper, linked with a basename dependency and an absolute runtime search path.

Before assembly emission, 41,106 original calls covered every bounded source branch, table boundaries, both sides of the pole, signed zeros, normal and subnormal tiny values, and fixed random angles. The complete 328,848 result bytes and fresh status matched the ordered graph, with unchanged `errno`. An independent 180-digit sine and cosine calculation checked 123,318 relations and found a maximum sampled error of 0.534121 units of last place. This sample result is not a proof of an error bound for all finite inputs. The direct helper then passed the same complete corpus with zero differing bytes and exact fresh status and errno. Its immediate scalar interface passed 44 calls, 42 sticky-status cases, eight unsupported-input guards, and three calls from another working directory. These checks and their failures are retained locally.
