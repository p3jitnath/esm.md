# Scalar Exponential With Original Rounding

The exponential function returns e raised to a dimensionless input x. This support child is needed by standard-atmosphere setup in SUSTA. The direct entry md2asm_exp_original_rounding takes x in d0 and returns one FP64 result in d0 under AAPCS64. It has no numerical buffer arguments. The original arithmetic reference is the frozen Arm optimized-routines scalar exp.c and exp_data.c at commit 649ccc8411e7c4862965710f25c570d854a1483f. Exact source identities and the retained separate C control are retained in the local source-identity record.

Use nearest-even rounding, gradual underflow, FPCR zero and the original signed-zero and NaN behaviour. Preserve incoming sticky FPSR flags and add the original numerical exception flags. Normal results preserve errno. A finite result that overflows to infinity or underflows to zero sets the C range error value 34. The positive infinity input returns positive infinity, negative infinity returns positive zero, and NaNs use the source expression one plus x. Required saved registers, x18 and stack alignment are preserved. The ordinary path is a leaf; range-error handling uses a 64-byte frame and calls only __errno_location to find the C error slot.

The source configuration is N = 128, polynomial order five, no wide polynomial, no narrow integer conversion, HAVE_FAST_FMA = 0, HAVE_FAST_ROUND = 0, WANT_ROUNDING = 1 and WANT_ERRNO = 1. Each operation has its own FP64 rounding point. No FMA, contraction, reassociation, approximate division or external numerical fallback is permitted. Frozen table words are copied as literal data; no stored forecast result replaces a calculation.

For ordinary inputs, compute z = x times the frozen constant N/ln(2). Add the frozen shift 1.5 times two raised to 52, reinterpret its bits as the source unsigned integer ki, and subtract the shift to recover rounded k. Compute the remainder in source order: x plus k times the high negative ln(2)/N constant, then plus k times its low constant. The low seven integer bits select a table pair containing a small correction tail and an adjusted scale word. The upper scale bits receive ki shifted left by 45 bits.

Let r be the remainder and r2 its separately rounded square. Evaluate tmp in this exact tree: tail plus r; plus r2 times (C2 plus r times C3); then plus (r2 times r2) times (C4 plus r times C5). Return scale plus scale times tmp, with a separate product and addition. The four hexadecimal coefficients and all 128 table pairs are the original literals recorded in the [exponential tables](../../../../../src/openifs/support/exponential_tables.S).

For absolute x below two raised to -54, return one plus x without the general reduction. Absolute x at least 512 uses the source adjusted-scale path. Positive k subtracts 1009 from the scale exponent and multiplies the separately computed scale correction by two raised to 1009. Negative k adds 1022 to the scale exponent, applies the source high/low correction before subnormal rounding, explicitly raises underflow when required, and multiplies by two raised to -1022. Finite absolute x at least 1024 uses the original overflow or underflow multiplication. These operations retain every source intermediate rounding point.

The focused verifier reuses the retained RADCFG step-zero log-surface-pressure owner as actual EXP operands and its captured surface-pressure return bytes. It also checks the shift-reduction boundaries, all table slots, tiny inputs, normal/subnormal transitions, zero-underflow and overflow boundaries, infinities and NaN payloads against the separate C control, including raw FPSR and errno. One independent high-precision exponential check measures error in units of the result's last place and checks positive finite results. Native register checks cover ordinary and error paths. No model run is added. The enclosing standard-atmosphere constructor and the selected complete forecast check pass.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected route. Its declared upstream data and branch limits remain in force.

## Paired Ordinary Exponential

The [paired helper](../../../../../src/openifs/support/paired_exponential.S) accepts two independent dimensionless FP64 values in `q0` and returns their exponentials in `q0`. FPCR must be zero on entry. Integer guards accept exact positive or negative zero, or a magnitude from $`2^{-54}`$ inclusive to $`512`$ exclusive. Success returns `w0=0`. A refusal returns `w0=1` before floating-point work and preserves `q0`, all input memory, FPSR, `errno` and the shared EXP counter. The caller sends refused values to its accepted scalar assembly path.

Each lane uses the same shift reduction, ordered remainder, frozen table pair, polynomial tree and separate final multiply and add as the scalar ordinary path. Integer loads select table words independently for the two lanes. At exact zero, reduction selects table zero, the polynomial is exact zero and the scale is one, so the result is exactly one with no new flags. No floating-point comparison, special-case arithmetic or external call occurs inside this admitted path.

The raw entry is `md2asm_try_exp_pair`; the counted entry is `md2asm_try_exp_pair_counted`. Both preserve all 128 bits of `q8` through `q15` and `q24` through `q31`, as well as `x18` and the standard saved registers. The raw entry has no counter effect. Counted success adds two modulo $`2^{64}`$ to the existing scalar alias counter after both lanes pass admission. Counted refusal leaves that counter unchanged.

The focused verifier reuses the 1,868 accepted scalar input words, pairs distinct table indices and reverses lane order under eight incoming status seeds. It checks raw and counted entries against the retained separate C control, including exact result bytes, refusal preservation, immediate FPSR and `errno`, counter wrapping and the full private vector ABI. The main 60,416 calls and the 672-call isolated boundary supplement pass with zero differences. The supplement isolates zeros, admission neighbours, infinities and NaN payloads so a refusal in the other lane cannot hide an accepted boundary. No new independent accuracy claim is needed because each admitted lane retains the qualified scalar arithmetic.
