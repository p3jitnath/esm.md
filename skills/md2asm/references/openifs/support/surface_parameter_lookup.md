# Owned surface parameter lookup

A surface handle is the stored address of the surface parameter record. The original YOS_SURF GET_SURF searches its allocation list for that address and returns the same record pointer. The selected standalone forecast owns one live MODEL. Its complete SUPHEC producer writes the owned surface address to MODEL.TEPHY.YSURF at byte 1,578,328, and clears that word when it releases the object. The public entry exposes the current MODEL pointer through md2asm_owned_initial_model_owner.

The original-compatible entry __yos_surf_MOD_get_surf receives the address of one mapped, eight-byte-aligned handle word in x0 and returns the matching surface record pointer in x0. The current MODEL and its surface owner must be live. The getter reads the handle and the actual owned MODEL field, requires the same nonnull address, and changes neither record. It supports the one-model forecast lifetime. An invalid or unrelated handle follows the original fatal-error policy through libc abort. The original allocation list, constructor and getter are verification-only.

The integer leaf uses no stack and preserves x18, all saved integer and floating-point registers, FPCR, FPSR and errno. It calls no service on the valid path. Verification compares returned pointers against genuine ALLO_SURF/GET_SURF instances, checks the unchanged complete MODEL and input word, and uses the existing raw ABI probe. Fatal-path checks cover absent ownership, a null reference and an unrelated handle. No numerical source calculation or forecast is required by this pointer interface.

Two genuine source allocations and lookups return exactly the same handle bits as the direct getter. Each case retains all 4,275,088 MODEL bytes and its eight-byte input word. Both incoming FPSR 0 and 24 remain unchanged with FPCR 0 and errno 777, and the native ABI mask is zero. All three fatal ownership cases terminate with the expected abort signal. The independent source/ABI peer passes. No model forecast or numerical-source calculation was run.
