# Live forecast timer initialization

The selected SUTIM data stage obtains three current times from the public FIAT USER_CLOCK interface. RSTART is total CPU time in seconds, RVSTART is vector CPU time in seconds, and RTIMEF is wall time in seconds from FIAT's clock origin. The direct utility owns the OpenIFS argument placement and destination storage. It omits human date/time printing, environment selection for that printing and profiling. This is the complete consumed timer-data stage, with no whole SUTIM body credit.

`int md2asm_initialize_forecast_timers(result, capacity)` takes a caller-owned mapped, eight-byte-aligned result address in x0 and capacity in x1. The result contains 24 bytes, ordered RSTART0, RVSTART8 and RTIMEF16. The utility rejects null, misaligned, short or wrapping ranges with return 2 before mutation. It trusts that the complete range is writable and does not overlap the stack or live external state. It calls USER_CLOCK once with `{result+16, null, result+8, result}` in x0 through x3. The second optional argument is absent. Return 0 means the clock call has returned and all three FP64 words contain its actual values.

The utility uses a 32-byte stack frame and preserves the Arm ABI, x18 and the natural FPCR, FPSR and errno effects of the public clock API. It does not force status flags or supply zero timer values. The optional namespace owns one 24-byte record with three original GNU object aliases over those same bytes. The caller initializes that stable record before STEPO and keeps it alive through reporting and the forecast loop. Do not reset it between steps; later accepted source calls own subsequent updates.

The genuine source control compiles the unchanged SUTIM source with a separate reference YOMTIM namespace. A verification-only observer forwards every USER_CLOCK call to actual FIAT and records its four argument addresses, returned values and immediate status. Source and direct calls each preserve every returned clock byte. Their observations occur at different real times, so no byte-equality claim is made across those different external inputs. The changed interface checks compare each complete 24-byte state with its own actual external observation, check nonnegative finite times, fresh and preseeded status, protected output bounds, atomic rejections and ABI preservation. The genuine source call can expose the retained FIAT x18 clobber (mask 2 on its first clock call); the direct utility saves and restores x18 across that external call. The production graph contains only direct assembly plus public FIAT and its permitted runtime dependencies, with no original OpenIFS state or callable.
