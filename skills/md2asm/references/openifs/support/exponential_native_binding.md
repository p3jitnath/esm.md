# Native scalar exponential names

This assembly adapter exports the original scalar `exp` and `__exp_finite` interfaces. Both names receive one dimensionless FP64 input in d0 and return its exponential in d0. They tail-jump to the independently checked direct body `md2asm_exp_original_rounding`, whose numerical source and full special-case arithmetic remain unchanged. That body follows the pinned original Arm scalar implementation with FPCR zero, gradual underflow, preserved signed zeros, source NaN behaviour and source FPSR/errno results.

The alias entry increments one uint64 counter using only caller-saved integer registers x9 and x10. It then jumps directly to the numerical entry. It uses no stack and preserves x18, saved registers and the incoming numerical input. The getter `uint64_t md2asm_exponential_native_count_get(void)` returns the observed alias-call count. The selected serial forecast requires a positive count and records its actual value. Calls to private raw EXP children are outside this alias counter.

The new shared library contains these aliases, the unchanged direct EXP numerical object and its literal table object. Its only external service is the C error-slot lookup used by the qualified numerical range-error paths. It has no original Fortran callable, constructor, vtable or module-data input. The focused binding check compares both original names against the retained C control for ordinary, tiny, underflow, overflow, infinity and signalling-NaN inputs, with result bits, raw status, errno and saved registers checked. Existing 1,868 numerical cases, 24 retained forecast operands, the independent high-precision result and the numerical source peer are reused. Actual consumed EXP bindings and the selected complete forecast check pass. The __exp_finite alias has separate interface checks but no consumed relocation in this case.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected route. Its declared upstream data and branch limits remain in force.
