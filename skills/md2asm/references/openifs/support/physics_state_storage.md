# Physics State Storage

A physics state groups wind, temperature, humidity, ozone, aerosol, turbulence and water-phase arrays. This component constructs and releases their storage records without calculating a weather value. A view describes part of an existing array. These records contain addresses and counts, which have no physical unit. The separate original control is STATE_TYPE in arpifs/module/ecphys_state_type_mod.F90, with field allocation and cleanup from field_registry_mod.fypp and field_module.fypp.

The raw initialization entry is `md2asm_initialise_physics_state(state, geometry, supplied_fields, field_mask, presence, persistent)`. Registers x0 through x3 carry the four addresses, while w4 carries eleven argument-presence bits and w5 is zero or one. The state spans 1,240 bytes, geometry 17,096 bytes, supplied fields 88 bytes and mask 32 bytes. All require eight-byte alignment, mapped storage and disjoint bounds. The mask may exactly alias the state's first 32 bytes. The caller starts with no live owned fields.

Presence bits and supplied-field slots follow U, V, T, O3, Q, A, QL, QI, QR, QS and TKE. A present argument can contain a null field pointer. The mask has eight four-byte logical values in order O3, Q, A, QL, QI, QR, QS and TKE. Copy that complete mask first. U, V and T use a supplied field whenever present. O3, Q, A and TKE use one only when its argument is present and its mask is true. Each other field in these seven positions receives a new owned three-dimensional field. QL, QI, QR and QS use supplied fields when present and null otherwise. Always allocate a new four-dimensional cloud field with five component planes.

Geometry stores the block width at byte 5,144, vertical count at 5,224 and block count at 5,160. Supported counts are nonnegative, with positive block width and block count, and their byte products fit the allocated bounds. The checked forecast uses 24 rows, 19 levels and 86 blocks. Persistent storage uses all blocks. Nonpersistent storage uses one block in this one-thread run and sets the thread-buffer flag. Shapes are [rows, levels, blocks] and [rows, levels, 5, blocks]. The accepted direct registry allocator constructs DATA and PTR descriptors. New numerical values remain undefined until their producer writes them, as in the source.

The typed layout places the mask at byte zero, eleven 88-byte views from byte 32, the 112-byte cloud view at 1,000, eleven field pointers from 1,112, the cloud pointer at 1,200 and seven ownership flags from 1,208. Flag order is U, V, T, O3, Q, A and TKE. Field pointers and views have separate named offsets because their declaration orders differ. Initialization preserves incoming views and the final four padding bytes.

Initialization returns zero for success and one for allocation failure. It cleans newly created fields after a failure and never releases supplied fields. The raw finalizer `md2asm_finalize_physics_state(state)` receives its address in x0, releases the seven flagged owners and cloud field, and clears released pointer slots. Borrowed fields, views, flags and other bytes remain unchanged. Null owned slots support failure cleanup. C allocation, release and error-address lookup are the external system services. No original numerical fallback is called.

The original INIT adapter translates its two-word class descriptor, eleven optional pointer arguments, mask and optional persistent flag. FINAL obtains the raw state from its class descriptor. MASK_GFL_TYPE_INIT copies eight logical arguments, including its last stack argument. Native initialization terminates after an allocation failure. All entries preserve x18, saved integer registers, required vector-register halves, stack alignment, floating-point controls and flags, and the library error value. Initializer and finalizer frames are aligned and bounded.

Six source ownership cases, three masks and 18 seeded calling-interface checks pass. They compare complete source-defined metadata, ownership relationships, borrowed numerical buffers, incoming views and cleanup. Separately allocated addresses are checked through their declared relationships. The complete forecast records 200 direct initializations, 200 finalizations and 25 mask calls. All 685 final owners and ten saved files agree byte for byte. Other physics work records and autonomous construction remain unfinished.
