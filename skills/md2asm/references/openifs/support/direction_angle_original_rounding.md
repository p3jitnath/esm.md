# Original-Compatible Two-Component Direction Contract

Revision 1. The [input](../../../../../formulations/openifs/support/cartesian_direction_angle.md) gives the two-component geometry. The [direct source](../../../../../src/openifs/support/direction_angle_original_rounding.S) implements the complete supported route. The unique direction export is `md2asm_atan2_original_rounding(double y, double x)`. Its separate integer child has the unique export `md2asm_round_product_sum_direct`. It implements the complete finite-input route of the installed GNU libc 2.38 `atan2`, whose scalar wrapper calls `__atan2_finite`. All finite FP64 components, their signs and signed zeros are supported with FPCR zero. The four both-zero combinations use the original axis convention under the observed library mode 2. The incompatible legacy SVID mode 0 for a both-zero pair is rejected before calculation. Non-finite components and other FPCR values are also rejected.

## Ordered Arithmetic

Let $`R(v)`$ round a value once to FP64, using nearest rounding with even ties. Let $`S(a,b,c)=R(ab+c)`$ round the exact product and sum once. The direct integer child `md2asm_round_product_sum_direct` supplies $`S`$ using the previously accepted exact-integer math-helper contract. It has no C numerical dependency. This is fused-result semantics inside an atomic original math call, even though there is no fused floating-point machine instruction. This reproduces the frozen math library's internal rounding points while the weather equations retain separately rounded arithmetic. Every other product, sum, subtraction and division below has its own $`R`$ step. Preserve signed zeros, gradual underflow, floating-point status FPSR and the error indicator errno.

For zero $`y`$, return its signed zero when $`x`$ has positive sign, otherwise return the high part of $`\pi`$ with the sign of $`y`$. For zero $`x`$ and nonzero $`y`$, return the high part of $`\pi/2`$ with that sign. Let $`d`$ be the difference between the two unsigned stored exponent fields. If $`d\ge57`$, return the signed high part of $`\pi/2`$. If $`d\le-57`$ and $`x<0`$, return signed $`\pi`$. Otherwise, when $`d\le-57`$, divide $`|y|`$ by $`|x|`$ and supply the sign of $`y`$. If this result is subnormal, evaluate its square to retain the original underflow status, using the minimum normal value when the result is zero. Set errno to ERANGE, value 34, when a nonzero $`y`$ produces zero.

For the remaining inputs, set $`a_x=|x|`$ and $`a_y=|y|`$. If either magnitude is below $`2^{-500}`$, separately multiply both by $`2^{500}`$. Then, if either magnitude is above $`2^{500}`$, separately multiply both by $`2^{-500}`$. This exact scaling protects the corrected component ratio. Let $`n`$ be the smaller scaled magnitude and $`b`$ the larger. Compute

```math
u=R(n/b),\qquad v=R(bu),\qquad e=S(b,u,-v),\qquad \delta=R(R(R(n-v)-e)/b).
```

Let $`P(w)`$ be the small polynomial. Set $`p=d_{13}`$ and replace it by $`S(w,p,d_k)`$ for $`k=11,9,7,5,3`$, in that order. The six coefficient words are the frozen original literals. For $`u<1/16`$, compute $`w=R(u^2)`$ and $`m=R(uw)`$. When $`x>0`$ and $`a_y<a_x`$, the unsigned result is $`R(u+S(m,P(w),\delta))`$.

The other three small branches use $`z=R(mP(w))`$ and a high constant $`H`$ with its low remainder $`L`$. For a subtraction branch, compute $`t=R(H-u)`$, $`c=R(R(H-t)-u)`$ and $`R(t+R(R(R(L+c)-\delta)-z))`$. Choose $`H=\pi/2`$ when $`x>0`$ and $`a_x\le a_y`$, otherwise $`H=\pi`$. For the addition branch, where $`x<0`$ and $`a_x<a_y`$, use $`H=\pi/2`$, $`t=R(H+u)`$, $`c=R(R(H-t)+u)`$ and $`R(t+R(R(R(L+c)+\delta)+z))`$. These branches have $`H>u`$, so their exact-addition error formulas use the proved larger constant. Each result receives the original sign of $`y`$.

For $`u\ge1/16`$, compute $`i=\operatorname{int}(R(S(u,256,2^{52})-2^{52}))-16`$. The supported ratio satisfies $`1/16\le u\le1`$, so $`0\le i\le240`$. Each immutable row has seven words $`c_0`$ through $`c_6`$. The table is bit-for-bit identical to the accepted one-input ATAN table. For the direct positive-horizontal branch, form the exact-addition pair $`v+v_l=R(u-c_0)+\delta`$, where $`v`$ is its rounded sum and the residual $`v_l`$ follows the original larger-magnitude operand rule. Compute $`p=S(v,c_6,c_5)`$, then $`p=S(v,p,c_k)`$ for $`k=4,3`$. Compute $`q=R(R(v^2)p)`$, $`q=S(v_l,c_2,q)`$, $`q=S(v,c_2,q)`$ and $`R(c_1+q)`$.

For the other table branches, use $`v=R(R(u-c_0)+\delta)`$. Compute $`p=S(v,c_6,c_5)`$, then $`p=S(v,p,c_k)`$ for $`k=4,3,2`$. The three unsigned results are $`R(R(H-c_1)+S(-v,p,L))`$ for either subtraction branch, and $`R(R(H+c_1)+S(v,p,L))`$ for the negative-vertical addition branch. Choose the same high and low constants as the small branches, then copy the sign of $`y`$.

## Scalar Interface And Checks

The Arm application binary interface places $`y`$ and $`x`$ in registers d0 and d1 and returns the angle in d0. There are no caller-owned buffers. Preserve x19 through x29, x18, the low 64 bits of d8 through d15, the stack pointer and FPCR. The private frame is 144 bytes and keeps 16-byte stack alignment. Reads are restricted to the bounded immutable table, constants and the original library-mode record. The only numerical child is the direct assembly integer rounding body in [rounded_product_sum.S](../../../../../src/openifs/support/rounded_product_sum.S), linked into the same library. The libc errno address helper supplies no numerical calculation.

Before emission, an independent 160-digit decimal angle calculation qualified 41,576 original pairs across every quadrant, axis, table-selection tie, scaling threshold, finite extreme, subnormal and signed zero. Its largest observed error is 0.510039 units in the last place, within the frozen one-unit sampled limit. Reuse that accepted original accuracy result for the native gate. Require zero differing result bytes and exact fresh FPSR and errno agreement for the full frozen corpus. The completed native gate passes all 41,576 pairs over 332,608 returned bytes with zero differences in result bits, fresh FPSR or errno. Twenty-three immediate two-input ABI calls and thirty inherited-status cases also pass. The direct integer child separately passes its 6,846-case gate and immediate three-input interface checks. The instruction and dependency review finds no fused or approximate floating-point instructions, no FPCR writes, no x18 use and no C numerical dependency. This is sampled accuracy and does not establish a global correct-rounding bound. Weather callers still need their physical, complete-byte and actual forecast gate.

## Source And Generation

The LLM emits the assembly directly from these equations and the frozen original rounding route. No high-level solver, compiler-generated assembly or intermediate representation supplies the implementation. The original machine instructions are inspected to identify rounding points and instruction requirements, not copied as emitted code. The pinned GNU libc commit is `36f2487f13e3540be9ee0fb51876b1da72176d3f`. Only the missing original ATAN2 source and constant header were retrieved through normal GitHub SSH into this ignored checkpoint. Existing table and integer-rounding proofs are reused unchanged.
