# Selected Perturbation Views

PERTURB_TYPE holds pointers for stochastic physics, which adds controlled random changes to a forecast. The source is arpifs/module/ecphys_perturb_type_mod.F90. This component implements UPDATE_VIEW and FINAL for the selected LSPSDT false and LSPP false path. These two flags disable the original allocated SPPT and SPP copies. There is no INIT method in the original type. All other source pointer decisions remain active and read their original live inputs.

The record spans 1,584 bytes and holds 18 descriptors. MODEL spans 4,275,088 bytes and TSTOPH spans 2,904 bytes in the queried GNU layout. Individual typed queries record every consumed flag, owner and destination offset in typed_layout.json. A descriptor records a data address, element type, shape, lower bounds and strides. Each stride is the distance between consecutive elements along an array index. These are storage quantities without physical units. Numerical values retain their original units and are never calculated or changed by the view methods.

The raw interface is `int md2asm_update_perturbation_views(record, model, stoph, controls, forcing_descriptors)`. Registers x0 through x4 hold those pointers in that order. Controls is five contiguous int32 values ordered IBL, IOFF, ICEND, NPROMA and NFLEVG. They give block index, first global grid point, active point count, allocated block width and vertical level count. Forcing_descriptors is four descriptor addresses ordered GPFORCEU, GPFORCEV, GPFORCET and GPFORCEQ. They are read only when LFORCENL is true. A false flag permits a null forcing_descriptors pointer.

The source flags LSPSDT and LSPP must both be false. Either true value returns two before record mutation or allocation. These two unsupported paths would require separate owned SPPT or SPP arrays and ordered source copies. LSPPTGFIX is inactive under the checked false LSPSDT flag. The source rank-five ZSPPTGFIX argument is therefore not read. Existing R3 NODE evidence records LSPSDT false at line 2974 and LSPP false at line 2982. Runtime guards keep the scope explicit for other configurations.

All objects are mapped, eight-byte aligned, distinct where their ownership requires it and alive throughout a call. Scalar logical values use the source canonical zero or one. IBL and IOFF are positive, ICEND lies from one through NPROMA, and NFLEVG is nonnegative. Borrowed descriptors are true original contiguous GNU FP64 allocatables with rank, dtype, span and canonical origin. Canonical origin means descriptor offset plus the sum of lower bound times stride is zero. Every consumed index or section lies in its corresponding owner. Integer sums and byte products fit their declared types and address space. The direct leaf relies on these original descriptor invariants rather than accepting arbitrary external descriptors.

PSTOPHCA is associated only when RSTOPHCA is allocated. PGP2DSDT and PGP2DSPP are explicitly null on the supported path. GPTOTDISS allocation controls both PTOTDISS_SMOOTH and PTOTDISS, using the separate corresponding source owners. GPVORTGRAD allocation controls three views over levels 1 through NFLEVG, NFLEVG+1 through 2*NFLEVG and 2*NFLEVG+1 through 3*NFLEVG. Their returned level indices start at one. Inactive source conditions retain the incoming destination descriptor bytes.

LFORCENL controls four views from the original rank-four GPFORCE arrays at block IBL and final index zero. These descriptor inputs remain read-only compatibility data. The native adapter obtains their addresses from the original module data exports. It retains no original procedure or vtable target. This data boundary is not autonomous construction of forcing metadata. The raw entry can instead receive equivalent descriptors owned by an assembly context.

PCUCONVCA and PNLCONVCA always select the original MODEL arrays from IOFF through IOFF+ICEND-1. LCUCONV_CA controls the same section of RCAPECONVCA. GPSTREAM allocation controls PSTREAM. LSTOPH_SPBS_T selects the original GPTEMP block when true. When false, the method allocates the original one by one FP64 dummy PTEMP and sets its complete rank-two descriptor. Its eight numerical bytes remain undefined. No weather value is inserted. All borrowed block sections keep complete allocated rows, including inactive rows in the final block.

The raw cleanup is `int md2asm_finalize_perturbation_views(record, model, stoph)`, using x0 through x2. It has the same two source flag guards. On the supported path it frees only dummy PTEMP when LSTOPH_SPBS_T is false and nulls its data pointer. It never frees a borrowed owner. A dummy PTEMP from an earlier successful update must be finalized before the next dummy allocation. Cleanup follows a successful update with the same LSTOPH_SPBS_T ownership flag. Update returns zero on success, one on dummy allocation failure or two for unsupported flags. Cleanup returns zero or two. A failed dummy allocation can leave preceding source pointer associations in the record, with no new owned allocation retained.

Native symbols are `__ecphys_perturb_type_mod_MOD_perturb_type_update_view` and `__ecphys_perturb_type_mod_MOD_perturb_type_final`. UPDATE_VIEW retains nine original arguments. SELF, MODEL and TSTOPH are in x0 through x2. Five scalar pointers occupy x3 through x7. The final rank-five descriptor is on the incoming stack. SELF is a GNU class descriptor whose first word points to the record. The selected native adapter reads the five scalar pointers, while the unsupported-flag guards make the final descriptor unused. FINAL retains SELF, MODEL and TSTOPH. Native adapters abort after a nonzero raw return. They do not call an original method.

The optional `MD2ASM_PERTURBATION_RAW_ONLY` assembly build includes only the two direct raw methods and their private helpers. It takes forcing descriptions through the explicit argument and links only to libc. Original module-data addresses, original-name adapters and adapter counters stay in the normal compatibility build. The normal object remains byte-identical, and the raw option preserves every checked raw instruction and relocation. It preserves the physics and calculation order.

Raw methods use a 192-byte frame and native update uses a 112-byte frame. Native final uses 32 bytes. All keep 16-byte stack alignment and preserve x18, saved registers, FPCR, FPSR and errno. Only integer address and descriptor operations are used. The counter object `md2asm_perturbation_view_native_counters` contains two uint64 values ordered UPDATE_VIEW and FINAL. Counters count original-interface entries only. Direct raw calls require an enclosing route report instead of those adapter counters.

The bounded check uses genuine original type-bound methods in a separate verification library. Three cases cover absent conditional owners with dummy temperature, all conditional borrowed owners at the final 8 of 24 allocated rows, and empty vertical sections with dummy temperature. They cover non-one lower bounds, the four forcing arrays at time index zero and original nine-argument register and stack passage. Complete returned record bytes and all input owners remain exact, with the one separately allocated dummy compared by its corresponding owner identity. Verification marks the undefined dummy only after both methods return. Both unsupported flag cases return two before any mutation.

The retained result has three passing cases and 12 immediate original or direct ABI calls, with zero returned metadata or input byte differences. Original source calls can change x18 under their platform ABI, which the receipt records separately. Every direct route preserves incoming x18. Both routes return the same FPCR, FPSR and errno. Independent source review and the selected complete native forecast check pass.
