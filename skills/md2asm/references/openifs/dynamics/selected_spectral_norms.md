# Owned Selected Spectral Norms

A spectral norm measures the size of a field from its spherical-harmonic coefficients. This utility retains the numerical work consumed by the selected SPNORM route, including its divergence mean used by the forecast report. It reuses the qualified direct SPNORMB, SPNORMBE and SPNORMAVE arithmetic. It does not call an original OpenIFS routine or read original module storage.

The ABI is `int md2asm_compute_selected_spectral_norms(Geometry, GCONF, TDYNA, SPECTRAL, controls, persistent, results)`. The seven addresses use x0 through x6. Geometry contains at least 17,096 bytes, GCONF contains 1,556,112 bytes, TDYNA contains 456 bytes, and SPECTRAL contains 2,992 bytes. These records come from the owned producers. The six int32 controls are NSPPR, LELAM, LREFGEN, LREFOUT, NPROC and LDSPOR. Their selected values are 0, 0, 0, 0, 1 and 0. An absent source LDSPOR and a present false value both select this numerical path. SUGRIDG sets the actual initial flag false; CNT4 omits that optional argument. Present true is outside this utility. The persistent record contains three FP64 words, ordered AVNRMDIV, AVNRMPD and AVNRMVD. Only AVNRMDIV changes. The result buffer contains 20,928 bytes.

All seven arguments are nonnull and eight-byte aligned, except that the controls need only four-byte alignment. Complete outer records, descriptor payloads, controls, persistent state and results are mapped, nonwrapping and disjoint. These are caller obligations. Source field descriptors have contiguous unit-stride levels 1:19, coefficient indices 1:506, and one thermal field. SP has 506 contiguous values. Their canonical GNU origin and full descriptor shape are caller preconditions; the utility uses the declared offsets and strides. Geometry supplies NSMAX21, NUMP22, NFLEVG19, NFLEVL19, NPSP1 and NSPEC2=506. GCONF supplies NFTHER1, NFD2D1 and NUMSPFLDS0. TDYNA selects hydrostatic dynamics. MYMS contains 0 through21 and NASM0 contains the source coefficient starts. The selected serial partition has NALLMS0:21 equal0:21 and zero first NPTRMS/NPTRLL, as produced by the qualified SUMP graph. Thus COMMSPNORM's consumed gather is an exact identity copy. The utility computes directly in the destination order and omits that temporary copy, with no numerical operation omitted.

For each wave number m and degree n from m through21, square the real coefficient and, when m is positive, the imaginary coefficient separately. Add those squares, multiply by the metric and accumulate in increasing degree order. The scalar metric is one for ordinary norms and minus RLAPIN(n) for kinetic energy; multiply the metric by two first when m is positive. Each returned wave sum is the larger of the sum and 100 times the smallest normal FP64 number. Combine the vorticity and divergence kinetic matrices by adding them and then multiplying by one half. For each level, add waves0 through21 in order and take the square root except for kinetic energy. Add the level norms in increasing level order, divide by the level count, and store that mean. Every FP64 multiplication, addition, division and square root has its own rounding. No fused operation, expression contraction or reordered reduction is used.

The result layout is unchanged from the retained qualified graph. Matrix offsets0,3344,6688 and13376 hold vorticity, divergence, combined kinetic energy and thermal values, each19 by22 FP64 words. Offset10032 holds the private divergence kinetic matrix. Offset16720 holds the22 surface-pressure wave values. Per-level norms start at20064,20216,20368,20520 and20672; the last field has one value and the others19. Five means start at20824. All gaps and reserved bytes retain their incoming contents. The output is raw numerical state, without rounding for text display. AVNRMDIV is copied from the divergence mean; the other two persistent words remain untouched.

Return zero means complete and return two rejects a checked control, null/alignment, fixed dimension, floating-point mode or coefficient-map condition before mutation. The routine preflights all22 MYMS and NASM0 values before writing output. Payload validity and the full mapped/disjoint range conditions remain caller obligations. The parent uses a512-byte aligned frame and the matrix child adds256 bytes, for a maximum768-byte call chain. Preserve x18, x19 through x29, the required halves of v8 through v15, FPCR and errno. FPSR retains incoming flags and adds natural arithmetic flags. The qualified arithmetic child retains its libc abort dependency for an unreachable violated internal MYMS precondition. Valid production calls perform no allocation, file I/O, original module read, constructor or method-table call.

Human-readable diagnostic output, profiling and GSTATS accounting are omitted explicitly. Reference-generation and reference-file comparison are inactive because both source controls are false. Nonhydrostatic, distributed, limited-area, orography-norm, per-level-print and wave-print branches are outside this selected utility. No whole SPNORM or COMMSPNORM body credit is claimed. The existing genuine five-stage source packets, complete arithmetic bytes, immediate source return status, independent high-precision relations and ABI/bounds evidence are reused. Only the changed owned-state interface, persistent update, rejection boundary and standalone dependency graph require a new check. Whole forecast admission remains separate.

The optional `owned_spectral_norm_namespace.S` supplies one persistent24-byte BSS record and three original GNU object aliases at offsets0,8 and16. It has no instructions or dependencies. The original YOMSPNRM declaration contains these three saved FP64 variables and no initialization assignment. Fresh zero storage is an explicit process preimage, not a missing numerical initializer. When this object is linked, pass `md2asm_owned_spectral_norm_state` as x5 so original-compatible reporting consumers read the same newly computed divergence value. Callers that own a separate explicit record can omit this namespace object.

At the initial owned dispatch, call this utility after the spectral and surface input producers have finished and before the progress report reads AVNRMDIV. Pass Geometry, MODEL+8 for GCONF, MODEL+1564136 for TDYNA, and FIELDS+22736 for SPECTRAL. Build the first four controls from the already produced SUCT0 words35120,35288,35584 and35312; supply the verified external process count1 and the source-selected false LDSPOR. Keep the persistent record alive across initial dispatch and every later time-loop call. Each call computes ordinary vorticity and divergence matrices first, the two kinetic contributions next, then thermal and surface-pressure matrices. It combines the kinetic contributions before computing the five ordered level norms and means. The same utility is used when CNT4 omits LDSPOR, because NSPPR0 makes the absent source option false.

The [complete GPU phase](../../../../md2asm-gpu/references/openifs/dynamics/selected_spectral_norm_complete_contract.md) retains this selected interface and all output bytes. Independent matrix cells run in parallel, while each degree, wave and level sum keeps its original order. The host keeps the original preflight, and one device phase computes the matrices, kinetic combination, level norms, means and persistent divergence update. Its changed interface and buffer checks pass against retained reference bytes. Complete forecast acceptance remains separate.
