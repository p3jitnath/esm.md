# Retained Forecast Callers

These direct assembly callers connect the owned forecast state to the accepted calculations and output stages. They retain the selected OpenIFS call order, array views, temporary storage and scalar decisions. They use the serial global T21 case with 19 model levels, 506 spectral words and 2,048 grid points. The grid has 86 blocks of 24 rows; the final block contains eight active rows. A spectral word is one stored coefficient of a spatial wave.

All interfaces use the Arm application binary interface, or ABI. The first eight integer or address arguments use x0 through x7, and later arguments occupy consecutive eight-byte entry-stack slots. A source scalar is passed by address unless an interface below states a value. An absent optional argument has address zero. Original character arguments retain their final hidden byte lengths. The stack remains aligned to 16 bytes, and the callers preserve x18, the Arm saved integer registers and the saved lower halves of vector registers where used. Raw FPCR, FPSR and errno follow the unchanged children; no result status is replaced.

The caller owns complete, mapped, nonwrapping records and payloads for the whole call. Scalar and descriptor words keep their original alignment. Geometry has 17,096 bytes, MODEL has 4,275,088 bytes, FIELDS has 529,288 bytes and the complete Fullpos record has 503,824 bytes. The selected spectral record has 2,992 bytes and TGFL has 1,096 bytes. Associated arrays use the accepted GNU descriptor layout: base at zero, element offset at eight, element bytes at 16 and dimensions at 40 with 24 bytes per dimension. An array's first element is its base plus its element bytes times the sum of the offset and each lower bound times its stride. Strides count elements. Each consumer retains the whole source allocation and all active, unused and padding bytes that its existing contract compares.

The inverse unsplit controller calls LTINV_CTL and then FTINV_CTL. The direct controller calls FTDIR_CTL and then LTDIR_CTL. The public ECTRANS interfaces may perform the transform algorithm. OpenIFS owns the surrounding field selection, count checks and address packing in assembly. The field-splitting control NPROMATR is nonpositive and the process count is one. Other supported predicates remain the explicit guards in the retained source; an unsupported branch stops rather than forwarding to an original OpenIFS routine.

SCAN2M first uses the accepted temperature and mixture children, then the complete grid driver. After the driver returns, it reloads the current owner descriptors before copying tracer values. A tracer is copied only when LGP and LT1 are true and NCOUPLING is zero. Only active rows are written. The no-gradient GP_DERIVATIVES branch and the two false STEPX diagnostic branches retain their complete source decisions and profiling pairs without inventing a numerical stage.

MONIO_T clears the complete strided output view before selecting periodic events. Its finite 32-bit step range and output extent are each at most one million entries. The reset interval is positive. It preserves the source integer division and optional logical decisions. The accepted corrected caller passes the source reset-index slice consistently; formerly undefined slice bytes are not a reference output.

The spectral packing interface receives a request record, input descriptor, coefficient destination, 16-byte-per-field metadata destination, spectral-word count and integer selector in x0 through x5. The last two are values. The grid packing interface receives a request record, input descriptor, grid destination, eight-byte-per-field metadata destination, point count, block-row count and integer selector in x0 through x6; its last three are values. Complete destinations hold the requested count, at most 39 fields, times the supplied field extent. The selected physical codes are 130, 133 and 152. The routines keep the source level conversion, integer metadata, field order and direct bit copies. They do not encode GRIB messages.

The output calculation retains the source pressure preparation, extrapolation, mixture, pressure logarithm, neighbouring-level search and interpolation order. Its FP64 additions, multiplications and divisions round separately. No fused multiply-add, reassociation, fast-math or reduced-precision replacement is introduced. The accepted output children own encoding and emitted four-byte record framing; their canonical saved-file comparison remains separate from diagnostic text.

The embedded older TRANSDIR_FP body is removed from `forecast_output_controller.S`. Calls now resolve to the already accepted `scalar_output_transform_caller.S`, which supplies the correct scalar-grid argument slot and reads the same Fullpos counter storage through its existing getter. There is one production definition of the numerical body. The other retained controller instructions and all data bytes are unchanged by this removal.

Private aliases target the accepted direct Coriolis, spectral filtering, implicit solve, vertical interpolation, greenhouse and solar lookup, aerosol and pressure children. The remaining transform guard target is libc abort. Their original-looking symbols identify owned assembly, not an original OpenIFS provider. Hook and timer calls use permitted FIAT services. Allocation and release use libc, file encoding uses the owned writer plus its declared ecCodes service, and required external libraries can use their language runtimes. The enclosing startup must establish each consumed data symbol from its named owned producer; this source-closure check does not certify that all such calls have been joined.

The publication check assembles all 17 translation units with GCC 12.3.0. Each complete object is identical to its retained counterpart after comment changes, using the corrected output-controller object for that one source. Removing its old transform body deletes 712 instruction bytes; all remaining instruction words are exact apart from local branch displacements that retain the same destinations. Remaining relocation expressions and data, constants and BSS sizes are exact. Existing complete numerical and physical evidence is reused. The enclosing autonomous forecast, final 685-owner state and ten saved files still require their separate actual agreement gate; this source closure alone does not admit a forecast or a performance result.
