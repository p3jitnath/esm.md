## Physical meaning and grid

A divergence measures the rate at which air leaves a horizontal region. Let $`D_{c,j}`$ be this input in inverse seconds for column $`c`$ and level $`j`$. Let $`N`$ be NFLEVG, $`C`$ be KNLON, $`a`$ be KLEV and $`b`$ be KLON. The levels increase from the top towards the ground. Supplied coefficients describe a fixed reference atmosphere, while the caller supplies its divergence. SITNU applies a linear operator once; it does not advance time.

The temperature result PT is the positive operator product Tau times D, in kelvin per second. The surface result PSP is Nu times D, in inverse seconds. With SIRPRN equal to the inverse reference surface pressure, PSP is a logarithmic surface-pressure rate. It is not an absolute pressure in pascals. For example, SPCSI lines 392–394 subtract the time factor times these results from temperature and logarithmic surface pressure. This sign and time factor belong to the caller.

SIDELP is a layer reference-pressure weight $`w_j`$ in pascals; SIRDEL is an inverse-pressure coefficient $`u_j`$ in inverse pascals; SILNPR is a dimensionless pressure logarithm $`\ell_j`$; SIALPH is a dimensionless local coefficient $`\alpha_j`$; SITR is a reference temperature $`T_r`$ in kelvin; SIRPRN is an inverse reference pressure $`r_s`$ in inverse pascals; and RKAPPA is the dimensionless dry gas-constant to heat-capacity ratio $`\kappa`$. SITLAF is an effective full-level pressure $`p_j`$ in pascals, and VFE_RDETAH is an inverse eta-layer width $`h_j`$, with no unit. SUSI lines 157–164 copy pressure coefficients and construct SITLAF=SIDELP/SILNPR; line 441 sets SIRPRN=1/SIPR. These setup calculations are inputs to this body.

For conventional pressure layers, define $`S_{c,0}=0`$ and $`S_{c,j}=\sum_{k=1}^{j}D_{c,k}w_k`$. Mass balance and adiabatic temperature change give the discrete positive products:

```math
(\tau D)_{c,j}=\kappa T_r\left(u_j\ell_j S_{c,j-1}+\alpha_jD_{c,j}\right),
\qquad
(\nu D)_c=r_sS_{c,N}.
```

The previous cumulative sum is used in the temperature expression. The current layer enters separately through alpha. Replacing this previous sum with the new sum changes the physical operator.

For the finite-element branch, supplied matrices approximate the top integral of $`F_{c,j}=D_{c,j}w_jh_j`$, measured in pascals per second. Eta is dimensionless and increases from zero at the top to one at the ground. VERDISINT ITOP returns full-level rows followed by a ground row. Its first returned row is a full-level integral, rather than an artificial zero at the top. If $`Q_{c,j}`$ denotes its full-level row and $`Q_{c,s}`$ its ground row, the results are:

```math
(\tau D)_{c,j}=\kappa T_r\,Q_{c,j}/p_j,
\qquad
(\nu D)_c=r_sQ_{c,s}.
```

Do not infer SIDELP from adjacent pressure differences in a general finite-element setup. Physically consistent test profiles explicitly set $`w_j=P_r\Delta\eta_j`$, $`h_j=1/\Delta\eta_j`$, $`p_j=P_r\eta_j`$ and $`r_s=1/P_r`$. General forecast coefficients remain supplied source inputs, with their existing discretisation.

## Complete ordered FP64 arithmetic

RN denotes one correctly rounded binary64 operation with round-to-nearest and ties to even. Set FPCR=0 before the call and preserve it. Retain signed zero and gradual underflow. Fused operations, expression contraction, reassociation, approximate arithmetic, reduced precision and fast-math are forbidden.

In the conventional branch, set the private prefix to positive zero for each column. At each increasing level, obtain the old prefix first. Form RN(D*SIDELP), then the new prefix RN(old+product). Independently form RN(SIRDEL*SILNPR), RN(that*old), RN(SIALPH*D), and RN(the two temperature terms added). Form RN(RKAPPA*SITR), then RN(that*the temperature sum), and store PT at the selected cell. After all levels, store PSP=RN(prefix*SIRPRN). Immutable coefficients and the identical rounded RKAPPA*SITR factor can be reused. This reuse changes no rounding point.

In the finite-element branch, first fill every active private interior with RN(RN(D*SIDELP)*VFE_RDETAH). Set both private endpoint rows to positive zero. Call the complete direct VERDISINT dependency once with ITOP, 11, horizontal pitch C, first point 1, last point C, level count N, absent optional KBC and KCHUNK equal to geometry NPROMA. It selects the existing default NVFE_INTBC. Support all four defined IBC values 0, 1, 2 and 3 with the correct allocated matrix. IBC 0 uses RINTE, IBC 2 uses RINTBF11_IMPL, and IBC 1/3 use RINTBF11. The last two include homogeneous first-derivative boundary constraints. No source-undefined vertical selection is needed.

After the integral, at each selected level form ZREC=RN(1/SITLAF), form RN(RKAPPA*SITR), form RN(that*the corresponding full-level integral), and form RN(that*ZREC) before storing PT. In particular, division of the numerator directly by SITLAF is not the declared rounding route. Store PSP=RN(the ground integral*SIRPRN). Native allocation and release provide private scratch only; every numerical stage remains in SITNU or its accepted direct dependency.

## Supported shapes, storage and mutation

Support C>=0 and N>=0 with positive a and b. Nonempty finite-element work requires N>=1 and positive geometry NPROMA. Empty finite-element work permits N=0 because no dependency is called. All scalar and object arguments remain valid; no input or output array value is accessed when C=0. For conventional N=0 with C>0, no PD or PT value is accessed, and each active PSP is RN(positive zero*SIRPRN).

The source index is IDT=1+(j-1)*a+(c-1)*b. All selected indices and the source expression for its explicit dummy extent must fit signed 32-bit integers, and every allocation and byte address must fit signed 64-bit integers. The selected addresses must be distinct: if g is gcd(a,b), require N-1<b/g or C-1<a/g for nonempty work. This prevents columns or levels from writing the same cell. The explicit dummy extent is max(0,1+(N-1)*a+(C-1)*b), including the source zero-shape expression.

PD and PT have matching strided selected cells. PSP has C contiguous selected values. Arrays are eight-byte aligned and their selected input and output ranges do not overlap. Only selected PT cells and the first C PSP values can change. Preserve every other physical output byte, all input bytes, all coefficient bytes, all geometry/TDYN/vertical-object bytes and RKAPPA. A caller may provide extra physical padding around the dummy extent; it remains observable and must be preserved.

LASSIE lines 105–116 declares complete PGMV(NPROMA,NFLEVG,NDIMGMV), PTOD0/9(NPROMA,NFLEVG) and PSDIV0/9(NPROMA) arrays. Lines 146–164 pass an offset KST pointer with a=NPROMA, b=1 and C=KPROF-KST+1. It must not read NPROMA*N values beyond an already shifted pointer. The single logging-only LASSIE relay, owned by the SIGAM comparator, exposes this scope and the complete PGMV/PGMVS allocations. Original GMV view aliases are preserved in shadow copies, and writes in output views are distinguished from immutable input cells.

SPCSI lines 114–117 declares compact local ZHELP(N,KSTA:KEND), ZST(N,KSTA:KEND) and ZSP(KSTA:KEND), then line 383 passes a=1, b=N and C=KEND-KSTA+1. Their actual capacities are N*C, N*C and C, regardless of the caller’s spectral column lower bound. SUBMAT similarly passes its complete N-by-N basis matrices and N-value surface output.
