# Semi-Implicit Tendency Layout

This setup gives each required field a position in a diagnostic work array. A tendency describes a field's change with time. A semi-implicit calculation uses selected future values to keep fast waves stable. This producer prepares integer field positions, rather than calculating a tendency. The positions and the resulting array dimension are dimensionless.

The source is the complete semi-implicit cursor block in `arpifs/dia/sunddh.F90`, from `IPT=1` through `NDIMSIGMV=IPT-1`, plus its earlier named zero defaults for these same members. It owns NDIMSIGMV and the fifteen MSIDDH positions for source groups 1, 0 and 9. It does not claim to implement every SUNDDH diagnostic stage.

The live owned MODEL supplies NFTHER at byte 16 and the logical LNHDYN at byte 1,564,144. NFTHER is the number of thermal fields and must be nonnegative. LNHDYN is zero or one and selects the source nonhydrostatic branch, which retains additional pressure and divergence fields. Both inputs must already come from their named field-dimension and dynamics producers. The cursor starts at one. For each source group, it assigns positions for the two horizontal wind components, then temperature when NFTHER is positive, then the two additional fields when LNHDYN is true. It increments the cursor once per assigned field, and the final dimension is the last cursor minus one. Unused field positions keep their named source zero defaults. Thus the selected thermal hydrostatic case derives nine entries, rather than receiving nine as an input.

The C application binary interface is `int md2asm_initialize_semi_implicit_tendency_layout(MODEL,capacity)`, with MODEL in x0, its byte capacity in x1 and status in w0. MODEL is an 8-byte-aligned, mapped, nonwrapping 4,275,088-byte owned record. Return zero succeeds. Return two refuses a short, misaligned, null or unsupported input before mutation. Only bytes 4,267,708 through 4,267,771 change, covering the complete 64-byte dimension-and-position block. All borrowed inputs and every other MODEL byte remain unchanged.

The producer is a leaf, which means it calls no other function. It allocates no storage, needs no stack frame, preserves x18 and every saved register, and executes no floating-point instruction. FPCR, FPSR and errno remain unchanged. Production has no external symbol, original OpenIFS routine, original global, constructor, method table or captured-state dependency.

The separate verification reference compiles the original complete cursor block and named defaults with genuine MODEL declarations. It compares the whole MODEL after each supported branch, checks the independent field-count relation, and observes the native register obligations and raw numerical state. The enclosing autonomous forecast and its exact saved-output gate remain separate requirements.

Four genuine profiles cover both thermal branches and both hydrostatic choices, comparing 17,100,352 complete MODEL bytes with zero differences. The first profile uses the actual selected input controls from the original-file r10 entry. Independent checks find exactly the required number of nonzero positions, with no duplicates or gaps. Native ABI masks are zero and immediate FPCR, FPSR and errno match. Five critical null, alignment, capacity and unsupported-control refusals leave the whole MODEL unchanged. No unchanged forecast or physical kernel was rerun.
