# Rotation And Vertical Interpolation Controls

These two small setup entries supply named control statements from `arpifs/setup/sudyn.F90`. They preserve the existing forecast equations. The Coriolis term describes the effect of the Earth's rotation on moving air. Its two switches select how the accepted forecast calculations include that term. The vertical interpolation settings select the original method for combining information from nearby atmospheric levels.

`int md2asm_initialize_coriolis_controls(MODEL,model_capacity,platform)` receives MODEL in x0, its byte capacity in x1 and the live 16-byte platform record in x2. MODEL is mapped, aligned to eight bytes and at least 4,275,088 bytes long. The platform record is aligned to four bytes, mapped and disjoint from MODEL. Its words are NCONF, LECMWF, LR2D and LR3D. This stage reads LECMWF and LR2D, together with the live MODEL flags LSLAG and LTWOTL. These four logical inputs must each be zero or one.

The entry owns only LADVF and LIMPF. On the ECMWF two-dimensional branch it sets LADVF false and LIMPF true. On the ECMWF three-dimensional branch, LIMPF is true when both semi-Lagrangian transport and the two-time-level scheme are enabled, and LADVF is its opposite. On the other platform branch, LIMPF is false and LADVF is true only when both of these scheme flags are true. A semi-Lagrangian method follows moving air parcels, and a two-time-level scheme stores two time positions of the model state. These are the original SUDYN branch relations, rather than observed values copied from a run.

`int md2asm_initialize_vertical_smoothness_controls(MODEL,model_capacity)` receives MODEL and its capacity in x0 and x1. It runs after the spectral-diffusion control producer supplies the live dimensionless level setting KLSPONGE. This setting must be finite and between zero and 255. The entry sets the dimensionless RALPHA and RALPHA_TOP parameters to two, sets NEDER to the source's fifth smoothness-indicator option, and sets LWENOBC and NQMHOISLT to false and zero. A smoothness indicator measures how rapidly nearby values change. NLEV_ZALPHA is the nearest integer to KLSPONGE, with half ties rounded away from zero, as required by the original NINT operation.

The two entries write two and six fields respectively. Every other MODEL byte remains unchanged. The accepted selected-namelist admission and the owned scheme defaults precede these stages. The Coriolis selectors precede their forecast consumers. The smoothness settings follow the diffusion controls and precede all vertical interpolation calculations that use them. Neither stage allocates storage or needs a release call.

Both entries use a private record check, use no stack space or external calls and preserve x18 and all required saved registers. FPCR must be zero for the frozen floating-point settings. The Coriolis entry uses integer operations. The smoothness entry uses finite comparisons and the exact Arm nearest-integer conversion, with no expression contraction or reduced precision. Return zero means success and two means an invalid or unsupported interface. Every rejected call leaves MODEL unchanged.

The separate typed Fortran reference retains only the named source assignment statements and their original branch conditions. It does not claim to compare the complete SUDYN routine. The focused gate compares complete MODEL records with nonzero initial bytes, all 16 Boolean input combinations, positive half-integer rounding cases, current forecast scheme inputs, bounds guards, register obligations and immediate numerical status. Independent truth tables and exact-rational rounding rules check the returned controls. The live upstream diffusion-control fixture also passes with its source-produced KLSPONGE value of 16, and the independent source/interface review passes. Complete forecast file agreement is a separate acceptance gate.
