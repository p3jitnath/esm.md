# GRIB Output Metadata

`int md2asm_read_grib_output_metadata(const void *geometry, void *metadata512)` reads the live typed geometry and initialized scalar configuration for the selected T21 forecast. It returns the 512-byte record declared by the common-template child. This is a metadata reader, with no field calculation and no saved-message input. Geometry must own its complete 17,096-byte declared object, its referenced 512-byte vertical-coordinate object, and the three complete arrays described below. The output must be aligned to eight bytes, writable and disjoint from every input.

The typed GNU Fortran 12 layout places the dimension object at Geometry byte 4872, latitude descriptor at 4744, and the vertical-coordinate pointer at 3240. The pointed object contains the B descriptor at 64 and A descriptor at 128. Selected integer guards require 32 latitudes, 64 longitudes, spectral degree 21, 19 levels and 2048 grid points. Grid type at 7524 must be zero, spectral type at 7520 must be zero or one, and the FP64 stretch factor at 7512 must be exactly one.

Each GNU rank-one descriptor has base pointer at 0, element offset at 8, element size at 16, version at 24, rank at 28, type at 29, attributes at 30, span at 32, and stride/lower/upper at 40/48/56. The reader requires version zero, rank one, REAL type three, attributes zero, eight-byte elements and span, and stride one. Latitude bounds are -1 through 34 with offset one; A and B bounds are zero through 19 with offset zero. Logical element i is at base plus eight times offset plus i. The complete arrays contain 36, 20 and 20 FP64 elements. The reader copies latitude indices 1 and 32, then all twenty A and B values.

The reader uses original module data symbols for date, seconds since midnight, cycle, local definition, stream, forecast type, class and experiment name. These are declared compatibility inputs to this child, not original call targets. It requires whole-hour time, local definition one, forecast type fc, class rd, no variable-resolution ensemble, no observation-cycle adjustment, and initial step zero. The eventual autonomous initializer must own these same metadata inputs. This entry calls no Fortran procedure, library routine or numerical helper.

The Arm application binary interface passes Geometry in x0 and output in x1, and returns zero on success or two on a rejected guard. A 528-byte frame keeps 16-byte stack alignment and preserves its two saved registers. The entry leaves x18, all other saved registers, FPCR, FPSR and errno unchanged. It uses integer loads, stores and arithmetic only. Rejection leaves the output unchanged. Source offsets are taken from the retained typed layout receipts, and focused typed comparison passes.

The required joint selected forecast passes the unchanged complete-owner, raw-status and ten-file byte gate through the [GRIB field writers](grib_field_writers.md). The format boundary remains the ecCodes C interface, with no original Fortran numerical callable.
