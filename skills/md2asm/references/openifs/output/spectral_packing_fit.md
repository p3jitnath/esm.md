# Spectral Packing Fit

Revision 1 replaces original `FITSPECTRUM` for the selected T21 output. The fit chooses a scale for spectral file packing and changes no forecast coefficient. A spectral field stores real and imaginary coefficients labelled by total wave index $`n`$ and zonal wave index $`m`$. The original triangular layout has zero-based base $`m(45-m)`$, with component index $`m(45-m)+2(n-m)+j`$. Use only the real component for $`m=0`$ and both components for positive $`m`$.

For each $`n=11,\ldots,21`$, form the largest absolute selected coefficient and raise it to at least $`\epsilon=2^{-52}`$. Start with weight $`w_n=11/(n-10)`$; a norm equal to the floor instead receives the exact weight $`100\epsilon`$. Let $`x_n=\log(n(n+1))`$ and $`y_n=\log(\mathrm{norm}_n)`$, with coefficient units fixed by the field. Weighted means $`\bar x,\bar y`$ come from increasing-$`n`$ sums. The slope is the weighted sum of $`(y_n-\bar y)(x_n-\bar x)`$ divided by the weighted sum of $`(x_n-\bar x)^2`$, and the intercept is $`\bar y-\beta_1\bar x`$.

Let $`R(q)`$ mean one FP64 rounding to nearest, with ties to even. Keep every original FP64 rounding point. In the slope numerator, multiply the weight by the $`y`$ difference before multiplying by the $`x`$ difference. In the denominator, round the square before multiplying by the weight. The first pass uses $`S_x\leftarrow R(S_x+R(x_nw_n))`$, $`S_y\leftarrow R(S_y+R(y_nw_n))`$ and $`S_w\leftarrow R(S_w+w_n)`$, then rounds each mean division separately. Repeat both LOG calls in the second pass. Store the slope before the intercept. Every accepted fit makes 44 calls to the [direct positive-natural-logarithm child](../support/positive_natural_logarithm.md), with no fused operation, original numerical call or C numerical fallback.

FP64 uses 64-bit floating-point numbers. The application binary interface (ABI) defines argument registers and saved state. The original module symbol and `md2asm_fitspectrum_original_rounding` share the same entry. Six pointer arguments in `x0` through `x5` address `KSMAX`, `KSPEC2G`, `PSPEC`, `KSTRUNK`, `PBETA0` and `PBETA1`. The 32-bit controls are 21, 506 and 10. The complete coefficient span is 4048 bytes with eight-byte alignment and finite values. Integer pointers have four-byte alignment. Both FP64 outputs are aligned, mapped and disjoint from each other and all inputs. The caller supplies valid complete spans. Other controls, nonfinite values, null or misaligned pointers and FPCR other than zero stop with exit 116 before an output write.

FPCR controls floating-point arithmetic, FPSR holds its status flags, and errno is the runtime error number. The frame has 576 bytes and 16-byte alignment. Preserve `x18`, saved general registers, the required low vector halves, the stack pointer, FPCR and errno. Retain inherited FPSR flags and the flags added by the ordered arithmetic. Inputs remain unchanged. The serial verification getters `md2asm_spectral_fit_count_get()` and `md2asm_spectral_log_count_get()` return their 64-bit counters in `x0`, with no floating-point or errno change.

Critical checks matched 35 complete fields in 70 coefficient/status/errno comparisons and eight seeded ABI cases. Independent spectra with known decay exponents 1 and 2 returned exact slopes −1 and −2. Replay of the actual source packet matched all 120 fields, 485760 coefficient input bytes and 1920 result bytes, including complete input guards and raw return status. The required 24-hour T21 forecast reached 120 native fits and 5280 native LOG calls, with zero differing bytes across all 685 final-owner records and ten saved files. Original WROUTSPGB and WROUTGPGB still own the surrounding Fortran writer path; this milestone does not establish an autonomous forecast.
