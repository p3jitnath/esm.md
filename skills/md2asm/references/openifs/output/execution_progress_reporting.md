# Selected Execution Reporting

This component owns LOGDIS and the hydrostatic OPDIS route. These routines report forecast progress and elapsed execution time without changing weather fields. GNU runtime representation metadata comes from the official GCC 12.3.0 sources in runtime_abi. FIAT is the public Fortran IFS and Arpege Toolkit. Its actual library defines GSTATS, memory counters, energy monitoring, EC_MEMINFO and EC_FLUSH; none of these names is an original OpenIFS wrapper in this build.

The caller owns a 152-byte, eight-byte-aligned context. Four 32-bit integer values at offsets 0, 4, 8 and 12 are MYPROC, NULOUT, NULERR and NULSTAT. IFIRST is 32-bit integer at 16 and starts at zero. Bytes 20 through 23 are retained padding. CNDISPP occupies 120 characters at 24. The pointer at 144 addresses the live FP64 AVNRMDIV norm, which OPDIS reads when it writes the current status. The context contains no original module address. Units are already configured through the public GNU runtime, except that OPDIS opens its own status unit on its first call. The actual source units are NULSTAT one, NULERR zero and the selected caller's NULOUT. Nonnegative explicit unit numbers are supported.

The C ABI `int md2asm_logdis_selected(context, arguments)` receives x0 and x1. Its read-only 40-byte argument record has 32-bit integer KSTEP at 0, LDTIMER at 4, LDDATER at 8, retained padding at 12, and FP64 model seconds, first CPU time and second CPU time at 16, 24 and 32. The optional source CDSTEP is absent, so the text is STEP. MYPROC is at least one, KSTEP is zero through 25 and both logical values are zero or one. Model seconds lie from zero through 1e9; the absolute CPU times are finite and at most 1e12 seconds. LOGDIS always calls DATE_AND_TIME and preserves its two source internal writes, the first stderr write and owned MEMINFO call on process one, followed by the timer/date suppression only for the listing write.

The C ABI `int md2asm_opdis_selected(context, arguments)` receives x0 and x1. Its read-only 80-byte argument record holds CDCONF at 0 through 8, retained padding through 15, a caller-text pointer at 16 and byte count at 24. The caller text has one through 18 printable ASCII characters. FP64 PCP, PVCP, PRT, PACP and PART occupy 32, 40, 48, 56 and 64. KSTEP is 32-bit integer at 72 and LDNHDYN is 32-bit integer at 76, which must be zero for this hydrostatic route. KSTEP is minus 999 for the initial CNT3 report, or zero through 25 for forecast reports. PCP, PVCP and PRT are finite, with absolute values at most 1e12 seconds; accumulated PACP and PART lie from zero through 1e9 seconds. The live norm is finite. For MYPROC greater than one, OPDIS returns without reporting or changing IFIRST.

All complete mapped ranges must not wrap. Context, argument record and the norm and caller-text inputs must be disjoint where one is written. The two main records align to eight bytes, as does the norm. The context's IFIRST must be zero or one. FPCR must be zero for reporting arithmetic. Return zero means success, two means unsupported input before report or context mutation, and one means a GNU I/O error after reporting starts. Source runtime errors can terminate the original; this adapter returns the reported I/O status instead. Caller buffers other than IFIRST are read-only. Nondeterministic diagnostic files remain separate from canonical weather output.

The direct arithmetic keeps every FP64 source rounding point. LOGDIS separately divides model seconds by 3600, truncates hours, converts hours back to FP64, multiplies by 3600, subtracts and divides by 60 before truncating minutes. It subtracts the two CPU times separately. OPDIS separately divides each accumulated time by 60, truncates minutes, converts them back, multiplies by 60, subtracts and truncates seconds. Signed integer memory and energy divisions retain source truncation toward zero. No fused or approximate arithmetic is permitted.

The direct code retains every source format string, source character slice, TRIM and ADJUSTL result and the order of external calls. The owned MEMINFO wrapper formats its 32-character prefix, selects ICOMM minus one at step zero and minus two otherwise, and calls FIAT EC_MEMINFO with KBARR zero, KIOTASK minus one and KCALL minus one, followed by EC_FLUSH. OPDIS calls genuine FIAT GSTATS for event 1930 at entry and exit, opens CNDISPP's first-space prefix plus ifs.stat, reports the live norm and monitor values, and flushes NULSTAT. A separate owned release closes that status unit and resets IFIRST after success.

A reusable assembly helper builds GNU st_parameter_dt records of 528 bytes, sets explicit IOSTAT storage and performs ordered character, 32-bit integer, int64 and FP64 transfers. OPDIS constructs the 344-byte GNU OPEN record directly. These are runtime descriptors, which describe a single I/O statement; they contain no solver state or original callable. Every external call preserves the incoming x18 value through an explicit saved slot. The complete routines preserve the Arm callee-saved integer and floating-point registers and stack alignment. FPCR, FPSR and errno follow the actual permitted runtime services; numerical status is not masked to imitate formatted I/O.

The owned child `int md2asm_write_memory_information(unit, step)` receives pointers to mapped 32-bit integer values in x0 and x1. These read-only inputs supply a valid nonnegative writable unit and a step from zero through 25; its caller establishes those preconditions. It returns zero or the I/O error class one. The owned `int md2asm_close_reporting_status(context)` receives x0, accepts IFIRST zero or one and closes only an owned live status unit. It returns zero for an already-closed record, zero after successful close and reset, one for an I/O error, or two for an invalid context. It preserves all other context bytes.

The maximum private assembly stack is 1520 bytes for LOGDIS, 2048 bytes for OPDIS, 896 bytes for the standalone MEMINFO child and 192 bytes for the release. GNU and FIAT use their own separate runtime stacks. The assembly has no heap owner; the external GNU unit manager owns its permitted file buffers. The 64-byte CLOSE descriptor is independently checked from the same official runtime metadata.

Twelve complete genuine LOGDIS and OPDIS calls compare 1082 diagnostic text bytes with zero differences. Four genuine MEMINFO calls compare all 352 captured external argument bytes, including each source-formatted prefix and all six explicit call arguments. The three cases cover both timer/date settings, both memory-unit threshold choices, step zero and step 25, live norm changes, repeated append state and process gating. Incoming FPSR is eight and both routes return 24 for the arithmetic cases; process-gated OPDIS retains eight. Source x18 masks are two, while all native masks are zero. Other runtime status is captured at the actual return without masking.

The verification-only external provider fixes DATE_AND_TIME and the three memory counters and energy monitor values. Its EC_MEMINFO replacement records the complete permitted external call, while memory-report text from that external service is outside the canonical comparison. It supplies no OpenIFS calculation or field. The production object has no reference to this provider. The reference uses the complete genuine routines and an explicit optional-argument interface, so LOGDIS receives an absent CDSTEP exactly as its selected caller does. No cleanup follows a genuine call inside its observed wrapper boundary.

Forty unsupported cases reject before I/O and leave caller buffers and processor status unchanged. Four protected input ranges end at unreadable pages and pass. A failed status-file open returns the documented I/O error class and the owned release safely restores IFIRST. An independent raw assembly entry initialises FIAT arguments through ec_args and GNU arguments through _gfortran_set_args, opens its listing and stderr units, calls the real reporting and memory services and closes all three units. It completes in an environment containing only PATH. These real date and process-monitor logs remain separate from exact source comparison files and weather output.

A zero-call provider check resolves original LOGDIS and OPDIS to libarpifs, and their original MEMINFO wrapper to libifsaux, only in the separate verification control. Every one of the production object's 16 undefined symbols resolves to the permitted GNU or FIAT library. In particular, GSTATS is defined by contrib/fiat/src/fiat/gstats/gstats.F90 and is a public FIAT profiler. The standalone executable directly needs libfiat, libgfortran and libc; its complete clean-environment dependency list contains no original OpenIFS or verification library. No forecast or performance run was made.

The initial CNT3 route is separately checked against genuine OPDIS with CDCONF `000000000`, caller `CNT3` and KSTEP minus 999. All 158 report bytes agree, both raw floating-point returns are FPCR zero and FPSR 24, and the native ABI mask is zero. The two adjacent unsupported negative steps reject before I/O or context mutation. This change adds only the initial-step guard alternative; the accepted forecast reporting arithmetic, formats, external calls and earlier checks are reused.
