# Source aerosol tables on the TEGEN grid

Five source routines SUECAEBC, SUECAEOR, SUECAESD, SUECAESS and SUECAESU supply monthly optical thickness for black carbon, organic particles, soil dust, sea salt and sulfate. Optical thickness is dimensionless and nonnegative. Each source table has72 longitudes,46 latitudes and12 months. Its entries are declared JPRB FP64 literals. The direct readers retain those already rounded literals and perform the same grid permutation; they do not load a constructed model-state packet.

The five raw entries are `int md2asm_read_tegen_black_carbon(output, capacity)`, `md2asm_read_tegen_organic_aerosol`, `md2asm_read_tegen_soil_dust`, `md2asm_read_tegen_sea_salt` and `md2asm_read_tegen_sulfate`. Output is in x0 and byte capacity in x1. Each complete result has39744 FP64 elements and317952 bytes, in Fortran order with longitude varying first, latitude second and month third. Output is mapped, eight-byte aligned, nonwrapping and disjoint from the table, code and stack. Mapping and disjointness are caller obligations. Null, alignment, capacity and address wrapping are checked before mutation. Return0 succeeds; return2 rejects without mutation.

Source input longitude runs from minus180 degrees and latitude rows run in its stored order. For each month and source row JI1:46, destination latitude is47−JI. Destination longitudes1:36 copy source37:72; destination37:72 copy source1:36. Preserve each FP64 word without arithmetic. Literal extraction retains every source index and decimal token before assembler rounding, with no precomputed permutation or numerical field supplied by a driver. All552 rows of72 values are required for each field.

The reader is a bounded integer leaf with no stack, allocation, library call, original module state or method table. It preserves x18, all nonvolatile integer/FP registers, FPCR, FPSR and errno. Data copy does not add arithmetic flags. Source human diagnostics and profiling are omitted explicitly. Genuine source controls compare every returned word and immediate status. Independent checks verify nonnegative finite optical thickness, all coordinate-map pairs and the complete permutation. Protected outputs, critical rejection conditions and ABI checks cover the new flat-buffer interface. Production is assembly-only and links without an OpenIFS library.
