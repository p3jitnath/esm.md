# Hardcoded volcanic aerosol optical thickness

This child owns the selected SUECAEC hardcoded data path. The incoming CVOLCDATA string is blank, so the parent selects these source PART1 through PART7 values. The volcanic owner has24 latitude rows, years1850:2100 and12 months, with latitude varying first. Its72288 FP64 values occupy578304 bytes. The latitude owner has24 FP64 values in degrees and192 bytes. Security parameter REPAER is one FP64 word, set to the declared source value1e−12 after the complete profile is written. Optical thickness is dimensionless.

`int md2asm_initialize_tegen_volcanic_values(volcanic, volcanic_capacity, latitudes, latitude_capacity, security, security_capacity)` uses x0 through x5. All three complete outputs are mapped, eight-byte aligned, nonwrapping and disjoint. Mapping and disjointness from code, literal tables and stack are caller obligations. Nulls, alignment, full capacities, wrapping, pairwise output overlap and FPCR0 are checked before any store. Return0 succeeds and return2 rejects without mutation. The routine is a leaf with no stack or external call, preserving the Arm ABI, x18, FPCR and errno.

Write positive zero to every volcanic element first. Copy the24 source latitude literals, then apply all source24-element year/month assignments in their original PART order. Each assignment contains the original unscaled FP64 constants. After all assignments, multiply every volcanic value by the declared FP64 source constant1e−4 in increasing stored-element order, with one FP64 rounding for each product. Do not load scaled values or a constructed climatology packet. Preserve signed zeros and incoming sticky FPSR bits, adding only natural multiplication flags.

The source's ISYEAR1957 and IEYEAR2010 variables are private saved diagnostic bounds in SUECAEC. They do not write the containing TEAERC_TEGEN fields. The raw child therefore does not manufacture those record stores. The parent retains the actual declaration defaults in those fields and separately owns LVOLCDATA=false and the shared reference count. Human diagnostic printing and profiling are outside this numerical child. All source-written volcanic, latitude and security bytes require a genuine source comparison, independent exact scaling/coordinate relations and ABI/status/bounds checks before parent composition.
