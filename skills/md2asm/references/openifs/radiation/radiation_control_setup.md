# Selected radiation control and storage stages

This checkpoint owns the selected SUECRAD control calculations and flux-array storage. It has two source-order stages. The first covers defaults, the live NAERAD choice, visibility constants, the two-band Planck owner, selected T21 radiation-grid reset and nonlinear longwave loop controls before SURDI. The second covers source frequency derivation and the selected flux allocations after the intervening coefficient and aerosol setup children. Those original OpenIFS children remain explicit unowned dependencies; this checkpoint does not claim complete SUECRAD or move their numerical work into a driver.

The first ABI is `int md2asm_initialize_selected_radiation_controls(records112,text,text_bytes,constants520,upstream112)`, x0 through x4.
