# Selected spectral Planck setup

This assembly owns the selected YOE_SPECTRAL_PLANCK INIT and FREE work used by SUECRAD when owned TEPHY.NEMISSSCHEME is zero. It constructs two long-wave emissivity bands with wavelength boundaries at eight and thirteen micrometres and range map {1,2,1}. The enclosing caller must establish this selected control. The 201 table temperatures run from 150 through 350 kelvin. Each value is a band-integrated thermal irradiance in watts per square metre. Other interval selections, CALC, PRINT and complete SUECRAD remain separate work.

`int md2asm_create_selected_spectral_planck(record, capacity, constants, constants_capacity)` receives x0 through x3 in that order. The caller owns a writable, eight-byte-aligned 240-byte record and a read-only, eight-byte-aligned complete 520-byte constant record from the owned physical-constant producer. Both capacities must cover those sizes. Ranges must be mapped, nonwrapping and disjoint. The three incoming allocation base words must be zero, for fresh or previously released storage. FPCR must be zero for round-to-nearest with ties to even and gradual underflow. Return zero means success, one means allocation failure after cleanup, and two means rejected input before mutation. Buffer and constant-domain guards use integer operations and retain incoming numerical status.

The source-layout record has int32 NINTERVALS at 0, int32 NTEMPS at 4, FP64 TEMP1 at 8 and FP64 DTEMP at 16. GNU descriptors start at 24 for PLANCK_LUT, 112 for WAVLEN_BOUND and 176 for INTERVAL_MAP. They occupy 88, 64 and 64 bytes. The constructor allocates bounds16, map12 and table3216 in source order. Each descriptor is complete, with lower bounds one and contiguous element strides. The table has logical shape {2,201}, FP64 elements and offset minus three. Bounds use two FP64 elements; the map uses three int32 elements. Only the table is first filled with zero. No original type descriptor, method table, object instance or constructed payload supplies this metadata or its values.

The raw child `void md2asm_fill_selected_spectral_planck_table(record, constants)` requires the valid live descriptors, source-defined bounds/map and zeroed table. It computes the source coefficients `2*RPI*RHPLA*RCLUM*RCLUM` and `RHPLA*RCLUM/RKBOL`, reading constants at 0, 16, 8 and 24 respectively. Each wavelength range uses the source 100-subinterval Simpson rule: endpoint weights one, interior weights alternating four and two, with ascending temperature, range and wavelength loops. The short range starts at the source minimum of one micrometre and 0.8 times the first boundary. The long range ends at the source maximum of 200 micrometres and the final boundary plus twenty micrometres. All adds, multiplies and divides round separately. The unchanged qualified scalar EXP and its table are the same numerical provider used by the admitted R8 original exp slot. No reference provider is changed to obtain agreement.

The constructor uses 96 bytes of private stack and the raw numerical child 192 bytes, for a maximum own depth of 288 bytes on the selected normal EXP route. It preserves x18, required callee-saved registers, low d8–d15, stack alignment, FPCR and incoming errno. Natural arithmetic FPSR flags remain. Public libc malloc, free, memset and errno services are the only external APIs. Allocation failure retains the allocator's errno after cleanup. The standalone production allocator is unchanged.

`int md2asm_release_selected_spectral_planck(record, capacity)` receives x0 and x1. It requires the same mapped aligned outer range and either valid owned allocations or zero base words. It returns zero for success or two for a basic buffer rejection. It frees the table, bounds and map in source order and clears only the corresponding three base words. Other record bytes remain unchanged. It allocates nothing, uses 48 bytes of private stack and preserves the Arm ABI and numerical status. It permits any incoming FPCR because it performs no floating-point calculation. A repeated release of the resulting record is valid. Reinitialization can then use the retained metadata, because all three owners are absent.

Three genuine INIT/FREE comparisons cover zero, A5 and 5A incoming metadata bytes. They compare 10452 complete created bytes and 720 complete released record bytes, with zero differences and twelve immediate ABI/status calls. Each of the 3244 payload bytes is compared first; only the three newly allocated descriptor base words use an explicit source-to-direct owner correspondence. Every other descriptor and record byte stays exact. Native ABI masks are zero, and natural FPCR/FPSR match. The source's formatted table diagnostics may change errno and x18; the raw owned service omits those diagnostics and preserves its entry errno and x18.
