# Runtime Radiation Flux Controls And Owners

This component prepares two radiation control words and the numerical buffers that later field registration borrows. It follows the selected original `SUECRAD` assignments and allocation order. It adds no radiation equation and does not complete radiation setup, registration or a forecast. The earlier fixed T21 producer remains unchanged.

The actual input selects approximate longwave update as true and one longwave output. This result follows the true default at source line 531, both original `NAERAD` reads, and actual `NEMISSSCHEME=0` from the accepted physics-control producer. The actual namelist group supplies only `CRTABLEDIR`, `NRPROMA` and `LECOMPGRID`. The later source branch assigns `NLWOUT=1`; later setup reads these words without changing them. An explicit approximate-update override is respected. For emissivity scheme one, the output count is six when approximate update is true and one when false. Unsupported schemes and `LSRTM=false` reject before publication.

The application binary interface, or ABI, defines the registers and memory used by a call. Capacities and quotas count bytes. Every full record must be mapped, eight-byte aligned and live through its last use. All complete spans must be nonwrapping. The caller supplies actual owned records; captured model images supply no production stage.
