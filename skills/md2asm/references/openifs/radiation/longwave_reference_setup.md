# Owned longwave reference parameters

This batch owns complete SURDI, SURRTAB, SURRTPK and SURRTRF from arpifs/phys_radi. It builds mass mixing ratios from live volume ratios and owned molecular masses, then constructs the transmission, Planck and reference-atmosphere tables that the original radiation setup prepares before its coefficient readers. It does not own those later readers or claim complete SUECRAD.

The checked interface is `int md2asm_initialize_longwave_reference_parameters(out,capacity,terdi,terdi_capacity,constants,constants_capacity)` in x0 through x5. The output is 68224 bytes, TERDI is 176 bytes and owned constants are 520 bytes. All complete spans must be mapped, aligned to eight bytes, nonwrapping and pairwise disjoint. FPCR is zero. Molecular masses must be positive finite FP64 values, and the eight incoming volume mixing ratios must be finite and nonnegative. Return zero means success; return two rejects before mutation. No buffer is allocated or released.
