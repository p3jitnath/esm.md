# Preallocated Radiation Gaussian Fields

This SUECRAD entry fills the Gaussian fields after the [source-order storage parent](radiation_transform_storage.md) has allocated them. RMU stores latitude sines, RSQM2 stores the positive cosine magnitude and RLATIG stores latitude angles in radians. ZMU is the sine input and also receives the polar extension. The new entry and the [existing allocating entry](radiation_gaussian_fields.md) share one unchanged arithmetic include. The complete existing creation and release object stays identical.

The application binary interface, or ABI, defines argument locations and saved registers. The entry takes the mapped 1376-byte radiation record in x0, its capacity in x1, writable ZMU in x2, its byte capacity in x3, the live read-only physical520 record in x4, its capacity in x5 and NRADINT in x6. NRADINT is the live interpolation selector, with admitted values two and three. The even row count N at record byte 52 lies in 2 through 8192. There are two surrounding rows at each pole. All complete records and arrays are nonwrapping and aligned to eight bytes.

The caller already owns RMU, RSQM2 and RLATIG through descriptors at record bytes 968, 1032 and 1096. Each descriptor has FP64 elements and span eight, rank one, unit stride, offset one and bounds -1 through N+2. FP64 means a 64-bit floating-point number. Each of the four vectors contains $`8(N+4)`$ bytes. The three output owners, ZMU, radiation record and physical record are pairwise disjoint. New integer checks validate complete descriptor shapes, spans and separation before output writes. Ordinary ZMU values must be finite, strictly decreasing and inside -1 through 1, with both endpoints excluded. The physical producer supplies the rounded RPI word at byte zero, equal to pi in this checked route.

The entry copies ordinary ZMU to RMU, then evaluates $`\sqrt{1-ZMU^2}`$ and asin(ZMU), with separately rounded multiplication and subtraction before square root. The public asin function gives an angle whose sine is its argument. Two northern rows then use RPI-angle, and two southern rows use -RPI-angle, with the original sine and cosine copies. All instruction order and rounding points remain in the shared body. The entry allocates and frees no memory, changes no descriptor and leaves all 1376 record bytes and all 520 physical bytes unchanged. The owning parent keeps each vector alive through its last later consumer.

The 128-byte frame preserves x18, all required saved registers and 16-byte stack alignment. Return zero means success, while two means an atomic refusal. FPCR must be zero. FPCR controls floating-point rounding and FPSR records arithmetic flags. Natural FPSR and errno propagate from the unchanged calculations and public asin call. The only strong external numerical import is asin.

Sixteen saved inputs bind the new storage parent's four actual process maps, N800 and N32, and its two incoming flag cases. The parent's post-inquiry FPSR is 16 or 24. Every ordinary and untouched polar ZMU word agrees with the earlier accepted Gaussian input, while the actual physical producer supplies the same RPI bits.
