# Selected Spline Matrix Factorization

LU factorization rewrites a square matrix as a row permutation times a lower and an upper triangular matrix. The lower triangle has an implicit diagonal of one. This child owns the selected unblocked `DGETF2` calculation consumed by `MINV_8` through `DGETRF`. The separate source-component control recorded 25 matrix inversions, with dimensions four, four, four, 21 and 21 for each of five hydrostatic spline operators. There are eight distinct scaled matrices. The actual Cray route is `dgetrf_` to `__sci_dgetrf_`, `dgetrf_grace`, `dgetrf_var_a_` and then `dgetf2_`; the recorded calls select no recursive panel factorization.

## Raw Interface And Owners

`int md2asm_spline_lu_factor(const int32_t *dimension, double *matrix, int32_t *pivots, int32_t *info)` takes four addresses in x0 through x3 under the Arm procedure call standard. Dimension is one through 24. The caller supplies a contiguous square FP64 matrix in column order, with leading dimension equal to dimension. It owns all matrix cells, dimension pivot words and one info word. Inputs and outputs are mapped and mutually disjoint. Integer addresses have four-byte alignment and the matrix has eight-byte alignment. All initial matrix values and all executed arithmetic intermediates are finite. The selected four- and 21-dimensional matrices meet this precondition.

Return zero means the factorization completed. Matrix storage then contains the upper triangle and the lower triangle below its implicit diagonal. Each pivot is a one-based row index. Info is zero for a nonsingular matrix or the first one-based zero-pivot index; factorization continues after a zero pivot, matching the source. Return two rejects null, alignment, dimension or nonfinite initial input before changing matrix, pivots or info. Raw mapped extents, disjointness and finite intermediates are caller preconditions. No allocation, original module data, descriptor, type table, class method or original numerical callable is needed.

The direct body uses a 176-byte, 16-byte-aligned stack frame. It preserves x18, x19 through x29 and the low 64 bits of d8 through d15. Its only numerical child is the already accepted `md2asm_round_product_sum_candidate`, linked from the unchanged assembly source `src/openifs/support/power_integer_rounding.S`. That child uses a separate 1,728-byte frame and preserves the same required registers, FPCR and errno. Its sole external service is libc `_exit` for an unsupported nonfinite operand, which the declared domain excludes.

## Frozen Source Arithmetic

For each increasing column j, select the first row with largest absolute value in that column at or below j. Apply its row exchange across the complete matrix and record the pivot. For a nonzero pivot, scale the lower column. If its magnitude is at least the smallest normal FP64 value, first compute `reciprocal=1/pivot`, then multiply each lower element by that rounded reciprocal. Below that threshold, divide each lower element by the pivot separately. A zero pivot records info and leaves the column unscaled.

For each later column with a nonzero pivot-row entry y, form `factor=(-1)*y`, rounding that product separately. For each lower row, the consumed Cray rank-one update is `RN(x*factor+old)`, with one final rounding.
