# Native standard atmosphere entry

This assembly adapter replaces the original `susta_` entry for the selected input whose NAMSTA group is empty. It reads `fort.4` through the operating system, validates that empty group in assembly, applies the source height default and calls the checked [standard-atmosphere constructor](standard_atmosphere_setup.md). It then stores the calculated ICAO and post-processing reference values at their live module-data addresses. No initialized table packet is an input.

The original application binary interface (ABI) supplies the 17,096-byte Geometry address in x0. The adapter uses an 896-byte frame with 16-byte stack alignment. It preserves x18 and required saved registers. Its file services restore the incoming FPCR, FPSR and errno before numerical construction. The numerical child preserves FPCR and errno and adds the source arithmetic flags to FPSR. Unsupported input, file failure or failed construction terminates through operating-system exit status 121.

The file must be nonempty and at most 262,144 bytes. A temporary 262,145-byte owner lets the reader reject excess input without an unchecked store. Reads may return short records, and interrupted reads are retried. The owner is freed and the descriptor is closed before construction. The selected NAMSTA starts after line-leading spaces or tabs, with ASCII letter case ignored. Spaces, tabs, carriage returns, newlines and exclamation-mark comments may occur inside its empty body. A slash closes the group. Any assignment in the selected group is explicitly unsupported. A missing group, truncated group or malformed body is rejected. This is the actual empty-group scope, rather than a general Fortran namelist parser.

For ECMWF mode one, the source default HEXTRAP is 150 metres. For mode zero it is 100 metres. The adapter reads live RG, RD and RCVD from YOMCST, RPLRG from YOMDYNCORE, VP00 and TOPPRES from YOMVERT, and LECMWF from YOMCT0. These six numerical scalar values and one logical are original module-data compatibility inputs. Their earlier numerical initialization remains a separate startup dependency. There is no retained original callable, constructor or vtable address. A fully autonomous executable will own equivalent scalar data addresses.

The child returns two complete 288-byte tables and NLEXTRAP. The adapter stores 68 FP64 reference globals in source correspondence: eight heights, nine gradients, nine temperatures and eight pressures for each of the ICAO R and post-processing V families. Surface height remains the explicit zero used by the source, and surface pressure remains VP00. It also writes the int32 NLEXTRAP and FP64 HEXTRAP globals. The address table is metadata, meaning addresses and byte offsets. Every stored numerical value is produced by assembly construction in the current call.

The getter `uint64_t md2asm_standard_atmosphere_native_count_get(void)` reports completed native calls; the selected forecast requires exactly one. The critical native fixture reuses the whole-body source cases and compares all six complete owners, complete descriptor metadata and every source-written reference global after calling the original one-pointer interface. Parser cases check the actual complete fort.4, case and comment handling, nonempty input and missing or truncated groups. Saved registers, outer guards, raw numerical status and unchanged upstream owners are checked. Original module globals remain explicit compatibility data, and the selected complete forecast check passes.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected route. Its declared upstream data and branch limits remain in force.
