# Owned global grid cutoffs

This component implements the selected SUGEM1A ownership and state changes. The owned Geometry record supplies truncation 21, 32 Gaussian latitudes, a live external resolution handle and a halo width from zero to two, with matching global bounds. The source-selected ECMWF flag and supersede flag are explicit inputs equal to one. The non-ECMWF file-correction branch is outside this route. No original OpenIFS module data supplies a production input.

The application binary interface (ABI) is `int md2asm_initialize_global_grid_cutoffs(void *geometry, const int32_t options[2])`, with inputs in x0 and x1 and status in w0. Geometry contains 17,096 mapped caller-owned bytes, is eight-byte aligned and has fresh null NMEN, NMENG and NDGLU pointers at byte offsets 7704, 7768 and 7832. Options is four-byte aligned and contains `{1, 1}`. All consumed records and complete buffers are mapped and disjoint. Scalar offsets come from the typed layout receipt. The enclosing assembly program owns setup and release of the permitted external ectrans resolution.

Allocate integer NMEN and NMENG over NDGSAG:NDGENG and NDGLU over 0:21, with canonical GNU rank-one descriptors. NMEN remains source-unwritten. Call the fixed permitted TRANS_INQ interface to fill NMENG(1:32) and NDGLU(0:21), then reflect active NMENG values into halo rows in the original increasing-index order. No saved map packet supplies these outputs. Other record bytes and all inputs remain unchanged.

Status zero is complete. Status two rejects unsupported shapes, options or nonfresh pointers before mutation. Status one reports allocation failure with all three data pointers cleared; partial descriptor bounds can remain. The separate release frees only these three owners, clears their pointers and preserves other metadata and status. Original allocation printouts and profiling are omitted diagnostics. The initializer frame is 576 bytes, with a 47-word argument table at bytes 128 through 503 and a 64-byte section descriptor at bytes 504 through 567. With the qualified inquiry adapter, the maximum nested assembly stack is 928 bytes, excluding the external library stack. Preserve x18 and all ABI saved registers. External inquiry status propagates naturally.

The original source is a separate control whose source-selected globals are set only in verification. Automatic scratch allocations and new owner payloads receive an explicit common verification preimage. This permits complete comparison of the source-unwritten NMEN bytes; production does not fill them. Four genuine source cases pass 1,456 complete owner bytes, 136,768 complete record and released-record bytes, 12 immediate ABI/status calls and 364 live cutoff or unchanged-preimage relations. Halo widths zero, one and two, incoming FPSR values zero and 24, and two incoming byte patterns are covered. The direct component has no OpenIFS call or data dependency. Whole geometry/startup integration remains separate.

After all payload bytes agree, the three new descriptor base-address words are compared under explicit source-to-direct owner correspondence; actual addresses differ between allocations. Every other record byte is compared unchanged.
