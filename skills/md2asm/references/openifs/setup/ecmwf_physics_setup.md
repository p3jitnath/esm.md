# Complete selected ECMWF physics setup

This component composes the complete selected SUPHEC source at `arpifs/phys_ec/suphec.F90`. It initializes parameter records before a forecast step. It does not advance forecast fields. The source calls SUPHMF first, then selected SUPHEC, as recorded by SUPHY. This parent therefore borrows an owned final MODEL after full SU0PHY and SUPHMF, the owned physical constants and controls, and live Geometry with completed standard-atmosphere pressure and vertical-coordinate owners. Original OpenIFS state, constructors, type tables, callables and captured parameter packets are verification-only.

The frozen interface is `int md2asm_initialize_selected_ecmwf_physics(vertical_context20400,MODEL4275088,context208,radiation_context,text,text_bytes)`, using x0 through x5. The first 17,096 bytes of the complete vertical context are the final Geometry, completed in place by the owned geometry producer; VP00 is at 20,320. The separate 1,872-byte geometry sidecar manages allocations and is not the Geometry record. MODEL contains the final typed parameter records. The opaque radiation context is constructed by the owned radiation producer. Text has 1–262,144 live bytes. All records and tables have eight-byte alignment and complete mapped nonwrapping extents. Writable namespaces, MODEL, context and borrowed buffers are disjoint, except the named live embedded MODEL records. FPCR is zero. Return zero means complete success, one means allocation failure and two means unsupported input. An initialization that fails after a successful child releases only the allocations acquired through this context; completed scalar writes remain observable and must not be used as a complete setup result.

Context holds twelve address/capacity pairs, followed by a 64-bit ownership word at 192 and eight preserved reserved bytes at 200. The ownership word starts zero. Its bits track cloud CETA, optimization owners, the radiation attempt and the owned surface object. The outer context and namespaces belong to the caller.

The source-reachable order is: thermal section 0.2; GPHPRE and its two eta division loops; SUCLD; SUCOND; SUCUMF; SUCUMF2; SUGWD; SUGWWMS; SUVDFS; SUVDF; SUECRAD; the minimum-ice guard; SUOPTSURF; complete SUSURF; selected SUCLOPN; SU_CLOP550; SUCLDP; SUWCOU; SUPHLI; SUMETHOX. The parent reuses qualified direct children. Its qualified SUECRAD child is the direct entry `md2asm_initialize_selected_radiation_setup(Geometry17096,MODEL4275088,radiation_context,PETAH160)`. The caller constructs that 7,168-byte context and runs its earlier SUALLO storage stage before this parent. The fourth argument points directly to this parent’s twenty source-computed half-level eta values. No substitute Geometry eta field or original fallback is permitted. Selected LRAYFM15 is false, LRAY is false, NAERMACC is one, NACTAERO is zero and NFPOS is two. Thus late SU_AERW and SUWAM are inactive. External profiling/timer services and public file-format/math libraries may remain; unconsumed human setup messages are omitted without artificial numerical-status changes.

Thermal section 0.2 and SUVDFS use separate unchanged raw entries at their original source points. SUCUMF changes RTICECU to RTT minus 38 kelvin and its reciprocal after section 0.2 initially used minus 23 kelvin. The parent joins these three named convection outputs into the live thermal namespace before later physics. It never calls the combined thermal constructor after convection. The two existing pressure/eta loops retain their ordered FP64 divisions. RHOUR comes from physical constants at 56, while the live convection/gravity-wave timestep comes from MODEL.TRIP+200.

The minimum-ice guard updates live TEPHY.RCIMIN before surface controls are packed. A finite negative value becomes 0.005 for dynamic sea ice without one-way coupling, and 0.02 otherwise. Nonnegative values, including signed zero, remain unchanged. Raw control producers remain explicit: TEPHY supplies surface switches/fractions, TMCC supplies the coupling flags, complete forecast controls supply NFPOS, the runtime namespace supplies roughness choices, SUDYNCORE supplies scaling, and the owned clock supplies date/seconds. The source-written YSURF pointer must refer to the newly owned complete surface parameter object, not a copied source object.

The runtime namespace has int32 LSCMEC at 0, LVDFTRAJ at 4 and LROUGH at 8, four preserved padding bytes at 12, then FP64 REXTZ0M at 16 and REXTZ0H at 24. The three roughness words have no assignment in the selected original source; their original module symbols occupy zero-filled ELF storage. The owned producer uses the same explicit initial-storage policy and does not call this a declared source default. The integer producer `md2asm_initialize_ecmwf_physics_runtime_inputs(output32,capacity)` owns LSCMEC=false from SUMPINI:169 and LVDFTRAJ=false from IFS_INIT:157, plus the explicit roughness zero-fill policy. It preserves bytes 12–15, rejects a short, unaligned or wrapping output before mutation, and changes no status. Its actual namespace supplies five source-compatible data aliases; no original module data is read.

The surface stage takes the actual longwave NSIL/TSTAND/XP values and live radiation RSUN payload after the radiation child. It builds only a transient input view for the qualified complete surface parent. Optimization owners remain live while surface construction copies their values. Returned surface owners and the cloud CETA owner persist until release. Every other original parameter byte, unassigned descriptor word and numerical owner follows the accepted child contracts. No whole-state normalization is allowed.

`int md2asm_release_selected_ecmwf_physics(MODEL,context208,radiation_context)` frees the surface object, optimization owners, radiation-context resources and cloud CETA in reverse construction order, then clears only its ownership bits and corresponding live pointer/base words. It does not free Geometry, MODEL, constants, text or outer namespace buffers. The radiation child releases its own earlier SUALLO allocations according to that separate context’s ownership flags; independently borrowed resources remain with their caller. The radiation release entry is `md2asm_release_selected_radiation_setup(MODEL,radiation_context)`. Repeated release is valid. The initialization frame has 2,048 bytes and the release frame has 160 bytes. Both preserve x18, x19–x29 and the stack alignment required by the AArch64 ABI. No new FP64 arithmetic is emitted by this parent; each ordered numerical stage remains in its qualified child. The complete source comparison passes all 34,471,264 captured bytes, including the full MODEL and complete surface object. It first compares every owner payload, then relates only 243 typed allocation-base words and the declared surface-object pointer. All other bytes remain exact. The same actual MODEL address is used for both calls, and all 20,400 Geometry/context bytes remain unchanged. No forecast rerun is part of this component checkpoint.

The separate SUGFL1 flag producer receives a writable eight-byte `{LAERNITRATE,LAERSOA}` output and three live int32 counts `{NCHEM,NGHG,NAERO}`. It rejects a nonzero count before mutation, then writes the exact source false assignments at SUGFL1 lines 645 and 648. It does not claim these uninitialized YOMCOMPO declarations are type defaults. It runs at the upstream SUGFL1 source boundary, before this parent, and introduces no original type or module input.

The optional `owned_ecmwf_thermal_namespace.S` supplies one owned 1,920-byte destination with forty exact YOETHF/YOEVDFS data aliases. Context pair 80 must point to this actual owner when those later source-compatible consumers are linked. The complete surface global destination is the existing owned surface thermal namespace, whose contiguous first 72 plus next 944 bytes supply YOS_THF/YOS_EXCS. Optimization, methane and cloud-optical global destinations similarly use their existing owned namespace objects. Raw callers may instead pass disjoint explicit buffers when no alias consumer is present.

The genuine complete parent and direct parent return with FPCR zero and FPSR 24. Original informational I/O leaves errno zero, while the quiet direct setup naturally retains arithmetic errno 34. This declared I/O boundary preserves both raw observations and applies no status correction. Native initialization, release and repeated release have zero ABI masks. Thirty-seven atomic precondition refusals, two runtime-buffer preimages, a protected 208-byte context boundary, the actual first CETA allocation failure and 45 independent enclosing physical relations pass. The CETA failure returns one with zero owned resources and preserves incoming errno and floating-point state. Nineteen genuine control-assignment cases and seven associated refusals also pass. Unchanged child science, buffer and allocation-failure checks are reused.

The original SUALLO statement allocates CETA before SUPHEC. This bounded owner composition acquires the same 19-value owner immediately before its first use and releases it through its explicit context. The genuine reference prepares that source allocation and the original INTDYN pressure-index map before calling the unchanged complete SUPHEC body. Both calls receive the same pre-call allocation bytes for source-unwritten payloads. Reference preparation, temporary observation, serialization and any original module association stay outside the production executable.

The assembly-owned setup prefix starts at `_start` and loads no original OpenIFS library or verification wrapper. It retains public ecRad, NetCDF, ecCodes, transform, mathematical, FIAT, operating-system and required language-runtime services. These services do not supply an omitted OpenIFS setup stage. The complete forecast time loop and its final saved-file gate remain a separate integration checkpoint.
