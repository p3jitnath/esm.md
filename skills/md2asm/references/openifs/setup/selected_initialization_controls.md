# Selected initialization controls

This utility owns the five initialization switches initialized by `arpifs/dfi/suini.F90` and the single `LJCDFI` switch consumed by the trajectory caller from `YOMVAR::SETUP_VAR`. It supports the live forecast configuration `NCONF=1` and the actual empty `NAMINI` and `NAMVAR` groups. `SUINI` sets all five switches false. `SETUP_VAR` sets `LJCDFI` false when `NCONF` is one, independently of its other upstream conditions. Later code in that method does not assign it again. No other variational configuration field is supplied by this utility.

`int md2asm_initialize_selected_initialization_controls(text, bytes, output, capacity, nconf)` receives text and its byte count in `x0` and `x1`, a writable 24-byte record in `x2`, its capacity in `x3`, and a read-only int32 `NCONF` address in `x4`. The input text contains one through 262144 bytes. Both selected groups must be empty apart from whitespace or comments under the accepted uppercase-exact empty-group parser. Unsupported input returns two before mutation; success returns zero. Record offsets 0, 4, 8, 12, 16 and 20 are `LDFI,LBIAS,LINCR,LINITER,LSCRINI,LJCDFI`, each a four-byte logical value. All six source-produced values become zero. Surrounding bytes remain unchanged.

The caller supplies mapped, nonwrapping, disjoint complete ranges. Output and `NCONF` have four-byte alignment. The routine checks nulls, bounds, alignment and output overlap. Its 64-byte frame has 16-byte stack alignment. The integer-only graph preserves `x18`, the Arm callee-saved registers, FPCR, FPSR and `errno`. It calls only the accepted bounded empty-group parser. An optional owned namespace exposes the six original scalar names over this same record, with no original module or constructor input. The entry must invoke this producer before passing `LDFI` and `LJCDFI` into trajectory construction.

Verification calls the genuine `SUINI` and `SETUP_VAR` on the same actual input text in a separate original executable. It compares every defined record byte, surrounding storage and immediate native ABI obligations. The utility owns only the selected data effects; source profiling, namelist I/O, printing and unrelated variational initialization stay outside this interface. Their natural status effects are recorded separately. No numerical result is supplied by the driver and no whole `SETUP_VAR` body credit is claimed.
