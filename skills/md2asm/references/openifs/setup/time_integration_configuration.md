# Selected Time-Integration Configuration

This component completes the selected `SURIP` time-integration record from explicit owned clock and live namelist producers. Time integration advances the forecast in steps of a fixed duration. The source is `arpifs/setup/surip.F90`, with the selected `SUDEFO_TSTEP` call. It uses the live NAMRIP input record and calendar output already constructed by `selected_forecast_controls.S` and `model_clock_initialization.S`. It does not parse another copy of the namelist or recalculate the calendar. The original source remains a separate verification control.

The C ABI is `int md2asm_initialize_time_integration_configuration(clock_inputs,clock_state,controls,trip,capacity,optional_step)`, using x0 through x5. The complete read-only inputs are the accepted 40-byte clock input, the accepted 360-byte clock state, and four int32 controls `{NCONF=1,NSUPERSEDE=1,L4DVAR=0,reserved=0}`. The optional step is null, or points to one complete FP64 value equal to the live TSTEP. Each record aligns to eight bytes and maps its complete declared extent. The output is a complete typed TRIP record of 175976 bytes with at least that capacity. The output must not overlap any complete input range; read-only inputs may share storage. All range sums must remain in bounds without address wrap. FPCR must be zero. Unsupported input returns two before any output mutation or floating-point operation; success returns zero.

The caller passes the clock input and state from one successful owned forecast-control initialization of the same live text. Clock-input offsets 8 and 16 hold the live TSTEP and eight CSTOP characters from NAMRIP. NFOST at 24 is source zero and the incoming trajectory step at 32 is either source minus one or 3600 seconds. The accepted clock stores the parsed stop count at state offset 24, the absolute start time RTIMST at 8 and the adjusted trajectory step at 40. The producer checks the selected TSTEP of 3600 seconds, lower-case t followed by one or two digits selecting one through 25 steps and trailing spaces, exact agreement with the parsed stop count, zero NFOST, the selected trajectory choices, a finite RTIMST and the optional matching step. It consumes named owned scalars rather than an original module or captured state packet. The full live NAMRIP parser and its first-group/assignment rules remain those of the accepted forecast-control producer.

The owned controls select NCONF one, NSUPERSEDE one and L4DVAR false. In this route, `SUDEFO_TSTEP` performs no assignment, so it does not read Geometry or dynamics fields and adds no arithmetic stage. The source initial TSTEP of 600 seconds is replaced by the required live NAMRIP value. The source trajectory adjustment and integer stop read are already supplied by the accepted clock. The allowed selected trajectory step is an exact multiple of TSTEP, so the source MOD check returns positive zero without adding a floating-point flag. Other stop formats, time steps, nonzero NFOST, optional mismatches and alternate configurations are outside this entry contract.

The producer owns every selected SURIP assignment in TRIP. It writes NSTART, NSTADD, NSTASS and NFOST as zero, copies NSTOP and CSTOP from their live producers, sets TSTEP and TDT to the live step, copies RTIMTR from RTIMST and sets each source-listed time, solar and lunar coefficient to positive zero. These fields occupy the typed prefix through byte 311. The four next-step solar values RCODECN, RSIDECN, RCOVSRN and RSIVSRN at bytes 136 through 167 remain untouched, as do padding bytes 28 through 31. The complete gas and aerosol tail at bytes 312 through 175975 remains untouched. No owner, pointer, allocation or type object is created by SURIP in this selected route.

The adjusted TSTEP_TRAJ value remains owned by the accepted clock state at offset 40. This component validates that value and does not allocate a duplicate global namespace. A caller can bind forecast consumers to that owned scalar. Original OpenIFS module data, callable entries and method tables are excluded from production. The direct leaf uses caller-saved integer registers only, has no stack frame, makes no external call and preserves x18, all saved registers, FPCR, FPSR and errno. Original namelist and formatted diagnostics remain reference-only I/O, with their immediate status recorded separately. The natural clock-to-SURIP composition is the enclosing status comparison; no flag is forced to imitate diagnostic formatting.

Verification compares the complete 175976-byte typed record against genuine whole SURIP calls on the same output address, including every unchanged nested record and padding byte. The accepted parser and clock are reused unchanged. A small independent check tests the stop count, time step, initial elapsed time, zero coefficients, unchanged next-step/tail bytes and optional-step edge. Bounds and unsupported controls must leave the complete output unchanged. A standalone assembly entry links only the direct owned graph, with no OpenIFS harness or original library. This checkpoint supplies time-integration configuration; a complete autonomous forecast remains unfinished.

The complete typed map contains 47 named members. Thirty-seven record fields, totalling 276 bytes, are assigned by the selected source route. The remaining 175700 bytes keep their exact incoming values. The separate owned clock supplies TSTEP_TRAJ. Three genuine whole-SURIP cases compare 527928 full record bytes with zero differences at the same output addresses; no pointer or numerical normalization is used. They cover the actual t25 run, a one-step leap-day run with present optional PTSTEP, and a leading-zero t07 run at the calendar upper edge. The last case also skips a lowercase NAMRIP duplicate before the actual uppercase group through both genuine and owned selection.

Six immediate source/native calls, three owned-control calls and one natural-return call pass, with zero direct ABI masks. The natural return is FPCR=0, FPSR=16, errno=0. The raw utility preserves caller errno777, while genuine source namelist and diagnostic I/O returns errno0. There are 126 independent control, elapsed-time, zero-value and preservation checks, 26 atomic rejections and one successful five-range protected-page check. A static assembly entry reads live fort.4, composes the unchanged owned controls and clock with this producer, then compares 176000 complete bytes, including the separate trajectory scalar and FPCR/FPSR. Its explicit header scalars are verification fixtures; production receives live header outputs. The static link has no dynamic library or unresolved symbol, and the component itself has no callable dependency. No forecast or unchanged numerical suite was rerun.
