# Owned serial partitions and grid maps

This component implements the selected global serial SUMP state calculation. It composes the qualified 26-array SUALMP1 storage phase, two blocked-array allocations, six-array SUALMP2 phase and selected first-call stream geometry metadata. All 34 Geometry owners and two stream owners belong to the assembly caller. No original OpenIFS routine, global variable, constructor or procedure table supplies production work. Public ectrans query and spectral-distribution APIs remain allowed external dependencies.

The ABI is `int md2asm_initialize_serial_partition_maps(void *geometry, void *stream, const int32_t settings[7])`, with inputs in x0 through x2 and status in w0. Geometry contains 17,096 mapped bytes and stream contains 872 mapped bytes; both are eight-byte aligned. Settings is four-byte aligned and stores NPRTRV, NPRTRW, NPRTRNS, north/south region count, east/west region count, external process rank and process count. Every value is one on this selected serial route. All complete records, input buffers and new owners are disjoint and mapped. Both stream owner pointers and all 34 partition owner pointers are fresh null values before entry.

The supported input has truncation and NCMAX 21, NMSMAX zero, 32 Gaussian latitudes, 64 longitudes, 19 levels and NPROMA 24. The original negative input NPROMA disables block-size optimization, so LOPTPROMA is false. The borrowed LNONHYD_GEOM flag is a caller-owned canonical false logical value. Geometry contains the live resolution returned by the allowed ectrans setup for this regular grid, split latitude option and one process. Its canonical contiguous NLOENG descriptor spans NDGSAG:NDGENG, including active indices 1:32. Each active longitude count is 64; the actual halo bounds are −1:34. Other qualified halo bounds 1:32 are also covered. The input Geometry, namespace and scalar layout are those established by the owned setup components; they do not borrow an OpenIFS constructor.

Allocate the first 26 arrays, derive the vertical partition, then call the actual transform spectral inquiry, spectral distribution, latitude inquiry and Fourier inquiry in source order. Pass assumed-shape arguments with complete GNU descriptors, including the temporary IULTPP descriptor and NSTA/NONL sections. The selected serial whole-column partition retains the source reverse accumulation order. Derive the spectral starts, level starts, level-set map and local dimensions. At the source INI_IOSTREAM call position, allocate and populate the two owned stream copies from the live Geometry. Translate the NLOENG stored lower bound before copying its active 1:32 section.

Apply the selected SUOPTPROMA assignments, calculate 86 blocks, allocate the final eight Geometry owners and build the level, latitude, local/global and processor maps. The temporary IGLOBAL array is zeroed and filled in global row order. On this regular serial grid, the local and global order is identical. Initialize both complete 24-by-86 blocked latitude/longitude owners to the source sentinel −99999, then write the 2,048 active cells. The final 16 padding cells keep that sentinel. Source-unwritten NDLUNL and NDLUXL payloads retain their incoming bytes. No driver or saved numerical-state packet supplies a map.

Status zero is complete, status two rejects the checked shape, options or owner freshness, and status one reports allocation failure. Failure cleanup releases only this component's 36 new owners and clears their data pointers; partial descriptor bounds and completed scalar writes can remain. Call `md2asm_release_serial_partition_maps(geometry, stream)` before releasing either enclosing record. It frees these 36 owners and clears only their data pointers. Initializer and release frames use 9,216 and 64 bytes with 16-byte stack alignment. The initializer frame includes an 8,192-byte IGLOBAL workspace at bytes 1,024 through 9,215. The maximum nested assembly stack is 9,568 bytes through the public inquiry adapter, excluding external library stack use. Preserve x18 and all ABI saved registers. Natural returned FPCR, FPSR and errno agree with the genuine source; original printouts and profiling are omitted diagnostics.

Three genuine complete source cases pass 153,032 owner bytes, 107,808 complete Geometry/stream and released-record bytes, nine immediate ABI/status calls, three atomic freshness rejections and 36,960 independent map relations. The actual halo descriptor −1:34, a zero-halo edge, incoming FPSR zero and 24, two explicit verification-only allocation preimages and all final padding cells are covered. The reference retains the complete SUMP body, separately renamed allocation and block-size children, and the complete original INI_IOSTREAM body in a private verification namespace. It is never a production provider. After every payload byte agrees, the 36 new data-address words and the read-only NLOENG input address use explicit owner correspondence; every other record byte remains exact. Production performs no allocation fill or returned-state repair. Whole owned geometry/startup integration remains pending.
