# Atmospheric Physics Parameters

SUPHY0 sets constants for atmospheric exchange, clouds and convection. This direct service owns its complete selected 3,456-byte TPHY0 record. A parameter is a value that controls a model calculation. The service reads the actual empty NAMPHY0 group and keeps the original physical values and arithmetic. Alternative physics has LCOEFKTKE, LMPHYS and LSIMPH false, with LECMWF true. Other turbulence-model choices are outside this selected interface.

`int md2asm_initialize_atmospheric_physics_parameters(text, bytes, output, capacity, inputs)` uses x0 through x4 in that order. Text has 1–262144 mapped bytes. Output is a writable, eight-byte-aligned 3456-byte TPHY0 record, with capacity at least 3456. Inputs is an eight-byte-aligned read-only 48-byte record. All declared ranges must be mapped and nonwrapping, and output must be disjoint from them. The caller owns each buffer. Return zero means success and two means unsupported input, with the output unchanged.

| Input offset in bytes | Value | Meaning |
| --- | --- | --- |
| 0, 8 | Address and uint64 capacity | Complete live TPHY record, at least 1096 bytes |
| 16 | FP64 ROMEGA | Rotation rate in radians per second, finite with magnitude at most one |
| 24 | FP64 RDELXN | Horizontal grid length in metres, between one and 100000000 |
| 32, 36 | int32 LSIMPH, LECMWF | Zero and one respectively |
| 40, 44 | Reserved int32 words | Not consumed |

The TPHY controls LCONDWT, LPROCLD, LNEBCO, LNEBR, LNEBGR, LECT and LCVRAV3 must each be zero or one. Their typed byte offsets are 36, 200, 808, 816, 908, 712 and 916 respectively. LCOEFKTKE at 736 and LMPHYS at 12 must be zero. Other TPHY fields are not consumed by this selected path. The parent checks these controls, ranges, FPCR and the empty group before the first output store. The original informational startup text is outside the quiet numerical interface. Required errors use the explicit return code.

The literal child sets each original constant with its declared rounding. In particular, unsuffixed RSMOOTHMELT and the real-kind JPIM literal for GDDFRAC first round to single precision before widening to FP64. The arithmetic child sets GPETAU to one divided by a nonzero ROMEGA, or positive zero for either signed zero input. This is the rotation time in seconds per radian. It divides the three original convection parameters by the live grid length to form TEQK, TEQC and TEQH. RDTFAC is one half only when both condensate controls are true. TENTRVL becomes zero only when LCVRAV3 is true and the original grouped cloud condition is false.

The turbulence calculations retain the source NUPTKE value 0.52 and C3TKEFREE value 1.184. The child forms the fourth power with two squared products. It then evaluates the source ZSM0, ZLAMF_X, ZLAMBDA and ZSF dependencies before storing ETKE_LAM1, ETKE_LAM3 and ETKE_LAM2. Separate source products and divisions set ETKE_CTHETA and ETKE_KA1 through ETKE_KA3. The setup source supplies the equation definitions, and the assembly comments follow those quantities. No earlier stage or verification driver supplies a missing calculation.

Every FP64 operation rounds separately. FPCR must be zero, which selects round-to-nearest with ties to even and gradual underflow. Fused arithmetic, reassociation, reduced precision and approximate division or square root are excluded. The service preserves x18, required saved registers, low d8–d15, aligned stack, FPCR and errno. Natural FPSR arithmetic flags remain visible. The parent uses 64 bytes of private stack, and both numerical children and the reused empty-group reader are leaves. It acquires no heap owner and has no operating-system, library, original module or original callable dependency.

The raw children `md2asm_set_atmospheric_parameter_literals_raw(output)` and `md2asm_set_atmospheric_parameter_arithmetic_raw(output, inputs)` use x0 and, for arithmetic, x1. They require the checked parent contract and complete live records. The literal child changes only original literal-assignment fields, and the arithmetic child completes the ordered calculations and control-dependent stores. The typed offset include records each original field name. The selected whole parent writes 3412 bytes and retains all 44 other bytes, including UN3412. Output words use the target little-endian representation without rounding, masking or padding repair.

Six genuine complete SUPHY0 comparisons cover live controls, condensate selection, both cloud-condition results, zero rotation and negative rotation under three incoming exception-flag patterns. All 20736 output bytes match, including every source-unwritten byte. All 102 independent high-precision and physical relations pass. Native ABI masks are zero and natural FPCR/FPSR agree exactly with the source. The source diagnostic I/O clears errno and changes x18, while this quiet service preserves both, as declared. Eight atomic refusals and four complete ranges ending at protected pages pass. A separate static assembly process matches all 3456 bytes with no undefined symbol or dynamic dependency. No complete SUPHMF or forecast is claimed by this checkpoint.
