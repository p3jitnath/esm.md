# Standard Atmosphere Layer Tables

This numerical child implements the first nine-layer atmosphere calculation in SUSTA, before model-level pressure and temperature are calculated. A layer boundary is a height at which the prescribed vertical temperature gradient changes. Heights are in metres, temperature is in kelvin and pressure is in pascals. The source is arpifs/setup/susta.F90, from ZSUR initialization through the first temperature and pressure loop.

The raw interface is `int md2asm_initialize_standard_atmosphere_layers(output, physical, ecmwf)`. Registers x0 and x1 address a writable 288-byte result and a read-only 32-byte physical input. Register w2 is the source LECMWF logical, either zero or one. The two mapped, eight-byte aligned spans are nonwrapping and disjoint. The physical values are RG in metres per second squared, RD in joules per kilogram per kelvin, dimensionless RPLRG, and reference pressure VP00 in pascals. Supported finite positive ranges are RG from 9 through 10, RD from 270 through 310, RPLRG from 0.5 through 2 and VP00 from 90000 through 110000. Return two before writing if a checked requirement fails. Return zero means that all 36 result words are initialized.

The result contains four consecutive arrays of nine FP64 words: height, temperature gradient, temperature and pressure. Heights are 0, 11000, 20000, 32100, 47400, 51400, 71700, 85700 and 100000 metres. The initial temperature is 288.15 kelvin and initial pressure is VP00. With LECMWF true, gradients are -0.0065 kelvin per metre followed by eight positive zeros. With LECMWF false, they are -0.0065, zero, 0.001, 0.00275, zero, -0.00275, -0.00197, zero and zero kelvin per metre. These are source inputs, not precomputed atmosphere values.

For each of the first eight boundaries, subtract the current height from the next height in source order to obtain the positive height difference. For a nonzero gradient g, compute temperature at the next boundary as T plus g times the height difference. Compute pressure as P times POWER of the base one plus (g times height difference) divided by T, with exponent (((-RG)/RPLRG)/RD)/g. For a zero gradient, copy T and compute pressure as `P*EXP(((((-RG)/RPLRG)/RD)/T)*height_difference)`. Every multiplication, addition, subtraction and division has its own FP64 rounding point. POWER and EXP call the already qualified direct original-rounding entries, not a C or Fortran numerical fallback.

Require FPCR zero, nearest-even rounding, gradual underflow and source signed zeros. The child preserves incoming sticky FPSR bits while adding source arithmetic flags. The supported physical ranges avoid error-producing math domains, and errno remains unchanged. It preserves x18, all required saved integer registers and d8 through d15 with a 128-byte, sixteen-byte aligned frame. There is no allocation or hidden state.

Verification compares every result byte with the separate original source prefix using the same physical inputs and original strict EXP provider. Cases cover both gradient branches and a changed planet-gravity scale, so the RPLRG division remains a calculated stage. Independent high-precision checks enforce positive decreasing pressure and the hydrostatic pressure relation, with the source rounding error reported. The enclosing standard-atmosphere constructor supplies model-level tables and configuration handling. No original SUSTA body credit is awarded by this child.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected route. Its declared upstream data and branch limits remain in force.
