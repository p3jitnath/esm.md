# Model Component Pointer Aliases

MODEL_SET associates fifteen module pointer words with components inside one read-only MODEL record. The source is `arpifs/module/model_mod_model_set.F90`; `source_associations.json` gives the exact source order and names. MODEL_UNSET in `model_mod_model_unset.F90` has no effect when profiling hooks are disabled, so it retains every pointer. This component performs no numerical calculation and does not construct the MODEL record.

`md2asm_set_model_component_aliases` receives an eight-byte-aligned MODEL record of 4,275,088 bytes in x0 and an eight-byte-aligned table of fifteen destination addresses in x1. Each table entry points to one writable eight-byte pointer word. The complete MODEL and 120-byte table remain read-only. Every output word is distinct and disjoint from both inputs. The routine checks nulls, alignment, address wrap, overlap and duplicate destinations before its first store. It returns w0 zero after all fifteen associations, or two before any store on an unsupported address relation. The caller must map all declared buffers; the function cannot discover inaccessible memory.

The typed offsets are frozen in `model_alias_layout.json`. The destinations receive `MODEL base + component offset` in the original order. The raw entry uses only integer registers x0 through x17, has no frame or child call, preserves x18 and all saved registers, and leaves FPCR, FPSR and errno unchanged. `md2asm_unset_model_component_aliases` is a void empty return; it does not clear aliases.

The raw object has no original callable, module-data, type or vtable dependency. An autonomous caller supplies its own fifteen pointer destinations and owns the MODEL storage. The separate `model_module_alias_native_entry.S` adapter writes the original module pointer words through their GOT addresses. That adapter exists only for compatibility verification and is not part of the autonomous storage boundary. Its MODEL_SET frame is 160 aligned bytes, and its integer-only getter returns SET or UNSET completed counts for indices zero and one. Other indices return zero. The original interfaces receive a raw TYPE(MODEL) address, not a class descriptor.

Four original/raw/native cases pass 24 immediate ABI and raw-status calls, all with mask zero. Complete pointer results, 1,440 compared alias bytes, 960 guard bytes and 102,602,112 read-only MODEL bytes agree. The cases use distinct real records, repeated binding and a protected read-only copy. Seven rejected address relations leave every output unchanged. The retained source peer is `root_independent_source_ABI_review.json`. These are local component checks; no forecast or complete model construction is claimed.
