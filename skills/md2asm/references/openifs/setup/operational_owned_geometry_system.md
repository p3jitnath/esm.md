# Owned Operational Geometry

Revision 1 joins the accepted setup calculations for the supplied TCo1279 grid with 137 layers. TCo1279 is the input's triangular spectral grid, with 6,599,680 surface points. Geometry stores the grid dimensions, coordinates and array descriptions used by later calculations. This parent completes the horizontal part around an existing, accepted [vertical system](owned_vertical_system_contract.md). It uses one process. Distributed Geometry remains separate work.

## Parent Interface And Ownership

The interface is `int md2asm_complete_owned_operational_geometry(vertical, headers, constants, text, text_bytes, output)`. The six arguments enter registers x0 through x5 under the Arm application binary interface (ABI), and w0 returns the status. Vertical has 20,400 readable and writable bytes, headers has 9,328 read-only bytes and constants has 520 read-only bytes. Text has 1 through 262,144 readable ASCII bytes. Output is a fresh eight-byte pointer slot containing zero. All record addresses align to eight bytes. Every complete owner range is mapped, disjoint and does not wrap around the address space.

Vertical comes from the live accepted vertical constructor. Its 28 array owners and descriptions remain borrowed and unchanged. All 121 new horizontal pointer slots and the terrain pointer start null. Headers comes from the [actual file-header reader](../input/initial_model_file_headers.md), including all 1,280 northern row lengths. The live configuration establishes LIOLEVG=true, so file and active layer counts both remain 137. The parent preserves the actual 17-column block layout and final eight-column block.

The new 1,872-byte sidecar is a small record that owns related setup state. It contains the Geometry association at byte 0, stream state at 8, transform state at 880, physical constants at 1184, seven process settings at 1232, a transform-lifetime flag at 1264, an ownership tag at 1272, atmosphere state at 1280 and an extrapolation setting at 1856. Nine temporary partition settings use private stack bytes 512 through 547, apart from the lifetime flag. Publish the sidecar pointer only after every stage succeeds.

The parent retains source order through dimensions, reduced-grid setup, public transform setup, process partitioning, Gaussian latitude values, Laplacian coefficients, stream association, standard atmosphere, grid maps, spectral maps, complete spherical Geometry and terrain storage. The accepted children retain their ordered FP64 arithmetic and independent checks. Public file-format, transform, message-passing, mathematical and allocation services may remain. No original OpenIFS constructor, global state or numerical routine supplies the native production calculation.

`int md2asm_release_owned_operational_geometry(sidecar)` releases terrain arrays, the 121 horizontal owners, five stream owners, two transform metadata owners, the public transform lifetime and the sidecar, in that order. It clears owned pointers and retains every borrowed vertical owner. It returns zero on success. A failed construction releases acquired owners while dimensions or descriptor metadata already written may remain. The output slot stays null. Zero constructor status means ready; nonzero propagates a child failure. The parent uses status 1 for its sidecar allocation failure, 2 for an entry refusal and 3 for an external-service failure.

The constructor frame is 2,048 bytes and the release frame is 96 bytes, each aligned to 16 bytes. Both preserve x18 and the required saved integer registers. FPCR, the floating-point control register, must be zero. Each numerical child retains its declared rounding and status effects. The successful original and native calls naturally return FPCR 0, FPSR 24 and errno 0. FPSR holds floating-point exception flags, while errno is the library error indicator. Release preserves the caller's incoming values. No saved status or payload is repaired after execution.

The record has 200 mapped bytes, the four dimensions are 1279, 1280, 819840 and 0, and each integer index array has 1,280 four-byte entries. Stretch is one FP64 word equal to 1. The record and stretch addresses align to eight bytes, while the integer inputs align to four bytes. The new GMR and SCGMAP owners have 13,117,440 and 19,676,160 bytes. The child preserves the complete recurrence, divisions and square roots in the [spectral map contract](spectral_geometry_maps.md), including unit stretch. Its 10,384-byte frame holds 1,282 recurrence words. Unrelated record bytes remain unchanged.
