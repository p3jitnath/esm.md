# Owned stream geometry metadata

SUMP records its partition information in the OpenIFS stream namespace. This child owns that selected first-call effect of INI_IOSTREAM. The source's complete 872-byte TYPE_INT_VARS layout is retained as an owned record, with no original OpenIFS global variable, constructor or callable in production. The other INI_IOSTREAM optional updates are outside this child.

The ABI is `int md2asm_initialize_stream_geometry_metadata(void *stream, const void *geometry, const int32_t process[2])`. Inputs use x0, x1 and x2, and status uses w0. Stream contains 872 mapped bytes and Geometry contains 17,096 mapped bytes; both are eight-byte aligned. The four-byte aligned process pair contains the live external rank and process count, both one on this serial route. All complete objects and buffers are mapped and disjoint. Geometry supplies truncation 21, 32 Gaussian latitudes, 19 levels and NBSETSP equal to one. Its NBSETLEV and NLOENG are true contiguous canonical-origin int32 arrays with bounds 1:19 and NDGSAG:NDGENG. The latter bounds contain the active section 1:32 and can include the actual halo −1:34. Data addresses point at the stored lower-bound element. Translate the NLOENG lower bound to select 1:32 before copying. These descriptors and inputs are read-only caller preconditions.

Stream starts before its first initialization, with fresh null NBSETLEV and NLOENG data pointers at offsets 64 and 144. Allocate those two owners, copy the live Geometry values and write the source-defined scalar defaults and four geometry counts. Other record bytes stay unchanged. The maximum grid count is the declared source parameter 52,428,800. The stored pi and reference pressure are the original compile-time FP64 constants; pressure is 100,000 Pa. No numerical setup output is imported from a saved state.

Status zero is complete, status two rejects the checked scalar, alignment or freshness scope before mutation, and status one reports allocation failure with both data pointers cleared; partial descriptor bounds can remain. The separate release frees only these two owners and clears only their data pointers. Initializer and release frames are 112 and 64 bytes, with 16-byte stack alignment. Both preserve x18, required saved registers, FPCR, FPSR and errno. Ownership of Geometry and all unrelated stream arrays remains with the enclosing assembly program.

The separate verification module retains the genuine original value type and complete original INI_IOSTREAM body in a private source namespace. It is used only as a control. Three first-call cases pass all 612 copied owner bytes, 5,232 complete initialized and released record bytes, nine immediate ABI/status calls and three atomic freshness rejections, with incoming FPSR zero and 24. The changed origin case uses the actual halo descriptor −1:34 with distinct unused halo words, while the active 1:32 values are copied exactly. The transform/message library is used only to initialize the genuine source's allowed external rank queries. No whole INI_IOSTREAM body credit or whole startup admission is claimed.

After all payload bytes agree, the two new descriptor base-address words are compared under explicit source-to-direct owner correspondence; actual addresses differ between allocations. Every other record byte is compared unchanged.
