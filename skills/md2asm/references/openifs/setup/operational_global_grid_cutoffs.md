# Operational Global Grid Cutoffs

Revision 1 extends the selected SUGEM1A utility to spectral truncation 1,279 and 2,560 latitude rows. A spectral cutoff is the largest retained wave number at a row. The new utility obtains these integer limits through the permitted public transform inquiry. It preserves the complete [regular-grid entry and release](global_grid_cutoff_contract.md). No original OpenIFS routine or module variable supplies a production stage.

The application binary interface (ABI) is `int md2asm_initialize_operational_global_grid_cutoffs(void *geometry, const int32_t options[2])`. Arguments occupy x0 and x1; w0 returns the status. Geometry contains 17,096 mapped bytes and aligns to eight bytes. Options contains two aligned four-byte integers, both one: the ECMWF-grid flag and the file-supersede flag. All consumed records and complete owners are mapped, nonwrapping and disjoint.

The caller supplies a live resolution handle created by the accepted [operational public transform setup](operational_transform_setup.md). Consumed Geometry integers are NRESOL at byte offset 5168, NSMAX=1279 at 5172, NDGLG=2560 at 4872, NDGSUR=2 at 4884, NDGSAG=-1 at 4888 and NDGENG=2562 at 4904. NDGSUR gives the two extra rows at each pole. The new entry supports this complete tuple; other tuples remain outside its domain.

Fresh null data pointers at offsets 7704, 7768 and 7832 become NMEN, NMENG and NDGLU. NMEN reserves local cutoffs for a later stage. NMENG contains global cutoffs, while NDGLU counts the northern rows that retain each wave number. NMEN and NMENG each have 2,564 four-byte integers over bounds -1 through 2562, covering 10,256 bytes. NDGLU has 1,280 integers over bounds 0 through 1279, covering 5,120 bytes. The three complete owners total 25,632 bytes. Every descriptor retains its GNU 12-compatible type, bounds, stride and bias fields.

Allocation order remains NMEN, NMENG, then NDGLU. NMEN receives no payload write: its complete incoming allocation bytes remain unchanged. Production does not fill that source-unwritten owner. The fixed public `TRANS_INQ` adapter passes all 47 declared optional argument positions, including the live resolution handle, the active NMENG section over rows 1 through 2560 and the complete NDGLU descriptor. The public transform library produces these values; no saved map packet supplies them.

After inquiry, the utility reflects the first two and last two physical NMENG rows into the pole extensions in the original increasing-index order. Other Geometry bytes, descriptor metadata and input records remain unchanged. The selected ECMWF flag excludes the original non-ECMWF file-correction calculation. This checkpoint adds no floating-point calculation.

Status 0 means complete. Status 2 refuses unsupported controls, shape or nonfresh pointers before mutation. Status 1 reports allocation failure: every acquired owner is freed once and the three data pointers are null; descriptor metadata written before the failure can remain. The unchanged `md2asm_release_global_grid_cutoffs` releases only these three owners and clears their data pointers, preserving other record bytes and status. The caller retains Geometry and the external transform lifetime.

The constructor frame is 576 bytes. With the qualified public inquiry adapter, maximum nested assembly stack use is 928 bytes, excluding the external library stack. The reused release frame is 96 bytes. Frames align to 16 bytes. FPCR, the floating-point control register, must be zero. Required saved registers and x18 remain preserved. Successful inquiry propagates the external library's natural numerical status; allocation cleanup restores incoming errno. The release preserves FPCR, the floating-point status register (FPSR) and errno.

Two complete profiles use allocation bytes 0x5b with incoming FPSR 0 and 0xa7 with incoming FPSR 24. Both use FPCR 0 and errno 777. Separate original-source and native processes match all 51,264 owner bytes and 102,672 complete Geometry, released-record and guard bytes. Only six declared owner-address correspondences differ. Both complete source-unwritten NMEN preimages remain exact. Constructor and release status is 0/0/777 for the first profile and 0/24/777 for the second. All eight native ABI masks are zero; the source's permitted x18 difference is recorded separately from its unqualified void return.

Independent integer checks cover 7,688 cutoff, hemispheric symmetry, pole-extension and northern-count relations. Each NDGLU entry equals the number of northern NMENG rows whose cutoff admits that wave number. Focused controls pass allocation failures at attempts 1 and 3 and unsupported truncation or row-count tuples, with exact guards, precise partial metadata and complete cleanup. The actual public transform setup runs only to supply a live prerequisite handle; it receives no new acceptance credit. The old regular-grid bank is reused without replay. This qualifies the complete operational cutoff utility, with no SUMP, complete horizontal-geometry, original-parent or operational-forecast credit.
