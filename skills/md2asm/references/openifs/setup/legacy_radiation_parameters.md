# Legacy Radiation Parameters

SUPHY3 prepares fixed aerosol, gas and cloud coefficients in the original physics setup. This direct version supports the actual control values from owned SU0PHY: NRAY one, LRSTAER true, LRPROX false, LCLSATUR false and NRAUTOEV zero. They select the original gas and cloud tables, the simple aerosol profile and the old statistical fit. The first uppercase NAMPHY3 group is empty. The original formatted diagnostic output is outside this numerical interface.

The declaration entry is `int md2asm_declare_legacy_radiation_parameters(output, capacity)`, using x0 and x1. The complete TPHY3 record has 5,376 bytes. This entry writes only N_SPBAND=2 at byte zero and RTL=255.8 K at byte eight. It preserves the four-byte alignment gap and every remaining byte. These two defaults come from the original type declaration and its genuine typed query. They do not define any other previously unwritten field.

The complete numerical entry is `int md2asm_initialize_legacy_radiation_parameters(text, length, output, capacity, physics, physics_capacity)`, using x0 through x5. Physics is the live 1,096-byte TPHY record. Its five required controls occupy offsets 1,016, 132, 120, 92 and 1,028 respectively in the order above. The output must already contain the two declared defaults. Both complete records are mapped and eight-byte aligned, and their ranges must not wrap. The output is disjoint from all inputs. Text has one through 262,144 bytes. FPCR, the floating-point control register, must be zero.

Each bounded entry returns zero on success and two on an atomic refusal. Validation finishes before output mutation. The numerical parent has a 48-byte frame and calls only the already accepted empty-group reader and its own raw child. It preserves x18, Arm saved registers, errno, floating-point controls and exception flags, with sixteen-byte stack alignment. No allocation, mathematical-library function, original OpenIFS callable, module state, type table or prepared numerical packet supplies production.

The raw leaf is `void md2asm_set_legacy_radiation_parameters_raw(output)` in x0. Its caller must satisfy the checked parent contract. It performs all 270 source-ordered literal stores, assigning 2,160 bytes and retaining the remaining 3,216 bytes. The embedded assembly table contains each named source offset and exact FP64 literal bits. No high-level solver or compiler intermediate representation is generated. Unused newer radiation tables, the calculated-later solar value RII0 and all padding retain their incoming bytes.

The coefficient groups describe the fraction of radiation scattered backwards, absorption and scattering by aerosols and clouds, gas transmission, cloud optical fits and a statistical radiation model. Fractions and mixing ratios are dimensionless. The original table definitions retain their source units and coefficients. QCO2 is the mass fraction corresponding to the source carbon-dioxide concentration of 353.2 parts per million by volume. EARRT is the ratio of atmosphere depth to Earth radius. Source literal assignment adds no arithmetic rounding or numerical exception.

Three complete source cases compare 16,128 bytes with zero differences, using zero and two distinct incoming patterns. They include an unchanged signalling-NaN payload in RII0. All 102 typed field offsets and sizes agree, and every source-unwritten byte, input and buffer guard remains intact. Native ABI masks are zero, FPCR and FPSR match immediately, and the original diagnostic errno zero and source x18 use remain explicit service differences. Native errno remains unchanged.

The independent gate checks 134 optical, gas, geometry and coefficient relations, including the molecular-mass conversion for carbon dioxide and positive legacy Padé denominators at nonnegative argument. These checks cover the role of the fixed empirical tables. They do not establish independent physics for a complete forecast. Five meaningful refusals are atomic, and a complete record ending at a protected page passes. A static assembly entry constructs its own input controls and writes all 5,376 exact bytes, with no undefined symbols or dynamic dependencies. Enclosing MODEL integration and complete forecast admission remain separate.

An independent source and ABI review confirms all selected branches, literal offsets and the final cloud-exponent assignment. The review reuses the completed gates without numerical reruns.
