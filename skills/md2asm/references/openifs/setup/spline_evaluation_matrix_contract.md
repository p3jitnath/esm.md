# Spline evaluation matrix

This raw child implements the selected SETGP2VFE calculation in `arpifs/module/suvfe_hlp.F90`. A cubic spline is a polynomial with four coefficients on each knot interval. The returned matrix evaluates its value or first derivative at each requested dimensionless vertical coordinate. All coefficients and matrix values are dimensionless.

The application binary interface is `int md2asm_spline_evaluation_matrix(const int32_t controls[4], const double *threshold, const double *points, const int32_t *types, const double *knots, const double *pieces, double *output)`. The seven pointers enter in x0 through x6. Controls contain the row count 19 to 21, basis count 21 to 24, basis offset zero to basis count minus 21, and approximation flag zero. Threshold is positive zero. Each row type is zero for a value or one for a first derivative. Points are finite and lie from zero to one inclusive. Knots contain basis count plus four finite nondecreasing values, with four positive zeros at the start and four ones at the end. The caller supplies admissible knots and the complete finite coefficient array from the qualified knot and coefficient children. These are the actual 19-level hydrostatic, new-spline calculation and bounded edge shapes; approximation and second derivatives are outside this interface.

Integer pointers have four-byte alignment, and real pointers have eight-byte alignment. Each input has its declared full extent. Pieces use Fortran order `(basis,4,4)`, with the basis index changing fastest. Output uses Fortran order `(rows,21)`. Input and output buffers do not overlap. The caller owns every buffer. The child allocates nothing and borrows no OpenIFS metadata or numerical callable. Return zero means complete; return two rejects unsupported metadata before output mutation. Valid input satisfies the knot-to-basis admissibility precondition, so every point has a nonzero containing interval.

The child first clears the complete output to positive zero. For each row it scans every knot interval in source order. The final interval that includes the point wins, including equality at a shared knot. It computes the reciprocal interval width and the local coordinate `(point-lower)/(upper-lower)` with separate FP64 operations. It evaluates only the basis functions that cover that interval. A first derivative uses the source coefficient differentiation, Horner evaluation and final multiplication by the reciprocal width. All intermediate rounding points and signed zeros are retained. It uses no fused multiply-add instruction, contraction, approximate arithmetic or numerical table.

Execution requires FPCR zero: round to nearest with ties to even and gradual underflow. Incoming sticky FPSR bits are preserved and source arithmetic can add flags. The child preserves errno, FPCR, x18, x19 through x29 and d8 through d15. Its stack frame is 256 bytes with 16-byte alignment. Its only children are the accepted raw interval coordinate and polynomial derivative/evaluation leaves, so its maximum nested stack use is 256 bytes. Separate Fortran controls check complete returned matrices and immediate source status from fresh and preseeded flags. Independent polynomial identities check values and derivatives. Complete selected operator and forecast acceptance remain separate requirements; this local child has no original-body credit.
