# Selected Vertical Spline Matrix Inverse

This utility computes the matrix inverse consumed by the selected vertical spline setup. A matrix inverse converts the sampled basis values back to their spline coefficients. It implements the returned matrix computation of `algor/external/linalg/minv_caller.F90`, using the directly emitted LU factorisation and inverse children. It does not provide the original general `MINV_8` interface or a condition-estimate result.

The admitted numerical domain is the 25 matrices generated by the retained actual 19-level hydrostatic, new-spline `SUNH_VERTFESPLINE` source component with its actual 40 hybrid coefficients, 101325 Pa reference pressure and qualified eta construction. For each of five active operators, the source calls inverse dimensions 4, 4, 4, 21 and 21. The scaled inputs contain eight distinct matrices. The current source comparison checks every call in that sequence. The selected input packet is a separate verification record, never an input to the production utility. A future caller must construct these matrices through the owned spline children; it must not load the recorded matrices or inverses. Other finite matrices of the same dimensions are not admitted by this evidence.

`int md2asm_selected_spline_inverse(const int32_t *scale, const int32_t *dimension, const double *input, double *output)` takes four addresses in x0 through x3 under the Arm procedure call standard. Dimension is 4 or 21, and scale is zero or one. Each matrix is dimension squared FP64 values in column-major order, with the row index varying fastest. Integer addresses are aligned to four bytes and real addresses to eight bytes. The caller owns mapped buffers of these sizes, with disjoint input and output. The input is read-only and all consumed values and arithmetic intermediates are finite. FPCR is zero, with nearest/ties-to-even rounding and gradual underflow.

Return zero means all output values were written. Return two rejects null addresses, alignment, unsupported dimensions or scale flags, and nonfinite input before mutation. Return three reports a rejected numerical child or singular factor; output remains unchanged. Matrix-domain membership, disjointness and mapped extents are caller preconditions. Numerical failure can add floating-point exception flags, as can the selected source arithmetic.

When scaling is enabled, add the absolute diagonal values in increasing index order and divide their sum by dimension. If that average is positive, divide each matrix entry by it. The direct LU child then chooses the first largest absolute pivot and performs the source factor operations. The inverse children preserve the source upper-inverse and full-inverse column order and pivot swaps. Finally, divide every inverse entry by the same positive average. Every ordinary addition, multiplication and division rounds separately. The consumed BLAS update sites require a single rounding of an exact product plus its addend; the accepted integer rounding child supplies that result without any fused floating-point instruction.

The source `minv_8.F90` uses `DGECON` only to write a private reciprocal condition estimate, private scratch and private integer work. Line 130 rejects a nonzero diagnostic status, and line 67 aborts if that estimate is no larger than tolerance. `minv_caller.F90` lines 108–109 supplies tolerance `100*TINY(binary64)`, or 2.2250738585072014e-306, with zero right-hand-side systems and inverse mode one. The estimate is never used in a returned matrix calculation. This selected utility explicitly omits that unused diagnostic calculation. It does not claim complete `MINV`, `MINV_8` or `DGECON` body replacement credit.

The separate source record shows all 25 diagnostic statuses are zero and all estimates exceed that threshold. An independent exact rational calculation uses each computed inverse B to bound the residual rho = norm1(I−A B). The largest rho is 8.542e-15, below one. The convergent geometric series then gives norm1(A inverse) no larger than norm1(B)/(1−rho). Thus every selected reciprocal condition is at least 0.0047163359012276414, far above the source abort threshold. This proves the declared domain is safely invertible; it does not supply or replace an estimator output.

The source reuses diagnostic scratch as `DGETRI` work. In its selected unblocked branch, `WORK(1)` is written first, and each later column copies all lower entries required by that column before the matrix-vector operation reads them. No prior diagnostic scratch value enters the returned inverse. The focused control captures each genuine incoming scratch preimage, then compares source `DGETRI` with that preimage and a distinct complete byte fill. All returned inverse values, status and errno agree. The raw inverse child owns its corresponding scratch and writes each consumed word before reading it.

Its maximum nested frame is 6080 bytes including the inverse and integer rounding children. It allocates no heap owner and needs no caller cleanup.
