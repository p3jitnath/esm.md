# Post-processing standard atmosphere

This assembly child implements section 2 of `arpifs/setup/susta.F90`. It places the reference tropopause, the boundary above the lowest atmosphere layer, on the nearest model full-pressure level when its pressure is within 5,000 pascals (Pa) of the original boundary. It then recalculates the higher reference layers. The original ICAO table remains unchanged.

Its application binary interface (ABI) is `int md2asm_adjust_postprocessing_atmosphere(double *output, const double *layers, const double *pressure, const double *physical, uint64_t levels)`. Registers x0 through x4 hold these arguments. Register w0 returns zero on success or two when a checked shape, address or model-pressure requirement fails before any output write. All spans are mapped, aligned to eight bytes and disjoint from the output. The layer and output tables each contain four nine-word FP64 arrays: height in metres, temperature gradient in kelvin per metre, temperature in kelvin, and pressure in Pa. The 32-byte physical input holds gravity, dry-air gas constant, dimensionless RPLRG scalar and surface pressure. The qualified layer child supplies the input table. Model pressure contains 1 through 256 positive finite FP64 words.

The child copies all 288 table bytes, then searches model pressure in increasing index order. The source `<=` rule selects the later index on a distance tie. It leaves the copy unchanged if the closest distance exceeds 5,000 Pa. Otherwise, it calculates the new boundary height and temperature from the original lowest gradient, changes the second gradient to reach the original third-layer temperature and height, then recalculates layers three through nine. The recalculation uses `-RG / RD`, in the source order, without RPLRG used by the initial table calculation. Every FP64 operation rounds separately.

This child calls the accepted direct POWER leaf and the direct EXP child. It allocates no heap storage and uses a 160-byte aligned stack frame. It preserves x18, x19 through x29, the low halves of v8 through v15, errno and the floating-point control register. Existing sticky floating-point status bits remain set, and its arithmetic adds the same flags as the source. FPCR must be zero. Original logging and profiling are omitted diagnostics; no forecast calculation is omitted.

The separate Fortran control retains the source nearest-level search and adjustment expressions. Focused cases compare the complete returned table, unchanged inputs, the no-adjustment branch, distance ties, source status and saved registers. This component does not supply a precomputed model state or an original Fortran callable. The enclosing standard-atmosphere construction passes the selected complete forecast check.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected route. Its declared upstream data and branch limits remain in force.
