# Standard atmosphere geometry construction

This assembly constructor implements the numerical and storage work of `arpifs/setup/susta.F90`. It constructs the six standard-atmosphere owners in the selected Geometry record, calculates the original ICAO and post-processing reference tables, and selects the model level used for temperature extrapolation. It takes initialized hybrid-coordinate coefficients and vertical-mode controls as upstream inputs. It supplies no initialized atmosphere packet and calls no original Fortran procedure, constructor or vtable.

Its application binary interface (ABI) is `int md2asm_initialize_standard_atmosphere(void *geometry, const double *physical, uint32_t ecmwf, double *references, int32_t *extrapolation_level)`. Registers x0 through x4 hold these arguments. The physical input is seven FP64 words: gravity RG in metres per square second, gas constant RD in joules per kilogram per kelvin, dimensionless RPLRG, surface pressure VP00 in pascals (Pa), extrapolation height HEXTRAP in metres, top pressure TOPPRES in Pa, and heat capacity RCVD in joules per kilogram per kelvin. HEXTRAP is the already parsed NAMSTA scalar, whose source defaults are 150 m in ECMWF mode and 100 m otherwise. Configuration parsing must preserve any explicit user value. Supplying that scalar does not supply a missing numerical calculation.

Geometry spans 17,096 bytes under the queried GNU 12 layout. NFLEVG at byte 5,224 contains 1 through 256 levels. Pointer slots 3,240 and 3,264 hold live TVAB and TCVER records of 512 and 216 bytes. Their original coefficient descriptors and numerical preconditions follow the accepted GPHPRE contract. Consumed coefficients are genuine contiguous GNU arrays with canonical origin: descriptor offset plus lower bound is zero for unit stride, and the raw data address points at the stored lower-bound element. The private pressure child reconstructs indexed bases from that data address and lower bound. The caller checks every consumed rank-one descriptor's element length, type, span, stride and lower/upper coverage before allocation. This selected caller supports conventional NDLNPR=0 and finite-element mode. All six YRSTA allocation data pointers must initially be null. The six 64-byte descriptors start at Geometry byte 3,272 and occur in source order: STPREH, STPRE, STPHI, STTEM, STDEN and STZ. All input and output spans are mapped, aligned to their element size and disjoint, and their address arithmetic must not wrap.

The child allocates STPREH(0:NFLEVG), then the five NFLEVG-word owners in source order. It writes complete genuine rank-one GNU descriptors. Its layer child computes all nine heights, gradients, temperatures and pressures. The caller sets bottom half-level pressure to VP00, then invokes the accepted GPHPRE arithmetic through a private entry with explicit TOPPRES, RD, RCVD and integer field-map inputs. The map [1,2,3,4,5,6,7,7] is metadata from the source SUPTR_TXYB true branch. GPHPRE retains every numerical instruction and replaces only its original module-address lookup and math-call targets. Its LOG and EXP operations call the qualified direct leaves. Source coefficients remain unchanged.

The single-column ICAO profile child computes STTEM and STPHI from full pressure. The caller then calculates STZ=STPHI/RG and STDEN=(STPRE/RD)/STTEM, preserving both division roundings. It selects NLEXTRAP by searching levels downward with strict smaller-distance comparison, so an equal-distance tie keeps the larger level number. It finally calculates the post-processing reference adjustment. References spans 576 bytes: the complete original ICAO table followed by the complete post-processing table, each ordered height, gradient, temperature and pressure with nine FP64 words per array. The extrapolation result is one int32 level number.

Register w0 returns zero on success, two for a checked input failure, or three for allocation failure. Checked input failures precede allocation and output mutation. Allocation failure frees every new owner and clears all six data pointers; descriptors may retain partially written bounds. No original array is freed. On success the six allocations belong to Geometry and must be released once by its owner. This caller uses a 288-byte frame with 16-byte stack alignment, preserves x18 and required saved registers, leaves FPCR unchanged at zero, preserves errno around storage operations, and retains the numerical status flags produced by the source arithmetic. Original logging, DR_HOOK and NAMSTA file handling are outside this raw numerical ABI. The native adapter obtains the selected configuration value explicitly.

The critical control runs the separate complete original SUSTA body and its original GPHPRE and PPSTA children. The fixture supplies only upstream hybrid coefficients, scalar constants and NAMSTA text. It compares all six returned numerical owners, all source-defined descriptor bytes, both complete reference tables, NLEXTRAP, unchanged upstream owners, guards and ABI/status. It includes the retained actual 19-level finite-element startup inputs plus conventional positive-top and closed-top cases. Existing child physical checks are reused, and the complete composition also checks positive pressure, temperature and density, height order and the density equation. The selected complete forecast check passes.

The [complete forecast check](../../../../../src/openifs/README.md#verification) passes for the selected 19-level route. Its declared upstream data and branch limits remain in force.

The constructor uses [layer tables](standard_atmosphere_layers.md), the [pressure profile](standard_atmosphere_profile.md) and the [post-processing adjustment](postprocessing_atmosphere.md). The [native entry](standard_atmosphere_native_entry.md) reads the selected configuration group.
