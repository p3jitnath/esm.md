# Selected Convection Parameter Setup

This component owns the selected `SUCUMF` and `SUCUMF2` parameter setup from `arpifs/phys_ec`. Convection describes rising and sinking air that carries heat, moisture and momentum. These setup routines provide rates, thresholds and switches for that later calculation. They do not advance a forecast field. Original OpenIFS code and state occur only in the separate verification control.

The C ABI is `int md2asm_initialize_convection_parameters(text,length,records,inputs,controls)`, using x0 through x4. Text contains 1 through 262144 live bytes. The four output `{address,capacity}` pairs are TECUMF (344 bytes), TECUMF2 (240), TCUMFS (12) and an owned thermal namespace (24). TCUMFS aligns to four bytes; every other record and table aligns to eight. Each output maps its complete extent, has no address wrap and is disjoint from every other output and every live input, table, text or control range. Complete record capacity tails remain outside the written extent. Read-only inputs may share storage. Unsupported input returns two before output changes; success returns zero. FPCR must be zero.

The four read-only input pairs are live STPRE (19 FP64 pressures, 152 bytes), physical constants (520 bytes), three dynamical scaling factors (24 bytes) and the current TRIP timestep (8 bytes). Controls are two int32 values `{level_count=19,spectral_limit=21}`. STPRE comes from the owned standard atmosphere. Constants RG at byte 112 and RTT at 368 come from `physical_constant_setup.S`. The scaling words are named RPLRG, RPLDARE and RPLRADI, in that order; the complete caller must supply these through its own selected SUDYNCORE producer, with actual values one. That upstream namespace remains separate integration work. The timestep points to the live TRIP TSTEP field at offset 200. No source global or captured parameter packet supplies production values.

Supported pressures are finite and positive. RG is finite in [1,100] m/s², RTT lies in [200,350] K, the three scaling factors lie in [0.25,4] and the finite timestep lies in [1,86400] seconds. These bounds keep all supported divisions and products finite and away from zero denominators. Nonnegative IEEE binary64 encodings are checked with integer comparisons, so rejected NaNs do not change FPSR. The actual owned Earth inputs are a subset of this bounded raw interface. Synthetic scaling and threshold profiles verify the source arithmetic; they do not claim an alternative complete planetary setup.

The first uppercase-exact NAMCUMF and NAMCUMFS groups must be present and empty, using the accepted source ten-column marker subset. The unchanged empty-group reader rejects unsupported overrides. Therefore LMFGLAC remains true, the linearized short-timestep switch remains false and the timestep-dependent limiter branch is inactive. There is no allocation or retained pointer in these output records. All inputs are borrowed only for the call and remain unchanged. The caller owns the outer records and their lifetime.

The thermal namespace contains RTWAT, RTICECU and RTWAT_RTICECU_R as three FP64 words. The first assignment owns the consumed `SUPHEC` statement RTWAT=RTT. `SUCUMF` then sets RTICECU=RTT−38 K and the reciprocal to `1/(RTWAT−RTICECU)`, in that order. This is an explicit owned namespace for these three named source scalars; it does not claim the remaining YOETHF initialization.

Both children preserve every source multiplication and division involving the live scaling factors and constants. Rates for air entering or leaving a convective plume are scaled by RPLRG. The main evaporation coefficient divides by RG, its rain factor divides by RPLRG, and its melting timescale evaluates `18000/(RPLRG*RPLDARE)*0.66` with separate rounds. The linearized melting timescale is a source-only constant expression. Its final closure coefficient is `0.33*RPLRADI`, preserving the source overwrite of earlier resolution choices. Literal-only constant expressions use their correctly rounded source FP64 values without an invented runtime stage. Fused multiply-add, contraction and approximate arithmetic are excluded.

The source scans STPRE from level 19 down through level 2, using strict pressure comparisons. The main thresholds are 35000, 6000, 95000, 85000, 50000, 70000, 10000 and 100 Pa. Its NJKT1, NJKT2 and NJKT8 start at two; NJKT3 starts at seventeen and ends at the minimum of seventeen and its scan result. Other main index words keep their incoming value if no pressure crosses their threshold. The linearized scan uses 35000, 6000, 95000, 50000 and 70000 Pa, with the corresponding source defaults and minimum. This preserves strict ties and source-unwritten words rather than inventing an index for an inactive case.

The full 620 output bytes include source-unwritten data and padding. In particular, TECUMF2 RTAU02 at byte 184 is not assigned by this selected source and remains incoming. Each raw numerical child uses caller-saved registers only. The parent uses a 160-byte frame and calls the accepted empty-group child and these two raw children, preserving x18, saved registers, FPCR and errno. Numerical operations may add FPSR flags.
