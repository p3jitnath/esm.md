# Alternative Physics Parameters

SUPARAR initializes parameters for alternative cloud, turbulence and surface schemes. The selected forecast does not activate those schemes, but its original startup still sets this record. This direct service follows the complete selected source path for the 904-byte TPARAR record. LMSE and LMPA are false, so the pseudo-history buffer GPARBUF has zero size and is neither allocated nor read. The actual NAMPARAR group is empty. No original module, object or callable supplies production data or arithmetic.

`int md2asm_initialize_alternative_physics_parameters(text, bytes, output, capacity, inputs)` uses x0 through x4. Text has 1–262144 mapped bytes. Output is writable and eight-byte aligned, with capacity at least 904. Inputs is a read-only, eight-byte-aligned 32-byte record. All ranges must be mapped and nonwrapping, and output must be disjoint from both inputs. The eight int32 input words are LMSE, LMPA, LRAYFM, LRAYFM15, YH.LACTIVE, NUNDEFLD, LSFORCS and reserved. The first two must be zero, the next three must be zero or one, and NUNDEFLD can be any int32 value. The last two words are not consumed by this selected path. FPCR must be zero. Return zero means success and two means unsupported input before any output store.

The service sets the original scalar and blank-padded string constants, with each literal's original binary rounding. RCRIAUTI and RCRIAUTC are mixing-ratio thresholds, in kilograms per kilogram, for changing cloud particles into precipitation. Their unsuffixed literals first round to single precision before widening to FP64, a 64-bit floating-point value. XFRACM90 and XSPLIT_MAXCFL retain the same source literal rule. The source temperature-threshold parameter RT0CRIAUTI is the ordered base-ten logarithm of RCRIAUTI, plus 3.5, divided by the widened single-precision 0.06. Its numerical convention is kept from the original alternative scheme. XA1 is two divided by three. The direct child performs each FP64 stage itself using the original scalar LOG10 library provider.

A true YH.LACTIVE selects seven total and four ice species, with CMICRO equal to OLD4. False selects six total and three ice species, with CMICRO equal to OLD3. The liquid count remains two. The short-wave band count is six when either radiation flag is true and one otherwise. NPRINTFR is the exact integer product 3600 times 36. NGPAR is zero, and nineteen pseudo-history indices each copy NUNDEFLD. Source text strings retain their full declared widths and trailing blanks.

The parent writes 806 record bytes and retains the other 98 bytes, including UN806. The allocatable XSW_BANDS descriptor remains untouched and has no owned allocation on this path. The caller retains each buffer. Raw children are `md2asm_set_alternative_parameter_literals_raw(output)` and `md2asm_set_alternative_parameter_arithmetic_raw(output, inputs)`. They require the checked parent interface. Typed assembly offsets keep the original field names, and all scalar representations use target little-endian order.

The parent uses 64 bytes of private stack. Its arithmetic child uses a further 64 bytes, for 128 bytes of own depth, excluding libm. The literal child and reused empty-group reader are leaves. The service preserves x18, required saved registers, low d8–d15, aligned stack, FPCR and incoming errno. It retains natural arithmetic FPSR flags. The fixed positive LOG10 argument has no mathematical error. Fused instructions, reassociation, approximate operations and output normalization are excluded. The sole external numerical API is system libm LOG10; the two actual source and direct consumer slots resolve to exactly the same provider. Source informational formatting can clear errno and change x18, while the declared quiet service preserves both.

Three complete genuine SUPARAR profiles match all 2712 bytes, including every unchanged descriptor and padding byte. All 108 independent relations, six atomic refusals and three complete ranges ending at protected pages pass. Native ABI masks are zero, and natural FPCR/FPSR match the original. The source comparison includes both hail choices, both short-wave default outcomes, and three undefined-field sentinels. A separate assembly process matches all 904 source bytes with only libc and libm. No full SUPHMF or forecast is claimed at this boundary.
