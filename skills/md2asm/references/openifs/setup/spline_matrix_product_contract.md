# Small spline matrix product

This raw child multiplies the matrices used at the end of selected SUVERTFEB. All matrix entries are dimensionless. For every output entry it starts at positive zero, then adds 21 products in increasing shared-index order. Each multiplication rounds to FP64 before the addition rounds. This is the consumed small-matrix source branch: the genuine five operators use the inline loops and no runtime MATMUL call. A separate source control captures the four operand matrices at their original child boundaries and establishes that these three separately rounded products give every original final operator bit. Single-round product-plus-add arithmetic is a different result on this corpus.

The application binary interface is `int md2asm_spline_matrix_product(const int32_t *rows, const double *left, const double *right, double *output)`, with pointers in x0 through x3. Rows is 19, 20 or 21. Left has shape `(rows,21)`, right has shape `(21,21)`, and output has shape `(rows,21)`. The first index changes fastest, as in Fortran. Integer input has four-byte alignment and real buffers have eight-byte alignment. Inputs are finite, complete buffers; the output does not overlap an input. The caller owns all storage. Return zero means complete, and return two rejects unsupported pointer, alignment, row count or floating-point mode before output mutation.

Execution requires FPCR zero for round to nearest with ties to even and gradual underflow. The child preserves errno, FPCR, x18 and every saved register. Incoming sticky FPSR bits remain and the source arithmetic can add flags. It has no stack frame, allocation, external callable, type descriptor, module input, or precomputed numerical result. The assembly contains separate multiply and add instructions and no fused operation. Source controls and exact rational dot products qualify this child; complete parent and forecast admission remain separate. No standalone MATMUL runtime body is claimed.
