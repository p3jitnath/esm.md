# Selected grid field configuration

`md2asm_initialize_selected_grid_field_configuration(gfl, constants, text, text_bytes, controls, effects)` constructs the complete selected GFL namespace. GFL is the persistent record that describes the grid-point fields. Every returned byte comes from declared component defaults, selected source assignments, explicit owned inputs or live NAMGFL text. The original SUGFL1, SUGFL2 and SUGFL3 bodies are separate verification controls.

The AArch64 arguments are x0 for a fresh zero 1,359,136-byte output record, x1 for the owned 520-byte physical constant record, x2 for exact input text bytes, x3 for their length, x4 for eight four-byte control words and x5 for two four-byte output logicals. The output, constant, control and effect buffers have 8-byte alignment; the text has byte alignment and a length of 1–262,144 bytes. Output ranges are disjoint from every input and each other, with no address wrap. Read-only inputs may overlap each other. The caller provides valid complete allocations. FPCR must be zero, which selects round-to-nearest with ties to even and gradual underflow. The metadata service preserves raw incoming FPSR and errno.

The control words are `{19, 0, 25, 1, 1, 0, 1, 1}` in this order: vertical levels, supplementary levels, stopping step, GRIB file-format code, LSPRT, LTRAJHR, NCONF and LECMWF. Counts are integers, and logicals use four-byte 0 or 1. The 19 levels and GRIB signature come from owned initial-file metadata. Stopping step 25 comes from the owned model clock, whose TRIP record contains NSTOP at byte 52. LSPRT true follows selected ECMWF SUDYNA defaults and empty actual dynamics groups. LTRAJHR false is an explicit owned integer-zero storage policy supported by original source and ELF zero-fill evidence; it is not a Fortran-declared default. NCONF 1 and ECMWF mode are configured inputs. A different tuple is rejected before output mutation.

A temporary nine-profile buffer receives the qualified source defaults. The bounded direct NAMGFL reader applies live text and checks its supported keys and syntax. The parent requires the selected rain and snow input requests −1. Registration validates every profile byte against the selected route, constructs all 2,163 component records, registers the eight active fields, constructs all 61 aliases, applies source-ordered attributes and builds the fixer maps. The remaining-default child constructs all 53 other template families, which occupy 555,488 bytes, and all 52 selected phase-1 scalars. All returned pointers refer to persistent output storage; none refers to the temporary profiles.

Inactive profiles and phase-1 scalar stores occupy source slots that are disjoint from the active registration writes. Their selected bit-copy operations can therefore follow registration without changing dependencies. The same-address whole-source comparison verifies this ordering. Source-default character case, indexed names and integer field codes are retained. The four unsuffixed chemical metadata literals −99999.9 preserve the original REAL32 rounding before FP64 widening. No captured namespace packet or compiler-produced numerical body is an input.

The two output logicals are the selected LVSPLIP and LSPLTHOIGFL effects, both false. The service owns the complete GFL namespace, including inactive profiles, unassigned bytes under the zero policy, descriptors, aliases and maps. Other SUGFL1 changes to enclosing chemistry or model records remain separate startup work. Original PRINT_GFL console output is outside this metadata service. The utility leaves status unchanged and does not imitate formatting flags. In the enclosing check, the owned physical constant producer naturally sets FPSR 16 before both genuine source and direct construction; final FPCR, FPSR and errno match exactly for final flag words 16, 31 and 24.

The parent uses a 2,416-byte aligned frame; its largest nested registration path uses 5,104 bytes before leaf children. It preserves x18, x19–x29, the required SIMD registers, SP alignment and FPCR. Return 0 means success, 2 means a checked input rejection before output mutation, and 3 reports an unexpected internal-child rejection after construction has begun. The graph contains directly written assembly only and needs no original program, module data, type metadata, virtual table, callable, libc or Fortran runtime.

Three genuine SUGFL1/SUGFL2/SUGFL3 cases compare all 4,077,408 final GFL bytes at the same MODEL-backed address, including complete raw pointers. Six immediate ABI/status calls pass with native masks zero; the separate original reference retains its x18 difference as mask 2. The 599 independent relations check field counts, names, codes, thermodynamic copies, backward links, interpolation positions, fixer indices, profile boundary names, indexed codes and wavelength defaults. All 480 guard bytes and five before-mutation rejection cases pass. A pure assembly `_start` example constructs the namespace from owned constants and explicit live text and exits 0 without a dynamic dependency or undefined symbol. No forecast or original-body count is claimed by this local checkpoint.
