# Selected Cloud and Gravity-Wave Setup

This component implements complete `SUCLD`, `SUGWD` and the selected one-launch-level `SUGWWMS` setup from `arpifs/phys_ec`. It owns the numerical parameter calculations and one CETA allocation. The production link has explicit owned buffers, the accepted empty-group reader and libc allocation/error-address services. Original OpenIFS routines, globals, type objects and method tables occur only in the separate reference control. This is one physics-parameter stage, not complete SUPHEC or an autonomous forecast.

The parent C ABI is `int md2asm_initialize_cloud_gravity_wave_parameters(text,length,records,inputs,controls)`, using x0 through x4. Text contains 1 through 262,144 live ASCII bytes. Record table `records[6]` contains three `{address,capacity}` pairs for TECLD (264 bytes), TEGWD (96 bytes) and TEGWWMS (168 bytes). These records and tables align to 8 bytes. Controls are two aligned int32 values `{level_count=19,LEPHYS}`, with LEPHYS either 0 or 1. The first descriptor word in the incoming TECLD record must be null, so the new CETA owner cannot replace an unreleased owner. The caller owns and eventually releases the three outer records.

Input table `inputs[12]` contains six read-only `{address,capacity}` pairs: eta (19 FP64 words), STPRE (19), VAH (20), VBH (20), physical constants (520 bytes) and current timestep (one FP64 word). Every address aligns to 8 bytes, maps its complete consumed extent and is disjoint from all output records. The records are mutually disjoint and do not intersect text, tables or controls. Read-only inputs may share storage if their values meet each declared role. FPCR must be zero. Unsupported bounds, scalar domains, owner state or namelists return 2 before mutation.

Eta is dimensionless and lies in [0,1]. STPRE contains finite positive reference pressures in pascals. VAH contains finite pressure coefficients from 0 through 101325 Pa; VBH contains finite dimensionless coefficients in [0,1]. Standard pressure and eta profiles come from their owned setup producers. The finite positive timestep lies from 1 through 86400 seconds. The live physical-constant record is produced by `physical_constant_setup.S`; its RHOUR at byte 56 is 3600 seconds. The parent validates that selected source-defined value, then the numerical children read it through its owned address. No original constant namespace supplies a value.

The actual first uppercase NAMGWD and NAMGWWMS groups must be empty. The reused bounded empty-group reader preserves original POSNAME group-case rules within its declared first-nonblank, ten-column marker subset. NCONF is the selected configuration 1. The empty NAMGWWMS leaves NLAUNCHLEV at 1, so the multiple-launch fractional-power branches are outside this contract. Both retained source groups are empty.

After validation, the parent allocates 152 CETA bytes, corresponding to the CETA owner allocated at `SUALLO:127`. Its rank-one GNU descriptor has element length and span 8, bounds 1:19, stride 1, offset -1 and REAL type. Every eta value is copied by its complete 64-bit word. The source SUCLD constants fill all 24 FP64 parameter fields and LOMEGA; record padding at bytes 260 through 263 is preserved. The raw cloud child uses no floating-point arithmetic.

For SUGWD, each midpoint pressure is evaluated in the source descending level order as `0.5*(VAH(j)+VAH(j+1)+80000*(VBH(j)+VBH(j+1)))`, with a separate FP64 rounding after every add and multiply. Its ratio to 80000 Pa selects NKTOPG using `>=0.94`. The source ascending scan selects NGWDTOP using midpoint pressure `<9.9 Pa`. The descending STPRE scan selects NGWDLIM using `>=1000 Pa` for this 19-level route, and LEPHYS=false resets that result to zero. Both source tendency divisions, 20/RHOUR followed by 80/RHOUR, retain their rounding points; the final tendency has units m/s per second. No fused multiply-add or reassociation is used.

SUGWWMS retains its source stores, including unassigned GMSTAR_L(2:3) and padding. It starts the call frequency at RHOUR, changes it to `2*TSTEP` when `TSTEP>=RHOUR`, then computes `INT(frequency/TSTEP)*TSTEP` with a signed 32-bit truncation toward zero and conversion back to FP64. The descending level scan from 19 through 2 uses strict `>` tests against 45000, 70000 and 20000 Pa to select all three launch indices. Momentum flux has one active launch amplitude; inactive amplitudes are positive zero. All remaining scalar parameter stores follow the declared source constants.

The numerical children use explicit raw buffers, preserve x18 and all saved registers, and use only caller-saved floating-point registers. The SUGWD child has 160 bytes of source midpoint scratch. The owning parent preserves entry errno around allocation, allows numerical FPSR events and retains FPCR. Original namelist and formatted-diagnostic I/O is omitted and its immediate source errno/status is recorded separately. The source and direct complete parent agree at the natural enclosing status after all three children. No arithmetic flag is forced to imitate logging.

`md2asm_release_cloud_parameter_eta(record,capacity)` releases CETA and clears only its descriptor data pointer, retaining other record bytes and descriptor metadata. It preserves FPCR, FPSR, errno, x18 and saved registers. Array allocation failure returns 1 without publishing an owner or changing the three output records. The owner may be released only once while its outer record remains live.

Verification inputs reuse the admitted R4 owned vertical output and the retained genuine SUSTA output. VAF and VBF use Geometry descriptors 272 and 336; VAH and VBH use 144 and 80. Eta input preparation applies the accepted finite-element pressure expression only in the verification tool. Production receives the live eta produced by owned GPHPRE. The original source remains a separate control and no captured output record is included in production assembly.

The parent uses a 160-byte frame and its orographic child uses 160 scratch bytes, so the maximum assembly stack use is 320 bytes. The release frame is 80 bytes. External libc services have their own implementation-defined stack use. The parent does not read record capacity tails, input capacity tails or bytes beyond the live text length. One guarded check puts all thirteen declared ranges immediately before inaccessible pages.

Three genuine child-source profiles compare 2,040 complete record and CETA bytes, with twelve immediate source/native ABI observations. The original formatted I/O uses x18 in the source wrapper, which is retained as source ABI mask 2; every direct child and new parent/release observation has mask zero. The new parent reuses those unchanged expected bytes and preserves every scalar, descriptor word, source-unwritten spectrum word and padding byte. All 152 CETA payload bytes are compared before the one descriptor base word uses the explicit correspondence between separate allocations. No numerical word is masked or changed.

The new parent and release pass eight immediate lifecycle ABI/status calls, thirty atomic input rejections and a further protected-range parent/release pair. A separate allocation fixture fails the one selected allocation before publication, then checks one balanced allocation and release; it is not linked into production. The independent check covers 651 eta, pressure, threshold, positive-coefficient, launch-flux, integer-period and preservation relations. The synthetic pressure-threshold case is a numerical edge profile, not a physically ordered atmosphere; the actual owned eta and reference-pressure profile retain their producer evidence.

A separate assembly entry reads live namelist text and explicit verification input owners, links these production objects directly and writes 704 complete bytes: 528 record bytes, 152 CETA bytes and 24 immediate status bytes. The complete numerical and metadata bytes match the retained source under the single allocation correspondence, and the natural return status is FPCR=0, FPSR=16, errno=0. Its only dynamic dependency is libc, and its only unresolved services are malloc, free and __errno_location. No OpenIFS or Fortran library is loaded. These checks establish this bounded parameter stage; complete SUPHEC, its other parameter families and an autonomous forecast remain outside the claim.
