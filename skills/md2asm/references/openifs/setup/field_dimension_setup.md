# Selected Field-Dimension Setup

This component owns the selected SUDIMF1 and SUDIMF2 calculations. A field stores one model variable across the grid. These setup stages choose field counts, surface-layer counts and switches for storing spatial derivatives. They use integer and logical operations, so all counts are dimensionless. The selected configuration is global, three-dimensional ECMWF forecast mode with NCONF one. The original routines remain separate verification controls.

The first interface is `int md2asm_initialize_physics_field_dimensions(text, bytes, records, controls)`, using x0 through x3. Text contains one through 262144 live bytes. The records table contains six `{address, capacity}` pairs in the order below. Controls contains ten int32 values in this order: NCONF, LECMWF, LR3D, LR2D, LELAM, L_OOPS, LJC, LMCC01, JPVXP and JPCXP. Their supported values are `{1,1,1,0,0,0,0,0,20,50}`. Boolean one means true. The first eight values select the forecast route and the last two come from the source field-description declarations. Each consumed logical member in the input records is zero or one.

| Record | Complete bytes | Use |
| --- | ---: | --- |
| TDIMF | 176 | Read and update model field counts and derivative switches |
| TDPHY | 88 | Read and update physics field and surface-layer counts |
| TDYNA | 456 | Read live dynamics switches |
| TEPHY | 448 | Read live lake, urban, ocean, ozone and diagnostic switches |
| TPHY | 1096 | Read the ozone switch |
| TARPHY | 88 | Read the surface-model switch |

The table, controls and records align to eight bytes and map their complete declared sizes. Every range is nonwrapping. The six records are mutually disjoint, and the writable records do not overlap text, the table or controls. The routine checks address arithmetic, alignment, capacities, overlap, selected controls and consumed logical values before changing public output. Mapped storage is a caller obligation. FPCR, the Arm floating-point control register, must be zero. Return zero means success and two means unsupported input with both outputs unchanged.

The first uppercase NAMDPHY group uses the accepted ten-column group-marker rule. Its keys are case-insensitive and duplicate assignments retain source order. A later duplicate group is ignored. Supported keys are NVEXTR zero, NCEXTR zero and NCSNEC from one through sixteen. Omitted NCSNEC retains source one. A table selects these three keys through the unchanged bounded scalar-parser instructions in `selected_forecast_controls.S`. Parser output is private until validation succeeds. Unknown keys, malformed groups and unsupported values are rejected.

SUDIMF1 source defaults precede the live snow-layer assignment. The producer writes all selected counts and retains source switch precedence. Lake physics raises the surface-tile count from eight to nine, and urban physics then sets it to ten. The ocean mixed-layer model sets 35 fields, while its turbulence option then sets nine. Ozone chemistry selects one two-dimensional group with seven or eight coefficients. The original ozone consistency condition remains. Derivative switches retain the source logical expressions. NVEXTRDI, inactive array descriptors, padding and every other source-unwritten byte remain unchanged. The actual case has five snow layers, nine tiles, four soil layers and four sea-ice layers.

The second interface is `int md2asm_initialize_spectral_field_dimensions(dimensions, dynamics, numspflds, controls)`, using x0 through x3. It receives TDIMF176, TDYNA456, one int32 GFL NUMSPFLDS and the same controls40. The first, second and fourth inputs align to eight bytes, and NUMSPFLDS aligns to four. All complete ranges are mapped and nonwrapping, and TDIMF is disjoint from the three read-only inputs. NUMSPFLDS is zero through 255. Incoming NFC2D is one, and consumed LSPT, LADER and dynamics logical values are zero or one. It computes the source dynamic and thermodynamic counts, combines them with NUMSPFLDS and writes all three spectral counts. LADER false clears LUVDER. The actual case produces three three-dimensional fields, two two-dimensional fields and two one-dimensional fields.

Both interfaces preserve x18, all Arm saved registers, FPCR, FPSR and errno. FPSR records floating-point exception flags. The first interface uses a 416-byte aligned frame and the reused parser adds 96 bytes. The second is a frame-free leaf. Neither allocates storage or calls an original OpenIFS routine. The sole new callable dependency is the accepted owned scalar-parser entry. No numerical weather calculation, original module, type table or prepared model-state packet enters production.

Six complete source cases compare 2640 output bytes with zero differences and unchanged upstream inputs. Twenty-four source/native observations have zero native ABI masks and matching arithmetic controls and flags. Genuine SUDIMF1 namelist I/O clears errno, while the direct utility preserves it. Genuine SUDIMF2 and the direct second stage preserve the tested errno. Seventy-eight independent checks cover tile and ocean precedence, layer counts, ozone groups, retained bytes and spectral count identities. Twelve meaningful rejection cases preserve all caller buffers. One protected-page check places all ten ranges at their actual operating-system page ends and compares all 264 returned bytes.

A separate assembly verification entry reads live fort.4 and uses explicit named input-switch fixtures from the accepted owned producers. It compares 288 complete bytes, including returned status, against the retained genuine source outputs. No returned source packet is embedded. Its link is static with no unresolved symbol. The component's production callers receive live owned records. Independent source and ABI review passes, and the exported parser alias has identical instruction and constant sections to the accepted parser. Complete MODEL construction, forecast integration and performance remain separate work.
