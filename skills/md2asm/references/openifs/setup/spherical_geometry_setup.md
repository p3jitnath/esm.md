# Spherical Geometry Construction

This component composes the checked point geometry, computational geometry and blocked storage children for the selected serial SUGEM2 setup. The grid has 32 Gaussian latitude rows, 64 longitudes on each row, 2048 active points and blocks of 24 rows, with 8 active rows in the final block. The selected stretch type is NSTTYP=1 with stretch factor 1, RC2P1=2 and positive-zero RC2M1. The existing child contracts define every numerical expression and its separate FP64 rounding points.

The raw entry is `int md2asm_initialize_spherical_geometry(geometry, physical, process)`, with addresses in x0 through x2. The objects span 17096, 48 and 8 bytes, require eight-byte alignment and must be mapped, nonwrapping and disjoint from each writable geometry record. The physical record contains stretch, RC2P1, RC2M1, radius in metres, pi and rotation rate in inverse seconds. Radius is 6371229 metres, pi has bits 0x400921fb54442d18, and the positive finite rotation rate lies from 2 raised to minus 30 through 2 raised to minus 8. The two INT32 process indices MYSETW and MY_REGION_EW must both be 1. Each of 54 incoming owner addresses must be null. Return 0 on success, 1 on allocation failure or 2 on a rejected input before mutation.

The caller supplies the live latitude owners previously constructed by direct SULEGA. Read physical indices 1 through 32 of RW, RMU and RSQM2 from their complete GNU descriptors. Read the actual MYLATS, NLOENG, NSTAGP, NSTA and NONL map entries. Require MYLATS(j)=j, NLOENG(j)=64, NSTAGP(j)=1+64 times (j minus 1), NSTA=1 and NONL=64 for every consumed row. NPTRFLOFF may be 0 or 1. The bounded contiguous map owners may include their original halo rows; translate their checked lower bounds before reading. The rank-two owners have one process column. These guards prove the selected computation from consumed values and do not infer a partition from total counts alone.

On success the geometry owns 23 nonblocked spherical numerical allocations, six nonblocked computational allocations, 23 blocked spherical allocations and two arrays of view descriptors. Their numerical storage totals 822016 bytes and their per-block view metadata totals 159616 bytes. Compute every active numerical value through the direct children, bind the views, copy active spherical values into blocked storage and calculate SLHDP through the direct resolution-scale child. All numerical inputs remain unchanged. If a later allocation fails, free every allocation created by this call and clear its address, retaining any partial descriptor bounds. The preflight null checks prevent this cleanup from freeing a foreign owner.

The original entry `sugem2_` receives the live geometry in x0. It reads the initialized RA, RPI, ROMEGA, MYSETW and MY_REGION_EW scalar addresses, which remain explicit compatibility inputs. Full autonomous bootstrap must own their equivalent values. No original Fortran constructor, callable target, vtable or type descriptor supplies a production operation. The new library contains only direct assembly and C allocation, failure cleanup and abort calls. Source logging and accounting calls are outside this numerical and storage interface.

The raw composition uses a 112-byte frame and the original entry uses a 96-byte frame, both aligned to 16 bytes. Preserve x18 and every required saved register. The counter getter `md2asm_spherical_geometry_native_count_get()` returns the number of completed original-entry calls as a 64-bit integer in x0.
