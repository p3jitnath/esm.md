# Public transform interface packing

These assembly leaves call fixed public FIAT and ectrans interfaces from their existing external libraries. They do not call OpenIFS source. The caller owns every configuration value, pointer table, descriptor and output buffer. These tables contain argument addresses and the declared character-length words; no original constructor, method table or OpenIFS module object is used. OpenIFS wrappers still own source-selected input parsing, storage and the order of these calls.

Each entry takes x0 as an eight-byte-aligned complete argument-word array. Its fixed target and count are MPL_INIT with 6 pointers, SETUP_TRANS0 with 18 pointers, SETUP_TRANS with 22 pointers plus two GNU hidden character-length words, TRANS_INQ with 47 pointers, or INI_SPEC_DIST with 15 pointers. The leaf names state the target. At least eight words are mapped even for the six-argument entry. Optional absent pointers are null. Character options are absent in the selected SETUP_TRANS route, so their pointers and both hidden lengths are zero. Arrays passed to assumed-shape dummy arguments use complete caller-owned GNU descriptors; explicit-shape INI_SPEC_DIST arrays use raw addresses. All buffers obey the published external interfaces and remain alive for the call.

The wrappers return w0=0 after the external call or 2 for a null/misaligned argument-word array before the call. They preserve x18 and required saved registers. External return errno,FPCR and FPSR propagate naturally, so the wrapper does not force numerical status. Own frames are 32, 112, 160, 352 and 96 bytes respectively, with 16-byte alignment. External library stack and allocation costs are separate. The largest frame packs 39 inquiry arguments on the stack and saves two register pairs above them. Numerical arithmetic belongs to the allowed external library; these leaves execute no FP64 arithmetic or instruction contraction.

Qualification calls the genuine public APIs from a separate Fortran control and compares complete selected setup/query results with the assembly call route, including native immediate status and ABI. This interface layer alone is not complete SUTRANS0,SUTRANS,SUGEM1A or SUMP ownership. Its source-selected parent and lifetime remain required.

Two fresh-process profiles use incoming FPSR 0 and 24. Each source/direct profile calls real MPI/FIAT initialization, transform environment setup, one actual T21 transform setup and five selected geometry/partition queries. All 3,048 complete output bytes agree, including 285 returned integer words, resolution1 and immediate status after each call; 32 ABI/status calls pass. The source control and direct route use the same existing public libraries. No OpenIFS executable, module or object constructor is loaded by this component fixture. Root-owned setup parsing, complete map construction and lifetime integration remain separate.
