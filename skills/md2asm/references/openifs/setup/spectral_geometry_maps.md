# Owned spectral geometry maps

This checkpoint implements the selected global SUSPGEOM calculation and its SUSPGM, SUSMAP and SUGMRE numerical children. It constructs the two spectral map arrays from a serial triangular wavenumber layout and the live stretch factor. The actual T21 input has truncation 21, 22 wavenumbers, 253 complex spectral positions and stretch 1. Smaller truncations 1 and 2 and stretches 0.5, 2 and near 1 are critical arithmetic/bounds controls. External transform and Atlas implementations are outside this component.

The application binary interface is `int md2asm_initialize_spectral_geometry_maps(void *record, const int32_t dimensions[4], const int32_t *wavenumbers, const int32_t *starts, const double *stretch)`, with addresses in x0 through x4 and return status in w0. The 200-byte caller-owned record has GNU rank-two GMR metadata at 0, SCGMAP metadata at 88 and 24 untouched ESCGMAP bytes at 176. Both data pointers must be null. Dimensions are `{N, N+1, (N+1)(N+2)/2, 0}`, with 1≤N≤21. Integer vectors have N+1 stored elements: wavenumbers[j]=j and starts[j] is the cumulative number of positions in all earlier wavenumber columns. The record and FP64 input are eight-byte aligned; int32 inputs are four-byte aligned; all buffers are mapped, complete and disjoint. The live finite stretch is in [0.5,2]. Descriptor and input checks precede allocation or mutation. No original module object, type table, method table, constructor or numerical callable is an input.

GMR has shape(NSPEC,2), and SCGMAP has shape(NSPEC,3), each with one-based contiguous GNU descriptors and separate malloc owners. Return 0 means complete; return 2 rejects inputs without mutation. Return 1 reports allocation failure with both data pointers cleared; descriptor bounds may remain. `md2asm_release_spectral_geometry_maps(record)` frees only those two owners, clears their addresses and preserves all other record bytes. Callers own the record and release both arrays exactly once before record destruction. Allocation does not supply a precomputed numerical stage or fill payloads in production.

The integer $`N`$ is the highest retained degree, $`m`$ is the longitudinal wavenumber, $`n`$ is the degree within that column and $`c`$ is the dimensionless stretch factor. A spectral position stores one complex coefficient, which represents a spatial wave. The weights $`e(n)`$ connect neighbouring degrees. For each wavenumber $`m`$, source recurrence coefficients are $`e(n)=\sqrt{\max(0,(n^2-m^2)/(4n^2-1))}`$ through N+2. SUSPGM first forms $`a=0.5(c+1/c)`$ and $`b=0.5(c-1/c)`$, then writes GMR diagonal a and off-diagonal b*e(n+1), with the final off-diagonal positive zero. SUSMAP separately repeats the ordered reciprocal and stretch expressions, then computes $`a^2`$, $`b^2`$ and $`(2a)b`$. SUGMRE recomputes every recurrence coefficient and writes the three SCGMAP planes in source order: $`a^2+b^2(e(n)^2+e(n+1)^2)`$, $`((2a)b)e(n+1)`$ and $`(b^2 e(n+1))e(n+2)`$. Preserve both final positive-zero writes in the third plane, including the shared previous-column boundary when m=N. The selected regular grid gives identity map factors, but the production code executes the source arithmetic and every source write.

All ordinary FP64 operations round separately in source order, with hardware division and square root, FPCR 0, gradual underflow and nearest/ties-to-even. No fused multiply-add or reassociation is permitted. Incoming FPSR bits remain and source operations may add flags. The component preserves errno, FPCR, x18, x19–x29 and d8–d15 as required by AAPCS64. Its maximum recurrence scratch is 24 FP64 values. The setup frame is 320 bytes with 16-byte alignment; its 24-word recurrence scratch occupies bytes 128..319. The release frame is 64 bytes, so maximum nested stack use is 320 bytes apart from the external allocation services. The only production external services are malloc/free and errno access.

A separate typed Fortran control calls the genuine complete original SUSPGEOM with explicit local Geometry and Laplacian inputs. It captures source return status immediately, before copying or releasing reference owners. Acceptance requires all numerical owner bytes, complete source-defined descriptor metadata, untouched ESCGMAP bytes, immediate status and ABI to agree. Independent high-precision recurrence and map-action checks remain separate. No forecast or original-body credit is implied by component readiness.

No forecast calculation is omitted. The complete component checks compare 104,800 numerical bytes and 6,000 record bytes over 30 source cases, with 90 ABI/status calls and 36 atomic input rejections. Independent 90-digit checks cover 6,550 coefficients, 6,690 polynomial map actions and 525 positive-zero boundaries.
