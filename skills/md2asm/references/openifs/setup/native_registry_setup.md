It uses the same live geometry, field and model records after the three next-time arrays have been allocated and set to zero. The seven direct methods then create registry metadata in the original source order. This metadata records array sizes, strides, addresses and ownership; it does not calculate or replace any missing numerical initialization.

The caller retains its ordinary Arm interface, its existing variable-associated guard, all numerical calls and its stage counters. Created metadata and declared temporary buffers belong to the field record, while wrapped numerical arrays retain their existing owners. If allocation fails part way through registration, earlier metadata owners remain live until the rejected process exits.

The SULAP adapter receives the original raw TLAP record in `x0` and read-only TDIM record in `x1`. Failure frees earlier buffers, clears all nine data pointers and aborts; descriptor bounds written before failure can remain.
