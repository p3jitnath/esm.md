# Owned selected grid field aliases

`md2asm_bind_selected_grid_field_aliases(configuration)` builds all component associations used by the selected eight-field `SUGFL2` path. An association stores an address of an existing record; it does not allocate another record. The complete 1,359,136-byte configuration owns all 2,163 embedded 368-byte components at byte 3848. Every returned association borrows that fixed array and is valid only while the configuration remains at the same address.

The AArch64 interface takes the configuration address in x0 and returns 0 on success or 2 before mutation. The complete mapped buffer has 8-byte alignment. The child requires eight registered grid fields, two NOGW fields and FPCR = 0. It checks all inactive group counts and LAERLISI false, then verifies that every borrowed target has the expected active state and MP index before it changes any association. The earlier registration child supplies the active records; the declared-default and reset children supply the inactive records. Other field families are outside this selected entry.

There are 44 scalar associations and 17 complete rank-one descriptors. The six named active scalars borrow components 1–6 in Q, L, I, S, R, A order, and YNOGW borrows components 7–8. The 38 inactive named scalars borrow their source-defined upper-array dummy targets; the 16 inactive groups each borrow one upper-array dummy target. These inactive targets are ordinary components inside the same owner, with LACTIVE false. No dummy heap owner is introduced.

Each scalar association is one 64-bit address. Each complete 64-byte GNU descriptor contains base address at 0, element offset −1 at 8, element length 368 at 16, version 0 at 24, rank 1 at 28, derived type code 5 at 29, attributes 0 at 30, span 368 at 32, stride 1 at 40, lower bound 1 at 48 and upper bound 1 or 2 at 56. The logical first component is at `base + 368 * (offset + lower * stride)`, which equals the stored base. This representation is a declared compatibility layout written by the assembly; no original type or virtual-table object is consumed.

The source map is retained in `source_alias_map.json`, with typed address evidence in `field_component_reset_reference/typed_registration_layout.json` and `typed_alias_controls.json`. The source is the initial pointer-association block in `arpifs/setup/sugfl2.F90`, followed by its selected active reassociations. The verification-only control retains that original block and compiles the same typed pointer operations. It does not stand in for the complete original SUGFL2 routine.

Writes are confined to the 1,440 association bytes. Every component, counter, remaining descriptor, source-unwritten byte and guard byte remains unchanged. The child performs no floating-point calculation, uses no stack and calls no service. It preserves SP, x18, x19–x29, all SIMD registers, FPCR, FPSR and errno; caller-saved integer registers and condition flags may change. Its standalone DSO has no required library or undefined symbol.

Two source/direct cases compare all 2,718,272 configuration bytes at two owner addresses, including raw pointers. Four immediate ABI/status calls pass for the direct entry, 482 independent owner-membership, extent and descriptor relations pass, and five invalid-input cases reject before mutation, including a bad target in the final table row. This is one owned metadata child; complete selected defaults, input parsing and caller composition remain separate. No model or forecast was run.
