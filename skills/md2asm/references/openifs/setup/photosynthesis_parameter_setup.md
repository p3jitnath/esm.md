# Selected photosynthesis parameter setup

This component owns complete SUCOTWO and SUFARQUHAR for twenty vegetation types, including the complete one-cell COTWO child that SUCOTWO calls for each type. Its scientific sources are `surf/module/{cotwo_mod,sucotwo_mod,sufarquhar_mod}.F90`; `yos_ags.F90` and `yos_agf.F90` define the two output records. The inputs come from owned fundamental constants, owned vegetation dimensions and the nine parameter tables from the accepted selected SUOPTSURF producer. Production uses no original OpenIFS state, constructor, method table, callable or captured parameter packet.

The guarded Arm application binary interface is `int md2asm_initialize_photosynthesis_parameters(TCST128,TVEG776,optimization_namespace1368,records32)`, using x0 through x3. The final argument contains two address/capacity pairs for writable TAGS 2344 bytes and TAGF 1472 bytes. All six complete buffers and the nine consumed input arrays must be mapped, aligned to eight bytes, nonwrapping and disjoint. Both output records must have fresh complete zero allocation descriptors; all other incoming bytes can be arbitrary. FPCR, the Arm floating-point control register, must be zero, which selects nearest-even rounding and gradual underflow. Return zero means success, one means allocation failure with cleanup, and two means rejected input. Rejection and allocation failure leave both output records unchanged.

TVEG.NVTYPES at byte zero is twenty. TCST.RPI at byte eight is between three and four. TCST.RDAY at byte sixteen is 43200, 86400 or 172800 seconds. The first nine optimization descriptors have their accepted GNU12 layout for FP64 arrays with bounds 1:20 and 1:2. Each descriptor has offset minus twenty-one, element length and span eight, version and attribute zero, rank two, real type three, and strides one and twenty. Their data are copied as raw bytes, including any supported floating-point payload. The nine optional parameter arrays are not consumed.

The parent allocates forty-one owners privately in source order, performs complete SUCOTWO followed by complete SUFARQUHAR, and commits the two outer records after success. TAGS owns one logical array of 84 bytes, one real array of 336 bytes and twenty-nine real arrays of 168 bytes. Their vegetation bounds are 0:20. TAGF owns ten real arrays of 320 bytes with bounds 1:20 and 1:2. The data owners contain 8492 bytes; the two outer records contain 3816 bytes. Genuine type queries establish every named field and allocation descriptor. Descriptor metadata is constructed from those declarations, rather than copied from constructed reference state.

`int md2asm_release_photosynthesis_parameters(records32)` frees these forty-one owners and clears only their base words. It accepts this constructor's result or an already released result, preserves every other record byte, and supports repeated release. The same table/output range and capacity rules apply. The caller owns the two outer records and the upstream optimization namespace. Reinitialization requires fresh complete zero descriptors.
