The selected original path is arpifs/setup/suvert.F90 from the first YRVETA calculation through the initial VFE_KNOT values, before CALL SUVERTFE. ## Interval Mapping Child

The source FX2T function is in arpifs/module/suvfe_hlp.F90. It maps an input x between endpoints a and b to $`t=(x-a)/(b-a)`$. The two differences each round once to FP64 before division. FP64 is the 64-bit floating-point format. The direct leaf performs these three operations in source order without contraction, reassociation or approximate arithmetic. Finite inputs and distinct endpoints are the supported mathematical preconditions.

md2asm_vertical_interval_coordinate receives a, b and x in d0, d1 and d2 and returns t in d0. The original __suvfe_hlp_MOD_fx2t alias receives three read-only, eight-byte-aligned FP64 addresses in x0, x1 and x2. Each complete word must be mapped. It loads those values and branches to the same raw leaf. Both interfaces allocate no storage, write no caller buffer and preserve x18, all saved registers, the stack pointer, FPCR and errno. FPCR must be zero. Incoming FPSR bits remain set, and the source subtractions and division may add flags. Original optional DR_HOOK profiling is omitted diagnostics.

In the selected SUVERT caller, the two original calls use a=0, b=1 and x=0 or x=1. The direct caller must still calculate these bounds with FX2T; a driver must not replace that numerical stage with stored results. Later finite-element callers may use the same qualified interval map within the declared input scope. Component checks compare the unchanged original source body, critical cancellation and signed-zero cases, immediate status and the original pointer ABI. ## Selected Eta Stage

md2asm_initialize_vertical_eta_coordinates receives the complete writable Geometry record in x0, a read-only two-word FP64 array containing reference pressure VP00 and pi in x1, and a read-only table of two writable FP64 addresses in x2. The two outputs are the independent RTMIN and RTMAX words. All records, arrays and address tables are mapped for their complete extents, eight-byte aligned and disjoint. Geometry already owns the storage constructed by selected SUVV1. This stage allocates no owner and changes no descriptor or pointer association.

Let $`N`$ be the layer count. The supported source configuration has either 19 or 137 matching model and I/O levels, LREGETA and LVFE_REGETA false, LVERTFE and LVFE_CENTRI true, LVFE_CHEB and LVFE_ECMWF false, order four, $`N-2`$ internal knots, RVFE_ALPHA=0 and RVFE_BETA=0.5. The original file inputs and qualified SUVV1 establish these conditions in the selected case. Pi has the source FP64 word 0x400921fb54442d18. The raw stage returns zero on success or two before output mutation when its scalar, selected-control or descriptor guards reject an input.

The first loop sets ordinary half-level eta to normalised A plus B and each interior full-level eta to the mean of neighbouring half levels. It copies both endpoint values to the extra full-level slots. The stage then calls FX2T twice to calculate RTMIN and RTMAX. For each layer it forms both reference pressures with a separately rounded product and addition, subtracts them and calls the accepted POWER child with the live source exponent zero. The cumulative sums therefore count the layers, but the source pressure and power operations remain present. Dividing those sums by the final sum gives the initial VFE half-level coordinates.

The next loop computes cosine at pi times each initial coordinate. It forms the source Chebyshev coordinate as 0.5−0.5*cos(angle), then combines the initial and Chebyshev coordinates with beta 0.5 using separate products and an addition. It explicitly restores the two exact endpoint values. Interior VFE full-level coordinates are neighbouring means, inverse layer depths are one divided by neighbouring half-level differences, and the $`N-2`$ even-order knots copy VFE full levels two through $`N-1`$. The six complete output arrays contain 944 bytes at 19 levels or 6,608 bytes at 137 levels. Their half-level arrays have $`N+1`$ words, full-level arrays have $`N+2`$ words, inverse-depth array has $`N`$ words and knot array has $`N-2`$ words. The two scalar bounds occupy sixteen further bytes. All other owner payload and all Geometry metadata remain unchanged.

The stack frame is 320 bytes at 19 levels or 1,264 bytes at 137 levels. Both preserve x18, all saved integer registers and the low halves of d8 through d15. Private cumulative sums occupy twenty or 138 FP64 words, respectively. At 137 levels, the complete scratch range is bytes 160–1263, disjoint from saved registers. Each sum is written before it is read. FPCR must be zero; incoming FPSR bits remain set and source calculations may add flags. The existing original-rounding POWER, COS and integer rounding children retain their separate accepted contracts. No floating fused instruction, external numerical fallback or precomputed eta packet supplies a result. Original console and optional profiling diagnostics are omitted.
