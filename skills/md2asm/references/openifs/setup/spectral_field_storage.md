# Owned Serial Spectral Field Storage

This component implements the selected global one-process CREATE_SPEC and DEALLOCATE_SPEC path from SPECTRAL_FIELDS_MOD. A spectral coefficient represents one horizontal wave. With truncation N, the source stores S=(N+1)(N+2) real FP64 words for each field and level. The supported level count is 1 through 64 and N is zero through 63. There are three three-dimensional fields, vorticity, divergence and temperature, with GRIB identifiers 138, 155 and 130, and two two-dimensional fields, logarithmic surface pressure and orography, with identifiers 152 and 129. Distributed and limited-area branches are outside this contract.

The raw initializer receives a fresh zero 2,992-byte SPECTRAL_FIELD record in x0, level count in w1, truncation in w2, a read-only five-int32 identifier array in x3 and writable three-FP64 dummy storage in x4. The first three identifiers must contain 138, 155 and 130 once each, and the last two must contain 152 and 129 once each. Their input order can vary within those groups. The record and dummy storage are eight-byte aligned, identifiers are four-byte aligned, all buffers are mapped for their complete bounds and disjoint. Status w0 is zero on success, one after allocation failure and complete cleanup, or two before record mutation for unsupported inputs. The caller owns the record, identifier array and dummy storage.

The source allocates sixteen owners in this order: MYMS, NALLMS, NPTRMS, NUMLL, NPTRLL, NPSURF, MYLEVS, NASM0, NASM0G, NUMPP, MS_PROC, NS2L, NGRIB, SP3D, SP2D and SP1D. The integer maps are built from the serial source distribution. All wave numbers are zero through N, PTRMS is one, NUMPP is N+1, and the first stored real coefficient of wave m has one-based offset 1+2*m*(N+1)-m*(m-1). MYLEVS is zero through levels-1. Local and global dimensions agree. Source values NPSURF=1, NPTRLL=0 and NS2L=2 remain explicit selected input semantics.

SP3D has shape(levels,S,3), SP2D has shape(S,2), and SP1D has shape(1,2), although source NS1D is zero. Every byte of these three owners is set to positive zero, as the source requires. The named VOR, DIV and T rank-two views select their three planes. SCAL and HV both select the one-plane T range as rank-three views. SP and OROG select the two SP2D columns, and UB/VB select SP1D's two words. Missing Q, O3, L, SPD, SVD and NHX use the caller-owned rank-two dummy word; GFL uses its rank-three dummy word. The I pointer stays null because its source branch has no ELSE association. NGRIB2 and NGRIB3 select the complete two- and three-field portions of the owned integer map. No original dummy or module address is imported.

The complete GNU descriptors use element widths four for int32 and eight for FP64, with the source lower bounds, strides and offsets. Empty descriptor private words start at zero under this fresh-record ABI; all associated descriptor bytes are defined and compared. The typed source layout is recorded separately. The serial distribution leaf uses integer registers only and has no external dependency. Its independent closed-form map and guard checks precede caller generation.

The allocating create wrapper receives levels in w0, truncation in w1, identifiers in x2 and an output pointer address in x3. It owns one 3,024-byte context whose first 2,992 bytes are the source-layout field record, followed by three eight-byte dummy words and an eight-byte lifetime marker. It publishes the pointer only after success. The paired release frees every numerical/map owner and the outer context. The raw release retains the caller's record and dummy storage. Both paths preserve source nullification and owner-release order; partial acquisition is cleaned up without publishing an incomplete owner.

Production uses direct assembly plus libc allocation, release and errno-address services. No original callable, module data, type descriptor, vtable, precomputed model state or high-level numerical driver is used. No floating-point arithmetic is required by this constructor: zero stores and integer address/map operations preserve FPCR and FPSR, while errno and all saved registers, including x18, are preserved. The code uses the Armv8.2-A integer instruction set. Each public entry preserves x18, x19 through x29, the stack pointer, and v8 through v15; the stack remains sixteen-byte aligned. The raw initializer uses a 144-byte frame, the raw release and owned creator each use 96 bytes, and the owned release uses 80 bytes. FPCR must be zero at construction. A raw release accepts a valid selected live or partially acquired record and leaves descriptor metadata in the source-defined released form. A released outer context must not be used again. This component does not construct a complete FIELDS record or forecast.

Four genuine source cases compare 249,060 complete owner bytes and 23,936 complete created/released record bytes with zero differences after replacing only allocation addresses by owner-relative identities. All associated descriptor words, source scalars and pointer offsets remain in that comparison. Sixteen immediate ABI/status calls include eight native calls with zero failure masks; the original constructor's x18 change is recorded separately. Three controlled allocation failures verify cleanup and an unchanged output pointer, while four unsupported-input cases reject before mutation. The independent map, zero-value and named-view checks cover 106 relations. The serial distribution child has six source-independent shape cases and 214 closed-form relations. A standalone assembly create/release executable exits zero with preload and library-path variables removed; both it and the production DSO depend only on libc. The assembler driver is GCC 12.3.0. No forecast or performance claim is made.

## Operational Serial Wave Map

The separate md2asm_serial_spectral_wave_distribution child now accepts truncation N=1279 as well as zero through 63. This extends only the one-process integer map. The allocating constructor, decoder and loading caller retain their stated limits.

Its Arm interface receives writable int32 ASM0[N+1] and ALLMS[N+1] in x0 and x1, writable int32 PTRMS[1] and NUMPP[1] in x2 and x3, then N by value in w4. ASM0 holds each wave's one-based first real-word position, ALLMS lists its wave number, PTRMS is one and NUMPP is N+1. At 1279 each array needs 5,120 bytes and each scalar needs four bytes. All complete buffers are mapped, four-byte aligned, nonwrapping and disjoint. The caller owns them. Return zero writes all 10,248 bytes. Return two rejects an existing pointer/alignment guard or unsupported N before stores.

The original SUWAVEDI selected by INI_SPEC_DIST and the direct leaf retain the running offset and closed-form positions given above. The complete 1279 spectrum has 1,639,680 real words, and every offset through the final end position 1,639,681 fits signed int32. The leaf uses no stack, floating-point instruction or external call. It preserves x18, all saved registers, FPCR, FPSR and errno.

The actual 1279 case matches all 10,248 source bytes with 128 guard bytes intact, 2,562 independent closed-form map relations and the complete coefficient-span check. All three native ABI/status calls pass with zero masks, including nearby unsupported 1278 and 1280 cases that preserve every output and guard. The original reference's platform-register x18 change remains separate from exact numerical and status agreement. The native library has no external dependency. Removing the two new integer admission instructions and label recovers the complete old source apart from its header, so earlier small-shape evidence is reused. No field allocation, complete model or performance claim follows.
