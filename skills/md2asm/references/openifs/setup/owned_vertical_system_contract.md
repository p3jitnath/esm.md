# Complete owned vertical system setup

A spline joins short polynomial curves to represent vertical changes. A vertical operator is a matrix that differentiates or integrates these curves. Eta is a dimensionless coordinate from zero at the model top to one at its surface. This caller composes the selected SUVERT calculation from the already qualified eta, spline-operator and A/B adjustment assembly. It uses the actual 19-level hydrostatic new-spline configuration. The existing vertical startup context owns Geometry and its 27 numerical buffers. This caller fills those buffers, creates the sole additional RDERB owner and leaves the existing context's lifetime unchanged. No original Fortran record, module object, vtable, constructor address or numerical callable is an input.

The application binary interface is `int md2asm_initialize_owned_vertical_system(void *geometry, const double scalars[2], void *const bound_outputs[2])`, with addresses in x0 through x2. Geometry is the caller-owned 17096-byte namespace constructed by the accepted direct TCVER and SUVV1 graph, with all 27 fresh canonical owners and its original inline-record associations. Scalars are reference pressure in pascals and pi in radians; selected values are 101325 and binary64 0x400921fb54442d18. Bound outputs contains two caller-owned writable FP64 addresses for RTMIN and RTMAX. All buffers are complete, eight-byte aligned and disjoint. The source eta, inverse and operator domain requirements apply. RDERB at Geometry descriptor1264 must initially be unassociated.

Before mutation, the caller checks the five preallocated operator descriptors at1088,1352,1440,1528,1616 and all five main adjustment output descriptors at464,400,336,272,208. Operators have shapes20 by21 or19 by21 with one-based canonical rank-two metadata. Every adjustment owner has19 words, bounds one to19 and canonical rank-one metadata. Main VAF/VBF do not have the separate I/O owners' extra level-zero word. The eta child checks its full selected configuration, scalar inputs, existing associations and consumed input/output descriptor metadata before calculation. Complete mapped extents, independent allocations and ownership provenance remain caller preconditions.

First call the raw eta stage, including its two FX2T sample-bound calculations, ordered source pressure/POWER/COS arithmetic, reciprocal depths and knot writes. Pass the freshly produced 21-word VFE_ETAF owner to the raw upper spline owner layer and the five existing operator payload addresses. That layer writes the new independent RDERB descriptor and payload. Finally call the raw A/B adjustment with the owned half-level A/B, reciprocal depths, newly constructed RINTBF11, live reference pressure and the five main output addresses. No driver loads or computes an intermediate, matrix, inverse or adjusted state for this production graph.

Return zero means complete. Return two rejects metadata or the eta child's preflight before mutation. Return one reports allocation failure, and return three reports a numerical child failure. If calculation has started, existing numerical owners can contain completed stages and callers must discard that setup. The caller releases a new RDERB owner if a later adjustment fails. Temporary scratch is owned and cleaned by its child. `md2asm_release_owned_vertical_system(geometry)` releases only the new RDERB owner and must precede the accepted vertical-context release, which still owns all earlier27 allocations. This division prevents duplicate frees.
