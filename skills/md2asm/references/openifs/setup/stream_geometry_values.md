# Stream geometry value copies

The raw entry `int md2asm_copy_stream_geometry_values(void *stream, const void *geometry, unsigned mode)` uses x0 for the owned 872-byte stream, x1 for the live 17,096-byte Geometry and w2 for mode zero or one. Mode zero copies all 20 half-level coefficients VAH and VBH from typed Geometry descriptors at 144 and 80 into fresh stream owners at 208 and 272. Mode one copies the 32 physical latitude angles from the Geometry RLATIG descriptor at 4744 into a fresh stream owner at 336. The input descriptor lower bound is translated explicitly; the source coefficients have bounds 0:19, and source latitudes include bounds -1:34. Output descriptors have bounds 1:20 or 1:32, as the original INI_IOSTREAM allocation from an assumed-shape argument does.

This selected first-association utility implements only the source-required PVAH/PVBH and PLATIG updates after the initial stream namespace exists. Each destination must be unassociated. It does not replace the complete general INI_IOSTREAM method. It uses no original OpenIFS state, procedure or type metadata. All numerical bytes are copied without floating-point arithmetic. Status zero is success, one is allocation failure after releasing the new owners, and two rejects unsupported metadata before mutation. The companion release frees these three owners and clears their data pointers. The caller retains the earlier stream owners and the input Geometry owners.

Every record is eight-byte aligned, mapped for its complete size and disjoint. Consumed source descriptors are canonical contiguous GNU rank-one REAL(kind=8) records, with element length/span eight, unit stride, canonical origin and bounds that cover every selected element. Source numerical inputs remain unchanged. The constructor frame is 144 bytes and the release frame is 80 bytes, both sixteen-byte aligned. The entries preserve x18, required saved registers, FPCR, FPSR and errno. Only malloc, free and the C error-indicator address are external services. Complete source-record comparison uses explicit new-address correspondence after comparing all payload bytes, and is part of the enclosing changed-parent gate.
