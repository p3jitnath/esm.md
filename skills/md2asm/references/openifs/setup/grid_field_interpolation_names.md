# Grid Field Interpolation Names

SUCSLINT selects the exact twelve-character name of an interpolation method from ten logical controls. An interpolation method estimates field values between stored grid points. This child preserves the original source decision order and space padding; it does not calculate an interpolated value. Source controls are LDSLHD, LDCOMAD, LDVSPLIP, LDHV, LDQM, LDQMH, LDQM3D, LDQML3D, LDINTLIN and LDVWENO in that order.

The direct entry md2asm_grid_field_interpolation_name receives ten read-only int32 logical words in x0 and a writable twelve-byte character buffer in x1. Every logical word must be zero or one. The input is four-byte aligned; the output may have byte alignment in normal mapped memory. Both complete buffers are mapped and disjoint. FPCR must be zero. Return w0 is zero after writing all twelve output bytes or two for unsupported input before mutation. The routine preserves input bytes, output guard bytes, FPCR, FPSR, errno, x18, x19 through x29, v8 through v15 and the stack pointer. It uses no stack frame, floating-point instruction or child call.

The first source branch handles horizontal diffusion, followed by vertical splines, linear interpolation, WENO interpolation, Hermite interpolation and the remaining quasi-monotone choices. A higher-priority choice takes precedence when more than one control is true. The exact twenty-three source strings remain explicit assembly constants. Production imports no original routine, module data, type descriptor, vtable, state packet or library service. Field registration, attribute counters and the selected eight-field SUGFL caller are separate children.

The complete finite input domain has 1,024 combinations. Every combination matches all twelve original output bytes, giving 12,288 compared character bytes and 2,048 immediate ABI/status calls. Native failure masks are zero, and the original reference's x18 change is recorded explicitly. All twenty-three exact source names are reached. The checks retain 40,960 input bytes, 73,728 output guard bytes, three selected-name/priority relations and four before-mutation rejects. Aligned and byte-unaligned output buffers both pass. The production DSO has no undefined symbol or shared-library dependency; the assembler driver is GCC 12.3.0. No interpolated numerical values, whole SUGFL body, forecast or timing are claimed.
