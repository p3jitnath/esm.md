# Current Step In Owned Clocks

The current step is the integer visit of the forecast loop. Original CNT4 stores this value in NSTEP after UPDTIM and before later forecast consumers. This component owns that store and its clock correspondence. It supports current steps zero through eight for the actual one-hour configuration, with 450 seconds per step. It does not implement or accept the complete live forecast loop.

`int md2asm_publish_operational_convection_step(configuration, capacity, current_step)` receives the three values in Arm registers x0 through x2. Configuration has 67,616 mapped bytes and capacity covers that full record. The current-step address names one mapped four-byte signed integer. Configuration aligns to eight bytes and the integer aligns to four. Both complete ranges are nonwrapping and separate from each other and the owned clock. The caller keeps the complete actual MODEL and Geometry records live through the configuration links. The caller serializes publication and later physics calls for one model in each process.

`md2asm_owned_runtime_convection_clock` names 360 assembly-owned bytes aligned to 16. The original-compatible four-byte symbol `__yomct3_MOD_nstep` is an exact address alias at clock offset 36. Link exactly one provider for that original-compatible symbol. The configuration owns a distinct 360-byte clock at offset 51,736, so its current-step word is at 51,772. These are two storage addresses containing corresponding values. They are not one shared alias.
