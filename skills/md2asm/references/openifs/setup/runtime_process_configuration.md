# Runtime Process Configuration

This entry reads process settings from the model input text. A process is one running copy of the forecast. The parser accepts the actual MPI process count and returns the source spectral partition setting, which limits how wave coefficients are shared. MPI is the public library that lets processes exchange data. The accepted factor child then uses these settings and the live thread count to choose the process groups.

Build `operational_process_configuration.S` with `MD2ASM_RUNTIME_PROCESS_CONFIGURATION` to expose `md2asm_runtime_process_configuration_group(text,text_bytes,world,out8,out_bytes)`. Its application binary interface (ABI) uses x0, x1, w2, x3 and x4. World is a positive signed 32-bit integer from 1 through 65,536. Text is a complete, nonempty mapped byte span whose address range does not wrap. The caller owns a separate mapped output of at least eight bytes, aligned to eight bytes, with a nonzero base and a nonwrapping range. Input and output must not overlap. The returned status in w0 is zero for success and two for refusal.

The two output int32 words are effective NPROC at byte zero and raw NSPECRESMIN at byte four. NPROC must match the live world count. Source NPROC zero defaults to one, so it matches only world one. NSPECRESMIN is zero through 1,000,000. Preserve its raw zero here; the factor child applies the source default from the world count. These counts have no physical units.

The parser keeps the accepted first-group search and the same thirteen-member schema in `NAMPAR0`. Group markers use the existing uppercase spelling, while member names follow the accepted bounded case rules. Every required member appears once. Unchanged statistics and control values retain their original checks. Unsupported members and explicit transform-factor overrides refuse. This is a checked configuration subset, so it does not claim to parse every valid Fortran namelist. The existing default build retains its qualified four-process, minimum-1280 entry and its complete object bytes.

No output word is written until the complete selected group passes. Refusal preserves every input and output byte. The entry uses integer operations, a private 16-byte frame and no calls or allocation. It preserves the floating-point control and status registers FPCR and FPSR, errno, x18, saved Arm registers, the return address and the required stack alignment. Errno is the operating system's error number. A caller must keep its owned spans separate from the callee's private stack.

Independent source, ABI and checker review passed. One small gate accepted six cases and refused eight invalid cases, with zero differing bytes. It read the actual prepared 768-process input and tested world counts one, two, four and 65,536, both source defaults, a changed minimum and its upper bound. Refusals covered a mismatched world, excessive minimum, duplicate or missing member, unsupported override, short output, overlapping input/output and negative world. Complete input text, the full 64-byte output backing, arguments and immediate status were retained in 84 raw files totalling 31,606 bytes. Read-only text, guard bytes, ABI, status, file-descriptor counts and release passed. The bounded child exited normally, and both assembly modes retained their complete qualified objects.

This is configuration metadata evidence. No original OpenIFS procedure, numerical bank, public MPI setup, model or forecast ran in this gate. The distributed parent must still consume these live outputs, allocate its runtime arrays and call public services in source order.
