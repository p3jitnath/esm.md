# Selected grid field namelist input

`md2asm_apply_selected_grid_field_namelist(text, length, profiles)` reads the selected `NAMGFL` input group from a live byte buffer and applies its nine supported members. A namelist is a text group that assigns named Fortran settings. The input supplies settings, not a completed model-state packet. The caller owns nine 256-byte profile records in Q, L, I, S, R, A, O3, NOGW1, NOGW2 order, and constructs their defaults separately.

The AArch64 interface takes the input address in x0, its byte length in x1 and the profile address in x2. The input length is 1–262,144 bytes, and the 2,304-byte profile array has 8-byte alignment. The complete mapped buffers must be disjoint. The function requires FPCR = 0. It returns 0 on success or 2 when a checked bound or grammar condition fails. It first copies the incoming profiles to its private stack record and commits that record only after the closing slash, so every profile byte remains unchanged on failure.

The first line-starting `NAMGFL` group is used. Its marker is the first nonblank token on that line. The group name must be uppercase `NAMGFL`, following the literal search in the original POSNAME utility. Lowercase or mixed-case group names are skipped. Member keys remain case insensitive; their conversion changes only letters A–Z, so underscores and the percent sign retain their meaning. Spaces, tabs, line endings, commas and exclamation-mark comments are accepted between assignments. The nine supported members are `YQ_NL%LGP`, `YQ_NL%LSP`, `YO3_NL%LGP`, `YQ_NL%LGPINGP`, `YR_NL%NREQIN`, `YS_NL%NREQIN`, `YL_NL%LGP`, `YI_NL%LGP` and `YA_NL%LGP`. Keys are contiguous; array indexing, repeated-value syntax, unknown members and an absent closing slash are rejected. Duplicate assignments follow the source's last-value rule.

Logical values are T, F, TRUE or FALSE in either letter case, with an optional balanced pair of periods. The two integer settings are −1, 0 or 1, with an optional sign. The parser stores canonical 32-bit logical and integer words. These settings occupy only 36 bytes across the profile array: offsets 44, 48, 1580, 36, 1044, 788, 300, 556 and 1324 in the key order above. Every other profile byte retains its incoming value, including source-unwritten names, real values and padding. A later registration caller checks that the completed settings select its qualified field mode; this parser does not register fields.

The implementation uses a 2,400-byte stack frame aligned to 16 bytes. It preserves x18, x19–x29, SP, all SIMD registers, FPCR, FPSR and errno. Caller-saved integer registers and condition flags may change. All helper calls are local integer assembly; the production DSO has no undefined symbol, required library, external callable, original module datum, original type object or virtual table.

`selected_grid_field_namelist_reference.F90` is a separate verification control. It imports the original declared profile type, associates its four named objects with the same nine-profile input layout and uses Fortran's typed `READ(...,NML=NAMGFL)` on the same text. It captures status immediately around that read. It checks the source input syntax and writes for this supported subset; it does not replace the complete original SUGFL1 procedure.

Five profile cases include the actual retained `fort.4`, an empty group, member letter case and comments, duplicate assignments, signed integer spellings and a buffer ending at a protected memory page. The member-case and page-end cases use an uppercase group marker; these two corrected cases pass with 4,608 complete bytes and four ABI/status calls, while the three unchanged cases and rejection checks are reused. All 11,520 complete source/direct profile bytes match; 11,400 non-target bytes retain their incoming values. Ten immediate ABI/status calls pass for the direct entry, 22 independent selected-setting relations pass, and 11 invalid-input cases reject without mutation. The original typed reader's x18 difference is retained; all direct ABI masks are zero. This utility does not claim default construction, complete field configuration or an autonomous forecast, and no model was run.

A separate genuine whole SUGFL1/SUGFL2/SUGFL3 case places a lowercase duplicate before the actual uppercase group. The original utility skips that duplicate. All 1,359,136 same-address namespace bytes and raw status match the corrected direct graph, with native ABI mask zero. The retained old case-folding parser selects the wrong rain and snow input requests in this case; its old source and artifacts remain local. Group selection is therefore checked against the original POSNAME route, rather than inferred from Fortran READ alone.

The operational qualification uses the same nine-profile default assembly and the actual first group from the 137-layer case. The defaults contain no level-sized arrays, and original SUDEFO_GFLATTR reads neither NFLEVG nor NSTOP. The actual group enables Q, L, I, A and O3 grid-point input and disables Q spectral input; rain and snow keep source NREQIN 1. A second case changes all three new flags, repeats a key and places a lowercase group before the first uppercase group and another uppercase group after it. Both cases run with incoming FPSR 0 and 24. All 18,432 complete default and parsed bytes match, all nine native ABI checks pass, 64 setting relations hold, and a late invalid new logical value leaves every public profile byte unchanged. The old default and parser evidence is reused without repeating its corpus.

This comparison uses the declared byte-buffer boundary. Genuine POSNAM first selects the original input record; its exact remaining byte slice is then passed to the typed internal-string READ. Source and native FPCR, FPSR and errno match naturally at that boundary. The earlier external-file POSNAM/read observation returns errno zero and remains separate evidence; no full file-I/O or SUGFL1 status agreement is claimed. This child does not choose a forecast duration, apply SUCTRL, construct the enclosing namespace or run a forecast.
