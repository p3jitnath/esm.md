# Selected grid field namelist input

`md2asm_apply_selected_grid_field_namelist(text, length, profiles)` reads the selected `NAMGFL` input group from a live byte buffer and applies its six supported assignments. A namelist is a text group that assigns named Fortran settings. The input supplies settings, not a completed model-state packet. The caller owns nine 256-byte profile records in Q, L, I, S, R, A, O3, NOGW1, NOGW2 order, and constructs their defaults separately.

The AArch64 interface takes the input address in x0, its byte length in x1 and the profile address in x2. The input length is 1–262,144 bytes, and the 2,304-byte profile array has 8-byte alignment. The complete mapped buffers must be disjoint. The function requires FPCR = 0. It returns 0 on success or 2 when a checked bound or grammar condition fails. It first copies the incoming profiles to its private stack record and commits that record only after the closing slash, so every profile byte remains unchanged on failure.

The first line-starting `NAMGFL` group is used. Its marker is the first nonblank token on that line. The group and keys are case insensitive; case conversion changes only letters A–Z in component identifiers, so underscores and the percent sign retain their meaning. Spaces, tabs, line endings, commas and exclamation-mark comments are accepted between assignments. The six supported members are `YQ_NL%LGP`, `YQ_NL%LSP`, `YO3_NL%LGP`, `YQ_NL%LGPINGP`, `YR_NL%NREQIN` and `YS_NL%NREQIN`. Keys are contiguous; array indexing, repeated-value syntax, unknown members and an absent closing slash are rejected. Duplicate assignments follow the source's last-value rule.

Logical values are T, F, TRUE or FALSE in either letter case, with an optional balanced pair of periods. The two integer settings are −1, 0 or 1, with an optional sign. The parser stores canonical 32-bit logical and integer words. These settings occupy only 24 bytes across the profile array: offsets 44, 48, 1580, 36, 1044 and 788 in the key order above. Every other profile byte retains its incoming value, including source-unwritten names, real values and padding. A later caller checks that the completed settings select the supported eight-field mode.

The implementation uses a 2,400-byte stack frame aligned to 16 bytes. It preserves x18, x19–x29, SP, all SIMD registers, FPCR, FPSR and errno. Caller-saved integer registers and condition flags may change. All helper calls are local integer assembly; the production DSO has no undefined symbol, required library, external callable, original module datum, original type object or virtual table.

`selected_grid_field_namelist_reference.F90` is a separate verification control. It imports the original declared profile type, associates its four named objects with the same nine-profile input layout and uses Fortran's typed `READ(...,NML=NAMGFL)` on the same text. It captures status immediately around that read. It checks the source input syntax and writes for this supported subset; it does not replace the complete original SUGFL1 procedure.

Five cases include the actual retained `fort.4`, an empty group, letter case and comments, duplicate assignments, signed integer spellings and a buffer ending at a protected memory page. All 11,520 complete source/direct profile bytes match; 11,400 non-target bytes retain their incoming values. Ten immediate ABI/status calls pass for the direct entry, 22 independent selected-setting relations pass, and 11 invalid-input cases reject without mutation. The original typed reader's x18 difference is retained; all direct ABI masks are zero. This utility does not claim default construction, complete field configuration or an autonomous forecast, and no model was run.
