# Spline profile integral

This raw child applies the selected top-to-level integral operator to one vertical profile. It implements the consumed VERDISINT ITOP/11, integral boundary mode three, one-column and 19-level calculation. The 20 by 21 matrix is constructed by the qualified spline operator graph, and the input contains its 19 interior values. The source imposes homogeneous derivative boundaries by constructing positive-zero endpoints before the matrix application. All quantities are dimensionless except when the caller's profile carries a declared physical unit, which the integral retains.

The application binary interface is `int md2asm_integrate_spline_profile(const double matrix[420], const double interior[19], double output[20])`, with addresses in x0 through x2. The matrix has output row as its fastest index. Buffers are complete, eight-byte aligned and disjoint. Inputs and arithmetic intermediates are finite. Return zero writes every output value. Return two rejects null addresses, alignment or nonzero FPCR before mutation. The caller owns all buffers; the child allocates nothing and has no OpenIFS record, descriptor, module value or original callable input.

The child copies the interior into a private 21-word input and supplies positive-zero endpoints. It calls the unchanged accepted ordered matrix leaf from `src/openifs/dynamics/strict_matrix.S` with one horizontal column, 20 outputs and 21 input columns. Each sum begins at positive zero and includes every input in increasing order. Multiplication and addition round separately, retaining signed zeros and subnormal values. There is no fused instruction or numerical fallback. The source OpenMP scheduling query and profiling are outside this fixed one-column raw interface; complete source return and status checks must establish the consumed computation.

FPCR is zero for nearest/ties-to-even rounding and gradual underflow. Incoming FPSR bits remain, and numerical arithmetic can add flags. The 320-byte stack frame has 16-byte alignment and preserves x18, all saved registers, FPCR and errno. The accepted matrix leaf uses no frame. Its unreachable domain-error call is bound to a private assembly termination leaf that exits with status 116. The only external production service is `_exit`. This child has no whole VERDISINT or library body credit; the already accepted numerical matrix contract remains unchanged.
