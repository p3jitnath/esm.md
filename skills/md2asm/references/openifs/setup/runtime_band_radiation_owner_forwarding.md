# Live longwave and shortwave setup forwarding

This component joins the already accepted complete SULWN and selected SUSWN calculations to the caller's MODEL. The two source routines define longwave constants and six-band shortwave coefficients. Their accepted child also owns two arrays of fourteen solar fractions. No new equation, constant or numerical routine is introduced.

`int md2asm_initialize_runtime_band_radiation_from_model(M,Mbytes)` uses x0 and x1. MODEL needs a complete mapped span of 4,275,088 bytes, an eight-byte-aligned nonzero base, enough capacity and an address range that does not wrap. The full MODEL span and the canonical physical 520-byte, dynamics 320-byte and longwave 9,440-byte spans must be separate. The entry checks all six pairs. Physical constants and dynamics must already have their accepted produced values. Actual MODEL LRAY at byte 4,144,588 must be false before the child is called. This selects the original first-SUSWN branch. The unchanged child requires FPCR zero, NSW six, NTSW fourteen, LONEWSW true, LRAYL true and null first-call solar bases.

The entry passes TERAD at MODEL byte 1,608,728 and TESWRT at byte 1,610,768 to `md2asm_initialize_selected_spectral_radiation_tables`. It resolves physical constants through `md2asm_owned_initial_physical_constants`, dynamics through `md2asm_owned_dynamical_namespace` and the longwave output through `md2asm_owned_legacy_longwave_band_parameters`. The complete existing radiation namespace object supplies that output and its 27 original YOELW field aliases. Every later reader must bind to those same owners. The complete namespace object has 8,515,680 bytes of static storage; a runtime memory plan must include its complete mapping.

On success, the child writes its declared TESWRT fields, both 112-byte solar payloads and 9,436 longwave bytes. Longwave padding at bytes 28 through 31 and every other MODEL byte stay unchanged. Return zero means success, one means allocation failure with private cleanup and two means refusal before public writes. Actual TERDI, including the early 353-parts-per-million carbon-dioxide volume fraction, is not passed or written.

`int md2asm_release_runtime_band_radiation_from_model(M,Mbytes)` accepts the same complete outer span and a valid result of this constructor. It releases the two owned solar arrays and clears only their descriptor base words. Repeated release is supported. Keep both owners through their final surface and weather readers, then release them before destroying MODEL. This stage neither owns nor releases the early prefix's three Planck arrays or the caller's other fields.

Both entries preserve x18, Arm callee-saved registers, stack alignment and floating-point control. They retain the accepted child's natural floating-point flags and errno rules. The constructor uses a 160-byte frame and at most 12,560 private nested stack bytes, excluding public library internals. Release uses a 32-byte frame and an 80-byte nested bound. The only numerical calls are to the unchanged qualified children. Their public libm and libc services stay unchanged.

The source boundary is SUECRAD's SULWN call at line 2058 and first selected SUSWN call at line 2064. This component does not supply preceding SURDI, absorption-table preparation or source call order outside that boundary. Later optical, SRTM and repeated-SUSWN branches remain separate caller work. It consumes no local or global level count, partition width, MPI rank or world size. The fourteen/six band configuration is the selected physical branch and does not fix the spatial resolution. Independent source and loaded-provider checks cover the complete wrapper, its two actual child bindings and all 27 longwave aliases.
