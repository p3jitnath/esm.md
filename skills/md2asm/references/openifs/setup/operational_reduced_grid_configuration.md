# Operational Reduced-Grid Configuration

Revision 1 constructs the two integer-array owners used by SUGEM_NAML for the accepted 9 km reduced grid. A reduced grid has different longitude counts at different latitude rows. The new raw utility receives explicit input records and configuration text. It uses no original OpenIFS numerical routine, global variable or constructor. The [regular-grid route](spherical_geometry_configuration.md) remains unchanged.

The interface is `int md2asm_initialize_operational_reduced_grid(geometry, words, coordinates, northern_PL, northern_count, text, text_bytes)`. The seven arguments occupy x0 through x6 under the Arm application binary interface (ABI); w0 returns the status. Geometry contains 17,096 mapped bytes and aligns to eight bytes. Words contains three aligned four-byte integers: file supersede flag 1, stretch type 1 and grid type 2. Coordinates contains three aligned eight-byte floating-point values: pole sine 1, pole longitude positive zero and stretch factor 1. Longitude uses radians; the other values have no unit.

Northern_PL contains 1,280 aligned four-byte positive row lengths, covering 5,120 mapped bytes. Northern_count must be 1,280, and each row length is at most 5,136. Text contains the complete mapped ASCII configuration of the declared nonwrapping length. All input spans, writable Geometry and its borrowed logical target obey the existing disjointness and mapped-storage obligations. The accepted [header reader](../input/initial_model_file_headers.md) supplies these source inputs. The qualified northern rows are the actual input rows; no row table is built into this constructor.

Geometry supplies 2,560 physical latitude rows, two extra rows at each pole, maximum row length 5,136 and spectral truncation 1,279. Its consumed integer words at byte offsets 4872, 4884, 4888, 4904, 4936, 5172 and 5208 are 2560, 2, -1, 2562, 5136, 1279 and 1279. These dimensions follow the unchanged SUDIM rules and the actual first NAMDIM group. Both NLOEN and NLOENG data pointers, at Geometry offsets 7576 and 7640, start null. The logical pointer at offset 0 remains a live borrowed address.

The bounded parser selects the first line-leading NAMGEM group. It accepts an empty group or only NHTYP=2 and LNONHYD_GEOM=false assignments, including the actual first group. Names are case-insensitive; ASCII punctuation is preserved when folding letters. Unsupported values, unknown members and missing closure return status 2. The parser cannot skip an unsupported first group to accept a later empty one. It reads the supplied text without file calls or mutation.

The constructor retains the source allocation, descriptor and unit-stretch arithmetic order. This includes the original rounded RNLGINC guess before the ECMWF-grid rule supplies its final value. RNLGINC is a dimensionless grid control. It sets the borrowed nonhydrostatic logical false, pole sine 1, pole longitude positive zero, stretch factor 1, stretch type 1, grid type 2 and RNLGINC 1. Every inherited floating-point operation keeps its original separate rounding point.

NLOENG holds global row lengths, while NLOEN reserves storage for later local row lengths. Each owner has bounds -1 through 2562, giving 2,564 four-byte integers and 10,256 bytes. NLOENG receives northern rows 1 through 1280, their mirrored southern rows, then the source two-row pole extension. Every NLOENG word is defined. NLOEN receives no payload write at this stage: its complete incoming allocation bytes remain unchanged until the later producer runs. Production does not fill that source-unwritten owner. Each complete GNU 12-compatible descriptor retains all 56 non-address bytes.

Return status 0 means success, 1 means an allocation failure with acquired owners released, and 2 means a preflight refusal before mutation. Allocation failure clears new data pointers; already written descriptor metadata may remain. The unchanged `md2asm_release_spherical_geometry` helper releases both owners once and clears their data pointers. The caller retains Geometry, text, input rows and the borrowed logical. This helper is not an original forecast destructor.

The constructor frame is 144 bytes, the parser frame is 16 bytes and the reused release frame is 48 bytes. Frames align to 16 bytes. FPCR, the floating-point control register, must be zero. The utility preserves FPCR, errno, x18 and required saved registers; its arithmetic adds the original floating-point status register (FPSR) flags. The explicit-text utility follows the accepted prepared-input raw status boundary. Original file and console effects are outside that boundary. The separate genuine source body returned errno 0, which remains recorded; the prepared raw comparison used incoming and returned errno 34. Whole original-body status equivalence is not claimed.

Two complete allocation profiles matched all 41,024 owner bytes, 102,672 Geometry and guard bytes, and 48 borrowed-logical and guard bytes. Only four owned and two borrowed pointer correspondences differed. All ten native ABI masks were zero. Constructor FPCR/FPSR/errno values were 0/16/34 and 0/24/34; release values were 0/24/34. Both complete NLOEN preimages remained exact. Independent checks compared every NLOENG word with the accepted full file-header rows and pole-extension rule, including the 6,599,680-point active sum.

Focused controls passed both allocation failures, a short northern row count, a zero row length, an unsupported first group before a later empty group, and missing first closure. Source and native ran in separate bounded processes. The source capture was reused after an observed identifier-folding defect was corrected; the original failure remains local. The old regular-grid numerical bank and transform setup were not repeated. Production depends only on direct assembly and libc allocation/error services. This qualifies the complete reduced-grid configuration utility, with no original-parent, complete horizontal-geometry or operational-forecast credit.
