# Selected Dynamics Controls

`md2asm_initialize_selected_dynamics_controls(text, length, record, capacity, controls)` constructs the complete selected 456-byte TDYNA record. TDYNA holds switches for the equations of motion and integer maps that identify temporary fields. The original SUDYNA body and its three INTDYN map constructors remain separate verification controls. Production receives no original OpenIFS object, module data, type metadata, virtual table or callable.

The AArch64 interface uses x0 for read-only live text, x1 for its byte length, x2 for a writable record, x3 for record capacity and x4 for eight read-only four-byte controls. Length is 1–262,144 bytes; capacity is at least 456 bytes. The record and controls have 8-byte alignment. The caller supplies valid complete mapped ranges, with no address wrap. The output record must be disjoint from both input ranges; read-only inputs may overlap each other. Return 0 means success. Return 2 means a checked rejection before any destination byte changes. FPCR must be zero, selecting round-to-nearest with ties to even and gradual underflow.

The control order and selected values are NDLON 64, NDGLG 32, NSMAX 21, NMSMAX 21, LVERTFE 1, NDLNPR 0, LNONHYD 0 and NCONF 1. The first four describe longitude count, latitude-row count and spectral wave limits. LVERTFE chooses vertical finite elements, while LNONHYD false selects hydrostatic balance, which relates vertical pressure change to weight. NDLNPR zero is the actual source vertical-control output. The caller establishes ECMWF mode, with LELAM, LRPLANE, LR2D and LSCMEC false and NPRINTLEV zero. These are explicit selected upstream conditions; they are not original globals read by production. A different eight-word tuple is rejected.

The text child requires the first supported uppercase NAMDYNA group to be empty. It matches the original POSNAME group name literally, so a lowercase duplicate does not override the actual uppercase group. A supported marker is the first nonblank token within the first ten character columns. The marker is followed by whitespace or a slash. Blank lines, spaces, tabs, carriage returns and comments beginning with `!` are supported within the group. A slash closes the group. Assignments, missing or incomplete groups, nonempty first groups and other unsupported syntax are rejected. The actual file is read and checked; an override is not silently ignored.

The default child writes all 78 source-defined scalar members and all 20 integer map words. The selected LSLAG, LSPRT, LTWOTL and LRHSVWENO switches are true. The three equation-selection switches LNHEE, LNHQE and LNHDYN are false. NPDVAR is 2, NVDVAR is 3, ND4SYS is 2 and NGWADVSI is 1. The SLHDKREF sentinel −999 is replaced with SLHDKMIN, which is positive zero. Boolean aggregate controls follow their selected false operands. All source real constants retain their exact FP64 bits; the unsuffixed RMIXNL_TRH literal 0.5 is exact in both source precisions. The child uses integer bit stores and performs no floating-point calculation.

The embedded YYTTND map occupies 36 bytes at offset 372. It assigns five active tendency positions and uses position one as the selected placeholder for absent nonhydrostatic fields. YYTGMVT95 occupies 28 bytes at offset 408 and identifies three active wind and temperature positions. YYTGFLT95 occupies 16 bytes at offset 436 and identifies three moisture positions. These are integer field indices, not function pointers or method tables. The 12 source-unwritten bytes at 156–159, 356–359 and 452–455 retain their complete incoming pattern. The owned enclosing constructor chooses its initial storage policy.

The parent checks every input and the live empty group before calling the store child. It uses a 32-byte aligned frame and preserves x18, x19–x29, the required SIMD registers and SP alignment. Both children are integer-only leaves with no frame. The complete graph preserves FPCR, FPSR and errno and has no allocation, external call, undefined symbol or dynamic-library requirement. Diagnostic printing and original namelist file services are outside this metadata utility; their raw source status is recorded separately. The original calls clear errno to zero, while the utility preserves its seeded errno 777. Both retain the same flag words in the checked cases. An enclosing call after the owned physical constant producer matches full original status exactly at FPCR 0, FPSR 24 and errno 0.
