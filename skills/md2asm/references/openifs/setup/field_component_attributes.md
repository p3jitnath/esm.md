# Selected grid field attributes

`md2asm_set_grid_field_attributes(configuration, component, plan, levels, supplementary_levels, family)` applies the source-defined `SET_GFL_ATTR` calls used by the eight selected grid fields after registration. It reads an owned 1,359,136-byte configuration and one embedded 368-byte component. It computes the advection and physics indices and copies input attributes, without original module data, type objects, virtual tables, callables or operating-system services.

The caller passes these arguments in x0, x1, x2, w3, w4 and w5. The configuration, component and 64-byte plan have 8-byte alignment; the plan is disjoint from the complete configuration. Every declared extent is mapped and has the required access. There are eight registered grid fields and six next-time fields, with no derivative, trajectory, previous-time or physics-tendency owners. The plan fixes LT9, PT and PC false. Levels are 1–64 and supplementary levels are 0–64. The function returns 0 on success or 2 before mutation when a checked condition fails.

The plan has nine 32-bit logical values: ADV at 0, MGRID at 4, ADV5 at 8, TDIAB at 12, HORT at 16, LT9 at 20, PHY at 24, PT at 28 and PC at 32. COUPLING is a 32-bit integer at 36, REFVALC is FP64 at 40, CSLINT contains 12 character bytes at 48, and bytes 60–63 are reserved. Family 0 supplies the optional arguments used for the six named moist and cloud fields. Family 1 supplies the sparse NOGW call: ADV, MGRID, LT9, PT and PC are false; ADV5 and CSLINT are absent and retain their incoming component values, while the absent TDIAB and HORT arguments explicitly set their component values false. Both families omit ADJUST0, ADJUST1 and BIPER, whose incoming bytes are preserved.

For an advected field, the source requires LT1 true and increments NUMFLDS_SL1. The new MP_SL1 is that count, and MP_SLX is `(MP_SL1 − 1) * (levels + 2 * supplementary_levels)`. Physics allocation occurs only while MPSLP equals the source's −99 marker; it requires LT1 when PHY is true. A false PHY changes this marker to the owned undefined sentinel −99999. Counts remain within the six named fields. The exact `LAITVSPCQM  ` name adds a spline owner only when MP_SPL is still undefined. Repeated attribute calls retain the original source's allocation gates.

Real and string inputs are copied as raw words. The child performs no floating-point arithmetic, uses no stack and calls no child or external service. It requires FPCR = 0 and preserves FPCR, FPSR, errno, SP, x18, x19–x29 and all SIMD registers. Caller-saved integer registers and condition flags may change. Source-unwritten fields, complete unrelated configuration bytes and input-plan bytes remain unchanged.

The original operation is `arpifs/module/gfl_subs_mod.F90:431–632`, and its selected optional-argument presence comes from `arpifs/setup/sugfl3.F90`. Typed component and counter offsets are retained in `field_component_reset_reference/typed_registration_layout.json`. The complete source/direct comparison uses the same configuration address, so every raw pointer byte is retained. This child does not claim the complete SUGFL caller or an autonomous forecast.
