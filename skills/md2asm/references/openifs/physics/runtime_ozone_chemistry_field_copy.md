# Runtime Ozone Chemistry Field Copy

This entry implements the original GPINO3CH memory transfer. It copies monthly chemistry coefficients for each active column from that column's latitude row. It does not change the coefficients or calculate a chemical reaction. The original fixed-grid entry and its accepted banks remain unchanged.

The application binary interface is `md2asm_copy_runtime_ozone_chemistry_fields(G, MODEL, controls, latitudes, output, capacity)` in x0 through x5. G is the complete 20,400-byte Geometry record and MODEL is the complete 4,275,088-byte model record. Controls has four int32 words for the first active column, last active column, column count P and reserved zero. Latitudes contains P int32 global row numbers. Output is an FP64 array with column, layer and coefficient order, and capacity is its available byte count. Records, output and coefficient storage require eight-byte alignment. Latitudes requires four-byte alignment. Every borrowed owner must be completely mapped and live through the call. Output must be disjoint from each complete borrowed owner.

P is read from live Geometry metadata and ranges from 1 through 1024. The layer count L ranges from 1 through 512. The retained physical option has seven coefficients, one two-dimensional monthly chemistry group and no three-dimensional group. These physical choices are separate from the grid dimensions. The complete monthly-table descriptor gives N latitude rows, with N from 1 through 65536. Its first bounds are 1 through 7L and its second bounds are -1 through N+2. Its strides are 1 and 7L. Active latitude indices are 1 through N. The first active column is from 1 through P+1, and the last is from one less than the first through P. An empty interval leaves output unchanged.

Output needs 8P(7L) bytes. The monthly owner needs 8(7L)(N+4) bytes. Their largest admitted sizes are 29,360,128 and 1,879,162,880 bytes. Address ends use checked 64-bit addition. The row-number vector needs 4P bytes. The monthly-table descriptor and column controls are checked before an output write. Return zero means success. Return two means an unsupported argument, with no public byte changed. The leaf uses caller-saved registers only, preserves x18 and all required saved registers, and has no stack storage, external call, allocation or floating-point operation. Each copied word therefore retains all 64 input bits, including signed zero.

One object passes all four retained 17-column, 137-layer source banks and four new 8-column, 5-layer, 32-row cases. The same original GPINO3CH binary remains the reference. Only its small verification bridge is shape-aware. All 530,656 complete output bytes match, including untouched cells. Independent source-index and untouched-cell checks cover 66,332 words. All 24 new ABI and raw-state observations pass, including 12 atomic refusals. Borrowed bytes and 768 guard bytes remain unchanged. The four new source calls cover full, final-two, shifted and empty work. No earlier original bank is replayed. The complete ozone tendency, monthly-table producer, physics parent and forecast remain separate qualifications.
