It uses a 2048-byte stack frame. The selected child has the original 26-address CLDPP interface and a 768-byte frame. The decorrelation child retains its nine-address interface, a 128-byte frame and an aligned private row of eight bytes per column. These entries preserve `x19` through `x29`, `x18`, the lower 64 bits of `v8` through `v15`, 16-byte stack alignment and FPCR zero. The parent has no eighth ordinary argument. Its verifier supplies an unused zero `x7` slot only because the unchanged shared register probe requires eight slots.

Let $`P`$ be the live column count and $`L`$ the live full-level count. The supported bounds are $`1\le P\le2048`$ and $`3\le L\le512`$. The first column is in $`1..P`$ and the last is in $`0..P`$; a first column greater than the last defines an empty interval. These bounds belong to the numerical children.

## Ordered calculations and constants

When diagnostics are enabled, use the new radiation scheme, exponential-random overlap code one and three nonempty high, middle and low cloud classes. Pressures are finite, positive at full levels and increase downward; temperature and surface pressure are positive. Class thresholds are ordered between zero and one, the cloud cutoff is finite between zero and one half, and the overlap length is positive. Finite cloud fractions may extend slightly outside zero to one because the original clips them. Copied water is finite; its sign and bits are retained. The caller remains responsible for physical condensate admissibility.

The runtime diagnostic child first admits each active latitude with $`\lvert\phi\rvert\le\pi/2`$, using the rounded FP64 endpoint `0x3ff921fb54442d18`. It calls the accepted original-compatible SIN body. The runtime decorrelation child admits active sine words in $`[-1,1]`$, then calls the accepted original-compatible ASIN body. Mode one uses the rounded angle. Every other nonzero mode evaluates COS of that rounded ASIN result before the unchanged length equation. This rounded composition is retained explicitly. Constant mode zero retains the original route and does not consume unused latitude-dependent inputs.

The remaining calculation retains `(RD/RG)*0.5*(T_j+T_next)*log(p_next/p_j)*0.001` in its original separately rounded order, followed by the original exponential overlap weight. The unchanged cumulative exponential-random child supplies total and three class covers. The diagnostic child clips each radiation cloud fraction and either copies both water words or stores original positive zero, according to the original strict cutoff. It leaves source-unused `PCC` unchanged. Diagnostics-off calls preserve all five diagnostic owners while applying the final filter. Removed radiation condensate is not claimed to be conserved.

The production closure binds `RPI`, `RG` and `RD` to offsets 0, 112 and 184 in the actual 520-byte assembly-owned physical record after `md2asm_initialize_physical_constants`. A separate four-byte read-only owner supplies the false profiling policy. The selected mathematical bodies and public FIAT profiling interface are explicit dependencies. Actual loaded symbols, data addresses, constant bits, direct child calls and resolved mathematical call targets were checked. The caller must produce all live model settings and field owners before this consumer runs.
