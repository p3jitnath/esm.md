# Runtime Physics Work Reset

PHYS_ARRAYS_INI sets the original physical work arrays to positive zero before a block is calculated. The same object reads the column count KLON at dimensions byte 12 and the layer count KLEV at byte 48. It admits one to 1,024 columns and one to 512 layers. Whole-array writes follow complete descriptor bounds, including inactive columns. Surface-vector writes use the live column count. The source LECURR flag controls the two current fields. PHYS_ARRAYS_FIN preserves all state under the selected false profiling flag.

`md2asm_initialize_runtime_physics_work` receives the original ten addresses for surface metadata, physical controls, tracer controls, dimensions, auxiliary fields, surface diagnostics, atmospheric diagnostics, surface work, radiation work and flux work. Its added borrowed 16-byte policy is argument eleven at incoming stack byte 16. `md2asm_finish_runtime_physics_work` receives dimensions and the six work records, followed by the policy in x7. The policy holds the address of the caller-owned four-byte LHOOK flag, which must be false, and a zero reserved word. Return zero means success and two means unsupported input rejected before mutation.

The caller supplies eight-byte-aligned complete valid source records and fully mapped, contiguous descriptors with correct sizes, ranks, offsets, strides and bounds. It retains the original dimensions record of 192 bytes, whose first 128 bytes hold the consumed scalar values. Work-record extents are 1,992 bytes for auxiliary fields, 912 for surface diagnostics, 4,104 for atmospheric diagnostics, 13,680 for surface work, 2,664 for radiation work and 5,064 for flux work. The caller supplies live surface handles with valid column indices and disjoint payload owners that remain live for the call. The 8,192-byte frame is aligned to 16 bytes and preserves x18 and all required Arm saved registers. FPCR must be zero. Integer stores create the exact source positive-zero bytes. The [assembly](https://github.com/p3jitnath/esm.md/blob/28940eb213fb69ab2b64cc0bf154ca733f7c1c21/src/openifs/physics/runtime_physics_work_reset.S) has no external import and supplies no additional physical calculation.

The same object and unchanged original binary cover 17-column, 137-layer inputs and an eight-column, five-layer input. All 2,097,696 compared payload bytes agree exactly, including the two original current-field branches. Independent positive-zero and preservation checks, complete input records, ABI and raw status, guards and atomic refusals pass. Earlier original banks are reused. Surface-handle indices and the remaining local descriptor extents are explicit verification inputs. Live FIELD_VARIABLES association, the complete physics parents and an autonomous forecast remain separate requirements.
