# Upper-Air Metadata Reader

The direct reader replaces the temporary typed metadata getter for the selected T21 upper-air input route. Its five pointer arguments are geometry, GFL storage, linear-physics controls, field descriptions and a writable 512-byte result. GFL is the original grid-point field buffer. Each pointer must address its complete original GNU 12 object. The result must be disjoint from those objects and aligned for 64-bit words.

The reader uses a 128-byte stack frame aligned to 16 bytes. It calls no procedure, uses no floating-point instruction and preserves the platform register `x18`, saved registers, FPCR, FPSR and the library error value. FPCR controls floating-point rounding, while FPSR records numerical flags. A zero first result word means success. A nonzero word rejects the selected route, and the caller consumes no remaining result after rejection.

The checked geometry is 24 rows per block, 19 model levels and 2,048 physical points. The true original allocatable descriptor must describe a contiguous one-based `(24, 19, 8, 86)` FP64 buffer with a 2,509,824-byte owner. This interface accepts only a true original allocatable descriptor, with its original GNU dtype, version and element-span fields. Its canonical origin requires `offset + sum(lower_bound * stride) = 0`. The selected one-based bounds give a stride sum of 4,129 and an offset of −4,129, so the stored base is the first allocated element. The reader checks the consumed rank, element length, bounds and strides, while this original-descriptor precondition supplies the untested origin, version, type and span invariants. The field-description array has its original fixed capacity 2,163. The reader scans its declared active prefix in source order. It requires distinct destination slots, four input codes 133, 246, 247 and 248 in slots 1, 2, 3 and 6, and the original final copy-or-clear action vector. The metadata outputs retain each scalar, complete owner address, byte extent and input code.

The linear-physics and low-resolution-constructor branches must both be inactive. The original private low-resolution flag is a compatibility input. In this frozen `libifsaux.DP.so` image, its 32-bit word is 44 bytes before the exported algorithm-state type vtable. The local provider-binding record retains the linked-image identity, original symbol positions and typed query proof for both logical values. This direct read preserves the live original word and has no procedure fallback. It does not construct autonomous algorithm metadata.

The surrounding original-interface bridge differs from the admitted bridge only in its metadata target and explanatory comment. The accepted assembly file reader and field placement remain unchanged. The original closing console statistics remain omitted under the admitted diagnostic boundary. The report environment and ten-word counters are unchanged. Twelve typed cases match all 512 metadata bytes. Three actual full-packet ABI cases preserve all 2,509,824 owner bytes, incoming numerical flags, the error value and `x18`, with zero original numerical calls or metadata-query calls.
