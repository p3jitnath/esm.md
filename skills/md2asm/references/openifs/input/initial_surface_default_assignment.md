# Initial Surface Default Assignment

Before SUGRIDG reads the input file, SUGRIDF calls GPOPER with SETDEFAULT for every block. A field whose NREQIN flag equals minus one receives its raw REFVALI value in the plane named by MP. A three-dimensional field performs this rule separately for each level. Other fields retain their incoming bytes. These assignments perform no floating-point arithmetic.

The selected grid stores 86 blocks with 24 rows each. The source default assignment covers every allocated row, including the final 16 padding rows. This differs from input placement, which writes only 2048 active points. Preserve the source rule separately for both stages.

The direct entry is `int md2asm_set_initial_surface_defaults(owners, owner_table_bytes, assignments, assignment_bytes, assignment_count, owner_count)`. The first six Arm machine registers carry the arguments. Owners contain three unsigned 64-bit words per row, giving a base pointer, capacity in bytes and number of consecutive planes. Assignments contain an owner index, plane index and raw 64-bit value. Indices start at zero. Each assignment has already been selected from a source NREQIN equal to minus one. The metadata collector must retain source field and level order. Repeated assignments to the same plane retain the final source value.

Each complete owner requires planes times 16512 bytes, since each plane contains 24 rows in 86 blocks with eight bytes per value. Support one through 64 owners, one through 4096 planes each, and up to 4096 assignments. Tables and owners require eight-byte alignment and mapped, non-wrapping storage. Read-only tables may overlap each other. Complete output owners must be disjoint from both tables and each other. An empty assignment list returns success without reading any pointer.

Check all table spans, owner bounds, overlaps and assignment indices before the first output store. Return 0 after successful assignments or an empty list, and 1 for an invalid supported buffer or index. Rejection changes no byte. The leaf uses an 80-byte stack frame aligned to 16 bytes, preserves all saved integer and vector registers and x18, and makes no external call. All FPCR, FPSR and errno values remain unchanged. Integer flags and caller-saved integer registers are scratch.

Nine focused buffer and value cases and two seeded ABI cases pass against an independent whole-slice source control, with every one of 2146560 owner bytes exact. These include raw signed-zero and NaN bits, repeated assignments, final padding and rejection before writes. The [complete startup route](initial_surface_state_startup.md) also passes the actual ten-owner packet and the joint native forecast. The primitive has no separate original-body or full-autonomy credit.
