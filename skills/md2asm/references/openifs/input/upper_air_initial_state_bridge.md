# Upper-Air Initial-State Bridge

This direct assembly bridge replaces the selected six-argument SUGRIDUG entry. The arguments are original geometry, model configuration, GFL storage, linear-physics controls, field descriptions and KFILE, passed in registers x0 through x5. Support requires KFILE zero and the frozen complete GFL shape `(24,19,8,86)`, with 2509824 bytes. The caller supplies mapped original typed objects. The bridge does not change their descriptors or field metadata.

The temporary Fortran getter reads live geometry and field descriptions. It checks that humidity, liquid, ice and cloud fraction are requested in original order with parameters 133, 246, 247 and 248, placed in slots 1, 2, 3 and 6. The other four slots must have the original complete-zero action. Each slot appears once. It rejects the branch that would change the first field description for linear physics. The getter also queries the original read-only low-resolution-constructor flag and requires false. This flag query is an explicit metadata boundary and performs no forecast arithmetic.

Assembly copies the first twelve characters of the live CFNIGG filename, appends UA and a zero byte, exactly reproducing the selected original file rule. It restores incoming FPCR, FPSR, errno and x18 after the metadata read, then calls only the accepted direct [`md2asm_load_initial_upper_air_state`](upper_air_initial_state_loading.md). That loader owns all input processing and state placement. Original SUGRIDUG and its numerical children are never called. The bridge has an 800-byte frame with sixteen-byte alignment and preserves all saved registers and the required vector-register halves.

Original closing GPNORM3 calls print startup statistics and do not update any forecast field. They are omitted from this bridge. The captured actual original call has FPCR zero, FPSR sixteen and errno two both before and after. The bridge reproduces that exact immediate status and all 2509824 returned state bytes from the complete original preimage. Three seeded native ABI cases pass with no original numerical call. Other incoming-status cases establish only the declared input-loading preservation rule and do not claim general equivalence to omitted diagnostic arithmetic. The separate original forecast keeps its statistics for reference.

Verification-only C code writes ten little-endian 64-bit counter words to native-upper-air-counters.bin in MD2ASM_NATIVE_UPPER_AIR_REPORT_DIR. They contain revision, entries, completions, failures, rejection code, entry FPCR, entry FPSR, returned FPSR, entry errno and returned errno. A successful forecast requires positive entries, equal completions, zero failures and zero rejection. Unsupported metadata or a loading error stops with exit 116 before any original fallback. Independent source and interface peer review passes. The joint native forecast also passes all 27486113 bytes in 685 complete final owners and all 618140 bytes in ten saved files, with matching immediate status and a positive direct upper-air input counter. This bridge retains original typed metadata and does not establish full autonomy.
