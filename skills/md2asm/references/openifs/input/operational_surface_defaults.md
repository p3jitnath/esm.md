# Operational surface defaults

Before surface input is read, the original `SUGRIDF` calls `GPOPER` with the action `SETDEFAULT` for every block. A field whose request flag `NREQIN` is −1 receives its raw `REFVALI` value in the plane selected by `MP`. A plane is one field and level across all rows and blocks. Other planes retain their complete input bytes. This component supplies the metadata collector and complete assignment stage for 17 rows in each of 388,217 blocks. It does not read a file, place input fields, convert physical values or complete `SUGRIDF`.

The caller supplies the qualified [surface field owners](../setup/surface_field_storage.md), complete Geometry and surface records, and the 70 metadata owners from operational surface configuration. A descriptor stores an array's address, element type, dimensions, bounds and strides. All descriptors and pointed buffers must have their true complete bounds. The actual configuration has 34 numerical owners, of which 10 are nonempty, with 553 planes and 29,197,024,136 bytes. The collector visits the original 33 `GPOPER` groups in order. It reads each field and level's request flag and default bits; the observed 423 selected planes and their values are acceptance facts, not a production lookup table.

The collector application binary interface (ABI) is `void md2asm_operational_surface_default_metadata(geometry, surface, owners, assignments, info)`, with arguments in x0 through x4. Geometry contains 17,096 mapped bytes and the surface record contains 18,224 mapped bytes. The collector reads only Geometry's `NPROMA` and `NGPBLKS` words, at byte offsets 5,144 and 5,160, and requires 17 and 388,217. All five records are aligned to eight bytes, mapped and disjoint from one another and from the pointed metadata and numerical owners. The caller supplies 1,536 writable owner-table bytes, 98,304 writable assignment-table bytes and 64 writable information bytes. The Geometry, surface record, metadata owners and numerical fields remain unchanged.

Each table row contains three unsigned 64-bit words in native little-endian order. An owner row gives its base address, complete byte capacity and plane count. An assignment row gives a zero-based owner index, zero-based plane index and the raw 64-bit default value. Layered fields use plane index `(MP-1)*levels+(level-1)`, with source `MP` and level indices starting at one. The collector clears both complete tables and the information record first. Information words give status, owner count, assignment count, rows, blocks, total owner bytes and two zeros. Status one remains on a checked shape or metadata refusal; a late refusal can leave partial table rows. Status zero is published only after every group passes. The caller must check this status before applying defaults.

The assignment ABI is `int md2asm_set_operational_initial_surface_defaults(owners, owner_table_bytes, assignments, assignment_bytes, assignment_count, owner_count, effect)`, with arguments in x0 through x6 and status in w0. Tables require eight-byte alignment. For a nonempty list, support one through 64 owners, one through 4,096 planes per owner and at most 4,096 assignments. Only the rows selected by these counts are input table storage. Each complete owner requires `planes*52797512` bytes, since one plane contains `17*388217*8` bytes. Output owners must be mapped, aligned to eight bytes, free from address wrap, and disjoint from each other and both used table spans. Read-only table spans may overlap each other. All byte capacities and addresses use 64-bit arithmetic.

The four-byte signed integer at `effect` is caller-owned storage for the original `GPOPER` counter reset, `NPTRSURF=0`. It requires four-byte alignment, mapped non-wrapping storage, and disjointness from the used tables and every complete numerical owner. In the complete stage it is also separate from the read-only Geometry, surface and metadata records. Check every owner range, overlap and assignment index before changing this word or any field. On success, reset the word to zero before the first field store, then retain source field and level order so a repeated assignment keeps the final source value. Return zero on success and one on an invalid checked argument. Refusal changes no owner or effect byte. With zero assignments, require only a valid effect word, reset it and return success without reading any table pointer or other count.

All 17 rows of every block participate in an assignment. The 6,599,689 allocated rows therefore include the final nine padding rows as well as 6,599,680 active points. Selected padding receives the same default as the rest of its plane; unselected planes and padding retain their input values. Both entries use integer loads and stores, with no floating-point arithmetic, library call or allocation. The collector and assignment frames contain 192 and 96 bytes and are aligned to 16 bytes. Preserve x18, every ABI saved register, vector registers, the floating-point control and status registers FPCR and FPSR, and the C library error word `errno`. The existing 24-by-86 collector, [assignment entry](initial_surface_default_assignment.md), shared group table and their accepted evidence remain unchanged.

Two genuine original `GPOPER` profiles and the independent typed Fortran collector pass all 58,394,048,272 numerical owner bytes with zero differences. Complete tables, records, read-only metadata and refusal observations bring the raw comparison to 58,399,093,704 bytes. The profiles retain the allocator's four source-defined zero owners and use two declared allocation preimages only for source-unwritten storage. All eight native ABI calls preserve the required registers and natural status; three protected no-write refusals, the empty-list effect rule and 13,888 guard bytes pass. The genuine source's x18 change is recorded separately as reference ABI mask 2. Pointer correspondence uses declared owner slots and data-word offsets; native runtime payload addresses were not archived. The original private counter is observed only in the verification process, while production uses the explicit effect word. This acceptance covers the complete raw default stage and does not admit enclosing startup or forecast execution.
