# Markdown To Machine Code

Choose the generation route from the project size and its integration needs. For large projects, turn the physics formulation into portable structured Fortran, then use an optimising compiler to produce machine code. Fortran is the intermediate source and the primary generated artifact for that route; identify assembly listings and machine code as compiler output. Direct assembly is also suitable for small projects with a compact calculation and interface. Record the selected route and apply the same numerical contract, independent physical checks and exact output requirements to both. Write for a first-year undergraduate. Define unfamiliar terms, explain choices, and follow the project [instructions](../../AGENTS.md), [formulation template](../../formulations/TEMPLATE.md) and [writing convention](../../standards/ASD-STE100-CONV.md).

For a conservative exchange between adjacent cells, define one physical face contract for both directions, including the precision of threshold constants and the branch taken at equality. Preserve the nonnegative solved amounts for outgoing fluxes, and keep later cleanup or history values separately when they differ. ## Find The Performance Bound

Profile complete time steps and their external-service waits before changing code. Count executed calls by child and caller, inspect the linked instructions, and identify repeated work. A profiling-only return-address tag can identify callers when its saved register remains unchanged throughout the observed child. Keep the profiling route separate and preserve the public ABI.

Build a [roofline model](https://www2.eecs.berkeley.edu/Pubs/TechRpts/2008/EECS-2008-134.pdf), which compares arithmetic throughput with memory bandwidth. Count useful operations, live working data and traffic at each relevant memory level. Distinguish logical bytes from measured cache refills and main-memory traffic. Measure bandwidth at the workload's read/write ratio, size and alignment, and calibrate the actual instruction mix, including division and square root.
